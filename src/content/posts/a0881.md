ailx10说：这篇是在2018年12月之前写的，后来又改过。研究 WAF 语义分析时，我先回到 flex 这个基本工具，想弄清规则究竟怎样把字符流切开。文件头放什么、规则写哪儿、yytext 和 yyleng 怎么用，再写个统计行数、词数的小例子，用 Makefile 编起来看结果。事情看着和检测攻击还隔着一段，却像先练一把最基础的刀。文章保留这轮准备工作，因为后面想讨论词法和语法，不能只拿名词说事，得先知道一条匹配规则怎样真的变成可运行的扫描器。

本文介绍 flex 词法分析和行、字符、单词统计的历史示例；提取的代码与 Makefile 转录可能损坏，未经编译。

提取源码中的换行、转义和构建脚本可能受损，需与原文件核对并编译后再使用。

flex文件格式：

```
%{
C语言声明，一般声明全局变量和函数，会复制进lex.yy.c中
%}
定义正则表达式的名字，可以在规则段中使用
%%
规则段，每一行都是一条规则，每一条规则由匹配模式和事件组成。每当一个模式被匹配到，后面的事件被执行！
%%
用户自定义过程，直接复制到lex.yy.c末尾
```

简单的文本分词器flex文件，目标是对一个文本分析行数，字符数，单词数！

规则解析：

- 遇到符合正则表达式

  ```
  
  ```
- 遇到符合正则表达式`WORD`，单词数加1，字符数加单词长度
- 遇到符合正则表达式`.`，字符数加1

flex提供的2个全局变量：

- `yytext`：刚刚匹配到的字符串
- `yyleng`：刚刚匹配到的字符串的长度

```
%{
#define T_WORD 1
int numChars = 0, numWords = 0, numLines = 0;
%}

WORD		([^ 	
\r\a]+)

%%

		{ numLines++; numChars++; }
{WORD}		{ numWords++; numChars += yyleng; return T_WORD; }
<<EOF>>		{ return 0; }
.		{ numChars++; }
%%

int main() {
	int token_type;
	while (token_type = yylex()) {
		printf("WORD:	%s
", yytext);
	}
	printf("
Chars	Words	Lines
");
	printf("%d	%d	%d
", numChars, numWords, numLines);
	return 0;
}

int yywrap() {
	return 1;
}
```

编写makefile文件：

Makefile 中 $@ 表示目标，$\< 表示第一个前置条件，$? 表示比目标更新的前置条件，$^ 表示全部前置条件。

```
run: w-s
	./w-s < w-s.l

w-s: lex.yy.c
	gcc -o $@ %JSON%lt;

lex.yy.c: w-s.l
	flex %JSON%lt;
```
