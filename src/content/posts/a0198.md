ailx10说：这篇是我2025年3月写的。这道题先给我的不是猪圈图，而是一份像 Base64 的文本。我从 /9j/ 这个开头猜它可能是 JPEG，先把数据还原成图，再对照猪圈符号读出字母，最后按题目要求整理成 flag。它有两次很明确的转身：先从字符回到图片，再从图形回到文字。这篇把这两层都留住了，不想只放最后一句答案。从一段文本里还原出图片，再从图里认出字母，这次的小练习像是在连续拆两层包装，题名里的“猪圈”直到后半程才真正派上用场。

---

编辑核查提示：JPEG 的 Base64 常见前缀仅是线索；补充 padding 不能修复任意缺失或损坏的数据。图形密码依赖对应映射表和原题图片，需逐图核对。

猪圈密码是一种古典加密方法，使用图形符号替换字母。难度系数：1

观察下载的文件，文件内容看起来像是base64编码的数据，可能是一个图片的base64表示，因为开头有`/9j/`，这通常是JPEG图片的base64头

![](/notes-assets/e50e2ef8d01915dfa295.webp)

先将Base64转换成图片

```
import base64
from io import BytesIO
from PIL import Image

def decode_base64_from_file(input_file, output_file):
    try:
        # 从文件读取Base64数据
        with open(input_file, "r") as f:
            base64_data = f.read().strip()  # 去除可能的空白字符

        # 补足可能缺失的 padding
        missing_padding = len(base64_data) % 4
        if missing_padding:
            base64_data += "=" * (4 - missing_padding)

        # 解码并保存图片
        image_data = base64.b64decode(base64_data)
        img = Image.open(BytesIO(image_data))
        img.save(output_file)
        print(f" 图片已保存为 {output_file}")
        return True

    except FileNotFoundError:
        print(f" 错误：文件 {input_file} 不存在")
    except Exception as e:
        print(f" 解码失败: {str(e)}")
        print("可能原因：1. 文件数据不完整 2. 非图片数据 3. 编码格式错误")
    return False

if __name__ == "__main__":
    input_filename = "base64_data.txt"  # 存放Base64数据的文件
    output_filename = "decoded_image.jpg"  # 输出图片
    decode_base64_from_file(input_filename,output_filename)
```
