## Libsvm 初探：训练与预测

下载：`git clone https://github.com/cjlin1/libsvm.git`

```
root@ubuntu:/home/csvm/libsvm# ls
COPYRIGHT  heart_scale  Makefile      matlab  README   svm.def  svm-predict.c  svm-toy      tools
FAQ.html   java         Makefile.win  python  svm.cpp  svm.h    svm-scale.c    svm-train.c  windows
```

编译：`make`

多出了4个文件，分别是**svm.o**  **svm-train** **svm-predict** **svm-scale**

```
root@ubuntu:/home/csvm/libsvm# ls
COPYRIGHT  heart_scale  Makefile      matlab  README   svm.def  svm.o        svm-predict.c  svm-scale.c  svm-train    tools
FAQ.html   java         Makefile.win  python  svm.cpp  svm.h    svm-predict  svm-scale      svm-toy      svm-train.c  windows
```

训练：`./svm-train heart_scale`

生成一个模型文件：`heart_scale.model`

```
root@ubuntu:/home/csvm/libsvm# ./svm-train heart_scale 
*
optimization finished, #iter = 162
nu = 0.431029
obj = -100.877288, rho = 0.424462
nSV = 132, nBSV = 107
Total nSV = 132
```

历史示例使用同一数据文件进行训练后预测，结果只反映该数据上的表现。

原文记录约 86%；这不是独立测试集上的泛化指标。

```
root@ubuntu:/home/csvm/libsvm# ./svm-predict heart_scale heart_scale.model out
Accuracy = 86.6667% (234/270) (classification)
```

以下为历史 Python 2 特征提取代码；运行前需迁移并检查数据泄漏。

```
# xss.py by ailx10
import logging
import urllib
import urlparse
import re

LOG_FORMAT = "%(message)s"
logging.basicConfig(filename='xss', level=logging.INFO, format=LOG_FORMAT)

def get_len(url):
    return len(url)

def get_url_count(url):
    if re.search('(http://)|(https://)', url, re.IGNORECASE) :
        return 1
    else:
        return 0

def get_evil_char(url):
    return len(re.findall("[<>,\'\"/]", url, re.IGNORECASE))

def get_evil_word(url):
    return len(re.findall("(alert)|(script=)(<)|(>)|( )|(onerror)|(onload)|(eval)|(src=)|(prompt)",url,re.IGNORECASE))


def etl(filename,isxss):
        with open(filename) as f:
            for line in f:
                line=line.strip('
')
                line=urllib.unquote(line)
                
                f1=get_len(line)
                f2=get_url_count(line)
                f3=get_evil_char(line)
                f4=get_evil_word(line)
                ff = "%d 1:%d 2:%d 3:%d 4:%d"%(isxss,f1,f2,f3,f4)
                logging.info(ff)


if __name__ == "__main__":
    etl("./xss.txt",1)
    etl("./good.txt",0)
```

这次练习帮助走通编译与调用，不足以证明面对新请求也有同样表现。分开数据、查看各类错误，再回看特征是否真的抓住问题，模型才有继续改进的方向。
