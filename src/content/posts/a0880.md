ailx10说：这篇是在2018年12月之前写的，后来又改过。做特征提取时，每份报文都走正则，我就想找个可能快一点的替代。于是试 pyahocorasick，用 AC 多模式匹配去找 XSS、SQL 那些特征，再把模型加载、预测和计时整个流程接起来。原本以为算法换了，速度也该明显不同，真正测下来却没占到预期便宜。这个落差我也留着，正好说明小实验不只负责证明想法，有时还得把过于顺手的猜测拉回来。文章记录的是这次替换尝试，以及我怎样把“应该更快”拿去和实际耗时碰一碰。

---

## 解决的问题：

本文比较正则与 AC 多模式匹配用于特征提取的历史尝试。字面多模式匹配并不等价于正则，大小写和边界规则也会影响结果。

> pip install pyahocorasick

## 性能分析：

仅凭耗时占比无法推算绝对加速倍数；需要相同负载下的总时间与资源数据。

在Nginx下测试，跑一个页面的消耗时间，提特征约4毫秒，预测约6毫秒，数据也不好看。

```
(0.0038950000000000005, 0.005604, 4.700000000000017e-05)
0 -请求正常页面
(0.004244000000000001, 0.006077999999999998, 2.000000000000092e-05)
1 -请求攻击页面
```

原测试仪结果没有比原正则快；原因仅为作者推测，需用可复现的基准验证。

# waf.py by ailx10
import re
import urllib
from sklearn import svm
from sklearn.externals import  joblib

import ahocorasick
import time

class PKT:
    def init(self,pkt_feature):
        XSS_CHAR = ahocorasick.Automaton()
        for index,word in enumerate("< >, \' \" / ] [".split()):
            XSS_CHAR.add_word(word, (index, word))
        XSS_CHAR.make_automaton()
        XSS_WORD = ahocorasick.Automaton()
        for index,word in enumerate("alert script= < > onerror onload eval src= prompt".split()):
            XSS_WORD.add_word(word, (index, word))
        XSS_WORD.make_automaton()
        SQL_CHAR = ahocorasick.Automaton()
        for index,word in enumerate("[ ] - , \' \" * /".split()):
            SQL_CHAR.add_word(word, (index, word))
        SQL_CHAR.make_automaton()
        SQL_WORD = ahocorasick.Automaton()
        for index,word in enumerate("select case when order group count char null and or".split()):
            SQL_WORD.add_word(word, (index, word))
        SQL_WORD.make_automaton()
        return (pkt_feature,XSS_CHAR,XSS_WORD,SQL_CHAR,SQL_WORD)


    def get_len(self,url):
        return len(url)
    def get_url_count(self,url):
        if re.search('(http://)|(https://)', url, re.IGNORECASE) :
            return 1
        else:
            return 0
    def get_xss_evil_char(self,A,url):
        num  = 0
        for item in A.iter(url):
            num += 1
        return num

    def get_xss_evil_word(self,A,url):
        num  = 0
        for item in A.iter(url):
            num += 1
        return num

    def get_sql_evil_char(self,A,url):
        num  = 0
        for item in A.iter(url):
            num += 1
        return num

    def get_sql_evil_word(self,A,url):
        num  = 0
        for item in A.iter(url):
            num += 1
        return num

def get_pkt_feature(A,pkts):
    x = []
    pkt_feature = A[0]
    for pkt in pkts:
        pkt = urllib.unquote(pkt)
        f1=pkt_feature.get_len(pkt)
        f2=pkt_feature.get_url_count(pkt)
        f3=pkt_feature.get_xss_evil_char(A[1],pkt)
        f4=pkt_feature.get_xss_evil_word(A[2],pkt)
        f5=pkt_feature.get_sql_evil_char(A[3],pkt)
        f6=pkt_feature.get_sql_evil_word(A[4],pkt)
        x.append([f1,f2,f3,f4,f5,f6])
    return x


def waf_load():
    clf=joblib.load("/home/nginx/aisecurity-0.2/model/waf.pkl")
    return clf

def waf_predict(clf,A,pkts):
    atk_flag = 0
    #o1 = time.clock()
    pkts = get_pkt_feature(A,pkts)
    #o2 = time.clock()
    atk_predicts = clf.predict(pkts)
    #o3 = time.clock()
    for atk_predict in atk_predicts:
        if atk_predict > 0:
            atk_flag = 1
            break
    #o4 = time.clock()
    #print(o2-o1,o3-o2,o4-o3)
    return (atk_flag,)

def test(clf,A):
    x1 = "i love web security!"
    x2 = "<script>alert(1)</script>"
    x3 = "-2' union select group_concat(Username),2,3 from Person"
    x = [x1,x2,x3]
    pkts = get_pkt_feature(A,x)
    print(clf.predict(pkts))

def waf_ac():
    pkt_feature = PKT()
    A = pkt_feature.init(pkt_feature)
    return A

if __name__ == "__main__":
