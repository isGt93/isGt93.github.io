本文用 Apriori 对 XSS 样本中的 URL 参数挖掘关联规则。

> Apriori算法是著名的关联算法，是一种无监督学习，通过分析数据集，挖掘出潜在的关联规则，比如尿布和啤酒。  
> **支持度**： `p(A \cap B)` 既有A也有B的概率，  
> **置信度**： `p(B|A)` 在A发生的前提下，B发生的概率，  
> **频繁k项集**：事件A包含k个元素，称A为k项事件集A，满足最小支持阈值的事件称为频繁k项集。

## 5.完整代码

```
from apriori import apriori
from apriori import generateRules
import re

if __name__ == '__main__':
    myDat=[]
    with open("../data/xss-2000.txt") as f:
        for line in f:
            #/discuz?q1=0&q3=0&q2=0%3Ciframe%20src=http://xxooxxoo.js%3E
            index=line.find("?")
            if index>0:
                line=line[index+1:len(line)]
                tokens=re.split('\=|&|\?|\%3e|\%3c|\%3E|\%3C|\%20|\%22|<|>|\n|\(|\)|\'|\"|;|:|,|\%28|\%29',line)
                myDat.append(tokens)
        f.close()


    L, suppData = apriori(myDat, 0.15)
    rules = generateRules(L, suppData, minConf=0.99)
```

只看攻击样本，容易挖出攻击样本共同的外观。把正常对照加进来以后，规则是否还有区分价值，才是这次实验接下来最值得问的问题。
