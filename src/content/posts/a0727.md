ailx10说：这篇是在2024年2月之前写的，后来又改过。巡检时，一段 data URI 里的编码勾起了我的兴趣，解完 Base64 却没迎来清爽的 PHP，反而又多了几层十六进制、异或、字符串拼接和 ROT13。我就顺着一点点剥，直到后面的动态执行链和大马界面逐渐露出来，才认出 OteTeam 的字样。文章把恶意代码做了省略，重点留下还原时怎么从一层走到下一层。那种感觉很像拆包装，只不过每拆开一次，还得判断新看到的到底是内容，还是为了挡住内容又套的一层。

---

从data URI解码PHP，再静态还原十六进制、异或、拼接ROT13/Base64与动态eval链，识别OteTeam大马。

## 结论与待核验条件

称加密实为多层混淆；代码省略不能完整复现，样本自署名不足归因神秘组织，保留证据等级。

def decrypt(encoded_string):

    # ROT13 解密

    decoded_string = encoded_string.translate(str.maketrans(

        "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz",

        "NOPQRSTUVWXYZABCDEFGHIJKLMnopqrstuvwxyzabcdefghijklm"

    # Base64 解码

    decoded_string = base64.b64decode(decoded_string)

    return decoded_string.decode('utf-8')
