ailx10说：这篇是我2023年10月写的。H2 给我的第一印象是开发和单元测试里会用的数据库，这次却从它的 Web 控制台一路看到了 JNDI。实验先做一个文件标记，确认目标真的执行了动作，再把命令换成连接，所以过程里有两个可以分别观察的结果。我把驱动类、远程地址和工具配合的步骤写下来，免得以后只记得点了几下就成功。这个结果依赖控制台暴露、认证和 Java 环境等条件，开发方便的配置一旦放到不该开放的地方，边界就容易跟着变。

---

以下为历史靶场记录，地址和命令仅作解释；实验未重新执行，测试应使用明确授权的隔离环境。

原实验在特定 H2 Web 控制台环境中观察 JNDI 调用。控制台暴露、认证状态和可执行效果需要分别验证；原文未提供完整 Spring 配置。

前提：准备好docker环境，下载好书籍配套实验环境，进入目录 ，开始复现漏洞

- `docker-compose build //可选`
- `docker-compose up -d`

完成试验后，记得删除漏洞环境哦～～

实验结束后可在确认项目目录和 Compose 配置后关闭该项目的服务；原文的全局 Docker 清理命令已移除。

控制台页面可访问不代表连接无需认证或 JNDI 一定能执行。
