原文尚未确认 oinasf 的内容和作用。

/proc/self/exe 指向访问它的进程的可执行文件；由 dd、cat 或 shell 访问时，具体指向可能不同。

```
./oinasf; 
dd if=/proc/self/exe bs=22 count=1 | hexdump -C || 
while read i; do echo $i; done < /proc/self/exe | hexdump -C || 
cat /proc/self/exe | hexdump -C;
```

原命令包含多个分支，读取对象和管道退出状态要按实际进程及 shell 语义核查。

原文概括了 dd、循环与 cat 的三个分支；不能将其简单视为同一个进程的三次读取。

我尝试在Linux下模拟：使用 dd 命令读取当前进程的前 22 字节，显示是`ELF....`
