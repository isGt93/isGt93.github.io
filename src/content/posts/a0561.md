## 三、主函数

应用上下文应按请求或 with app.app\_context() 的生命周期管理，不能无限期 push。

```
app_default.app_context().push()
db.create_all()
```

![](/notes-assets/98a14df14da14ab0a9c2.jpg)

## 四、需求文件

原文使用环境依赖清单；freeze 可能包含无关包，项目依赖和版本仍需审查。

```
pip freeze >requirements.txt
```

![](/notes-assets/66e65e29450eae12fef9.jpg)

完了你想创建这个虚拟环境，只需要

```
pip install -r requirements.txt
```

然后业务就可以在其他环境中运行了～
