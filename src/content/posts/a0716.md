ailx10说：这篇是我2023年12月写的。前几年我更多盯着告警算法，做过概率、网段分布、图关联和权重游走，到了后来才越来越注意前面的数据和日志。一个平台的效果不只在最后那条告警，测试时能不能按需要投递合适的原始数据，也会影响整个过程。于是我把日志发送小工具又改了一轮，让时间字段能走自定义函数，再整理 UDP、TCP 和 Kafka 的发送方式。这篇像一次工作重心的小转弯：从追着结果看，慢慢回到结果之前的数据是怎样被组织和送进去的。

---

本文记录 SIEM 日志发送工具的自定义时间函数和多协议发送方式。动态代码需要可信输入；网络协议处理还需检查分帧、发送完整性及资源管理。

核查提示：importlib也能运行时导入，exec打包理由失真且formta笔误；TCP缺分帧/sendall，Kafka重复创建，任意代码需信任边界。 原实验及图片细节尚未逐项核实。

最近接了很多POC项目，难熬的经历告诉我，2022年底，我做的傻瓜式打日志工具有些缺陷，因为傻瓜，所以不灵活，于是我花了2天的时间，重新设计了一个打日志工具，这个新工具的特色是灵活。

其实不管是syslog发送日志，还是kafka发送日志，代码都很简单，难的是修改日志里面的时间为当前时间，传统的打日志工具都是内置好一批，比如Top20的数据源厂商的样例日志，只对它们进行时间修改。

但是对于未知的日志，工具不可能提前知道如何替换里面的时间，因此传统的打日志工具，只能做成尽可能多的去正则匹配时间样式，比如`2023-12-16 10:00:06`，`10:00:06 2023/12/16` ，也可能是秒时间戳 `1702692922`，也可能是毫秒时间戳 `1702692922007` ，将其捕获到，然后替换成当前时间。

总之，上面的做法，可能应付99%的场景，但是总会有预料不到的新日志，打日志工具要么就是无法修改日志时间，要么就是错误的修改日志时间，因此，我设计了一个一劳永逸的打日志工具，特色就是灵活。

我最先想到的是通过配置文件，来告诉工具去读哪个日志，然后去找哪个自定义函数去修改日志中的时间，其中这个自定义函数是开放给使用工具的人自己写的，我的打日志工具可以动态的加载这些自定义函数。

针对未知的日志，可以通过新建自定义修改日志时间的函数，来解决日志时间匹配和修改的问题。因此，内置好常见的数据源日志时间匹配函数，然后使用工具的人自定义未知日志的时间匹配函数。

这个工具的价值，是一劳永逸，打日志再也不用找我了，直接win了。真正的交付大神，通过编写复杂的`change_log_time`函数，做到了匹配多种数据源日志，因此所有的`logchange`配置项只需填写`@conf.default.change_log_time` ，这样使用工具的人也直接win了。

siem大数据平台syslog发送日志

```
import socket

def send_log_syslog_udp(log_content, ip, port):
    udp_socket = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    address = (ip, port)
    udp_socket.sendto(log_content.encode("utf-8"), address)
    udp_socket.close()


def send_log_syslog_tcp(log_content, ip, port):
    tcp_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    address = (ip, port)
    tcp_socket.connect(address)
    tcp_socket.send(log_content.encode("utf-8"))
    tcp_socket.close()
```

siem大数据平台kafka发送日志

```
from kafka import KafkaProducer
from kafka.errors import KafkaError

def send_log_kafka(b_log_content,ip,port,topic):
    producer = KafkaProducer(
        bootstrap_servers=[
            "{}:{}".format(ip,port),
        ],
    )
    res = producer.send(topic=topic, value=b_log_content, key=None)
    try:
        record_metadata = res.get(timeout=10)
        res_topic = record_metadata.topic
        res_partition = record_metadata.partition
        res_offset = record_metadata.offset
        # 获取成功返回响应的数据
        print("{},{},{}".format(res_topic,res_partition,res_offset))
    except KafkaError:
        # 处理异常
        pass
```

```
func_import = "from {} import {} ;res = {}({})".formta(custom_module_name, custom_func_name,custom_func_name, func_parameter_json_str)
```

如果输入是字符串，需要是`json` 字符串，如果是普通字符串，就要转义，如下：

```
escaped_not_json_str = repr(not_json_str)
```

importlib 也可在运行时动态导入模块；打包时需要考虑动态依赖。exec 执行字符串代码应限制到可信输入。

```
module = importlib.import_module(module_name)
function = getattr(module, function_name)
function()
```

```
df_json = df.to_json()
```
