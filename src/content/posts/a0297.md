ailx10说：这篇是2022年8月之前写的，后来又改过。HMS 一开始连入口都让我绕了一圈：初扫没注意到 7080，后来全端口看过，才找到诊所系统。SQLmap 读到了摘要，却没恢复出明文，于是继续看登录条件，换条路进后台上传文件。进系统后又沿可写定时脚本换身份，最后看 sudo tar 的能力。写这篇时我把漏扫、没破解和没走通的尝试也记下来，因为它们确实影响了后面的选择。把数据库内容拿出来，只代表又多了线索，不会自动把所有账号口令都变成已知。

---

HMS初扫漏7080后全端口找到诊所登录，SQLmap读摘要仍未恢复密码，改登录条件旁路进后台上传PHP；可写用户cron脚本换身份，再sudo tar checkpoint提权。

阅读说明：普通用户到eren的脚本运行身份和可写条件主要在图；at失败与未破解摘要保留，不能将密码dump当得到明文。 原实验环境和代码未重新运行，涉及截图的关键细节仍待核对。

### 20、tar 提权，获得root的flag

```
sudo -u root tar cf /dev/null exploit --checkpoint=1 --checkpoint-action=exec="/bin/bash"
```

![](/notes-assets/c1c65c4a919ceda2e728.jpg)

tar 提权

到此，实验完成～

可写定时脚本和sudo tar又各给了一段机会。把每次转向的理由写出来，整台机就不是一串工具输出，而是一组根据现有证据逐步作出的选择。
