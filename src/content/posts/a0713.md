ailx10说：这篇是我2023年7月写的。手里接到一个国外同类产品调研任务，文档一大堆，靠逐段复制翻译实在不太想干。我就先用 Python 把文档收下来，再接百度翻译 API，让英文和中文能按段对照。注册、额度、请求限制和签名这些看着不起眼的事，都在动手时逐项碰到了，于是一起写进笔记。它的起点其实很普通：不想把时间全耗在重复操作上。等这条小流水线接通，才更容易把精力留给产品到底做了什么，而不是一直卡在读懂每一段说明上。

本文记录调用翻译 API 处理英文文档的历史示例。接口额度、价格及限制会变化，发送文本前应检查隐私与授权。

核查提示：额度限流为历史；HTTP和params放查询有隐私考虑，无超时重试/error处理，67万字符效果未评估。 原实验及图片细节尚未逐项核实。

3、给的示例python代码极其简单，需要填写自己的 appid 和 appkey ，然后准备好要翻译的内容，就能运行得到翻译结果了。

```
# -*- coding: utf-8 -*-

# This code shows an example of text translation from English to Simplified-Chinese.
# This code runs on Python 2.7.x and Python 3.x.

import requests
import random
import json
from hashlib import md5

# Set your own appid/appkey.
appid = '填写你自己的appid '
appkey = '填写你自己的appkey '

# For list of language codes, please refer to `https://api.fanyi.baidu.com/doc/21`
from_lang = 'en'
to_lang =  'zh'

endpoint = 'http://api.fanyi.baidu.com'
path = '/api/trans/vip/translate'
url = endpoint + path

# Generate salt and sign
def make_md5(s, encoding='utf-8'):
    return md5(s.encode(encoding)).hexdigest()

salt = random.randint(32768, 65536)

def query_baidu(query):
    headers = {'Content-Type': 'application/x-www-form-urlencoded'}
    sign = make_md5(appid + query + str(salt) + appkey)
    payload = {'appid': appid, 'q': query, 'from': from_lang, 'to': to_lang, 'salt': salt, 'sign': sign}
    r = requests.post(url, params=payload, headers=headers)
    result = r.json()
    print(result)
    print(json.dumps(result, indent=4, ensure_ascii=False))
    return result

if __name__ == "__main__":

    query = 'Network security
Artificial intelligence
10 invention patents
CISSP Information Security Expert'
    query_baidu(query)
```
