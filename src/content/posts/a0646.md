ailx10说：这篇是我2021年6月写的。AIO 转过几轮，我终于在原文记下一个新日期：开始正式读 OSG。七百多页，原本想二十一天拿下，回头一算前面一千页读了四十天，就把速度调成更现实的一个月，每天二十多页。这篇把计划和八域的弱项对应起来，像重新排一次行程。它没有假装上一轮都学牢了，反而是带着错题换个组织方式再读；同样的知识放进新的章节里，看看能不能把之前松散的连接补得更结实。

---

2021 年备考时，我计划用约一个月阅读 710 页的 Official Study Guide（OSG），每天约 24 页。这个节奏来自个人经验，应根据时间与理解程度调整。

做过习题后，我发现答题正确率不能代替知识体系，因此计划把章节内容与安全领域建立联系，并定期复习错题。

下表保留了当时对 AIO 八个领域与 OSG 章节的个人对应，以及章节页数；数字是历史记录，不代表当前版本。

| AIO | OSG |
| --- | --- |
| 1、安全和风险管理（-34%） | 1、实现安全治理的原则和策略（34） 2、人员安全和风险管理的概念（33） 3、业务连续性计划（20） 4、法律、法规和合规（22） |
| 2、资产安全（-9%） | 5、资产安全（25） |
| 3、安全工程（-21%） | 6、密码学和对策密钥算法（31） 7、PKI和密码应用（29） 8、安全模型、设计和能力的原则（31） 9、安全漏洞、威胁和对策（56） 10、物理安全要求（28） |
| 4、通信与网络安全（-21%） | 11、安全网络架构和保护网络组件（59） 12、安全通信与网络攻击（41） |
| 5、身份与访问管理（-28%） | 13、管理身份和身份验证（31） 14、控制和监控访问（27） |
| 6、安全评估与测试（-18%） | 15、安全评估与测试（26） |
| 7、安全运营（-33%） | 16、安全运营管理（28） 17、事件的预防和响应（47） 18、灾难恢复计划（32） 19、调查和道德（18） |
| 8、软件开发安全（-31%） | 20、软件开发安全（31） 21、恶意代码和应用攻击（24） |

制定计划时可预留回顾与休息时间，按薄弱知识点调整进度。

计划写下来以后，还要留回看和调整的空间。把读书、做题和解释错误接在一起，才不至于又完成一本书，却仍被相似概念反复绊住。
