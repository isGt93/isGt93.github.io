ailx10说：这篇是我2024年1月写的。这一题里，我先从公钥里读出模数，再去找它能否被分解；拿到因子后，还不能直接宣布结束，要把私钥和 CRT 参数重新构造出来，再按题目的填充方式处理二进制密文。我把 yafu、FactorDB 和 cryptography 这些环节串在一篇里，记录从一份公钥走到可用私钥的过程。它更像对前面 RSA 练习的一次收尾：前面零散练过的参数、文件格式和填充，这回都得在同一条流程里接上。走完之后，再回看那份公钥文件，也多了几个能下手的位置。

---

RSA 加密和数字签名是不同操作：签名包含哈希与填充验证，不能简单描述为“私钥加密、公钥解密”。本题从弱模数开始分析。

（1）使用openssl 输出公钥文件中RSA模数（N）

```
openssl rsa -in public-key.pem -pubin -text -modulus
```

- `-in public.pem` 指定了输入文件为「public.pem」
- `-pubin` 表示输入文件是一个公钥文件
- `-text` 表示以文本形式显示密钥的信息
- `-modulus` 表示要显示RSA模数（N）

（3）生成私钥文件。下面原例将 e 写死为 65537，实际分析必须读取公钥的 e 并验证参数；仅凭 p、q 并不能假定 e 的取值。

使用p值q值，生成私钥文件 `private_key.pem`

```
# -*- coding: utf-8 -*-

from cryptography.hazmat.backends import default_backend

from cryptography.hazmat.primitives import serialization

from cryptography.hazmat.primitives.asymmetric import rsa



def generate_rsa_private_key(p, q):

    # 计算模数 n

    n = p * q



    # 计算欧拉函数 φ(n)

    phi_n = (p - 1) * (q - 1)



    # 选择公钥指数 e

    e = 65537  # 通常选择为65537



    # 计算私钥指数 d

    d = pow(e, -1, phi_n)



    # 生成私钥

    private_key = rsa.RSAPrivateNumbers(

        p=p,

        q=q,

        d=d,

        dmp1=rsa.rsa_crt_dmp1(d, p),

        dmq1=rsa.rsa_crt_dmq1(d, q),

        iqmp=rsa.rsa_crt_iqmp(p, q),

        public_numbers=rsa.RSAPublicNumbers(e, n),

    ).private_key(default_backend())



    # 将私钥保存到文件

    with open("private_key.pem", "wb") as private_key_file:

        private_key_file.write(private_key.private_bytes(

            encoding=serialization.Encoding.PEM,

            format=serialization.PrivateFormat.TraditionalOpenSSL,

            encryption_algorithm=serialization.NoEncryption()

        ))
```

（4）根据题目使用的填充方式解密；下面原例使用 PKCS#1 v1.5，不应与 OAEP 混用。

```
from cryptography.hazmat.backends import default_backend

from cryptography.hazmat.primitives import serialization, hashes

from cryptography.hazmat.primitives.asymmetric import padding



def decrypt_file(file_path, private_key_path):

    # 从私钥文件加载私钥

    with open(private_key_path, "rb") as key_file:

        private_key = serialization.load_pem_private_key(

            key_file.read(),

            password=None,

            backend=default_backend()

        )



    # 读取加密文件

    with open(file_path, "rb") as file:

        ciphertext = file.read()



    # 使用私钥解密，这里使用PKCS1v15填充

    plaintext = private_key.decrypt(

        ciphertext,

        padding.PKCS1v15()

    )



    # 解密flag，写入文件

    with open("decrypted_flag.txt", "wb") as decrypted_file:

        decrypted_file.write(plaintext)







private_key_path = "private_key.pem"  #  私钥文件

encrypted_file_path = "flag.txt"  #  加密文件

# 使用私钥解密文件

decrypt_file(encrypted_file_path, private_key_path)



# FLAG_IS_WeAK_rSA
```
