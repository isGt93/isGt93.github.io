ailx10说：这篇是2022年8月之前写的，后来又改过。ICA 这台机的入口从 qdPM 的配置开始。先用暴露的连接信息进数据库，调整管理账号，再到后台试附件上传，拿到执行以后继续看本地的 get\_access 程序。它调用 cat 时没有固定完整路径，我又换了更方便的交互方式，才把 PATH 这段接起来。一路走下来，信息泄露、应用权限和本地命令查找各占一段。笔记里也有当时对摘要算法说得不准的地方，整理时得纠正；改掉一个管理口令，不等于已经破解了原来的摘要。

### 7、由于无法破解管理员的密码，但是可以修改密码

原记录中的 $P$ 前缀与后来写入的 $1$ 前缀并非同一种散列格式；原文把前者称为改进 DES 缺乏依据。更新数据库散列是重置认证数据，不是破解原口令。

```
MySQL [qdpm]> update configuration set value="$1$m0IX0vwl$HR6rGO5FjvC39TsfOXWLK0" where id=2;

Query OK, 1 row affected (0.007 sec)

Rows matched: 1  Changed: 1  Warnings: 0
```
