下面是原实验的历史部署步骤。容器使用 host 网络和 privileged 权限，数据库示例授予过宽权限，不应直接用于生产。

1、安装MySQL服务器

```
# 安装mysql
sudo apt install mysql-server
sudo systemctl stop mysql

# 修改端口为3307
vim /etc/mysql/mysql.conf.d/mysqld.cnf
# 找到 port 进行修改

# 开启mysql
sudo systemctl start mysql

# 防火墙
sudo ufw allow 3307/tcp
```

2、配置 MySQL ailx10 用户密码

```
mysql
CREATE USER 'aixl10'@'localhost' IDENTIFIED BY '<数据库密码>';
GRANT ALL PRIVILEGES ON *.* TO 'aixl10'@'localhost' WITH GRANT OPTION;
FLUSH PRIVILEGES;
EXIT;
```

3、创建数据库

```
CREATE DATABASE ailx10_hackbiji;
```

4、安装docker

```
sudo apt install docker.io
docker version
```

5、下载安装并运行

```
docker run -itd --name hfish \
-v /usr/share/hfish:/usr/share/hfish \
--network host \
--privileged=true \
threatbook/hfish-server:latest
```
