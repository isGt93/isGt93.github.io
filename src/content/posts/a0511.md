MyMap003把IPv4按/4扫描记80服务，约41万候选，先页面2048长度后发现错误页误判改HTTP200过滤，结果仍在生成。

## 技术条件和待核查点

4亿与全球/4列表不一致还漏112段，列表数量与41万需核；200也可能错误/蜜罐，strip空格不去换行，不能作资产真值。

拿到大约41万个IP，这些IP都开放了80端口，这里做一个简单的过滤，因为有些IP不能访问，那么返回数据的长度一定非常小，暂且设置一个返回长度阈值2048作为过滤条件。

```
while read line

do

  index=$(curl -s --connect-timeout 1 -m 3 $line)

  if [ ${#index} -gt 2048 ];then 

     echo $line >> v3.0_MyDb

  fi

done < db
```

跑是可以跑，但是通过判断返回内容的长度不合理，比如第一个IP地址`1.0.0106`返回长度大于2048，但是返回的结果是网站无法访问，所以需要用200状态码来判断网站是否能够被正确访问。

```
import requests



def get_status(ip):

    status = False

    try:

        r = requests.get("http://"+ip+"/",timeout=1)

        if r.status_code == requests.codes.ok:

            status = True

    except:

        status = False

    return status



def get_mydb(db_file):

    f = open(db_file,'r')

    ips = list()

    for ip in open(db_file):

        ip = f.readline()

        ip = ip.strip('

')

        ips.append(ip)

    f.close()

    for ip in ips:

        if get_status(ip):

            print ip

            

if __name__ == "__main__":

    get_mydb("db")
```
