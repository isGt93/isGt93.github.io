**列置换密码 (Columnar Transposition Cipher)**

- 将明文按固定行数排列成矩阵
- 按密钥指定的列顺序重组并读取字符（例如密钥215643对应列重排规则）
- 最终密文通过按行拼接重组后的列生成

```
flag{5
2048c4
53d794
df1} 

lf5{ag
024c48
3549d7
fd@@1}
```

> lf5{ag024c483549d7fd@@1} 一张纸条上凌乱的写着2 1 6 5 3 4

难度系数：1

原记录的题面、列序或结果存在冲突；需要获取原题并统一索引后复核。

```
ciphertext = "lf5{ag024c483549d7fd@@11"
rows, cols = 4, 6

# 将密文转为4x6矩阵
matrix = [ list(ciphertext[i*cols : (i+1)*cols]) for i in range(rows) ]

key_order = [1,0,4,5,3,2]
# 按密钥重组列并拼接
flag = ''.join(
    ''.join(row[col] for col in key_order)
    for row in matrix
).split('@@')[0] + '}'  # 处理填充字符

print(flag)
```
