你喜欢下棋吗？

解压密码为小写

4423244324433534315412244543

因为这一题考察2个密码，所以难度系数给个2吧

**棋盘密码原理**：使用5x5的 Polybius 棋盘

**棋盘布局：**

```
1行：a b c d e   
2行：f g h i k   
3行：l m n o p   
4行：q r s t u   
5行：v w x y z 
```

**数字分组**：将密文按两位分割为坐标对

```
44,23,24,43,24,43,35,34,31,54,12,24,45,43 
```

**坐标转换**：

```
44 → 第4行第4列 → t
23 → 第2行第3列 → h
24 → 第2行第4列 → i
43 → 第4行第3列 → s
35 → 第3行第5列 → p
34 → 第3行第4列 → o
31 → 第3行第1列 → l
54 → 第5行第4列 → y
12 → 第1行第2列 → b
45 → 第4行第5列 → u
```

**拼接结果**：将所有字母连结成密码 **thisispolybius**

```
class PolybiusCipher:
    def __init__(self):
        # 定义棋盘 (i/j合并)
        self.SQUARE = [
            ['a', 'b', 'c', 'd', 'e'],
            ['f', 'g', 'h', 'i', 'k'],
            ['l', 'm', 'n', 'o', 'p'],
            ['q', 'r', 's', 't', 'u'],
            ['v', 'w', 'x', 'y', 'z']
        ]

    def decrypt(self, ciphertext: str) -> str:
        plaintext = []
        # 每两位数字解析为一个坐标
        for i in range(0, len(ciphertext), 2):
            row = int(ciphertext[i]) - 1
            col = int(ciphertext[i + 1]) - 1
            plaintext.append(self.SQUARE[row][col])
        return ''.join(plaintext)


# 实例化解密器
cipher = PolybiusCipher()
encrypted_code = "4423244324433534315412244543"
password = cipher.decrypt(encrypted_code)

print(f"解压密码: {password}")
```

解压之后，竟然又是一层加密（博多码）

```
一种5bit的编码
bugku里面的内容为小写
bugku{11111 11001 00011 00111 01001 11011 10110 11111 10000 01110 11011 10110 11111 01001 00001}
```

这里注意啦，博多码是一种5位编码系统，通常用于电报通信。它有两种模式：字母移位（Letters Shift）和数字移位（Figures Shift），通过特殊的控制字符来切换模式。例如，当遇到特定的移位码时，后续的编码会切换到另一种模式，直到再次切换回来。

整个过程如下所示：

```
1. 11111 → [LS]（Letters Shift，初始状态已经字母模式）
2. 11001 → B
3. 00011 → A
4. 00111 → U
5. 01001 → D
6. 11011 → [FS]（切回数字模式）
7. 10110 → 0
8. 11111 → [LS]（切回字母模式）
9. 10000 → T
10. 01110 → C
11. 11011 → [FS]（切回数字模式）
12. 10110 → 0
13. 11111 → [LS]（切回字母模式）
14. 01001 → D
15. 00001 → E

把这些连接起来：
B A U D [FS]0 [LS] T C [FS]0 [LS] D E
```

使用python直接编程求解：

```
# 定义Baudot码的字母和数字模式映射
letters = {
    '00000': '', '00001': 'E', '00010': '', '00011': 'A', '00100': ' ',
    '00101': 'S', '00110': 'I', '00111': 'U', '01000': '', '01001': 'D',
    '01010': 'R', '01011': 'J', '01100': 'N', '01101': 'F', '01110': 'C',
    '01111': 'K', '10000': 'T', '10001': 'Z', '10010': 'L', '10011': 'W',
    '10100': 'H', '10101': 'Y', '10110': 'P', '10111': 'Q', '11000': 'O',
    '11001': 'B', '11010': 'G', '11011': '', '11100': 'M', '11101': 'X',
    '11110': 'V', '11111': ''
}

figures = {
    '00000': '', '00001': '3', '00010': '', '00011': '-', '00100': ' ',
    '00101': '', '00110': '8', '00111': '7', '01000': '', '01001': ';',
    '01010': '4', '01011': "'", '01100': ',', '01101': '!', '01110': ':',
    '01111': '(', '10000': '5', '10001': '"', '10010': ')', '10011': '2',
    '10100': '#', '10101': '6', '10110': '0', '10111': '1', '11000': '9',
    '11001': '?', '11010': '&', '11011': '', '11100': '.', '11101': '/',
    '11110': ';', '11111': ''
}

# 分割二进制序列为5位一组
binary_groups = "11111 11001 00011 00111 01001 11011 10110 11111 10000 01110 11011 10110 11111 01001 00001".split()

current_mode = 'letters'
result = []

for code in binary_groups:
    if current_mode == 'letters':
        if code == '11011':  # 遇到FS切换到数字模式
            current_mode = 'figures'
            continue
        elif code == '11111':  # LS无需处理
            continue
        result.append(letters[code])
    elif current_mode == 'figures':
        if code == '11111':  # 遇到LS切换回字母模式
            current_mode = 'letters'
            continue
        result.append(figures[code])

# 拼接结果并转换为小写
decoded = ''.join(result).lower()
print(f'bugku{{{decoded}}}')
```
