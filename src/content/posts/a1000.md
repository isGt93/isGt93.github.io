## 一、MLlib向量介绍

- MLlib自己实现了Vector类，
- 封装了Breeze向量方法，在MLlib函数里的参数传递都是使用MLlib自己的Vector

```
//向量
import org.apache.spark.mllib.linalg.Vector
```

## 二、MLlib Vector接口

- MLlib定义了Vector接口：
- DenseVector： 密集向量
- SparseVector： 稀疏向量
- Vector接口的主要方法有：
- toArray： 向量转数组
- toBreeze： 向量转Breeze向量
- toSparse： 向量转稀疏向量
- toDense： 向量转密集向量
- copy： 向量复制

## 三、MLlib DenseVector 类

- DenseVector集成Vector接口，重写其中的部分方法，实现密集向量类的定义
- DenseVector的主要方法有：
- toArray：向量转成数组
- toBreeze：向量转成Breeze向量
- toSparse：向量转稀疏向量

## 四、MLlib SparseVector 类

- SparseVector继承Vector接口，重写其中的部分方法，实现稀疏向量类的定义
- SparseVector的主要方法有：
- toArray：向量转数组
- toBreeze：向量转Breeze向量
- toSparse：向量转稀疏向量

![](/notes-assets/bf283a0e62530a062f81.jpg)

## 五、MLlib Vector 伴生对象

MLlib Vector伴生对象中定义了，创建MLlib向量的方法，和向量之间的相关操作函数，包括：

- dense：创建密集向量类
- sparse：创建稀疏向量类
- zeros：创建0向量
- fromBreeze：根据breezeVector创建向量
- norm：求向量的p范数
- sqdist：求向量之间的平方距离

## 一、MLlib Matrix 介绍

- MLlib自己实现了Matrix类，
- 封装了Breeze矩阵方法，在MLlib函数里的参数传递都是使用MLlib自己的Matrix

## 二、MLlib Matrix 接口

- MLlib定义了Matrix接口
- 最终由DenseMatrix、SpareMatrix实现密集和稀疏矩阵
- Matrix接口的主要方法有：
- toArray：矩阵转成数组
- toBreeze：矩阵转成Breeze矩阵
- transpose：矩阵转置
- multiply：矩阵乘法

## 三、MLlib DenseMatrix 接口

- DenseMatrix继承Matrix接口，重写其中部分方法，实现密集矩阵类的定义
- **DenseMatrix类的主要方法有：**
- equals：矩阵相等判断
- toBreeze：矩阵转换成Breeze矩阵
- index：矩阵元素位置索引
- update：矩阵元素更新
- copy：矩阵复制
- map：矩阵元素map操作
- transpose：矩阵转置
- toSparse：转换为稀疏矩阵
- **DenseMatrix对象的主要方法有：**
- zeros：创建全0矩阵
- ones：创建全1矩阵
- eye：创建单位矩阵
- rand：创建随机矩阵，平均分布
- randn：创建随机矩阵，标准正态分布
- diag：创建对角矩阵

## 四、MLlib SparseMatrix 接口

- SparseMatrix继承Matrix接口，重写了一部分方法，实现稀疏矩阵类的定义
- **SparseMatrix类的主要方法有：**
- toBreeze：矩阵转换成Breeze矩阵
- index：矩阵元素位置索引
- update：矩阵元素更新
- copy：矩阵复制
- map：矩阵元素map操作
- transpose：矩阵转置
- toDense：转换成密集矩阵
- **SparseMatrix对象的主要方法有：**
- fromCOO：创建稀疏矩阵，来源于坐标列表格式数据（i，j，value）
- speye：创建单位稀疏矩阵
- genRandMatrix：创建随机矩阵
- sprand：创建随机稀疏矩阵，平均分布
- sprandn：创建随机稀疏矩阵，标准正态分布
- spdiag：创建对角稀疏矩阵

## 五、MLlib Matrix 伴生对象

- MLlib Matrix 伴生对象中定义了创建MLlib矩阵的方法和矩阵之间的相关操作，包括：
- dense：创建密集矩阵类
- sparse：创建稀疏矩阵类
- fromBreeze：创建矩阵，来源于breezeMatrix
- zeros：创建全0矩阵
- ones：创建全1矩阵
- eye：创建单位矩阵
- speye：创建稀疏单位矩阵
- rand：创建随机矩阵，平均分布
- sprand：创建随机稀疏矩阵，平均分布
- randn：创建随机矩阵，正态分布
- sprandn：创建随机稀疏矩阵，正态分布
- diag：创建对角矩阵
- horzcat：横向连接矩阵
- vertcat：垂直连接矩阵

- MLlib自己实现了BLAS类，封装了部分BLAS线性代数方法
- 在MLlib的函数中使用封装的BLAS进行线性代数计算
- MLlib自己实现了BLAS类包含的线性代数运算方法：
- axpy：向量与向量运算
- dot：点积
- copy：复制

## 一、MLlib分布式矩阵介绍

- MLlib在Vector和Matrix基础上，实现了分布式矩阵类
- 分布式矩阵的数据分块或者分行存储
- 并且实现矩阵的基本运算，能够使矩阵分布式计算
- 比如：列统计、相似度、协方差、奇异值分解
- 目前MLlib实现的分布式矩阵包括：RowMatrix、IndexRowMatrix、CoordinateMatrix、BlockMatrix

## 二、行矩阵RowMatrix

分布式行矩阵是把每行对应一个RDD，将矩阵的每行分布式存储，矩阵的每行是一个本地向量。这和多变量统计的数据矩阵比较相似，因为每行以一个本地向量表示所以矩阵列的数量被限制在整数范围内，实际应用中列数很少。

- newRowMatrix：创建RowMatrix方法
- columnSimilarities：计算每列之间的相似度，采用抽样方法进行计算
- computeColumnSummaryStatistics：计算每列的汇总统计
- computeCovariance：计算每列之间的协方差
- computeGramianMatrix：计算格拉姆矩阵
- computePrincipalComponents：主成分分析计算，取前k个主要变量
- computeSVD：计算矩阵的奇异值分解
- multiply：矩阵乘法运算
- numCols：矩阵的列数
- numRows：矩阵的行数
- rows：矩阵转换成RDD，以行存储的RDD

## 三、行索引矩阵IndexRowMatrix

行索引矩阵和列索引矩阵都差不多：

- IndexedRowMatrix：创建行索引矩阵
- computeGramianMatrix：计算格拉姆矩阵
- computeSVD：计算矩阵的奇异值分解
- multiply：矩阵乘法运算
- numCols：矩阵的列数
- numRows：矩阵的行数
- toBlockMatrix：转换成BlockMatrix矩阵
- toCoordinateMatrix：转换成CoordinateMatrix矩阵
- toRowMatrix：转换成RowMatrix矩阵

## 四、坐标矩阵CoordinateMatrix

坐标矩阵，每一项都是一个（i，j，value）指示（行列值）的元组，如果矩阵非常大，而且稀疏，则坐标矩阵一定是最好的选择。

- CoordinateMatrix：创建坐标矩阵
- numCols：矩阵的列数
- numRows：矩阵的行数
- toBlockMatrix：转换成BlockMatrix矩阵
- toIndexRowMatrix：转换成IndexRowMatrix矩阵
- toRowMatrix：转换成RowMatrix矩阵
- transpose：矩阵转置

## 五、分块矩阵BlockMatrix

- BlockMatrix：创建分块矩阵
- add：分块矩阵相加
- blocks：分块矩阵的块矩阵元素
- colsPerBlock：构成每个块的列数
- multiply：矩阵相乘
- numColsBlocks：矩阵块列数
- numCols：矩阵列数
- numRowBlocks：矩阵块行数
- numRows：矩阵行数
- rowsPerBlock：构成每个块的行数
- toCoordinateMatrix：转成CoordinateMatrix矩阵
- toIndexRowMatrix：转成IndexRowMatrix矩阵
- toLocalMatrix：转成LocalMatrix矩阵
- transpose：矩阵转置
