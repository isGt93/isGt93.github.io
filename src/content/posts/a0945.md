ailx10说：这篇是2018年11月之前写的，后来又改过。这篇把 KNN 从命令习惯换到 KDD99 的 Telnet 连接，挑正常与 rootkit 相关记录，再从内容特征里选输入，做十折评估。样本并不多，所以从字段含义到筛选方式都得先搞清楚，不能把文件读进来就期待模型替我理解攻击。笔记留下的是那次选特征和跑结果的过程。Rootkit 在系统里做的事情很多，这份数据只照见其中一部分；把目标缩到当前能观察的连接行为，才知道这个小实验究竟想回答什么。

Rootkit篇筛KDD99 telnet正常与rootkit90记录，取12项内容特征，KNN十折报告约九成。

## 前提和待核查点

显示攻击仅两条无法支持十折分层稳定评估，常正常基线约98%；数据集rootkit类非通用rootkit检测，未缩放影响距离。

## 历史笔记与实验记录

Rootkit是啥？就是后门工具箱，它的功能是在肉鸡上隐藏自身以及指定的文件、进程和网络链接等信息。

def load_kdd99(filename):

    x=[]

    with open(filename) as f:

        for line in f:

            line=line.strip('

')

            line=line.split(',')

            x.append(line)

    return x



def get_rootkit2andNormal(x):

    v=[]

    w=[]

    y=[]

    for x1 in x:

        if ( x1[41] in ['rootkit.','normal.'] ) and ( x1[2] == 'telnet' ):

            if x1[41] == 'rootkit.':

                y.append(1)

            else:

                y.append(0)



            x1 = x1[9:21]

            v.append(x1)

    for x1 in v :

        v1=[]

        for x2 in x1:

            v1.append(float(x2))

        w.append(v1)

    return w,y



if __name__ == '__main__':

    v=load_kdd99("../data/kddcup99/corrected")
