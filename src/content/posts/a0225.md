ailx10说：这篇是我2023年10月写的。这次 PHP XXE 我没有把所有可能影响都做出来，主要跑通的是外部实体读取文件。命令执行和内网探测也试过，但不顺利，笔记就老老实实停在当时能确认的地方。它是个不长的实验，却帮我把 XML 里的实体、解析器配置和最终读到的内容连上了。现在回看，比起列一串听起来很厉害的危害，我更想让读者知道这次具体验证了哪一步：看到文件内容是一回事，后面那些能力还需要另外的条件和证据。

原实验通过 XML 外部实体观察到文件读取。XXE 的实际影响取决于解析 API、libxml 版本、外部实体选项和运行权限；其他影响并非该实验已验证结果。

前提：准备好docker环境，下载好vulhub，进入目录 ，开始复现漏洞

- `docker-compose build //可选`
- `docker-compose up -d`

完成试验后，记得删除漏洞环境哦～～

实验结束后可在确认项目目录和 Compose 配置后关闭该项目的服务；原文的全局 Docker 清理命令已移除。

简单访问一下，说明PHP XXE漏洞环境搭建成功了
