ailx10说：这篇是在2024年2月之前写的，后来又改过。前一天刚把那份 PDF 的文字复制问题解决，我就接着把 OSCP 目录提出来，想先看清里面究竟教些什么。英文目录直接读有点慢，于是调用翻译 API，按一百行分批处理，保存成中英文对照，再清理译文里的多余数字。整个过程像给自己铺一张学习地图：先不急着谈证书多神，拿到材料、看懂章节，才知道哪些地方想往下钻。这篇把文件处理和翻译接成了一条小流程，也留下当时准备重新认识这套课程的起点。

使用百度翻译API，轻松解决翻译任务，效果如何，自己评价：

```
# -*- coding: utf-8 -*-

import requests

import random

import re

from hashlib import md5



# Set your own appid/appkey.

appid = '...'

appkey = '...'



from_lang = 'en'

to_lang =  'zh'



endpoint = 'http://api.fanyi.baidu.com'

path = '/api/trans/vip/translate'

url = endpoint + path



# Generate salt and sign

def make_md5(s, encoding='utf-8'):

    return md5(s.encode(encoding)).hexdigest()



salt = random.randint(32768, 65536)



def query_baidu(query):

    headers = {'Content-Type': 'application/x-www-form-urlencoded'}

    sign = make_md5(appid + query + str(salt) + appkey)

    payload = {'appid': appid, 'q': query, 'from': from_lang, 'to': to_lang, 'salt': salt, 'sign': sign}

    r = requests.post(url, params=payload, headers=headers)

    result = r.json()

    return result



if __name__ == "__main__":



    input_file = "4.txt"  # 翻译前的英文文本

    output_file = "5.txt"  # 翻译后的中文文本



    with open(input_file, 'r', encoding='utf-8') as file:

        input_text = file.readlines()

        split_size = 100

        new_list = [''.join(input_text[i:i + split_size]) for i in range(0, len(input_text), split_size)]



    for input_text_str in new_list:

        result = query_baidu(input_text_str)



        with open(output_file, 'a+', encoding='utf-8') as file:

            all_trans = []

            trans_result_list = result["trans_result"]

            for trans in trans_result_list:

                src = trans["src"]

                dst = trans["dst"]

                dst = re.sub(r'\d+(\.\d+)*', '', dst)

                tmp_trans = "{}  {}

".format(src,dst)

                all_trans.append(tmp_trans)



            all_trans = "".join(all_trans)

            print(all_trans)

            file.write(all_trans)
```

目录里的数字也可能是版本和知识的一部分，不能为了版面整齐一删了之。翻译后再对照原文补齐术语，得到的路线才值得拿来安排下一步。
