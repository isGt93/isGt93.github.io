## 创建CA证书[\[1\]](#ref_1)

**1、生成私钥ca.key**

```
openssl genrsa -out ca.key 2048
```

![](/notes-assets/cb7f06f6115f03d2807a.jpg)

**2、生成证书请求文件ca.csr**

```
openssl req -new -key ca.key -out ca.csr
```

![](/notes-assets/5e8f06f024383e3ef674.jpg)

**3、生成自签名证书ca.crt**

```
openssl req -x509 -days 3650 -key ca.key -in ca.csr -out ca.crt
```

![](/notes-assets/39c15571737c569bce65.jpg)

**4、查看证书请求ca.csr信息**

```
openssl req -in ca.csr -text -verify -noout
```

![](/notes-assets/b1523f16a5b1c46f9d3c.jpg)

**5、查看证书ca.crt信息**

```
openssl x509 -in ca.crt -text -noout
```

![](/notes-assets/53fb7fd6ef7beab74466.jpg)

## 创建用户证书

**1、生成私钥server.key**

```
openssl genrsa -out server.key 2048
```

![](/notes-assets/997dabcc04817f594672.jpg)

**2、生成证书请求server.csr**

```
openssl req -new -key server.key -out server.csr
```

![](/notes-assets/42684c099b1135bc4678.jpg)

**3、生成证书server.crt**

```
openssl ca -in server.csr -out server.crt -cert ca.crt -keyfile ca.key -config openssl.cnf
```

![](/notes-assets/4f94ddf9555c392a81b2.jpg)

**4、查看请求证书server.csr信息**

```
openssl req -in server.csr -text -verify -noout
```

![](/notes-assets/3ae346eb722d00f336ba.jpg)

**5、查看证书server.crt信息**

```
openssl x509 -in server.crt -text -noout
```

![](/notes-assets/8a534b0b57b13dfad095.jpg)

**6、验证证书链的有效性**

```
openssl verify -CAfile ca.crt server.crt
```

![](/notes-assets/da0c5b11382e297b30bd.webp)

**7、生成PEM格式证书**

```
cat server.crt server.key > server.pem
```

![](/notes-assets/8998a6eabdc694959e69.webp)

## Ubuntu下Apache配置SSL证书[\[2\]](#ref_2)

**1、上传证书和私钥到服务器**

- /home/sec/ssl/server.pem
- /home/sec/ssl/server.key

**2、开启SSL模块**

```
a2enmod ssl
```

**3、启用SSL站点**

```
a2ensite default-ssl
```

**4、配置Apache站点SSL证书**

配置文件：`/etc/apache2/sites-available/default-ssl.conf`

![](/notes-assets/ce6e903054a5f7407759.jpg)

**5、重启Apache，访问HTTPS站点，端口443**

```
service apache2 restart
```

![](/notes-assets/aa95242e4ea037af39c7.webp)

## 可选OPTIONS

**1、配置 HTTPS 强制跳转**  
配置文件：`/etc/apache2/sites-available/000-default.conf`

```
RewriteEngine on 

RewriteCond %{HTTPS} !=on

RewriteRule ^(.*) https://%{SERVER_NAME}$1 [L,R]
```

![](/notes-assets/253d70a58775f57d011d.webp)

**2、如果没有开启apache的`rewrite`模块，还需要启用`rewrite`模块**

```
a2enmod rewrite
```

**3、重启Apache，访问HTTP站点自动跳转到HTTPS站点**

```
service apache2 restart
```
