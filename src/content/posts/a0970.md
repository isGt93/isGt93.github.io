原代码和结果来自历史实验，尚未在当前环境重新运行；依赖版本、数据划分和指标需复核。

本文使用含 300 个 ReLU 节点的隐藏层，在 MNIST 手写数字数据上演示 TensorFlow 1 风格模型。

## 1.数据清洗与特征提取

MNIST 是手写数字数据集，不等同于实际验证码；原示例使用历史 API。

呵呵，这里的神经网络还是要数据清洗，还是要特征提取...我们需要思考如何训练整个请求报文？如何将报文映射成图像呢？头疼。

我们使用one-hot编码处理标记数据，

```
def get_one_hot(x,size=10):
    v=[]
    for x1 in x:
        x2=[0]*size
        x2[(x1)]=1
        v.append(x2)
    return v
```

## 2.训练

隐藏层节点数是模型超参数，会影响容量、计算和过拟合风险，需要验证而非随意设置。

```
batch_size=100 #顺序取100个数据用于训练
in_units=784 #维度
h1_units=300 #300个隐藏节点

W1=tf.Variable(tf.truncated_normal([in_units,h1_units],stddev=0.1))#生成正态分布，标准差0.1
b1=tf.Variable(tf.zeros([h1_units]))
W2=tf.Variable(tf.zeros([h1_units,10]))
b2=tf.Variable(tf.zeros([10]))

x = tf.placeholder(tf.float32, [None, in_units])#系统输入
y_ = tf.placeholder(tf.float32, [None,10])#系统输出
keep_prob=tf.placeholder(tf.float32)#防止过拟合，0-1之间，每个元素保留概率

hidden1=tf.nn.relu(tf.matmul(x,W1)+b1)#隐藏层激活函数（none,300）
hidden1_drop=tf.nn.dropout(hidden1,keep_prob)#防止过拟合

y = tf.nn.softmax(tf.matmul(hidden1_drop,W2) + b2)#输出层激活函数（none,10）

cross_entropy = tf.reduce_mean(-tf.reduce_sum(y_*tf.log(y),reduction_indices=[1]))#损失函数
train_step = tf.train.AdagradOptimizer(0.3).minimize(cross_entropy)#Adagrad算法

init = tf.initialize_all_variables()#初始化变量
sess = tf.Session()#创建会话
sess.run(init)

#每次顺序取出100条数据用于训练，便于Adagrad算法快速收敛
for i in range(int(len(x_training_data)/batch_size)):
    batch_xs=x_training_data[(i*batch_size):((i+1)*batch_size)]
    batch_ys=y_training_data[(i*batch_size):((i+1)*batch_size)]
    sess.run(train_step, feed_dict={x: batch_xs, y_: batch_ys,keep_prob:0.75})
```

## 3.验证

> tf.argmax 的 axis\=1 沿每行的列维度取最大值索引；测试时应关闭 dropout。

原文报告约 95.7%；独热编码索引偏移需要确保训练、预测和解码映射一致。

每次跑的结果都会稍微有点不同，

```
correct_prediction = tf.equal(tf.argmax(y, 1), tf.argmax(y_, 1))
accuracy = tf.reduce_mean(tf.cast(correct_prediction, tf.float32))

print(sess.run(accuracy, feed_dict={x: x1, y_: y1,keep_prob:1.0}))
```

## 4.完整代码

```
import tensorflow as tf
import pickle
import gzip

def get_one_hot(x,size=10):
    v=[]
    for x1 in x:
        x2=[0]*size
        x2[(x1-1)]=1
        v.append(x2)
    return v


def load_data():
    with gzip.open('../data/MNIST/mnist.pkl.gz') as fp:
        training_data, valid_data, test_data = pickle.load(fp)
    return training_data, valid_data, test_data

training_data, valid_data, test_dat=load_data()

x_training_data,y_training_data=training_data
x1,y1=test_dat

y_training_data=get_one_hot(y_training_data)
y1=get_one_hot(y1)


batch_size=100
in_units=784
h1_units=300
W1=tf.Variable(tf.truncated_normal([in_units,h1_units],stddev=0.1))
b1=tf.Variable(tf.zeros([h1_units]))
W2=tf.Variable(tf.zeros([h1_units,10]))
b2=tf.Variable(tf.zeros([10]))

x = tf.placeholder(tf.float32, [None, in_units])
y_ = tf.placeholder(tf.float32, [None,10])
keep_prob=tf.placeholder(tf.float32)

hidden1=tf.nn.relu(tf.matmul(x,W1)+b1)
hidden1_drop=tf.nn.dropout(hidden1,keep_prob)


y = tf.nn.softmax(tf.matmul(hidden1_drop,W2) + b2)

cross_entropy = tf.reduce_mean(-tf.reduce_sum(y_*tf.log(y),reduction_indices=[1]))
train_step = tf.train.AdagradOptimizer(0.3).minimize(cross_entropy)

init = tf.initialize_all_variables()
sess = tf.Session()
sess.run(init)


for i in range(int(len(x_training_data)/batch_size)):
    batch_xs=x_training_data[(i*batch_size):((i+1)*batch_size)]
    batch_ys=y_training_data[(i*batch_size):((i+1)*batch_size)]

    sess.run(train_step, feed_dict={x: batch_xs, y_: batch_ys,keep_prob:0.75})


correct_prediction = tf.equal(tf.argmax(y, 1), tf.argmax(y_, 1))
accuracy = tf.reduce_mean(tf.cast(correct_prediction, tf.float32))

print(sess.run(accuracy, feed_dict={x: x1, y_: y1,keep_prob:1.0}))
```

分数提高是一个结果，标签映射和推理设置也得一起保存。把这些看似琐碎的环节记牢，以后加载模型时，才能确认它仍在回答训练时的同一个问题。
