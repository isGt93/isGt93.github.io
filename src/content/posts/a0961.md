ailx10说：这篇是在2018年11月之前写的，后来又改过。前面总是带着标签训练，这次我换 K-Means，想看域名能不能先靠相似性自己聚到一起。还是把字符和双词变成向量，指定两类，让中心不断更新，再把聚出的结果拿回黑白样本里对照。这样一来，思路从“告诉模型什么是攻击”变成“先看看它怎样分堆”。这篇是我把聚类接到 DGA 问题上的第一次小尝试，既想看算法跑通，也想理解，同一批名字在没有直接答案参与时，会被哪些相似之处拉到一起。

---

原代码和结果来自历史实验，尚未在当前环境重新运行；依赖版本、数据划分和指标需复核。

本文用 K-Means 对历史域名字符特征进行聚类。聚类编号是任意的，不能直接当作黑白标签。

> K-Means算法是最经典的基于划分的聚类方法，它的中心思想是，以空间中k个点为中心进行聚类，通过迭代的方法，逐次更新各聚类中心的值，直至得到最好的聚类结果。

- 从n个数据对象任意选择k个对象作为初始聚类中心，对于剩余的其他对象，则根据它们与这些聚类中心的相似度，分别将它们分配给与其最相似的聚类。
- 计算每个新聚类的聚类中心。
- 不断重复这一过程，直到标准聚类函数开始收敛。

## 1.数据搜集和数据清洗

使用alexa前1000域名（679个样本）作为白样本，标记为0，由于域名长度设置最低长度10，所以选取到679个样本，

## 5.完整代码

```
import sys
import re
import numpy as np
from sklearn.externals import joblib
import csv
import matplotlib.pyplot as plt
import os
from sklearn.feature_extraction.text import CountVectorizer
from sklearn import cross_validation
import os
from sklearn.naive_bayes import GaussianNB
from sklearn.cluster import KMeans
from sklearn.manifold import TSNE


#处理域名的最小长度
MIN_LEN=10

#随机程度
random_state = 170

def load_alexa(filename):
    domain_list=[]
    csv_reader = csv.reader(open(filename))
    for row in csv_reader:
        domain=row[1]
        if domain >= MIN_LEN:
            domain_list.append(domain)
    return domain_list

def load_dga(filename):
    domain_list=[]
    #xsxqeadsbgvpdke.co.uk,Domain used by Cryptolocker - Flashback DGA for 13 Apr 2017,2017-04-13,
    # http://osint.bambenekconsulting.com/manual/cl.txt
    with open(filename) as f:
        for line in f:
            domain=line.split(",")[0]
            if domain >= MIN_LEN:
                domain_list.append(domain)
    return  domain_list

def kmeans_dga():
    x1_domain_list = load_alexa("../data/dga/top-100.csv")
    x2_domain_list = load_dga("../data/dga/dga-cryptolocke-50.txt")
    x3_domain_list = load_dga("../data/dga/dga-post-tovar-goz-50.txt")

    x_domain_list=np.concatenate((x1_domain_list, x2_domain_list,x3_domain_list)

    y1=[0]*len(x1_domain_list)
    y2=[1]*len(x2_domain_list)
    y3=[1]*len(x3_domain_list)
    y=np.concatenate((y1, y2,y3))

    cv = CountVectorizer(ngram_range=(2, 2), decode_error="ignore",
                                          token_pattern=r"\w", min_df=1)
    x= cv.fit_transform(x_domain_list).toarray()
    model=KMeans(n_clusters=2, random_state=random_state)

    y_pred = model.fit_predict(x)
    print  y_pred
    print y
    print np.mean(y_pred==y)*100

if __name__ == '__main__':
    kmeans_dga()
```

K-Means这一回更适合看结构，而不是直接把簇号当预测标签。把分组结果重新映射或换合适指标后，才知道那两堆是否真和题目想找的行为有关。
