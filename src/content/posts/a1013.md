ailx10说：这篇是2022年1月之前写的，后来又改过。上一篇把文本翻译跑通了，我接着问自己：如果不是翻完一本就结束，而是不断有新文件进来，该怎么办？带着这个问题，再看DStream就没那么抽象了。我拿批处理和持续处理作对照，顺着StreamingContext、微批RDD、目录监控和启动等待这些环节，把原来的翻译例子往流处理方向改。它记录的是我理解执行流程的过程，不是贴一段代码就能完整运行的成品：原示例还缺输出和启动等环节，文件流也要看监控目录的要求。把这几个缺口一并说明，比只说“源源不断处理”更接近当时要解决的问题。

---

举一个例子来说，批处理翻译完一本书，就结束流，如果想翻译另一本书，需要重新启动一个批处理任务。但是流处理翻译完了一本书之后，还可以继续翻译下一本书。由此可见，流处理可以源源不断的执行任务～

![](/notes-assets/16bdf10ed8e624cba092.jpg)

与SpakrContext类似，StreamingContext是实时应用程序的入口，它充当应用程序与Spark引擎的连接纽带。DStream对于Spark Streaming的作用就如同RDD对于Spark的作用，DStream将潜在的无限数据流，转换成离散批处理的RDD～

![](/notes-assets/397100c6b48bedf8f873.jpg)

Spark Streaming的通常应用执行流程如下，最关键的还是步骤4、5、6：

1. Spark Streaming会创建一个SparkContext对象和一个JobScheduler对象
2. start启动JobScheduler -》JobGenerator，每个批处理间隔JobGenerator负责创建作业
3. textFileStream创建一个FileInputDStream对象
4. 这个FileInputDStream对象会监控指定目录获取新文件
5. 这个FileInputDStream对象可以调用map函数，创建一个MappedDStream进行操作
6. 这个FileInputDStream对象操作完事之后，可以调用saveAsTextFiles将结果写入文件
7. 重复4、5、6

```
import org.apache.spark.streaming.{Seconds, StreamingContext}
import org.apache.spark.{SparkConf, SparkContext}

import scala.io.Source

object TranslateApp2 {

  def getDictionary(lang:String):Map[String,String] = {
    if (!Set("German","French","Italian","Spanish").contains(lang)){
      System.err.println("不支持翻译")
      System.exit(1)
    }
    val url = "http://www.june29.com/IDP/files/%s.txt".format(lang)
    println("抓取内容:%s".format(url))
    Source.fromURL(url,"ISO-8859-1").mkString
      .split("\r?\
")
      .filter(line=> !line.startsWith("#"))
      .map(line=>line.split("\	"))
      .map(tkns=>(tkns(0).trim,tkns(1).trim)).toMap
  }

  def main(args: Array[String]): Unit = {
    val appName = "AILX10"
    val bookPath = "C:\study\spark\streaming\hack.txt"
    val outputPath = "C:\study\spark\streaming3"
    val lang = "German"

    val dict = getDictionary(lang)

    val conf = new SparkConf()
      .setAppName(appName)
      .setJars(SparkContext.jarOfClass(this.getClass).toSeq)
      .setMaster("local")


    val ssc = new StreamingContext(conf,Seconds(1))

    val book = ssc.textFileStream(bookPath)
    val translated = book.map(line => line.split("\s+")
      .map(word=>dict.getOrElse(word,word)).mkString(" "))
//    translated.saveAsTextFile(outputPath)

    println("翻译完成~")

  }

}
```
