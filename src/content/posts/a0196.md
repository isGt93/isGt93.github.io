ailx10说：这篇是我2025年3月写的。题目一开口就说“这不是 md5”，我便先不猜算法，盯着那串字符看：全是十六进制，长度也不对。把它按两位拆成一个字节，再转成文字，答案就逐渐露出来了。这篇是很短的一次练习，却挺适合提醒自己别被外观带跑。一长串字母数字不一定是摘要，更不一定需要“破解”；这次就是从最基础的拆分开始，几个字母一个个露出来，最后才确定整串原来是在用另一种方式写普通文本。

---

编辑核查提示：将十六进制表示还原为字节，再按 UTF-8 解码；原字符串长度实际为 44 个十六进制字符，得到 22 字节。

题目提示“这不是md5”，给出的密文是666c61677b616537333538376261353662616566357d

难度系数：1

```
666c61677b616537333538376261353662616566357d
```

字符串由十六进制字符组成，长度是 44 位，也就是 22 字节。

每两位十六进制字符构成一个字节；本题结果恰好可以按 UTF-8 解码为文本。

例如，"66"对应ASCII的102，即字符'f'。

因此，这题的处理是十六进制到字节，再按 UTF-8 解码。

```
def hex_to_ascii(hex_str):
    """十六进制转ASCII（解答CTF题目）"""
    bytes_obj = bytes.fromhex(hex_str)
    return bytes_obj.decode('utf-8')

cipher = "666c61677b616537333538376261353662616566357d"
print(f"解密结果：{hex_to_ascii(cipher)}")
```

解密结果：`flag{ae73587ba56baef5}`

还原出来的文本能回头对应原字节，这条来回关系就是很好的校验。短题也值得记下判断依据，否则只记一句“hex解码”，下一次遇到相似外观还是可能选错方向。
