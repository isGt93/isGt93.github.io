ailx10说：这篇是在2023年8月之前写的，后来又改过。那次试一款桌管，我先把管理端和终端装起来，再对着自己的测试电脑看它能拿到哪些信息。聊天、截图、U 盘和各种管控功能一项项点过去，才发现“企业管理”四个字下面其实塞了不少具体能力。我把十二类功能和当时观察到的界面整理下来，也聊到工作设备上的隐私。这篇不是站在远处猜工具能做什么，而是一次走进控制台后的使用记录：以前听过的功能，到了测试现场，才有了能对应起来的画面。

---

1、我先在老板电脑上安装桌管服务器端，安装完要重启电脑（老板电脑）

![](/notes-assets/1a6a0e68017ea1f0608e.webp)

2、然后再安装管理端，要输入本机IP地址（也是老板电脑），至此老板端安装完成

![](/notes-assets/2ad66cdcffaad0d373dd.webp)

3、最后给员工电脑安装桌管的终端，要输入管理端IP地址（员工电脑），安装完要重启电脑

![](/notes-assets/28746015cef8fea37d41.webp)

4、现在老板请睁眼，立马开启了天眼，打开终端安全管理系统（桌管），输入账号名（admin），密码（admin）

![](/notes-assets/aa797f92fc464e46460a.webp)

5、老板能看到员工电脑的一举一动，包括

| 编号 | 功能 |
| --- | --- |
| 1 | 终端信息 |
| 2 | 实时画面 |
| 3 | 多画面管控 |
| 4 | 屏幕管控 |
| 5 | 上网管控 |
| 6 | U盘管控 |
| 7 | 邮件管控 |
| 8 | 程序管控 |
| 9 | 文件管控 |
| 10 | 运维管理 |
| 11 | 资产管理 |
| 12 | 监控统计 |

6、最终效果呈现：微信/QQ监控的画面如下图所示，直接截屏聊天内容，辛苦出境的朋友们了

![](/notes-assets/8c0a3dcd13b620f08610.webp)

7、U盘监控的画面如下图所示，员工偷偷拷贝电脑文件出去，老板也是了如指掌

![](/notes-assets/2768ac424bd8289daa9d.webp)

最可气的是，桌管还是合法的，有些公司明目张胆给员工的电脑里安装监控。最后，想说的是，有些桌管客户端程序，可以被杀毒软件查杀出来，所以，一定要确保电脑上运行杀毒软件。

监控范围会随权限和配置变化，界面上的开关也不是所有场景的证据。把能力、使用范围和告知方式讲清，才有可能认真讨论企业管理与个人隐私。
