ailx10说：这篇是2022年1月之前写的，后来又改过。换了一本Spark相关的书，我原本还有点担心：前一本用的构建方式跟这本不同，代码风格也不一样，估计又得折腾一阵。没想到这个翻译小例子一下就跑起来了，当时还挺高兴。它的做法是读入一本英文文本，加载简单词典，再把每行拆开、替换词语、拼回去，让我把SparkConf、SparkContext和map这些东西又串了一遍。标题当时放进了Streaming系列，但代码本身是读文件的RDD批处理，还没到真正持续接收流的那一步。这份笔记保留的，就是从准备开新坑到先跑通一个小程序的那一段。

我们来看一个简单的Spark Streaming书本翻译的例子：

1. 每一个Spark应用程序都会用到一个SparkConf类型的配置对象
2. 与Spark集群保持连接主要靠SparkContext对象
3. 从一本叫hack.txt的书中创建一个RDD，命名为book
4. 每个RDD对象都有一组转换函数
5. map转换将每行进行分词，翻译单词后再组合成句子
6. 这个翻译是利用在线资源生产的词典来翻译的，它为简单的英文单词翻译成目标单词

```
import org.apache.spark.{SparkConf, SparkContext}

import scala.io.Source

object TranslateApp {

  def getDictionary(lang:String):Map[String,String] = {
    if (!Set("German","French","Italian","Spanish").contains(lang)){
      System.err.println("不支持翻译")
      System.exit(1)
    }
    val url = "http://www.june29.com/IDP/files/%s.txt".format(lang)
    println("抓取内容:%s".format(url))
    Source.fromURL(url,"ISO-8859-1").mkString
      .split("\r?\
")
      .filter(line=> !line.startsWith("#"))
      .map(line=>line.split("\	"))
      .map(tkns=>(tkns(0).trim,tkns(1).trim)).toMap
  }

  def main(args: Array[String]): Unit = {
    val appName = "AILX10"
    val bookPath = "C:\study\spark\streaming\hack.txt"
    val outputPath = "C:\study\spark\streaming2"
    val lang = "German"

    val dict = getDictionary(lang)

    val conf = new SparkConf()
      .setAppName(appName)
      .setJars(SparkContext.jarOfClass(this.getClass).toSeq)
      .setMaster("local")

    val sc = new SparkContext(conf)
    val book = sc.textFile(bookPath)
    val translated = book.map(line => line.split("\s+")
      .map(word=>dict.getOrElse(word,word)).mkString(" "))
    translated.saveAsTextFile(outputPath)
    println("翻译完成~")

  }

}
```
