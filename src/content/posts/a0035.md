ailx10说：这篇是在2019年12月之前写的，后来又改过。工作里要用正则，我就一边查资料一边把常用写法记下来，最早还在笔记里标了 2018 年 5 月的日期。开始只是字符类、数量和分组，后来碰到反向引用、前后向断言，再顺手补了贪婪、懒惰和括号匹配之类的例子。它不是一本按部就班的教材，更像放在手边反复添东西的小抄。读的时候别只抄符号，最好把自己的输入拿来试一试；尤其像平衡组这样的写法还挑引擎，当年能用的例子，换个环境不一定照样成立。

---

正则表达式用模式描述文本。不同引擎的语法和行为并不完全相同；下面的示例以 Python `re` 的字符串模式为准。

## 字符、数量和边界

| 写法 | 含义 |
| --- | --- |
| `\d` | 数字字符；Unicode 模式下不只包含 ASCII 数字 |
| `\w` | 字母、数字和下划线等单词字符；具体范围与模式有关 |
| `\s` | 空白字符，包括空格、制表符和换行等 |
| `.` | 默认匹配除换行外的任意单个字符 |
| `*`、`+`、`?` | 前一项分别重复零次或多次、一次或多次、零次或一次 |
| `{n}`、`{n,m}` | 前一项重复指定次数或指定范围 |
| `^`、`$` | 字符串边界；多行模式下也与行边界有关 |

字符类 `[aeiou]` 匹配其中一个字符，`[^x]` 匹配任意一个不是 `x` 的字符。它不是“匹配不以 x 开始的字符串”。

## 分组与引用

`(ab)+` 将 `ab` 作为一组重复；`(?:ab)+` 同样分组，但不保存捕获结果。`(\w+)\s+\1` 可以匹配相邻的重复单词，例如 `hello hello`。

## 前瞻和后顾

断言只检查当前位置的上下文，不消费字符。对 `singing` 使用 `\w+(?=ing\b)`，匹配到 `sing`；`(?<=re)\w+` 可以在 `reading` 中匹配 `ading`。`(?!exp)` 和 `(?<!exp)` 是相应的否定形式。Python 的后顾断言要求固定宽度，其他引擎规则可能不同。

## 贪婪和非贪婪

在 `aabab` 中，`a.*b` 默认尽量多匹配，结果是 `aabab`；`a.*?b` 尽量少匹配，第一次结果是 `aab`。是否找到其他匹配取决于使用的搜索 API。

## 验证 IPv4 的简单方法

`(?:\d{1,3}\.){3}\d{1,3}` 只能检查形式，不能拒绝 `999.999.999.999`。对 Python 程序，优先使用标准库 `ipaddress.IPv4Address` 做完整验证。不要将一种引擎的平衡组语法直接复制到另一种引擎。

参考：[Python re 文档](https://docs.python.org/3/library/re.html)、[ipaddress 文档](https://docs.python.org/3/library/ipaddress.html)。

同一条表达式最好既有能匹配的例子，也有不该匹配的例子。把输入、命中位置和引擎写在一起，回头查时就不是猜那串符号，而是重看当时验证过的行为。
