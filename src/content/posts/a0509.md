ailx10说：这篇是在2019年12月之前写的，后来又改过。MyMap 是我当时给自己开的一个小项目，想从零拼出区域 IP 情报的雏形。先随机取地址，查位置，调用扫描模块，再塞进 Elasticsearch；每个部分都不大，串起来却要照顾不少接口和数据格式。demo 跑了两天，才攒下几千条记录，离想象中的规模还很远。这篇就是最早那版积木式搭建过程，既留下跑通的部分，也留下速度慢这个马上逼着我改设计的问题，后面的几篇也正是从这里长出来的。

---

MyMap001分IP生成、国内定位API、python-nmap探测、旧ES mapping存储并主循环串联，2天约4000条，计划关联分析。

## 技术条件和待核查点

所谓随机实际从0顺序枚举含特殊地址，run示例与主runIp返回接口不一致，MyAddr导入未使用；资产数据库不自动威胁情报或1day武器。

## 原实验与代码

MyMap是一款区域IP威胁情报系统，是我自己开发的，当前demo版本已经可以正常运行，后期会添加更丰富的功能。

> 初衷是想设计一个1day威胁情报武器 --by ailx10

- 地址生成模块（原代码需核对，历史示例按顺序生成地址）
- 地图模块(获取IP地址对应的地理位置，只分析国内)
- 扫描模块(扫描IP地址的开放端口和OS服务)
- 存储模块(es)
- 关联分析

import sys

from time import sleep



def run():

    getipaddr = lambda x: '.'.join([str(x/(256**i)%256) for i in range(3,-1,-1)])

    i = 0

    while(i <= sys.maxint):

        ip = getipaddr(i)

        i += 1

        sleep(1)

        print ip





if __name__ == "__main__":

    run()

最后，写一个主函数，把所有模块串起来。

```
import MyAddr

import MyEs

import MyIp

import MyScan



def runMain():

    es = MyEs.ESOBJ('gut','gut_type',"192.168.0.103:9200")

    while 1:

        ip = MyIp.runIp()

        info = MyScan.runScan(ip)

        if len(info) > 0:

            es.index_info(info)







if __name__ == "__main__":

    runMain()
```
