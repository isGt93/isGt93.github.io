ailx10说：这篇是我2024年9月写的。做项目演示那阵子，我把挖矿从模拟程序一路试到真实 XMRig，也换过直连、端口转发和代理矿池。以前习惯用模拟数据，这次能碰完整运行过程，感觉许多告警字段终于有了实际画面。顺手准备了一个 Python 监护程序，检查进程、不在就启动，再打包配定时任务，虽然后来暂时没用上，还是先记下来。它像一份项目抽屉里的备件笔记：不是每个准备都会立刻出场，但自己走过一遍，下一回需要演示就知道怎样接起来。

---

（1）创建计划任务，每3分钟启动一次【模拟挖矿监控程序】，需要管理员权限运行

```
@echo off
REM 设置控制台编码为UTF-8
chcp 65001 >nul

REM 获取当前用户名
SET USERNAME=%USERNAME%

REM 创建定时任务
schtasks /Create /TN "Run1ExeEvery3Minutes" /TR "C:	mp\monitor_xmrig.exe" /SC MINUTE /RU "%USERNAME%" /RL HIGHEST /MO 3

REM 检查任务是否创建成功
IF %ERRORLEVEL% EQU 0 (
    echo 任务 "Run1ExeEvery3Minutes" 已成功创建。
) ELSE (
    echo 任务 "Run1ExeEvery3Minutes" 创建失败。
)

PAUSE
```

原程序按进程名判断是否启动 XMRig；同名进程不证明身份可信或运行健康。

原计划任务路径中的反斜杠可能被文本提取解释为制表符，应核对原始配置。

```
# -*- coding: utf-8 -*-
import time
import psutil
import subprocess
def is_process_running(process_name):
    for proc in psutil.process_iter(['pid', 'name']):
        if proc.info['name'] == process_name:
            print("proc={}".format(proc))
            return True
    return False

def start_process(exe_path):
    try:
        proc = subprocess.Popen([exe_path], shell=True)
        print(f'Started {exe_path}, Process ID: {proc.pid}')
    except Exception as e:
        print(f'Failed to start {exe_path}: {e}')

if __name__ == '__main__':
    process_name = 'xmrig.exe'
    exe_path = r'C:	mp\xmrig.exe'

    if not is_process_running(process_name):
        print("进程不存在,启动")
        start_process(exe_path)
        print("运行成功")
    else:
        print("进程存在，程序退出")
```

（4）进程不存在启动挖矿程序，矿池是代理地址

![](/notes-assets/9f81ac9716a86b9a680a.webp)

原文的收益估算只适用于当时个人场景；进程启动不代表成功挖矿。

![](/notes-assets/913d97107f8305389f97.webp)

同名进程不一定可信，成功创建进程也不等于持续工作。为每层留下状态和失败记录，演示才有可重复观察的结果，而不是只能碰巧成功一次。
