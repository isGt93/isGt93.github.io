## 一、FPGrowth关联规则算法简介

我以前写了一个专利，说的是背景流量的波动，对安全事件集发生的关联影响，说实在的，差不多用的就是FPGrowth关联规则的思想。只不过我加入了条件概率，让专利看起来更加的有说服力。很多时候，我们缺少的是钻研问题的恒心，也怪人间太浮躁，悠悠鹿鸣应何依，文章自古无消息，富贵于今是故稀\~

**1、项与项集**

其实FPGrowth关联规则解决的问题很简单，就是研究项集中元素组合的最大出现概率\~

- 项：{“啤酒”}
- 项集：{“啤酒”，“尿布”}

**2、关联规则**

- `X` 的发生，伴随着 `Y` 的发生
- 购买尿布的消费者往往会购买啤酒
- 关联的强度用3个概念度量，分别是支持度、置信度、提升度

**3、支持度**

- 支持度 support(X∪Y) 是同时包含 X、Y 的交易比例，即 P(X∩Y)。
- 通过设定最小阈值，剔除出镜率低的无意义组合
- 所有数据中假设 `X` 出现了80次， `Y` 出现了100次，那么支持度为0.8

**4、置信度**

- 置信度 confidence(X→Y) 是包含 X 的交易中同时包含 Y 的比例，即 P(Y\|X)。
- 有100个数据，其中60个数据，同时出现了 `X` ， `Y` ，那么置信度为0.6

**5、提升度**

- 提升度 lift(X→Y) \= P(Y\|X) / P(Y)，反映共现相对基准频率的变化。
- `提升度=\frac{置信度}{支持度}=\frac{0.6}{0.8}`

## 二、FPGrowth关联规则算法实战

- 下载地址：[github机器学习数据集](https://raw.githubusercontent.com/apache/spark/master/data/mllib/sample_fpgrowth.txt)
- 这里假设有6个人，每个人的购物车里买的不一样的字母

![](/notes-assets/66b00023eb7f6dc414f5.webp)

- 通过FPGrowth算法计算，发现支持度最大只有0.5，最小也有0.33
- 发现喜欢买x的人，也喜欢买y和z，那么可以把x、y、z放在一起
- 也就是说如果x发生了，那么很有可能y和z也会一起发生，很有用的性质哟\~

```
[x,z], 3
[y,x], 3
[y,x,z], 3
```

![](/notes-assets/c2359f5556ff1c5e98fc.webp)

    // 构建Spark 对象
    Logger.getLogger("org.apache.spark").setLevel(Level.ERROR)
    val conf = new SparkConf().setAppName("HACK-AILX10").setMaster("local")
    val sc = new SparkContext(conf)
    // 读取样本数据
    val datapath = "C:\study\spark\sample_fpgrowth.txt"
    val data = sc.textFile(datapath)
    val parsedData = data.map(_.split(" ")).cache()

    //建立FPGrowth模型，并设置训练参数
    val model = new FPGrowth()
      .setMinSupport(0.2)
      .setNumPartitions(10)
      .run(parsedData)

    //打印结果
    println("项集个数： "+ model.freqItemsets.count())
    model.freqItemsets.collect().foreach {
      item => println(item.items.mkString("[",",","]") + ", " + item.freq)
    }
  }
}
