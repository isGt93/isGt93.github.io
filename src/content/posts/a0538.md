ailx10说：这篇是在2022年7月之前写的，后来又改过。换到新安全公司三周后，我慢慢找到工作节奏，同事又分享了他自己用 C# 写的 BlueHound。听说能查内存里的 Beacon，我就把虚拟机里的样本拿来试，WebShell 扫描先崩了，另一种已上线样本则能在扫描和 MemHunter 里找到可疑进程。这篇保留了两种不同结果，也记了 Win7 的 .NET 依赖。新环境带来新工具，真正有意思的是亲手看一遍：同事介绍里的能力，到了自己这组机器和样本上，会以什么样子出现。

---

首先检查一下环境，win10或.net4.6\+win7，这里我使用的是win10，自带来.net4.6，如果是win7环境，需要安装.net4.6，建议都试一下，我的win10很遗憾，在webshell扫描的过程中出问题了～

```
reg query "HKLM\SOFTWARE\Microsoft\Net Framework Setup\NDP" /s
```

![](/notes-assets/f0c4da333e9aad516732.jpg)

第一个功能：Webshell扫描，这里不知道为什么，运行扫描程序就挂掉了，使用的是管理员权限，暂且忽略吧～

![](/notes-assets/3f7450af50a7d45a2dda.jpg)

第二个功能：beacon扫描，接下来我们测试一下Beacon，这里需要先构造一个C2连接，上CS脚本小子～

![](/notes-assets/f90be93477075dd09307.jpg)

使用Beacon扫描进程，确实发现咱们的artifact.exe存在beacon

![](/notes-assets/fcb902857c985ad7a10a.jpg)

第三个功能：扫描进程内存中是否被注入可疑PE文件，使用MemHunter扫描，同样发现artifact进程异常～

![](/notes-assets/407256745e9bbd618a86.jpg)

一入安全深似海，从此休息是路人，活到老，学到老，一点没错～
