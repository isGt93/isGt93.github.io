ailx10说：这篇是2022年7月之前写的，后来又改过。试过 nc 后，我又用 socat 做同样的 SSH 转发，加上 reuseaddr 和 fork，再拿 Mac 上的一张图片传到 Kali。一个工具同时连文件和网络，参数刚看挺长，拆开却是两端各是什么对象、按什么方式传数据。文章把双向转发和单向传文件放在一起，正好能看出 -u 的作用。对我来说，这是把“万物都能接一下”的印象变成几个具体例子；能送到对面只是功能通了，是否需要认证和加密，仍然得另外设计。

---

> nc是net cat ， socat 是socket cat，名字相似，功能相似

实验环境：

- macos：192.168.199.206
- kali：192.168.199.247
- centos：192.168.199.236

实验一：本地转发

```
socat TCP-LISTEN:8888,reuseaddr,fork TCP:127.0.0.1:22
```

从黑客视角看一看抓包

实验二：远程端口转发，换个IP地址即可


彩蛋：使用socat 将一个小文件从macos传递到kali

1、在macos上操作

```
socat -u open:黑客0717.png tcp-listen:7777,reuseaddr
```

2、在kali上操作

```
socat -u tcp:192.168.199.206:7777 open:黑客0717.png,create
```

3、检查，成功拿到「“黑客0717”这张图片」

![](/notes-assets/4a9d2b2bff603cef69b2.jpg)

图片能传到另一边，是一个清楚的结果；是否需要认证、是否暴露明文，则是另外的问题。方便的管道不自动变成安全的管道，这点在选工具时就值得想好。
