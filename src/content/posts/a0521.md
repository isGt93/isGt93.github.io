ailx10说：这篇是在2022年1月之前写的，后来又改过。我常把自己电脑上能跑的小东西发给别人，结果不是缺依赖，就是少环境变量，折腾一圈又回到“在我这里没问题”。所以这回搭 MulVAL，我想顺便把 Docker 也认真用起来，把 JDK、MySQL、XSB 和工具都放进同一个环境。中间换源、装依赖，还得记得保存进度，最后看到攻击图生成，才算把这套东西接通。这篇写的是一次从“环境总打架”走向可重复实验的尝试，攻击图怎么用，则留给下一步继续聊。

---

Docker 可帮助封装依赖，但运行仍受主机架构、镜像、网络和配置影响。本文记录在历史 Ubuntu 容器中安装 MulVAL 和生成图的过程。

上一次接触docker已经是一年前了，当时刚刚加入态势感知组，Boss要我做一个SQL注入语义引擎，提供restfulAPI，然后我就开始捣鼓基于C语言的restful框架，令人意外的是，一个星期就搞定了，通过docker进行交付，完美\~

---

准备工作：Win10专业版（家庭版不支持docker）

首先安装docker的时候，网速就慢的一比，实在没法看，于是选择国内镜像下载，首选阿里云，下载好之后，选择一个你想安装的ubuntu版本，比如我选择的就是ubuntu16.04

- 安装ubuntu16.04

![](/notes-assets/33e1a75ea7c05f617af4.webp)

- 进入ubuntu16.04

![](/notes-assets/056789a6680254955bcf.webp)

- 查看源，发现都是国外源，速度非常慢，因此我们需要更换成国内源，这里我使用的阿里源

```
deb http://archive.ubuntu.com/ubuntu/ xenial main restricted
deb http://archive.ubuntu.com/ubuntu/ xenial-updates main restricted
deb http://archive.ubuntu.com/ubuntu/ xenial universe
deb http://archive.ubuntu.com/ubuntu/ xenial-updates universe
deb http://archive.ubuntu.com/ubuntu/ xenial multiverse
deb http://archive.ubuntu.com/ubuntu/ xenial-updates multiverse
deb http://archive.ubuntu.com/ubuntu/ xenial-backports main restricted universe multiverse



deb http://security.ubuntu.com/ubuntu/ xenial-security main restricted
deb http://security.ubuntu.com/ubuntu/ xenial-security universe
deb http://security.ubuntu.com/ubuntu/ xenial-security multiverse
```

- 首先把最后几行删掉，因为我们还没有vim，只能使用sed命令

![](/notes-assets/92fa26d802952f5086e4.webp)

- 然后通过sed直接进行字符替换，这样我们成功的换成阿里源了

```
sed -i s@/archive.ubuntu.com/@/mirrors.aliyun.com/@g /etc/apt/sources.list
```

![](/notes-assets/02a43b9c0e56f5bb1fa6.webp)

- 现在就可以愉快的安装软件了

![](/notes-assets/8214e5ef16e2e00b5f19.webp)

- 安装java1.8

![](/notes-assets/6b6f08a09420649ab548.webp)

- 安装mysql

```
apt-get install mysql-server
apt install mysql-client
apt install libmysqlclient-dev
```
