ailx10说：这篇是我2024年7月写的。重装 Ubuntu 后，自己的 VPS 偏偏从本地连不上 SSH，换另一台 VPS 去连，同一个 22 端口又是通的，实在让人摸不着头脑。来回试了几轮，最后改了 sshd 的端口、重启服务，本地才终于接上。我把配置和操作顺序留下，省得以后重装又碰一次同样的坎。它没有复杂理论，就是一次“别处能连、我这里不能连”的排错经历；问题最终绕过去了，也能看见当时我是怎样对比不同入口，慢慢把注意力从服务本身移到连接路径上的。

---

本地无法使用Termius连接，但是从另一台vps却能SSH连接该vps的22端口，感觉很奇怪。

更换端口是这次环境中的绕行办法，不能推断所有 SSH 22 端口不可用。应依次检查服务监听、防火墙、网络路径和客户端日志。

我在另一台vps上，通过22端口，远程连接上这台vps。

（1）修改sshd的配置文件，将默认的端口`Port 22`修改成`Port 20242`

```
vim /etc/ssh/sshd_config
```

（2）重启SSH服务

```
systemctl restart sshd
```

（3）本地Termius连接，成功连接

![](/notes-assets/eb149d289c50d7e3d1ab.webp)

换端口让这次连接通了，却没有自动解释原来的故障。保留监听、服务和访问规则的排查线，下一次再遇到类似问题就不必只靠换个数字碰运气。
