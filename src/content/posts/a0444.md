ailx10说：这篇是2022年1月之前写的，后来又改过。前面拿到 NTDS 和 SYSTEM 文件，这篇终于把它们带到离线工具里处理。Linux 上用 secretsdump，Windows 上再看 NTDSDumpEx，得到散列后又回去试远程认证。文件、密钥、输出和后续访问这样接起来，之前抽象的“域凭据”才变成了一段能追的流程。它也让我重新看前面失败的哈希传递：一次没通并不代表方法已经失效。笔记最想留下的是每种材料在何处被使用，散列不是明文，能代表某个身份，也仍然受那个身份的权限限制。

---

## 今天的主题是：导出散列值

- 使用impacket工具包导出散列值（Linux）
- 使用NTDS Dumpex 导出散列值（Windows）

但是在开始之前，我们需要做一些准备工作，一个是`ntds.dit`活动目录文件，另一个是`system.save`文件， 可以通过HiveJack这个小工具轻松获得，github上可以下载。

![](/notes-assets/56299768a6b57ac1c705.webp)

原文使用 NTDS 与对应 SYSTEM.save 尝试导出散列；结果取决于文件完整性与工具版本。

```
impacket-secretsdump -system system.save -ntds ntds.dit LOCAL
```

![](/notes-assets/117e16d29c66bf139954.jpg)

---

如果在windows下，可以通过 NTDS Dumpex 进行导出散列值的操作，需要的依然是`system.save`文件、`ntds.dit`活动目录文件。

```
.\NTDSDumpEx.exe -d .\ntds.dit -s .\system.save
```

![](/notes-assets/ace440941f8ff1ea9dda.jpg)

---

原文报告利用得到的散列访问远程资源；散列不是明文，获得一个域用户凭据也不自动取得域控管理权限。

```
mimikatz "privilege::debug" "sekurlsa::pth /user:ailx32 /domain:hackbiji.top /ntlm:01c3a7ef8461fa07943fb2b50e5752aa
```

![](/notes-assets/3b9ef204ba7fa06b1c8d.jpg)![](/notes-assets/2eb6630a22203e245cff.webp)
