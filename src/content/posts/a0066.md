ailx10说：这篇是我2022年1月写的。那阵子在投稿，论文里的图被要求改成 EPS 或 PDF，本来以为导出一下就好，偏偏图里有中文，字体问题让我折腾了两三个小时。最后换着查 FontProperties 和 PdfPages，终于把坐标、标题、图例一起处理好，这才顺手记下做法。这种小问题最适合留笔记：代码不长，隔一阵再遇到却未必记得坑在哪儿。当时我还挺享受把研究变成论文、专利的过程，而这篇留下来的，就是成果背后一次很具体、也很普通的排版补课。

导出图表时，中文显示依赖可用的中文字库；字体文件路径错误或文件不可读可能导致字体加载失败。以下示例用 `FontProperties` 为标题、坐标轴和图例指定同一个字体，并通过 `PdfPages` 导出 PDF。

```python
from pathlib import Path
import matplotlib.pyplot as plt
from matplotlib.backends.backend_pdf import PdfPages
from matplotlib.font_manager import FontProperties

font_file = Path("SourceHanSansCN-Bold.ttf")
if not font_file.is_file():
    raise FileNotFoundError(f"字体文件不存在: {font_file}")
zhfont = FontProperties(fname=str(font_file))

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 4, 9], label="数据")
ax.set_title("示例图表", fontproperties=zhfont)
ax.set_xlabel("横轴", fontproperties=zhfont)
ax.set_ylabel("纵轴", fontproperties=zhfont)
ax.legend(prop=zhfont)
with PdfPages("chart.pdf") as pdf:
    pdf.savefig(fig, bbox_inches="tight")
plt.close(fig)
```

运行前将字体文件放在工作目录，或把 `font_file` 改为有效路径。这个例子展示一种 PDF 输出方式，不表示转换为 PDF 能解决所有字体问题；还应打开生成文件，检查中文字形、图例和符号是否完整。需要输出 EPS 时，应分别核对后端与字体设置。

参考：[Matplotlib PdfPages](https://matplotlib.org/stable/api/backend_pdf_api.html)、[字体属性](https://matplotlib.org/stable/api/font_manager_api.html)。

PDF成功生成以后，最后一步仍是打开看看。文件存在和文字完整是两回事；把当时可用的字体配置留下来，下回赶论文图时至少不用从同一个坑重新开始。
