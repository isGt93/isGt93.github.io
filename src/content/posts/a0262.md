ailx10说：这篇是2024年9月之前写的，后来又改过。终于把这一轮 Struts2 实验做完，我给自己写了个合集。工具里有些模块可以直接出结果，网上也有号称覆盖很多编号的脚本，但我还是用 Burp 一个个重放，想知道每个入口究竟差在哪。合集不是新的成功故事，而是这段练习的路标：调试、参数、重定向、标签、插件，各自有自己的条件。回头整理时也得记得，S2-052 走的是 XML 对象处理，不能因为大多数是 OGNL，就把例外也一笔带过去。

---

| 线索 | 阅读重点 |
| --- | --- |
| 参数处理与表达式回填 | 输入在哪里进入后续求值，是否需要特定验证失败路径 |
| 命名空间与重定向 | action、namespace 等配置是否满足触发条件 |
| 模板与标签属性 | 用户数据是否进入后续表达式解析，而不仅是普通模板插值 |
| REST 与 XStream | XML 反序列化对象链和运行环境，不能统称 OGNL |
| 沙盒绕过 | 可访问对象、排除规则和具体版本 |

练习时应记录实验版本、入口配置、完整请求、响应及独立验证结果；HTTP 状态码不一定单独证明执行成功。原系列中的脚本和截图属于历史材料，未在本索引中重新验证。

索引能缩短查找，不能替代每篇自己的版本与配置条件。带着一个具体问题回到手工请求，再用工具作对照，这份合集才真正把零散实验连成了知识。
