ailx10说：这篇是2019年12月之前写的，后来又改过。这篇我决定用 Python 登录自己搭的 MYZOO，不再让浏览器替我完成所有事。先发登录请求拿 Cookie，再去提交个人资料、查询用户，一轮轮把 GET、POST 和会话串起来。真动手后才发现，登录成功只是开头，后续请求有没有带上新状态、连接何时关闭，都会影响结果。我把这些小程序和网站代码对着写，像给自己的 Web 基础做一次体检。学爬虫和搭网站在这里碰到了一起，也让我对抓包里那些头字段多了一点实际感觉。

原代码以固定响应头下标取 Cookie，返回值与请求头更新逻辑有疑点；连接复用需实测。

本文记录 Python 客户端登录 MYZOO 教学网站、更新个人资料和查询的历史示例。

示例主要包含以下 GET 和 POST 操作：

> login 函数：用来登录，获取cookie和connect句柄  
> profile 函数：一个POST请求，用来更新数据库中的个人简介  
> query 函数：一个GET请求，用来向数据库查询个人ZOOBAR信息

代码实现登录、资料更新和查询；原正文虽提到退出，代码中没有独立退出函数。

理解请求、会话与服务端状态有助于学习 Web 安全。

> 1.会自己搭建网站  
> 2.会写爬虫访问自己的网站

先在自有实验环境复现正常登录与查询，观察响应和 Cookie。

学习建议：

理解请求方法、响应状态及 Cookie 生命周期。

比较登录前后服务端响应。

记录具体环境和结果。
