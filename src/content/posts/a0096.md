ailx10说：这篇是在2024年4月之前写的，后来又改过。这周在自己电脑上试 netsh，才发现保存过的 WiFi 配置比想象中留下更多痕迹。列表里一眼就能看见曾住过的酒店和租房网络，再查看具体配置，某些条件下连明文密钥也能显示。我就顺着把查询和删除配置的操作记下来，心里也重新掂量了一下，借用、转手一台电脑时究竟会留下什么。这篇不是让人去翻别人的密码，而是一次在自己机器上做检查的提醒：那些平时不用管的连接记录，拼在一起也可能勾出生活路线。

---

Windows 可以保存已配置的无线网络信息。检查自己的电脑时，可以在命令提示符运行：

```cmd
netsh wlan show profiles
netsh wlan show profile name="网络名称"
```

如果需要查看自己拥有的网络的密钥，在具备相应权限且该配置类型支持的情况下，可使用 `netsh wlan show profile name="网络名称" key=clear`。命令输出可能暴露敏感凭据，不要截图分享或粘贴到公开日志。

不再需要某个配置时，可以通过系统设置中的“忘记”操作，或在确认名称后使用：

```cmd
netsh wlan delete profile name="网络名称"
```

配置列表可能由用户、策略或设备管理创建；看到某个名称不等于能可靠证明用户曾在某个地点连接，删除配置也不意味着其他系统日志已清除。不同认证方式和权限下可查看的内容不同。

参考：[Microsoft netsh wlan 文档](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/netsh-wlan)。

清理一个配置，是修改了这一处保存状态，不是让所有历史消失。把查看和删除的范围说清楚，日常排查时既能找到线索，也不会高估自己已经清理了多少信息。
