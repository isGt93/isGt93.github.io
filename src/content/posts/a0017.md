## **探索C语言的可变长参数**

C语言标准库中头文件stdarg.h索引的接口包含了一组能够遍历变长参数列表的宏。 主要包含下面几个：

1. va\_list 用来声明一个表示参数表中各个参数的变量
2. va\_start 初始化一个指针来指向变长参数列表的头一个变量
3. va\_arg每次调用时都会返回当前指针指向的变量，并将指针挪至下一个位置，va\_arg根据第二个参数类型来判断偏移的距离
4. va\_end需要在函数最后调用，来进行一些清理工作

观察my\_print函数是如何实现可变长参数的?

```
root@gt:/home/git/myRubbish/seedlab# ./a.out 
3.500000 
4.500000 5.500000 
root@gt:/home/git/myRubbish/seedlab# cat live5_func_arg.c 
#include <stdio.h>
#include <stdarg.h>
int myprint(int Narg,...)
{
	va_list ap;
	int i;
	va_start(ap,Narg);

	for(i = 0;i < Narg;i++)
	{
		//printf("%d ",va_arg(ap,int));
		printf("%f ",va_arg(ap,double));
	}
	printf("
");
	va_end(ap);
}

int main()
{
	myprint(1,2,3.5);
	myprint(2,3,4.5,4,5.5);
	return 1;
}
```

## **格式化字符串攻击的应用**

1\. 在特定内存布局下，格式化字符串漏洞可能影响控制数据或程序状态。

2\. 实际影响取决于内存布局、权限和已有防护。

3\. 变量被意外修改可能改变程序逻辑；这不等同于竞争条件。

中间那些没读对、没写对的尝试，不是题解里的废话。它们把地址布局、参数解释和输出计数的问题暴露出来，沿着失败回头找，往往比照抄一次成功输出更接近理解。
