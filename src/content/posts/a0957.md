ailx10说：这篇是在2018年11月之前写的，后来又改过。前面做二分类顺手，我又想拿手写数字试试贝叶斯的多分类表现。把 MNIST 图片展开成七百多维像素，标签从零到九，数据拼好、交叉验证跑完，结果只有五成多，和想象里的“能自动认验证码”差了一截。我就把这点不理想也留下，没有只换个题目把它藏过去。它是这轮算法比较里很重要的一次碰壁：同样一套训练流程，换到图像，模型并不会因为前面好用就继续给好成绩，任务和输入方式都得重新考虑。

---

MNIST 是手写数字数据集，不是实际验证码测试集。

## 1.数据搜集和数据清洗

原文将部分训练与测试数据合并后做三折验证，失去了原始独立测试基准。

```
    training_data, valid_data, test_data=load_data()
    x1,y1=training_data
    x2,y2=test_data
    
    x = np.vstack((x1,x2))
    y = np.hstack((y1,y2))
```

## 2.特征化

图片的像素28x28（784），MNIST已经将图片像素转换成一维向量（1x784），

## 3.训练模型

实例化NB算法：

```
clf = GaussianNB()
```

## 4.效果验证

60000数据，采用3折交叉验证：

```
score = cross_validation.cross_val_score(clf, x, y, n_jobs=-1,cv=3)
print score
print np.mean(score)
```

原文报告约 55.5%，仅说明该模型和预处理在本次数据上的表现。

## 5.完整代码

```
import re
import matplotlib.pyplot as plt
import os
from sklearn.feature_extraction.text import CountVectorizer
from sklearn import cross_validation
import numpy as np
from sklearn.naive_bayes import GaussianNB


import pickle
import gzip


def load_data():
    with gzip.open('../data/MNIST/mnist.pkl.gz') as fp:
        training_data, valid_data, test_data = pickle.load(fp)
    return training_data,valid_data,test_data


if __name__ == '__main__':
    training_data, valid_data, test_data=load_data()
    x1,y1=training_data
    x2,y2=test_data
    
    x = np.vstack((x1,x2))
    y = np.hstack((y1,y2))

    clf = GaussianNB()
    score = cross_validation.cross_val_score(clf, x, y, n_jobs=-1,cv=3)
    print score
    print np.mean(score)
```

低分也能留下清楚的比较起点。只要把原数据划分和评价范围保存好，后面换逻辑回归或神经网络时，才有机会知道差异来自方法，还是来自实验安排。
