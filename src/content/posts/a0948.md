ailx10说：这篇是2018年11月之前写的，后来又改过。POP3 爆破这篇，我先从 KDD99 里筛正常和 guess\_passwd，再选连接长度、字节数和短时间统计等字段，训练决策树并把树画出来。以前讲暴力尝试，总盯着一条登录请求，这次换数据集后，模型看到的是一组连接特征。十折结果很高，我仍把取样和字段留在旁边，不想只贴百分比。这个练习让我把“什么行为可能有差别”转成程序里的输入，也方便回头顺着分支看看，树是不是在用我预期的信息作判断。

## 5.完整代码

```
import re
import matplotlib.pyplot as plt
import os
from sklearn.feature_extraction.text import CountVectorizer
from sklearn import cross_validation
from sklearn.datasets import load_iris
from sklearn import tree
import pydotplus
import numpy as np

def load_kdd99(filename):
    x=[]
    with open(filename) as f:
        for line in f:
            line=line.strip('
')
            line=line.split(',')
            x.append(line)
    return x

def get_guess_passwdandNormal(x):
    v=[]
    w=[]
    y=[]
    for x1 in x:
        if ( x1[41] in ['guess_passwd.','normal.'] ) and ( x1[2] == 'pop_3' ):
            if x1[41] == 'guess_passwd.':
                y.append(1)
            else:
                y.append(0)

            x1 = [x1[0]] + x1[4:8]+x1[22:30]
            v.append(x1)

    for x1 in v :
        v1=[]
        for x2 in x1:
            v1.append(float(x2))
        w.append(v1)
    return w,y

if __name__ == '__main__':
    v=load_kdd99("../data/kddcup99/corrected")
    x,y=get_guess_passwdandNormal(v)
    clf = tree.DecisionTreeClassifier()
    score = cross_validation.cross_val_score(clf, x, y, n_jobs=-1, cv=10)

    print score
    print np.mean(score)

    clf = clf.fit(x, y)
    dot_data = tree.export_graphviz(clf, out_file=None)
    graph = pydotplus.graph_from_dot_data(dot_data)
    graph.write_pdf("iris-dt.pdf")
```

很高的总准确率仍可能被多数类撑起来，历史数据也不等于现场流量。补上类别指标与特征采集条件，这个实验才有机会接近真实部署的问题。
