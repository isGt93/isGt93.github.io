## 2.训练RNN网路

照猫画虎，一些有必要掌握的函数，

序列预处理函数：`pad_sequences(sequences, maxlen=None,value=0.)`

功能：将长为`nb_samples`的序列（标量序列）转化为形如`(nb_samples,nb_timesteps)`2D numpy array。

> sequences：浮点数或整数构成的两层嵌套列表  
> maxlen：None或整数，为序列的最大长度。大于此长度的序列将被截短，小于此长度的序列将在后部填0  
> value：浮点数，此值将在填充时代替默认的填充值0

序列预处理函数：`to_categorical(y, num_classes=None)`

功能：将类向量（整数）转换为二进制类矩阵。

> y: 需要转换成矩阵的类矢量 (从 0 到 num\_classes 的整数)  
> num\_classes: 总类别数

```
#输入(None,100)，长度不足100就补0  

    x_train = pad_sequences(x_train,maxlen=100,value=0.)

    x_test = pad_sequences(x_test,maxlen=100,value=0.)

#2分类，one-hot编码

    y_train = to_categorical(y_train, nb_classes=2)

    y_test = to_categorical(y_test, nb_classes=2)

#输入(None,100)

    net = tflearn.input_data([None, 100])

#输入中的最大ASCII索引不能大于256，输出(None,100,128)

    net = tflearn.embedding(net, input_dim=256, output_dim=128)

#这一层128个节点，输出(None,128)

    net = tflearn.lstm(net, 128, dropout=0.8)

    net = tflearn.fully_connected(net, 2, activation='softmax')

    net = tflearn.regression(net, optimizer='adam', learning_rate=0.01,

                             loss='categorical_crossentropy')



    model = tflearn.DNN(net, tensorboard_verbose=3)

    model.fit(x_train, y_train, validation_set=(x_test, y_test), show_metric=True,

             batch_size=100,run_id="ailx10")
```

序列预处理函数：`embedding(input_dim, output_dim)`

形如（samples，sequence\_length）的2D张量，转化为形如(samples, sequence\_length, output\_dim)的3D张量。

> input\_dim：大或等于0的整数，字典长度，即输入数据最大下标\+1  
> output\_dim：大于0的整数，代表全连接嵌入的维度

序列预处理函数：`lstm(incoming, n_units, dropout=None)`

输入3-D张量`[samples, timesteps, input dim]`，

如果return\_seq等于True，输出3-D张量`[samples, timesteps, output dim]`

否则，输出2-D张量`[samples, output dim]`

## 4.完整代码

```
import sys

import urllib

import numpy as np

import tensorflow as tf

import tflearn

from tflearn.data_utils import to_categorical, pad_sequences

from sklearn.model_selection import train_test_split



def elt(line):

    x = []

    for i, c in enumerate(line):

        c = c.lower()

        

        x.append(ord(c))

    return x



def load_file(filename,label,ms=[],ns=[]):

    with open(filename) as f:

        for line in f:

            line = line.strip('

')

            line = urllib.unquote(line)

            if len(line)<= 100:

                m = elt(line)

                if(label):

                    n = 1

                else:

                    n = 0

                ms.append(m)

                ns.append(n)



def load_files(file1,file2):

    xs = []

    ys = []

    load_file(file1,1,xs,ys)

    load_file(file2,0,xs,ys)

    return xs,ys



def train(x,y):

    x_train, x_test, y_train, y_test=train_test_split( x,y, test_size=0.4,random_state=0)



    x_train = pad_sequences(x_train,maxlen=100,value=0.)

    x_test = pad_sequences(x_test,maxlen=100,value=0.)

    y_train = to_categorical(y_train, nb_classes=2)

    y_test = to_categorical(y_test, nb_classes=2)



    net = tflearn.input_data([None, 100])

    net = tflearn.embedding(net, input_dim=256, output_dim=128)

    net = tflearn.lstm(net, 128, dropout=0.8)

    net = tflearn.fully_connected(net, 2, activation='softmax')

    net = tflearn.regression(net, optimizer='adam', learning_rate=0.01,

                             loss='categorical_crossentropy')



    model = tflearn.DNN(net, tensorboard_verbose=3)

    model.fit(x_train, y_train, n_epoch=1,validation_set=(x_test, y_test), show_metric=True,

             batch_size=100,run_id="ailx10")





if __name__ == '__main__':

    xs,ys = load_files(sys.argv[1],sys.argv[2])

    train(xs,ys)
```

100%很容易让人兴奋，也最值得回头检查样本是否同源、是否重复。把这些问题带进下一组测试，模型才有机会从漂亮演示走向更难一点的真实输入。
