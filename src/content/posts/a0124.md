ailx10说：这篇是我2023年11月写的。图片隐写入门这几题，我先从最省事的观察做起：strings 看字符串，文件末尾找提示，后缀不对就检查它是不是压缩包。再往后才用 binwalk、foremost 拆出藏着的另一张图，或者到 StegSolve 里翻位平面找二维码。这篇把五道小题串在一起，保留了每次为什么换工具、结果又指向哪里。它想讲的其实很朴素：一张图不一定只有眼前看到的那一层，但也不用一上来就把所有隐写工具都跑一遍，先看看文件自己露出了什么。

---

1、01 steg1 插入文件尾

```
strings 1.jpg
```

看到最后一行是 `ZmxhZ3t3ZWxjb21ldG92ZW51c30=` ，一看就是base64编码

```
echo "ZmxhZ3t3ZWxjb21ldG92ZW51c30=" | base64 -d
```

得到flag：`flag{welcometovenus}%`  直接提交，解题完成

![](/notes-assets/7c43366f7f5b1706e155.webp)

2、02 steg2 插入图片中

```
strings 1.jpg
```

![](/notes-assets/5d3a7ee27a31e65d7b95.webp)

直接有flag明文，更简单了，直接提交

![](/notes-assets/749098a550602251b3e0.webp)

3、03 steg3 插入压缩包

直接改文件名后缀，然后解压缩，得到flag

```
cp new.jpg new.zip

unzip new.zip 

cat 1.txt
```

![](/notes-assets/58eff1acc636b7b6f81a.webp)

4、04 steg4 双图隐写

```
binwalk new.jpg
```

显示是2张图片合成的

![](/notes-assets/3b46d738e1cc5d330f62.webp)

```
foremost new.jpg 
```

得到2张图片，flag在第2张图片里

![](/notes-assets/5b3347d51498877225a7.webp)

5、05 lsb1 隐写二维码

正常打开是这样的

![](/notes-assets/85e2032011a436e7f3bc.webp)

使用stegsolve打开，就能看到这样的图像，扫一扫二维码，就能拿到flag，其中stegsolve 可由下面的命令安装

```
wget http://www.caesum.com/handbook/Stegsolve.jar -O stegsolve.jar

chmod +x stegsolve.jar

java -jar stegsolve.jar
```

![](/notes-assets/7894a3d5f653d17eb552.webp)

一张图里可能藏着另一个文件，也可能只是某一层像素有变化。把提取的中间结果留好，回头重走时，就能知道二维码或文本究竟从哪一层出现。
