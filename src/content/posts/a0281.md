ailx10说：这篇是我2024年10月写的。这篇起因不是刷靶场，而是研判时碰到不少帆软 channel 告警，想弄清哪些是噪声、哪些真的带着利用内容。我先把请求解压，沿着 Java 序列化数据去看 URL、字节码和取命令的位置，再对照工具连接的线索。拆完才发现，光看到序列化格式既不能判定攻击，也不能判定没事。笔记保留了这段分析过程：可打印字符串只是有损的窗口，命令也可能藏在请求头里；少看到一段文字，不代表整条行为就不存在。

将字节流进行gzip解压，然后转换成可读的字符串

```
import gzip

import binascii

import io

import string



hex_data = '1f8b08000000000000004590314b0341108527773972d1143185826069bb510b23582808c183d342b177cd6d6e4fd7db756f2ed92008365ad8aab58565fe84f80b6cad446cad6d04dd0b873e98e10dbcf90666fc095ea661e6980e28c93111649b667c872aaff6faf43c7bf8e282d385292169d4a53d943a803a72cd322e4564d4c626146a0c7ddb9bb62a16d698c05286e4602fbc5fecacce7f7f68176a01f8dcc2b764c402a82aa931843acd914b9de008a115168b6d41d3b8bd8f3a49e3f510aafd44b033b800d77a2e332cbdafb444d993a29c5dcdfa136bd44f2984399a08b3bc44469d449cac9028cd848c492f458022eba145222a65fe5e501c27418a2c66baf5fef0f87579bde64025006f4045ce8c86e67f6e373f3d62fa6a7cb7307dfb76e30018655f706e7e014fb8173055010000'



# 将十六进制字符串转换为字节串

byte_data = binascii.unhexlify(hex_data)



# 使用gzip解压数据

with gzip.GzipFile(fileobj=io.BytesIO(byte_data)) as f:

    decompressed_data = f.read()



# 将解压后的字节数据转换为字符串

decompressed_text = decompressed_data.decode('utf-8', errors='replace')

# 替换不可打印字符

cleaned_text = ''.join(c if c in string.printable else "." for c in decompressed_text)



print(cleaned_text)
```
