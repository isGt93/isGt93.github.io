3、Finger信息查询

Finger是一种计算机网络协议，用于查询有关特定用户的信息。它通常用于在Unix和Linux系统上查找用户的联系信息，例如用户名、真实姓名、电话号码、电子邮件地址等。Finger协议使用TCP端口79，客户端可以通过telnet等工具连接到服务器进行查询。然而，由于安全原因，许多现代操作系统已经禁用了Finger服务或限制了对其的访问。因此，使用Finger协议查询用户信息并不是一种安全的做法。

5、auth信息查询

auth服务（也称为identd）是一种用于验证用户身份的Internet服务。当用户连接到Internet上的某个服务（如IRC或SMTP）时，服务可能会尝试通过向auth服务发送请求来获取有关用户身份的信息。auth服务将检查该用户是否在本地系统上运行，并返回有关该用户的信息（如用户名）。这些信息可以帮助服务确定是否允许用户访问该服务。

![](/notes-assets/c38f773fbccd25982703.webp)

auth服务

需要注意的是，由于auth服务会向外界提供有关系统上正在运行的用户的信息，因此它可能会被攻击者利用来获取有关系统的敏感信息。因此，在使用auth服务时需要采取适当的安全措施，如限制对auth服务的访问权限。

7、ntp服务

网络时间协议（NTP）是一种用于同步计算机时钟的Internet协议。它允许计算机通过互联网与时间服务器同步，并根据需要调整其本地时钟。NTP服务通常运行在UDP端口123上，并使用一组时间服务器来提供时间同步服务。

```
nmap -sU -p 123 --script ntp-info joker1.top
```

![](/notes-assets/a0eca2458c112bf88195.webp)

ntp服务

NTP服务在许多网络应用中都很重要，例如日志记录、安全事件时间戳、证书有效期和计划任务等。因此，确保NTP服务的准确性和安全性非常重要。同时，NTP服务也是一个常见的攻击目标，攻击者可能会利用它来进行反射放大攻击或拒绝服务攻击。因此，在使用NTP服务时需要采取适当的安全措施，如限制对NTP服务器的访问权限和监控NTP服务的活动。

9、snmp服务

简单网络管理协议（SNMP）是一种用于管理和监控网络设备的Internet协议。它允许管理系统通过网络监视和控制网络设备，并从这些设备中收集有关它们的状态和性能的信息。SNMP服务通常运行在UDP端口161上，并使用一组管理工具来管理网络设备。

```
nmap -sU -p 161 --script "snmp-info" 125.69.90.16
```

![](/notes-assets/c0295a29e8888a250031.webp)

snmp服务

SNMP服务在许多网络应用中都很重要，例如网络管理、性能监测和故障排除等。同时，由于SNMP服务通常不加保护，攻击者可能会利用它来获取有关网络设备的敏感信息或进行远程攻击。因此，在使用SNMP服务时需要采取适当的安全措施，如限制对SNMP服务的访问权限、启用SNMPv3协议和使用加密来保护SNMP流量。

11、ldap服务

LDAP（轻型目录访问协议）是一种用于访问和维护分布式目录服务的协议，它允许客户端应用程序在LDAP服务器上执行各种操作，例如添加、删除、修改和查询目录中的条目。LDAP目录通常用于存储组织中的用户、组、计算机和其他资源的信息。LDAP服务通常运行在TCP端口389上，但也可以运行在其他端口上，例如636（加密的LDAP）和3268（全局目录服务）。

```
nmap -p 389 --script "ldap-novell-getpass" 39.104.30.126
```

![](/notes-assets/dc8b14c11dceaf7016ff.webp)

LDAP服务是企业级网络中广泛使用的一项技术，它可以帮助组织管理和维护其用户和资源的信息。LDAP服务还可以与其他企业应用程序集成，例如电子邮件、文件共享和Web应用程序。同时，由于LDAP服务通常包含敏感信息，因此需要采取适当的安全措施来保护LDAP服务，例如限制对LDAP服务器的访问权限、启用加密和身份验证、监控LDAP服务器的活动等。
