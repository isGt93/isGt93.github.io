ailx10说：这篇是在2024年3月之前写的，后来又改过。上篇试完 pyminifier，我接着换 pyobfuscate，拿一个很简单的加法程序看它会怎样改。注释和文档被删，标识符换掉，代码里还插进了不执行的分支，原来一眼能读懂的结构立刻拐了弯。这篇没有大项目的复杂依赖，反而适合盯着前后两份文件看变化。它让我把“混淆”这个词落到了具体改动上：不是功能换了，而是同样的功能被写成另一副样子，自己再读一遍，也能感到理解成本多了多少。

---

- pyobfuscate 会删除注释和文档字符串（不可逆）
- pyobfuscate 会改变缩进（可逆）
- pyobfuscate 会在标记之间添加空格（某种程度上是可逆的）
- pyobfuscate 会重命名函数、类和变量（不可逆）

1）安装 pyobfuscate，这是20年前的项目，4年前刚刚更新，支持Python2和Python3

```
python3 setup.py install
```

2）混淆前：代码一目了然，清晰易懂

```
# ailx10 test pyminifier

from src.my_add2 import my_add2

class Ailx10():
    def __init__(self):
        print("ailx10 test pyminifier")
    def my_add(self,n,m):
        # print n+m
        return n+m
    def my_src_add(self,n,m):
        return my_add2(n,m)


if __name__ == "__main__":
    ai = Ailx10()
    add1 = ai.my_add(1,1)
    add2 = ai.my_src_add(1,1)
    print("add 1+1={}".format(add1))
    print("src add 1+1={}".format(add2))
```
