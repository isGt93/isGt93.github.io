ailx10说：这篇是在2023年5月之前写的，后来又改过。AI 编程助手热起来后，我也想把它装进自己常用的 PyCharm，看看写代码时能不能少来回切窗口。于是从插件页安装 AWS Toolkit，跟着验证码和网页授权走，最后把 CodeWhisperer 的补全与扫描功能接起来。过程不长，可账号、密钥、跳转授权这些环节第一次做还是容易打断思路，我就一屏一屏记了下来。这篇就是当时把一个新工具放进开发环境的小尝试，先让它在手边真正出现，再看看自己会怎样用它。

---

本文记录 2023 年在 PyCharm 配置 Amazon CodeWhisperer 的体验；产品名称、套餐、授权方式及 IDE 支持可能变化，应查看当前官方资料。

核查提示：IAM访问密钥与编程助手授权混在一起，不假定必需长期密钥；品牌免费支持范围属当时描述。 原实验及图片细节尚未逐项核实。

### 步骤一：打开 PyCharm 的 plugins

搜索AWS Toolkit，点击Install，安装完成后重启 PyCharm

![](/notes-assets/eb0ba1a25b6c9322a617.webp)

### 步骤二：填写自己的AWS的访问密钥 ID和密钥

可以在AWS的IAM（身份和访问管理）「我的安全凭证」中创建

- key ID (访问密钥 ID大概长这样：`AKIAIOSFODNN7EXAMPLE`)
- secret access key (密钥大概长这样：`wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY`)

![](/notes-assets/384a0b9fd579b8ccf4dd.webp)

### 步骤三：AWS CodeWhisperer 启动

![](/notes-assets/95095e9b9ed4fa5f4a65.webp)

### 步骤四：复制验证码，点击Open and Copy Code

![](/notes-assets/5d321abce46bec906f19.webp)

### 步骤五：跳转到AWS的网站，粘贴验证码

![](/notes-assets/ca6305b89a177ae37079.webp)

### 步骤六：输入AWS的注册邮箱和登录密码

![](/notes-assets/bc52e74f17ed4175bd48.webp)

### 步骤七：点击允许AWS Toolkit 访问

![](/notes-assets/58c24919a26f602090bb.webp)

### 步骤八：AWS Toolkit 绑定成功，立即享受AI辅助编程

![](/notes-assets/3caacac83b4c6efbd7c4.webp)

### 步骤九：打开 PyCharm ，享受CodeWhisperer辅助编程

![](/notes-assets/a2545e376a87595e3ea6.webp)

能出现补全只是开始，权限和建议质量还得自己把关。这份记录保留的是当年的接入过程；今天再装时，应按当前产品和授权方式核对，不必照搬旧入口。
