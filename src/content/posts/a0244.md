ailx10说：这篇是我2024年9月写的。把 WebLogic 这组实验刷完后，我想给自己做个入口，不然隔一阵子只记得都能执行，却想不起从哪进去。于是把反序列化、上传、控制台、SSRF 和文件读取几条路集中放到一起，方便沿着问题回找原来的实验。这篇是整理笔记的目录，不是又多做了一个漏洞。相同的最终效果，前面的配置、认证和依赖可能完全不同；按入口把它们排一遍，也让我看清哪些地方容易被一句“拿到 shell”给省略掉。

---

本索引按入口和能力整理一组历史实验，方便查阅对应记录；各项是否影响实际环境，必须结合厂商公告、版本、配置和补丁确认。

| 主题 | 历史编号 | 实验关注点 |
| --- | --- | --- |
| XMLDecoder | CVE-2017-10271 | Web 服务入口与对象解析 |
| WLS Core Components | CVE-2018-2628 | T3、JRMP 与反序列化链 |
| Web Service Test Page | CVE-2018-2894 | 测试页配置及文件上传 |
| 管理控制台 | CVE-2020-14882、CVE-2020-14883 | 访问控制与后续执行环节 |
| IIOP/T3 相关调用 | CVE-2023-21839 | 触发路径和 lookup 条件 |
| 服务端请求 | 原记录未列 CVE | 内部地址访问与服务响应 |
| 文件读取 | 原记录未列 CVE | 实验页面读取配置及凭据 |

这些条目是历史笔记的导航，不能替代漏洞公告或已复现的证据。文件读取记录中的页面可能是靶场专用入口，不应推断为默认产品功能。

合集提供的是回看路径，不是七种能力自动同时存在的证明。带着当前版本、权限和暴露接口去找对应篇章，实验才更容易落到具体问题上。
