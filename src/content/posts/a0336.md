DVWA 是用于安全学习的脆弱 Web 应用，包含 SQL 注入、命令注入、文件上传、CSRF 和 XSS 等练习。原文基于 Ubuntu 16、Apache、MySQL 和 PHP 手工安装，并展示数据库、配置文件和初始化页面；具体依赖及安装方式应以当前项目文档为准。


## 原安装顺序与待核查项

原文依次安装 Apache、数据库和 PHP 组件，创建数据库与实验账户，获取 DVWA 源码，修改 `config/config.inc.php`，最后打开 `setup.php` 初始化。随后按当时页面提示处理验证码、目录权限及 URL 包含设置。具体 SQL、权限路径和 PHP 设置需要匹配版本；尤其应避免在公网暴露靶场。
## 先选择隔离环境

建议在本地虚拟机或隔离网络中运行，不要直接暴露到公网。靶场有意包含不安全功能，默认账号、弱配置和某些实验所需的危险 PHP 设置不适合生产环境。使用虚拟机快照可便于实验后恢复。

## 理解安装步骤

原记录依次安装 Web 与数据库依赖，建立实验数据库及专用账户，将应用配置指向该账户，再访问初始化页面。配置中可能涉及目录写权限或 CAPTCHA；哪些设置必须开启取决于版本和题目。

原文使用 `chmod 777` 和 `allow_url_include` 以满足旧实验条件，不应照搬到生产系统；使用时应限制到隔离靶场，并尽可能缩小范围。数据库授权语法和 PHP 配置路径也随版本变化。原文在线靶场早已是历史信息，本稿不提供访问地址。
