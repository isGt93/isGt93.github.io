ailx10说：这篇是我2024年5月写的。又一条蜜罐命令记录，这次用 root:root 进来后，活动持续了约三分钟。对方一会儿试路由器指令，一会儿看系统、CPU 和进程，还翻到短信、GSM 相关路径，我越看越想知道屏幕后面是手动敲的人，还是自动跑的脚本。可手里的数据还不足以分清，于是疑问也留在文章里。这篇就按顺序跟着那几分钟走，没有替对方编一个完整身份。看似零散的命令，至少能让人摸到它正在寻找什么环境。

---

```
蜜罐网址：https://ailx10.hackbiji.top:4433/web
用户名：ailx10
密码：ailx10@hacker
```

命令包含路由器信息、网络配置、进程及短信相关路径检查；其目的需要更多证据，不能单凭名称判断为挖矿或短信攻击。

```
/ip cloud print
ifconfig
uname -a
cat /proc/cpuinfo
ps | grep '[Mm]iner'
ps -ef | grep '[Mm]iner'
ls -la /dev/ttyGSM* /dev/ttyUSB-mod* /var/spool/sms/* /var/log/smsd.log /etc/smsd.conf* /usr/bin/qmuxd /var/qmux_connect_socket /etc/config/simman /dev/modem* /var/config/sms/*
echo Hi | cat -n
```
