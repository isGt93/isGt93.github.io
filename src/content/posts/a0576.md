ailx10说：这篇是在2023年12月之前写的，后来又改过。这篇先回忆了刚入职时隔离云桌面的经历：红、黄、绿区彼此分开，转一点内容都得绕不少手工步骤，代码还只能一小段一小段搬。后来我想到，文本也能先变成二维码图片，试着用 qrcode 读 UTF-8 文件再生成可扫码内容。这篇的小脚本背后，是那次低效操作留下的印象。它把文字、图片和扫码之间的转换做出来，也说明很多工具点子并不来自大方案，而是来自以前某件反复做得很别扭的小事。

用qrcode读取UTF8文本生成可扫码图片，缘起跨隔离区信息传递的个人经历。

核查提示：二维码有容量上限，fit非无限容纳；图片发布可能缺失，重编可讲编码与跨域信息控制，不执行外传。 旧环境及截图细节未逐项核验。

本文用 QR 码编码文本并生成图片。二维码有容量上限；跨安全域的数据传递应遵守组织的访问控制和授权流程。

直到2023年，同事提了一个需求，解决内网客户信息无法向外传递的问题，文字转图片，然后拍照传出去，最后微信扫一扫就能还原出文字来，竟然还有这样的骚操作，一下子让我回忆起5年前的傻瓜操作，真的是长见识了。

短短几行代码，轻松的实现了文本转图片，代码如下：

```
# python3
import qrcode

def generate_qr_code_from_file(file_path, output_file):
    with open(file_path, 'r', encoding='utf-8') as file:
        text = file.read()

        qr = qrcode.QRCode(
            version=1,
            error_correction=qrcode.constants.ERROR_CORRECT_L,
            box_size=10,
            border=4,
        )
        qr.add_data(text)
        qr.make(fit=True)

        img = qr.make_image(fill_color="black", back_color="white")
        img.save(output_file)

input_file_path = "ailx10.txt"
output_qr_file = "ailx10.png"

generate_qr_code_from_file(input_file_path, output_qr_file)
print(f"已从文件 {input_file_path} 中读取内容并生成二维码，保存至 {output_qr_file}")
```
