ailx10说：这篇是我2024年2月写的。网上找到一份想读的 PDF，偏偏文字不能复制，我就想能不能用 Python 重新整理一份。查到 PyMuPDF 后，试着把原文逐页放进新文件，结果文本能复制了，体积却从五十多兆长到两百多兆，顺手也把这个变化记了下来。脚本很短，事情却刚好解决了我眼前的阅读需求。它就是一篇从“这一下怎么复制不了”长出来的小工具笔记，后面能继续提目录、做翻译，也全靠先把这一道小门打开。

---

今天网上冲浪，发现一个宝藏PDF，内容无法复制，写了一个python脚本，成功去除限制。原始文档55M，去除限制之后200M，可以轻松复制PDF里面的文字。具体解决方案是通过`fitz`库打开原始PDF 文件，然后逐页将其内容插入到新的 PDF 文件中，最终生成一个可以复制文本的 PDF 文件。

![](/notes-assets/07d0bcf62cd431fd57b9.webp)

（1）安装依赖

```
pip install PyMuPDF -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
```

（2）python3.8 编程去除PDF文字限制

```
# python3.8

import fitz



def remove_text_restrictions(input_pdf, output_pdf):

    pdf_document = fitz.open(input_pdf)

    pdf_writer = fitz.open()



    for page_number in range(len(pdf_document)):

        page = pdf_document.load_page(page_number)

        pdf_writer.insert_pdf(pdf_document, from_page=page_number, to_page=page_number, start_at=page_number)



    pdf_writer.save(output_pdf)



if __name__ == "__main__":

    input_pdf = "PEN200_2023.pdf"

    output_pdf = "PEN200_2024.pdf"



    remove_text_restrictions(input_pdf, output_pdf)
```

继续学习PDF了，嘻嘻～

限制消失并不代表文档的其他部分毫发无损。书签、元数据和资源复用都可能变化，扫描图也不会凭空长出可复制文字；输出文件值得再翻一遍再交付。
