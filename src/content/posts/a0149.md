### 24、MD5

![](/notes-assets/0cc8f7aa1c0c436292d6.webp)

在某些旧版 PHP 的宽松比较中，形如 0e 后接数字的两个摘要可能按数值零比较相等；这不是 MD5 的真实碰撞，行为还依赖版本和上下文。

可以写PHP脚本，去寻找这样的值：

```
<?php

function findMD5Collision($prefix) {

    // 循环尝试不同的字符串

    for ($i = 0; $i < pow(10, 12); $i++) {

        // 生成一个候选字符串

        $candidate = $prefix . $i;

        // 计算 MD5 哈希值

        $md5 = md5($candidate);

        // 检查哈希值是否符合要求

        if (preg_match("/^0e[0-9]{30}$/", $md5)) {

            echo $candidate;

            return $candidate; // 返回符合条件的字符串

        }

    }

    return false; // 如果没有找到，则返回 false

}



$prefix = "ailx10"; // 我们希望字符串以 "ailx10" 为前缀

$string = findMD5Collision($prefix);

if ($string !== false) {

    echo "找到的字符串: " . $string . "

";

    echo "MD5 哈希值: " . md5($string) . "

";

} else {

    echo "未找到符合条件的字符串。

";

}

?>

```

### 26、秋名山车神

![](/notes-assets/42bdfeff4c78f2150674.webp)

多刷几次，碰到这个页面，才是解题的关键，然后写一个Python脚本，提交计算结果，就能拿到flag

```
import requests

import re



url = 'http://114.67.175.224:18141/'

headers_get = {

    'Cookie': 'PHPSESSID=2phs57dul2tcpleakof4n4dko3; Timeout=alive',

    'Proxy-Connection':'keep-alive'

}

s = requests.session()

s.headers = headers_get

response = s.get(url,headers=headers_get)

if response.status_code == 200:

    html_content = response.text

    # 使用正则表达式提取数学表达式

    print(html_content)

    pattern = r'<div>(.*?)=\?;</div>'

    pattern = r'Give me value post about (.*)=\?'

    match = re.search(pattern, html_content)

    if match:

        # 提取数学表达式

        math_expression = match.group(1)

        print("提取的数学表达式是:", math_expression)

        # 计算数学表达式

        try:

            result = eval(math_expression)

            print("计算结果是:", result)

            data1 = {"value":result}

            response2 = s.post(url,data=data1)

            if response2.status_code == 200:

                html_content = response2.text

                print({html_content})

            else:

                print(response2.status_code)

        except Exception as e:

            print("计算过程中发生错误:", e)

    else:

        print("没有找到数学表达式")

else:

    print("请求失败，状态码:", response.status_code)
```

### 27、速度要快

![](/notes-assets/b0060b71df71a06ec163.webp)

思路就是对响应头中的flag字段进行base64解码：

```
echo "6LeR55qE6L+Y5LiN6ZSZ77yM57uZ5L2gZmxhZ+WQpzogTXpReE5ERTU=" | base64 -d

跑的还不错，给你flag吧: MzQxNDE5
```

观察发现需要二次base64解码：

```
echo "MzQxNDE5" | base64 -d

341419
```

最后发一个POST请求，就可以拿到flag了，写个Python脚本就行了

```
import requests

import base64

import re



url = 'http://114.67.175.224:10516/'

s = requests.session()

response = s.get(url)

if response.status_code == 200:

    html_content = response.headers

    flag = html_content["flag"]

    flag1 = base64.b64decode(flag).decode('utf-8')

    pattern = r':\s?(.*)'

    match = re.search(pattern, flag1)

    if match:

        flag2 = match.group(1)

        flag2 = base64.b64decode(flag2).decode('utf-8')

        try:

            data1 = {"margin":flag2}

            response2 = s.post(url,data=data1)

            if response2.status_code == 200:

                html_content = response2.text

                print(html_content)

            else:

                print(response2.status_code)

        except Exception as e:

            print("请求失败:", e)

    else:

        print("正则匹配失败")

else:

    print("请求失败，状态码:", response.status_code)
```
