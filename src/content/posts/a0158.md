ailx10说：这篇是我2024年11月写的。看到“聪明的小羊”这题，我顺着提示去想栅栏密码，但不想只找个工具填轨数就结束，于是自己把 W 形的行走路径画进脚本。题目给两行，看着简单，推广到更多行时，中间行的步长和首尾行又不一样，还要单独处理只有一行的情况。这篇就把填回密文、再按原路径读出的过程写下来。它是一次很适合练索引的小题。密文按行填回去，再沿 W 形路径走出来，抽象的“栅栏”也就变成了可以一格格追踪的过程。

---

本题采用 W 形轨迹的栅栏排列，原文提供了行数提示；并非脚本自动识别加密方式。

![](/notes-assets/797f827dff95868d258b.webp)

```
def decrypt_rail_fence_cipher(ciphertext, numRails):

    # 如果行数是1，那么密文就是明文

    if numRails == 1:

        return ciphertext



    # 创建一个二维列表来模拟栅栏

    fence = [['' for _ in range(len(ciphertext))] for _ in range(numRails)]



    # 模拟栅栏密码的编码过程来确定每个字符的位置

    index = 0

    for row in range(numRails):

        i = row

        step = 0

        while i < len(ciphertext):

            fence[row][i] = ciphertext[index]

            index += 1

            if row == 0:

                i += 2 * (numRails - 1)

            elif row == numRails - 1:

                i += 2 * (numRails - 1)

            else:

                if step % 2 == 0:

                    i += 2 * (numRails - 1 - row)

                else:

                    i += 2 * row

                step += 1



    # 从栅栏中读取明文

    plaintext = []

    for i in range(len(ciphertext)):

        for row in range(numRails):

            if fence[row][i] != '':

                plaintext.append(fence[row][i])

                break



    return ''.join(plaintext)



# 根据提示，行数为2

ciphertext = "fa{fe13f590lg6d46d0d0}"

numRails = 2

print(decrypt_rail_fence_cipher(ciphertext, numRails))

# flag{6fde4163df05d900}
```

把密文填回轨迹，再按原顺序读出，程序每一步都有了对应动作。以后换行数时，也就不是靠修改常量碰答案，而是重新计算那条路径。
