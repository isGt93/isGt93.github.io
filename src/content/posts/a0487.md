ailx10说：这篇是2022年11月之前写的，后来又改过。这篇把蚁剑和 Beacon 接在一起。先在 Windows 的 phpstudy 放好 PHP 代理，Kali 上的加载器又碰到 mime 文件大小写，处理完才继续上传 CS 生成的程序，最后执行上线。一步步做下来，会发现后门入口、文件传输和新会话其实各是一个阶段，工具之间也没有自动提升权限的魔法。笔记把客户端和真实团队服务端的角色留下，免得都叫成“回连 Kali”就混了位置。那次小小的文件名问题也记着，因为准备工作常常比最后那一下执行更费时间。

### 2、在kali上从github下载蚁剑[\[1\]](#ref_1) 并初始化运行

kali linux 非常推荐大家使用，可以初始化源代码，也可以从github上下载源代码

如果报错 Error: Cannot find module 'mime'，可以在源代码中通过如下方案解决

```
mv node_modules/mime/mime.js node_modules/mime/Mime.js
```
