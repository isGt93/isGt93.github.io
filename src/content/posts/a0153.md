ailx10说：这篇是我2024年11月写的。刷题遇到 CBC 字节翻转后，我不想只记一条改 Cookie 的输入，就写了个 AES-CBC 本地小实验，把明文、密文和异或关系摆出来看。我先改前一个密文块，让后一个块里的 bdmin 变成 Admin，再换到 IV，看看第一块为什么也能跟着变。这篇就是把这个过程拆开的一次练习，连填充和加解密代码也放在一起。它想讲清楚的是“哪个字节影响哪一块”，而不是让一次靶场现象看起来像魔法；知道格式、认证条件这些前提同样重要。

测试demo：

```
from Crypto.Cipher import AES

import uuid

import binascii

import os



BS = AES.block_size  # 分组长度

key = os.urandom(16)  # 生成一个随机的16字节密钥

iv = uuid.uuid4().bytes  # 生成一个随机的16字节IV



# 统一的PKCS7填充函数

def pad(data):

    padding = BS - (len(data) % BS)

    return data + (padding.to_bytes(1, 'big') * padding)



# 去除填充

def unpad(padded_data):

    padding = padded_data[-1]

    if padding < 1 or padding > BS:

        raise ValueError("Invalid padding")

    return padded_data[:-padding]



# 加密

def enc(data):

    aes = AES.new(key, AES.MODE_CBC, iv)

    ciphertext = aes.encrypt(pad(data))

    # 将IV附加在密文前，并返回十六进制字符串

    return binascii.b2a_hex(iv + ciphertext)



# 解密

def dec(ciphertext):

    ciphertext = binascii.a2b_hex(ciphertext)  # 将十六进制字符串转换为二进制

    iv = ciphertext[:BS]  # 从密文前提取IV

    ciphertext = ciphertext[BS:]  # 提取密文

    aes = AES.new(key, AES.MODE_CBC, iv)

    padded_data = aes.decrypt(ciphertext)

    return unpad(padded_data)  # 去除填充



# 测试CBC翻转

def CBC1(ciphertext):

    ciphertext = binascii.a2b_hex(ciphertext)  # 将十六进制字符串转换为二进制

    iv = ciphertext[:BS]  # 提取IV

    ciphertext = ciphertext[BS:]  # 提取密文

    ciphertext_bytes = bytearray(ciphertext)

    ciphertext_bytes[9] ^= ord('b') ^ ord('A')  # 修改密文

    # 将修改后的密文和IV组合，并返回十六进制字符串

    return binascii.b2a_hex(iv + bytes(ciphertext_bytes))



def CBC2(ciphertext,attack_decrypted_data):

    ciphertext = binascii.a2b_hex(ciphertext)  # 将十六进制字符串转换为二进制

    iv = ciphertext[:BS]  # 提取IV

    ciphertext = ciphertext[BS:]  # 提取密文

    ciphertext_bytes = bytearray(ciphertext)

    text = r'a:2:{s:8:"username";s:5:"bdmin";s:8:"password";s:3:"123";}'

    iv2 = bytearray(iv)

    for i in range(16):

        iv2[i] ^= attack_decrypted_data[i] ^ ord(text[i])

    iv2 = bytes(iv2)

    # 将修改后的密文和IV组合，并返回十六进制字符串

    return binascii.b2a_hex(iv2 + bytes(ciphertext_bytes))



# 主程序

if __name__ == "__main__":

    data = b'a:2:{s:8:"username";s:5:"bdmin";s:8:"password";s:3:"123";}'

    ciphertext = enc(data)

    print("密文:", ciphertext)



    decrypted_data = dec(ciphertext)

    print("明文:", decrypted_data)



    attack_ciphertext = CBC1(ciphertext)

    attack_decrypted_data = dec(attack_ciphertext)

    print("CBC1 Attack:", attack_decrypted_data)



    ciphertext2 = enc(attack_decrypted_data)

    attack_ciphertext2 = CBC2(ciphertext2,attack_decrypted_data)

    attack_decrypted_data2 = dec(attack_ciphertext2)

    print("CBC2 Attack:", attack_decrypted_data2)
```

运行结果：经过2轮修改，成功将`bdmin`改成`Admin`

修改前一密文块会影响下一明文块，也会破坏其对应的明文块；重新加密并不等同于直接修复原密文。

出现Admin并不是加密算法被随手“解开”了，而是修改在特定条件下影响了解密结果。把块之间的关系亲手对照一遍，完整性保护为什么重要就有了具体画面。
