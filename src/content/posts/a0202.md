ailx10说：这篇是2025年3月之前写的，后来又改过。拿到题目里的 Linux 密码文件后，我先看摘要的格式，而不是马上乱试工具。开头的 $6$ 提醒我，这是带盐的 sha512crypt，于是把 John 和 hashcat 的字典、规则、掩码几种试法都走了一遍。这题最后靠候选口令匹配出了结果，算是一个认识 Linux 口令存储的小练习。这里想留下的不是“有 shadow 就能拿到密码”，而是先认清格式，再知道工具到底在替我猜什么；密码不在候选范围里，结果就没这么顺利了。

破解该文件，获得密码，flag格式为：flag{\*}

题目来源：第七届山东省大学生网络安全技能大赛

难度系数：1

打开文件内容是下面这样的，这是Linux系统的shadow文件

```
root:$6$HRMJoyGA$26FIgg6CU0bGUOfqFB0Qo9AE2LRZxG8N3H.3BK8t49wGlYbkFbxVFtGOZqVIq3qQ6k0oetDbn2aVzdhuVQ6US.:17770:0:99999:7:::                                         
```

用户名：root（系统管理员账户）

加密密码：$6$HRMJoyGA$26FIgg6...

$6$ 表示 sha512crypt 口令散列格式；HRMJoyGA 是这一条记录中的盐值。

（1）方法1：使用 john

John the Ripper是一个著名的开源密码破解工具，常用于渗透测试和网络安全领域

```
--wordlist=<字典文件>：指定字典文件进行字典攻击（例如 rockyou.txt）
--format=<哈希类型>：明确哈希算法（如 md5crypt, sha512crypt, nt 等）
--rules：启用规则模式（对字典单词变形，如大小写变换、添加数字等）
--show：显示已破解的密码
--incremental：启用增量模式（暴力破解，尝试所有字符组合）
```

破解 Linux 用户密码：

```
unshadow /etc/passwd /etc/shadow > hashes.txt
john --format=sha512crypt hashes.txt
```

破解 Windows 哈希（NTLM）：

```
john --format=nt hashes.txt
```

使用字典文件：

```
john --wordlist=passwords.txt --rules hashes.txt
```

运行 john --show hashes.txt 可查看已破解的密码

```
john shadow 

hellokitty       (root)     
```

（2）方法2：使用 hashcat

```
-a	指定攻击模式	0（字典攻击）、1（组合攻击）、3（掩码暴力破解）
-m	哈希类型	0（MD5）、1000（NTLM）、1800（SHA-512）
-D	硬件加速设备	1（CPU）、2（GPU，推荐）
-o	保存破解结果	指定输出文件路径（如 -o result.txt）
--show	显示已破解的密码	直接查看结果（如 hashcat --show hashes.txt）
-r	自定义规则文件	用于增强字典攻击（如 -r rules/custom.rule）
```

破解 MD5 哈希，使用`passwords.txt`字典文件

```
hashcat -m 0 -a 0 hashes.txt passwords.txt
```

破解 8 位数字密码（如 12345678），适用于 NTLM 哈希

```
hashcat -m 1000 -a 3 hashes.txt ?d?d?d?d?d?d?d?d
```

字典词后追加 3 位数字（如password123），破解 SHA-512 哈希

```
hashcat -m 1800 -a 6 hashes.txt passwords.txt ?d?d?d
```

这题的flag 就在 `/usr/share/john/password.lst` 中，因此使用字典攻击

```
hashcat -m 1800 -a 0 shadow /usr/share/john/password.lst
```

得到flag: `flag{hellokitty}`

匹配到口令以后，仍要核对它对应的材料。这个练习展示的是受限候选如何验证，不是从一串摘要直接反推出任意密码；记录清楚范围，结果才有意义。
