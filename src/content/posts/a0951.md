ailx10说：这篇是在2018年11月之前写的，后来又改过。学朴素贝叶斯时，我先想弄清“朴素”到底省略了什么，于是从条件独立假设往下看，再把 Gaussian、Multinomial、Bernoulli 三种形式放到一起比较。最后拿鸢尾花跑了一遍，连训练数据上也会出现几条分错的结果，这比单看公式更容易留下印象。文章就是一次算法入门的小笔记：先知道模型怎样把条件拼起来，再用一个小数据集看它真的怎么判断。有了这块基础，后面才好试着把安全里的日志和文件变成同样能送进去的输入。

原代码和结果来自历史实验，尚未在当前环境重新运行；依赖版本、数据划分和指标需复核。

本文介绍朴素贝叶斯的条件独立假设及三个常见模型。

> 贝叶斯定理为根据证据更新概率提供基础；具体历史背景不影响下方模型说明。

贝叶斯分类是一系列算法的总称，这类算法均以贝叶斯定理为基础，所以都叫贝叶斯分类。其中，朴素贝叶斯（Navive Bayesian）是其中应用最广泛的分类算法之一。

NB算法是基于`贝叶斯定理`和`特征条件独立假设`的分类方法，NB基于一个简单的假定：

> 给定目标值时属性之间互相条件独立。

朴素贝叶斯依赖条件独立假设，参数少且常作为基线；缺失数据须结合具体实现处理。理论最小错误率属于理想贝叶斯分类，不能保证朴素贝叶斯实现该值。

NB包括以下算法：

- 高斯朴素贝叶斯（Gaussian Naive Bayes）
- 多项式朴素贝叶斯（Multinomial Naive Bayes）
- 伯努利朴素贝叶斯（Bernoulli Naive Bayes）

```
>>> from sklearn import datasets
>>> iris = datasets.load_iris()
>>> from sklearn.naive_bayes import GaussianNB
>>> gnb=GaussianNB()
>>> y_pred=gnb.fit(iris.data,iris.target).predict(iris.data)
>>> print iris.data.shape[0]
150
>>> print (iris.target != y_pred).sum()
6
```

原文在鸢尾花同一批样本上训练并预测，150 条中记录 6 条错误，约 96% 是训练集指标，不是独立测试效果。

六条分错的记录也是结果的一部分。把它们和正确预测并排看，再意识到这还是训练过的数据，下一步该怎样独立评估，就比继续夸分数更明确了。
