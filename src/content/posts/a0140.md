ailx10说：这篇是在2024年1月之前写的，后来又改过。逆向入门这两题，我从 Windows 程序开始练眼力。第一道在 OD 里找密码字符串、跟几步执行，再看分支为什么走向不同结果；第二道换到 IDA，沿 main 往下追函数，把输入和偏移参数对起来。这篇没有复杂的保护壳，更像给自己找一个能站稳的起点：不急着改跳转，先看清程序在哪比较、拿什么比较、结果怎么出来。两种工具的过程都留下了，从窗口里的密码走到函数里的字符串变化，正好是一段由浅到深的小练习。

---

本例通过动态调试和静态反编译观察输入检查与分支行为。

1、使用OD逆向一个windows可执行程序 `disassemble-upx（case1）.exe`

（1）使用PEiD查看有没有加壳，这里显示没有加壳

![](/notes-assets/49e231bdfec73ee66ca8.webp)

（2）使用OD动态调试，找到关键字符串“请输入密码”的位置

![](/notes-assets/2d7a22d195bb4541436a.webp)

（3）然后F4跟进这一行，F8一步一步运行

![](/notes-assets/0e40a5cbfa05f3654fa5.webp)

（4）原记录在 test 指令后观察到条件跳转。分支含义要结合实际标志位和汇编语境核对，不能只看单条指令就推断完整逻辑。

![](/notes-assets/d830ecb825d92e62c194.webp)

（5）原实验通过修改跳转改变了执行流程；这是改变程序行为，不等同于求出原程序接受的正确输入。

![](/notes-assets/7646a6f341c106dd9573.webp)

（6）继续运行F9，得到flag

![](/notes-assets/3a3126245c11c8daee08.webp)

2、使用IDA 逆向一个windows可执行程序 `cesarCipher.exe`

（1）这题是通过IDA进行函数分析，首先看main函数：

![](/notes-assets/cf78a4e21e025b0acfbb.webp)

（2）分析：sub\_401005，跟踪函数最终来到这里，提示

```
should it be a number between 0 and 26?
```

必须输入1，才能返回1

![](/notes-assets/2937e692eb7c93230d36.webp)

（3）分析：sub\_40101E(byte\_43F4DC, dword\_43BDC0)

这里提示Str长度是7，根据对应的ASCII码，得到输入字符应该是 nee2rds ，到这里其实就可以直接运行程序，输入 nee2rds 和 1，就能拿到flag了

![](/notes-assets/a8c901b51bff6c3c31b5.webp)

（4）分析：sub\_401019(byte\_43F4DC)，跟踪函数最终来到这里，提示上一步后续的Str操作结果就是flag

![](/notes-assets/c90d18cda1cc118f84dc.webp)

（5）Str操作，当偏移后的ASCII码落在65～90之外，赋值了95（表示下划线：\_）

![](/notes-assets/199f8c202886fe723b39.webp)

（6）原程序在输入满足条件时输出结果；复现前仍需对照样本检查字符变换过程。

![](/notes-assets/8c67e4f39cedea7a179f.webp)

最后出现结果，并不意味着前面每个函数都必须读完。逆向入门里很重要的一步，是找到足够支持当前判断的路径，再知道哪些地方还没有展开。
