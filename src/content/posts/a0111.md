## `起名字真难`

给了一段PHP代码 大概意思就是输入一个`key`值

满足2个条件:

> 1.$number\=\='54975581388'  
> 2.($digit\>\=$one)\&\&($digit\<\=$nine)

呵呵 这个数字每个位数必须不在`1-9` 那怎么才能`== '54975581388'`

宽松比较可能触发类型转换，其具体规则随 PHP 版本变化。

> $a \=\= $b等于**`TRUE`** 如果类型转换后$a等于$b  
> $a \=\=\= $b全等**`TRUE`** 如果$a等于$b 并且它们的类型也相同

该题依赖历史版本对特定字符串的数值转换行为，现代环境应重新验证。

`54975581388 = 0xCCCCCCCCC` (16进制)

```
<?php

function noother_says_correct($number)

{

       $one = ord('1');

       $nine = ord('9');

       for ($i = 0; $i < strlen($number); $i++)

       {   

               $digit = ord($number{$i});

               if ( ($digit >= $one) && ($digit <= $nine) )

               {

                       return false;

               }

       }

          return $number == '54975581388';

}

$flag='*******';

if(noother_says_correct($_GET['key']))

   echo $flag;

else 

   echo 'access denied';

?> 

```

## `pass check`

给了一段`PHP`代码 大意是输入`pass` 等于`pass1`即可拿到 `flag`

```
$pass=@$_POST['pass'];

$pass1=***********;//被隐藏起来的密码

if(isset($pass))

{

if(@!strcmp($pass,$pass1)){

echo "flag:nctf{*}";

}else{

echo "the pass is wrong!";

}

}else{

echo "please input pass!";

}

?>

```

原题利用旧环境中类型不匹配后的错误处理，不能称为破解 strcmp 或获取密码。

原作者记录传入数组后比较发生错误，后续判断在旧环境中通过；新版本可能抛出异常。
