ailx10说：这篇是在2022年8月之前写的，后来又改过。很多人担心手机被监控，却说不清具体会暴露什么。我就拿安卓 9 模拟器做了一轮演示，把屏幕、摄像头、麦克风、应用、短信和通讯录这些能力逐项看过去。平时一句“手机中毒”太笼统，真把权限和操作摊开，才知道哪些信息会受影响。这篇留下的是那次环境里的观察，不是拿来吓人的故事。与其只盯着一个可怕的名词，我更想让人看见，安装来源不明的应用、授予权限之后，到底可能把什么交出去。

---

本文基于 Android 9 模拟器记录远程控制可能涉及的功能。具体能力受权限、系统版本和运行条件约束，不能推广到所有手机。

核查提示：取决于授权、root和载荷；不能由模拟器外推所有手机，图标消失不充分证明木马。 原实验及图片细节尚未逐项核实。

应用图标消失可能有多种原因，不能单凭此确认木马；应结合应用来源、权限、行为及专业检查。

1. 黑客可以看到手机屏幕上的一切画面
2. 黑客可以截屏，也可以录制屏幕
3. 黑客可以让手机偷偷录制声音
4. 黑客可以让手机摄像头偷偷的拍照
5. 黑客可以让手机摄像头偷偷的录制视频
6. 黑客可以给你安装APP
7. 黑客可以卸载你的APP
8. 黑客可以查看你的所有通话记录
9. 黑客可以查看你的所有短信
10. 黑客可以查看你的所有通讯录名单
11. 黑客可以让你手机偷偷发短信

模拟打开受害者手机的摄像头，对受害者身边环境实时监控

常用用户接口命令：

```
screenshare：实时查看手机屏幕
screenshot：给手机截屏
```

常用摄像头命令：

```
record_mic：让手机偷偷录制音频
webcam_snap：让手机摄像头偷偷拍照
webcam_stream：让手机摄像头偷偷录像
webcam_chat：开启视频聊天
```

常用应用控制：

```
app_install：偷偷给你安装手机APP
app_uninstall：偷偷卸载你的手机APP
app_run：偷偷运行你的APP
app_list：查看你的手机APP列表
```

常用安卓命令：

```
check_root：检查手机是否开启root
dump_calllog：获取手机通话记录
dump_contacts：获取手机所有联系人
dump_sms：获取手机所有短信
send_sms：让你的手机发送短信
hide_app_icon：隐藏APP图标
```

常用网络命令：

```
ifconfig、ipconfig：显示手机的IP地址
portfwd ：端口转发，肉鸡跳板
route：查看手机的路由表
```

常用系统命令：

```
getenv：获取手机的环境变量
localtime：查看手机时间
sysinfo：查看系统信息
```
