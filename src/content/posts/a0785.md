ailx10说：这篇是我2022年6月写的。想把抓到的 IP 包读明白，我就跟着书写了个解码器，用 struct 把固定头拆开，再打印协议、源地址和目的地址。Mac 和 Windows 上试出来的观察范围还不一样，我临时又找了一台 Windows 电脑来对照，才把实验接下去。以前 Wireshark 都替我排好了字段，这回要自己决定从哪几个字节取什么，协议头的长度和排列才真正有了分量。这篇就留下这段从原始字节走回熟悉字段的小练习。

---

本文记录使用 Python struct 解析 IPv4 固定头的实验。原代码使用小端序解析网络多字节字段，不能保证长度等字段正确；还应处理 IHL 和可选项。

核查提示：用小端解析网络头使长度等多字节字段错误，需网络序和IHL选项长度；只打印正确单字节字段不代表解析全正确。 原实验、代码和图片细节未逐项复测。

参考代码：

```
# -*- coding: utf-8 -*-
# @Time    : 2022/6/5 9:45 AM
# @Author  : ailx10
# @File    : sniffer_ip_header_decode.py

import ipaddress
import os
import socket
import struct
import sys

class IP:
    def __init__(self,buff = None):
        header = struct.unpack("<BBHHHBBH4s4s",buff)
        self.ver = header[0] >> 4
        self.ihl = header[0] & 0xF
        self.tos= header[1]
        self.len = header[2]
        self.id = header[3]
        self.offset = header[4]
        self.ttl = header[5]
        self.protocol_num = header[6]
        self.sum = header[7]
        self.src = header[8]
        self.dst = header[9]

        self.src_address = ipaddress.ip_address(self.src)
        self.dst_address = ipaddress.ip_address(self.dst)

        self.protocol_map = {1:"ICMP",6:"TCP",17:"UDP"}
        try:
            self.protocol = self.protocol_map[self.protocol_num]
        except Exception as e:
            print("%s No protocol for %s" % (e,self.protocol_num))
            self.protocol = str(self.protocol_num)


def sniff(host):
    if os.name == "nt":
        socket_protocol = socket.IPPROTO_IP
    else:
        socket_protocol = socket.IPPROTO_ICMP

    sniffer = socket.socket(socket.AF_INET,socket.SOCK_RAW,socket_protocol)
    sniffer.bind((host,0))
    sniffer.setsockopt(socket.IPPROTO_IP,socket.IP_HDRINCL,1)

    if os.name == "nt":
        sniffer.ioctl(socket.SIO_RCVALL,socket.RCVALL_ON)

    try:
        while True:
            raw_buffer = sniffer.recvfrom(65535)[0]
            ip_header = IP(raw_buffer[0:20])
            print("Protocol:%s %s->%s"%(ip_header.protocol,ip_header.src_address,ip_header.dst_address))
    except KeyboardInterrupt:
        if os.name == "nt":
            sniffer.ioctl(socket.SIO_RCVALL, socket.RCVALL_OFF)
        sys.exit()

if __name__ == "__main__":
    if len(sys.argv) == 2:
        host = sys.argv[1]
    else:
        host = "192.168.0.102"
    sniff(host)
```
