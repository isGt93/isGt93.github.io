## `综合题`

原作者执行页面中的脚本取得下一条线索；分析未知脚本时应先检查内容并使用隔离环境。

![](/notes-assets/8d2f572c8f4cef0723bf.jpg)

获得新的提示信息如下:

`1bc29b36f623ba82aaf6724fd3b16718.php`

咱们去访问这个新的地址获得提示信息如下:

![](/notes-assets/5f989eef2dd946f444d1.jpg)

打开`burp suite` 再次访问 查看响应报文获得提示信息如下:

![](/notes-assets/6a9c3751c06348b48fcd.jpg)

`/web3/b0b0ad119f425408fc3d45253137d33d/.bash_history`

获得新的提示信息如下 已经看到`flag`苗头了 继续努力

![](/notes-assets/aeaaea1c5ea4bf415c4d.webp)

接下来访问 `/web3/b0b0ad119f425408fc3d45253137d33d/flagbak.zip`

下载 解压 拿到结果如下:

![](/notes-assets/3c522eae975a2ad18279.jpg)

## `文件包含`

原题使用 PHP filter 包装器读取并编码文件内容；它能否生效取决于应用是否将可控输入用于文件操作及运行配置。

![](/notes-assets/958a5ec63e990d403cb2.jpg)

访问:`file=php://filter/read=convert.base64-encode/resource=index.php`

拿到`B64`编码后的`index.php`文件

![](/notes-assets/2259292941ed91cae987.jpg)

`B64`解码获得如下信息: 直接拿到结果`nctf{edulcni_elif_lacol_si_siht}`

![](/notes-assets/38a987e43170647da8d0.jpg)

## `上传绕过`

上传一张图片`02.png`获得如下提示信息:

> Array  
> (  
>  \[0\] \=\> .png  
>  \[1\] \=\> png  
> )  
> Upload: 02.png  
> Type: image/png  
> Size: 346.965820312 Kb  
> Stored in: ./uploads/8a9e5f6a7a789acb.phparray(4) {  
>  \["dirname"\]\=\>  
>  string(9) "./uploads"  
>  \["basename"\]\=\>  
>  string(6) "02.png"  
>  \["extension"\]\=\>  
>  string(3) "png"  
>  \["filename"\]\=\>  
>  string(2) "02"  
> }  
> 必须上传成后缀名为php的文件才行啊！

上传一个`PHP`文件`1.php` 获得如下提示信息:

> Array  
> (  
>  \[0\] \=\> .php  
>  \[1\] \=\> php  
> )  
> 不被允许的文件类型,仅支持上传jpg,gif,png后缀的文件

原题尝试在路径参数中使用空字节截断；结果依赖历史环境，现代运行时不应假定仍然成立。

![](/notes-assets/8cc97077268088ed7477.jpg)

然后在`HEX`将空格`20`改成`00`

![](/notes-assets/77ed3785553d4bd5292c.jpg)

直接拿到结果如下:

![](/notes-assets/139180f3b8b28a407be5.jpg)

综合题的节奏不一定是一路向前，有时读到源码才知道前面为什么没走通。把这些来回保留下来，回看时就能看到一条依据逐渐变多的路线，而不只是最终载荷。
