ailx10说：这篇是在2019年12月之前写的，后来又改过。这篇拿一个具体网站当例子，想把信息收集器需要的几块先拼出来。域名注册、DNS、子域、路由，再到公开邮箱和地址，用 whois、host、dig、dnsenum、theHarvester 一样样看结果。它像为一个小工具先画数据来源图：不是工具越多越好，而是每项信息从哪来、能说明什么、怎样接到下一步。手工走过一遍，后来真要写采集流程，才知道哪些能自动做，哪些输出还得继续整理和判断。

---

以网站为例组合whois/host/dig、dnsenum、TCP路由追踪和theHarvester，列公开子域邮箱与地址结果。

## 背景与待核查点

结果混域名URL/历史CDN，不能等同真实源站；版本依赖过时，标题采集器但主要现成工具流程。

## 历史记录与步骤

以知乎网站为例子分析：

**域名的注册信息如何获取**

```
whois zhihu.com
```

![](/notes-assets/8e08ec8e079d15e09ad1.webp)

我们可以看到这个域名（网站）成立的时间，这个信息对我们有用。

**DNS记录分析**

```
host zhihu.com
```

![](/notes-assets/95eb9be320e4b4962170.webp)

我们可以看到这个域名（网站）对应的IP地址。

```
dig zhihu.com
```

我们也可以通过dig获得相同的信息，来再次对获得的数据进行确认。

![](/notes-assets/09bcdce554efe4739d2d.webp)

接下来介绍一个兵器：**dnsenum**

**Ubuntu安装**

**第一步：下载**

```
git clone https://github.com/fwaeytens/dnsenum.git
```

**第二步：进入目录，安装必要的库（其他系统参考目录中的`INSTALL.txt`文档）**

```
apt-get install cpanminus
```

**第三步：安装必要的工具**

```
cpanm String::Random

cpanm Net::IP module

cpanm Net::DNS module

cpanm Net::Netmask

cpanm XML::Writer
```

**第四步：给个可执行权限（可提到第2步）**

```
chmod +x dnsenum.pl
```

运行结果如下：

```
./dnsenum.pl zhihu.com
```

![](/notes-assets/a70d5d45ed03cdd46a1c.webp)

可以通过 `-f` 指定爆破文件，爆破可能存在的子域名。

```
./dnsenum.pl zhihu.com -f dns.txt
```

![](/notes-assets/e0249ec572e2efb3080b.webp)

同时，我们也拿到了C类地址网段：

![](/notes-assets/fff7d1427810aaedd2d0.webp)

官方使用手册：

**第一步：安装`per-doc`**

```
apt-get install perl-doc
```

**第二步：执行`perldoc dnsenum.pl`**

```
perldoc dnsenum.pl
```

结果如下图所示：

![](/notes-assets/e5a1075c43a4e6fa2b5f.webp)

**路由信息获取**

网络路由信息可以帮我们分析，自己的主机到目标主机之间的网络通信，保护目标的防火墙信息，往往会暗藏在路由信息里。

获取路由信息的原理：逐步增加TTL标志位，直到数据包到达目标主机。

**基于traceroute（UDP\|ICMP数据包）**

安装：

```
apt install inetutils-traceroute

apt-get install traceroute
```

使用效果：失败，一般都被防火墙干掉了。

```
traceroute www.zhihu.com
```

![](/notes-assets/14ac636f1644fa90fc81.webp)

**基于tcptraceroute（TCP SYN）**

安装：

```
apt-get install tcptraceroute
```

使用效果：成功。

```
tcptraceroute www.zhihu.com
```

![](/notes-assets/8f55993ea357ae79b580.webp)

```
tcptraceroute zhihu.com
```

![](/notes-assets/86b69e92d4feaac348fb.webp)

再介绍一个黑客杀器，**`theharvester`搜索引擎**，这个需要python3.6才能运行。

```
python3 theHarvester.py -d zhihu.com -b google
```

![](/notes-assets/ebca40ad4bc2eec27ea2.webp)

这里显示`www.zhihu.com`的IP地址是`23.7.141.192`，我们尝试通过tcptraceroute来跟踪一下这个IP地址，如下：

![](/notes-assets/1a79bd7f15e11448d1d3.webp)

发现这个地址其实是**`Akamai`公司** 的地址，这个公司提供内容分发，是世界上最大的分布式计算平台之一，承担了全球15-30%的网络流量。该公司经营着分布于世界各地的服务器网络，主要业务为出租服务器资源给那些希望通过从靠近用户的服务器来分发内容来提高自己网站访问速度的客户。（由此可见，我的IP地址也是国外的）

换个姿势，咱们从领英上抓人，如下抓到了46个人，由此可见，领英还是蛮好用的。

```
python3 theHarvester.py -d zhihu.com -b linkedin
```

![](/notes-assets/1f730c6e644e8aab3aa4.webp)

再看看，百度搜索结果，信息量也很小，比谷歌多了2个邮箱地址。

![](/notes-assets/828f03981c80b45ac6fd.webp)

直接上大招吧！

```
python3 theHarvester.py -d zhihu.com -b all
```

![](/notes-assets/6e2bd2e5c173b3e6447b.webp)

通过`all`选项，我们拿到所有信息如下，发现了381个网址，这里面肯定有我们感兴趣的东西\~
