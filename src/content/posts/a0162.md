原文结合提示与源码，发现待验证字符串按口令拼接固定盐后计算 SHA-1。固定盐不能抵御来源可猜的口令。

![](/notes-assets/5a670615691591c04ae8.webp)

使用 wget 递归下载网站所有 pdf ，一共34个

```
wget --mirror --accept=pdf --no-parent http://61.147.171.105:51977/
```

--mirror 启用递归镜像相关选项；是否保留目录结构和其他参数应以实际 wget 版本的帮助为准。

原脚本使用 pdfminer.six 提取候选并与摘要比较。其 isalpha 筛选可能遗漏包含数字或标点的候选，找到后只退出内层循环；需结合样本复测。

```
# python3.8 



import os

import hashlib

from pdfminer.high_level import extract_text





def find_matching_sha1(word_list, target_sha1):

    for word in word_list:

        word = word + "Salz!"

        sha1_hash = hashlib.sha1(word.encode('utf-8')).hexdigest()

        if sha1_hash == target_sha1:

            word = word.replace("Salz!", "")

            print(f"找到匹配的单词: {word}")

            word = word + "Salz!"

            return word





def process_pdf(file_path):

    try:

        target_sha1 = "3fab54a50e770d830c0416df817567662a9dc85c"

        text = extract_text(file_path)



        words = text.split()

        word_list = [word for word in words if word.isalpha()]

        word = find_matching_sha1(set(word_list),target_sha1)

        if word:

            print(f"--- Content of {file_path} find {word} matching {target_sha1}---")

            return word

    except Exception as e:

        print(f"Failed to process {file_path}: {e}")



def recursive_read_pdfs(directory):

    for root, dirs, files in os.walk(directory):

        for file in files:

            if file.lower().endswith('.pdf'):

                file_path = os.path.join(root, file)

                word = process_pdf(file_path)

                if word:

                    break



if __name__ == "__main__":

    pdf_directory = '/Users/ailx10/ailx10/pdf/61.147.171.105:51977'

    recursive_read_pdfs(pdf_directory)
```
