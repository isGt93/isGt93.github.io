ailx10说：这篇是在2023年2月之前写的，后来又改过。上一回试了 PyInstaller 加密，我又换 Nuitka，看编译之后发布包会变成什么。普通编译、standalone、onefile 轮着试，运行库也得一起搬到虚拟机，才能确认离开开发电脑还能不能启动。旧的解包工具这次没照原路拆出来，文件结构也不再一样。这篇主要记录自己从“能编译”走到“能分发”的过程。保护代码是一条线，依赖和运行环境是另一条线，两条都得接上，工具才能真交到别人手里。

---

用Nuitka编译exe，复制运行库并尝试standalone/onefile迁移到VM，旧PyInstaller解包工具失败。

核查提示：格式不同使专用解包器失败不证明无法逆向；移植一台VM不等全部系统兼容。 旧环境及截图细节未逐项核验。

本文记录 Nuitka 编译与分发实验。旧版 PyInstaller 专用提取工具无法解析不同格式，并不代表编译结果无法逆向。

### 第一步：python代码打包成exe

- 依赖2个文件，会从github下载
- 可以通过迅雷下载到指定位置即可

```
nuitka main.py
```

### 第四步：破解失败，过去的解包工具已经失效，并且也没有任何其他解包工具

```
python pyinstxtractor.py main.exe
```

![](/notes-assets/0ac21fdaee110d5ca9a1.webp)

### 第五步：简单移植，让别的电脑也能运行

如果想要一堆文件，那么可以通过下面的命令（不推荐）

```
nuitka --standalone --nofollow-imports --enable-plugin=pyqt5 --follow-import-to=my_import --output-dir=out main.py
```

如果只要一个exe，那么可以通过下面的命令（推荐）

```
nuitka --onefile --nofollow-imports --enable-plugin=pyqt5 --follow-import-to=my_import --output-dir=out main.py
```

### 第六步：移植成功

移植到虚拟机中，成功运行～

![](/notes-assets/c229b19b66e177e18347.webp)

能迁移一次是一点进展，不是全平台兼容。工具不适用也不等于程序不可分析，交付和保护各自的问题，仍要分别拿样本去看。
