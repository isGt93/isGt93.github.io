## 一、Spark RDD创建操作

**1、数据集合**

创建一个能够并行操作的分布式数据集，集合中的元素都会被复制。例如，从普通数组创建RDD，里面包含1\~9，分别在3个分区里。

```
val data = Array(1,2,3,4,5,6,7,8,9)
val distData = sc.parallelize(data,3)
```

RDD的一个重要参数是将数据集划分成，分片的数量，对每个分片，Spark会在集群中运行一个对应的任务，一般情况下Spark会自行设定分片的数量。

**2、外部数据源**

可以通过Hadoop支持的外部数据源建立分布式数据集，Spark支持文本文件，序列文件，以及其他任何Hadoop输入格式文件。

通过文本文件创建RDD要使用SparkContext的textFile方法，这个方法会使用一个文件的URL路径，然后读入这个文件建立一个文本行的集合。

```
val distFile1 = sc.textFile("C:\study\spark\hack.txt")
val distFile2 = sc.textFile("C:\study\spark\hack.txt,C:\study\spark\ailx10.txt")
```

## 二、Spark RDD转换操作

**1、map**

map是对RDD中的每个元素都执行一个指定的函数，来产生一个新的RDD，RDD之间的元素是一对一关系。

```
    val rdd1 = sc.parallelize(1 to 9,3)
    val rdd2 = rdd1.map(x=>x*2)
```

![](/notes-assets/7d5ca05b4b867e6e95f6.webp)

**2、filter**

filter是对RDD元素进行过滤，返回一个新的数据集，经过func函数后，返回值为true的元素组成。

```
val rdd3 = rdd2.filter(x=>x>10)
```

![](/notes-assets/531eab26ae01130c304d.webp)

**3、flatMap**

flatMap类似于map，但是每一个输入元素，会被映射为多个元素，RDD之间的元素是一对多的关系。

```
 val rdd4 = rdd3.flatMap(x=>x to 17)
```

![](/notes-assets/bbe788cb3ff3e77a8c7a.webp)

**4、mapPartitions**

mapPartitions的map的变种，map的输入函数是应用于RDD中的每个元素，而mapPartitions的输入函数式每个分区的数据，也就是把每个分区中的内容作为整体来处理。

```
 def myfunc[T](iter:Iterator[T]):Iterator[(T,T)]={
    var res = List[(T,T)]()
    var pre = iter.next
    while(iter.hasNext){
      val cur = iter.next
      res.::=(pre,cur)
      pre = cur
    }
    res.iterator
  }

val rdd5 = rdd1.mapPartitions(myfunc)
```

![](/notes-assets/0ec74b0fee5c83575314.webp)

**5、mapPartitionsWithIndex**

mapPartitionsWithIndex与mapPartitions的功能类似，只是多传入split index而已，所有func函数必须是（Int，Iterator\<T\> \=\> Iterator\<U\> ）

**6、sample**

sample 依据采样比例和随机种子抽样，返回数量一般不保证固定。

```
    val a = sc.parallelize(1 to 100,3)
    val b = a.sample(false,0.06,0)
```

![](/notes-assets/a02722ac3157eb53d0f2.webp)

**7、union**

union是数据合并，返回一个新的数据集，由原数据集和otherDataset联合而成。

```
    val rdd8 = rdd1.union(rdd3)
    rdd8.collect().foreach(println)
```

![](/notes-assets/559f9dbce6c8a126f900.webp)

**8、intersection**

intersection是数据交集，返回一个新的数据集，包含两个数据集的交集数据。

```
val rdd9 = rdd1.intersection(rdd2)
```

![](/notes-assets/b72a5026017bce9340c4.webp)

**9、distinct**

distinct是数据去重，返回一个数据集，它是对两个数据集去重。

```
val rdd10 = rdd1.union(rdd2).distinct
```

![](/notes-assets/711397e44933160c2d43.webp)

**10、groupByKey**

groupByKey是数据分组操作，在一个由（Key，Value）对组成的数据集上调用，返回一个（Key，Seq\[Value\]）对的数据集。

```
val rdd11 = sc.parallelize(Array((1,1),(2,2),(1,2),(2,1)))
val rdd12 = rdd11.groupByKey()
```

![](/notes-assets/eace9deef7e96f5b59e9.webp)

**11、reduceByKey**

reduceByKey是数据分组聚合操作，在一个（Key，Value）对的数据集上使用，返回一个（Key，Value）对的数据集，Key是相同的值，都被使用指定的reduce函数聚合到一起，与groupByKey类似，任务的个数可以通过第二个参数指定。

```
val rdd13 = rdd11.reduceByKey((x,y)=>x/y)
```

![](/notes-assets/ce322eb85a454f9660ce.webp)

**12、aggregateByKey**

aggregateByKey和reduceByKey不同之处在于，reduceByKey输入输出都是（Key，Value）对，而aggregateByKey输出是（K，U）。

> aggregateByKey(zeroValue:U)(seqOp:(U,T)\=\>U,combOp:(U,U)\=\>U)

- seq操作符，描述如何将T合并入U
- comb操作符，描述如何合并2个U

```
val rdd14 = sc.parallelize(List((10,3),(1,2),(10,4),(2,3)))
val rdd15 = rdd14.aggregateByKey(0)(math.max(_,_),_+_)
```

![](/notes-assets/012af8ecfeee5570204e.webp)

**13、combineByKey**

combineByKey是对RDD中的数据集按照key进行聚合操作，聚合操作的逻辑是通过自定义函数提供给combineByKey。

- createCombiner：在遍历（k，v）时，如果combineByKey第一次遇到值为k的key，那么将这个（k，v）调用createCombiner函数，将v转化为c
- mergeValue ：在遍历（k，v）时，如果combineByKey不是第一次遇到值为k的key，那么将对这个（k，v）调用mergeValue 函数，将v累加到聚合对象中
- mergeCombiners ：在分布式环境中，RDD的每个分区独立进行combineByKey操作，最后需要对各个分区的结果进行聚合

```
val data = Array((1,1.0),(1,2.0),(1,3.0),(2,4.0),(2,5.0),(2,6.0))
val rdd16 = sc.parallelize(data,2)    

val combine1 = rdd16.combineByKey(
      createCombiner= (v:Double)=>(v:Double,1),
      mergeValue = (c:(Double,Int),v:Double)=>(c._1+v,c._2 +1),
      mergeCombiners = (c1:(Double,Int),c2:(Double,Int))=>(c1._1 + c2._1,c1._2 + c2._2),
      numPartitions = 2)
```

![](/notes-assets/43e4d1627f2af00db800.webp)

**14、sortBy**

sortBy是排序操作，第一个参数是函数，第二个参数是升序还是降序，第三个参数是RDD分区数。

```
val rdd17 = rdd1.sortBy(x=>x,false)
```

![](/notes-assets/9bc47d81d0565c1bd8cd.webp)

## 15、join

join是连接操作，将输入数据集（k,v）和另一个数据集（k,w）进行join，得到（k,(v,w)），该操作是对于相同的k的v、w集合进行笛卡尔积操作，也就是v和w的所有组合。

```
val rdd11 = sc.parallelize(Array((1,1),(2,2),(1,2),(2,1)))
val rdd18 = rdd11.join(rdd11)
```

![](/notes-assets/03893cf9fb511ffc3da6.webp)

**16、cogroup**

cogroup是将输入数据集（k，v）和另一个数据集（k，w）进行cogroup，得到一个格式为（k，seq\[v\]，seq\[w\]）的数据集。

```
    val rdd19 = sc.parallelize(Array((1,1),(2,2),(1,2),(2,1)))
    val rdd20 = sc.parallelize(Array((1,3),(1,4),(2,4),(2,3)))

    val rdd21 = rdd11.cogroup(rdd20)
```

![](/notes-assets/a3a83e06d214a2203730.webp)

**17、cartesian**

cartesian是笛卡尔积，对于数据集T和数据集U进行笛卡尔操作，得到（T，U）格式的数据集。

```
    val rdd19 = sc.parallelize(Array((1,1),(2,2),(1,2),(2,1)))
    val rdd20 = sc.parallelize(Array((1,3),(1,4),(2,4),(2,3)))

    val rdd22 = rdd11.cartesian(rdd20)
```

![](/notes-assets/fdf80cd4293f8752d539.webp)

**18、randomSplit**

randomSplit是对RDD按照权重进行数据分割，第一个参数为分割权重数组，第二个参数是随机种子，该方法用于样本划分。

```
    val rdd23 = rdd1.randomSplit(Array(0.3,0.7),1)
    rdd23(0).collect().foreach(println)
```

![](/notes-assets/6d413eb01e8697c9a048.webp)

**19、subtract**

subtract是对RDD进行减法，将输入的RDD中的元素减去参数中包含的元素。

```
    val rdd24 = sc.parallelize(1 to 9,3)
    val rdd25 = sc.parallelize(1 to 3,3)

    val rdd26 = rdd24.subtract(rdd25)
```

![](/notes-assets/15e2e52cd32d8e4afeca.webp)

**20、zip**

zip是对两个RDD进行拉链操作。

```
    val rdd27 = sc.parallelize(Array(1,2,3,4),3)
    val rdd28 = sc.parallelize(Array('a','i','l','x'),3)

    val rdd29 = rdd27.zip(rdd28)
```

![](/notes-assets/27af38bc705e938fc339.webp)

## 三、Spark RDD行动操作

**1、reduce**

对数据集的所有元素执行聚合函数，该函数必须是可交换的。

```
    val rdd30 = sc.parallelize(1 to 9,3)
    val rdd31 = rdd30.reduce(_+_)
    println(rdd31)
```

![](/notes-assets/fa4cbd51054caeeea86f.webp)

**2、collect**

collect是将数据集中的所有元素以一个array的形式返回。

```
    val rdd32 = sc.parallelize(1 to 9,3)
    rdd32.collect().foreach(println)
```

![](/notes-assets/c992359b21720e468146.webp)

**3、count**

count返回数据集中元素的个数。

```
    val rdd33 = sc.parallelize(1 to 9,3)
    print(rdd33.count())
```

![](/notes-assets/1630a670b48c42a52615.webp)

**4、first**

first返回数据集中的第一个元素。

```
    val rdd34 = sc.parallelize(1 to 9,3)
    print(rdd34.first())
```

![](/notes-assets/873f6d37d8133f429a5b.webp)

**5、take**

take(n)返回一个数据集中的前n个元素。

```
    val rdd35 = sc.parallelize(1 to 9,3)
    rdd35.take(3).foreach(println)
```

![](/notes-assets/b50c93a54c3a450b5593.webp)

**6、takeSample**

takeSample返回包含随机的n个元素的数组，第一个参数是抽样时是否放回，第二个参数是抽样数，第三个参数是随机种子。

```
    val rdd36 = sc.parallelize(1 to 9,3)
    rdd36.takeSample(true,3,0).foreach(println)
```

![](/notes-assets/d5e10ada1db65e0edfc8.webp)

**7、takeOrdered**

takeOrdered 返回按指定顺序排列的前 n 个元素，不是随机抽样。

```
    val rdd37 = sc.parallelize(1 to 9,3)
    rdd37.takeOrdered(3).foreach(println)
```

![](/notes-assets/2efb3012f85e1e7ba145.webp)

**8、saveAsTextFile**

saveAsTextFile把数据集中的元素写到一个文本文件，spark会对每个元素调用toString方法，把每个元素存成文本文件的一行。

```
    val rdd38 = sc.parallelize(1 to 9,3)
    rdd38.coalesce(1).
      saveAsTextFile("C:\Users\ailx10\IdeaProjects\hello\hello\day1006-maven\src\WordCount\ailx10")
```

![](/notes-assets/f8aa2742a418822c4379.webp)

**9、countByKey**

countByKey对于（k,v）类型的RDD，返回一个（k,Int）的map，Int为k的个数。

```
    val rdd39 = sc.parallelize(List((10,3),(1,2),(10,4),(2,3)))
    rdd39.countByKey().foreach(println)
```

![](/notes-assets/5f3081462d0dcf9f9612.webp)

**10、foreach**

foreach是对数据集中的每个元素都执行func函数。

```
    val rdd40 = sc.parallelize(1 to 9,3)
    rdd40.foreach(x=>x*2)
    rdd40.collect().foreach(println)
```
