ailx10说：这篇是我2022年6月写的。图片从 HTTP 流量里提出来之后，我又跟着书给它接上 OpenCV 的 Haar 级联，让程序在图片里找正面人脸、画框输出。前面是网络字节，这一步突然变成了图像，几个实验像积木一样拼到一起，挺能让人理解作者为什么这样排章节。这篇记录的主要是检测流程和本地结果，标题用了常见的“识别”说法，实际做的是找出可能的人脸位置。对当时的我来说，能把两段本来分开的技术接成一条链，就是这次练习最有趣的部分。

---

参考代码：

```
# -*- coding: utf-8 -*-
# @Time    : 2022/6/13 7:36 PM
# @Author  : ailx10
# @File    : detector.py

import cv2
import os

ROOT = "/Users/ailx10/py3hack/chapter4/picture"
FACES = "/Users/ailx10/py3hack/chapter4/faces"
TRAIN = "/Users/ailx10/py3hack/chapter4/training"

def detect(srcdir=ROOT,tgtdir=FACES,train_dir=TRAIN):
    for fname in os.listdir(srcdir):
        if not fname.upper().endswith(".JPG"):
            continue
        fullname = os.path.join(srcdir,fname)
        newname = os.path.join(tgtdir,fname)
        img = cv2.imread(fullname)
        if img is None:
            continue
        gray = cv2.cvtColor(img,cv2.COLOR_BGR2GRAY)
        training = os.path.join(train_dir,"haarcascade_frontalface_alt.xml")
        cascade = cv2.CascadeClassifier(training)
        rects = cascade.detectMultiScale(gray,1.3,5)
        try:
            if rects.any():
                print("Got a face")
                rects[:,2:] += rects[:,:2]
        except AttributeError:
            print(f"No face found in {fname}")
            continue

        for x1,y1,x2,y2 in rects:
            cv2.rectangle(img,(x1,y1),(x2,y2),(127,255,0),2)
        cv2.imwrite(newname,img)

if __name__ == "__main__":
    detect()
```

找到人脸不等于知道是谁，更不能由浏览图片推断个人行为。把输入限制和检测结果保留下来，这个小练习就能成为理解视觉任务边界的起点。
