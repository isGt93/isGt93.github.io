ailx10说：这篇是2022年11月之前写的，后来又改过。为了方便启停漏洞环境，我试着搭 Vulfocus。Docker 镜像起来以后，从 Web 管理页选环境、启动、连接，再去找 flag 提交，刷靶场的流程一下被集中到同一处。笔记把安装和使用都留下，也让我意识到便利背后交出了什么：挂进容器的 Docker socket 能管理宿主上的资源，不只是一个普通文件。它算一次为后续学习搭工作台的小练习，平台跑通以后，真正的漏洞原理还是要回到每个环境里逐个研究。

---

原命令挂载宿主机 Docker socket，授予高权限管理能力，不能直接在生产主机执行；latest 未固定版本，默认账号应更改。

Vulfocus 是用于组织漏洞实验的平台。本文保留历史部署记录；镜像和默认设置可能已改变。

### 一、启动docker

```
systemctl start docker
```

### 二、拉取vulfocus镜像

```
docker pull vulfocus/vulfocus:latest
```

![](/notes-assets/9dac4ac34fa464793c0c.webp)

### 三、运行vulfocus

```
docker run -d -p 80:80 -v /var/run/docker.sock:/var/run/docker.sock  -e VUL_IP=192.168.0.105 vulfocus/vulfocus
```
