ailx10说：这篇是我2025年3月写的。“抄错的字符”给了个很像日常粗心的设定：数字被抄成字母，字母又全改成了大写。我把它当成候选恢复问题，不猜某一种固定替换，而是按四个字符一组枚举可能的大小写和数字，再试 Base64 解码，逐步组合结果。这篇保留了这个小脚本的思路，也留下它的局限：能解成 ASCII 并不代表句子就对了，候选还得靠语义和题目格式继续筛。原文没有明确展示唯一的最终答案，这个空缺也不该在摘要里被悄悄补成成功。

---

编辑核查提示：枚举仅产生候选；ASCII 可含控制字符、正确解码不代表有意义，最终唯一答案未由原文明确确认。组合量很大，应限制候选范围并处理末组填充。

老师让小明抄写一段话，结果粗心的小明把部分数字抄成了字母，还因为强迫症把所有字母都换成大写。你能帮小明恢复并解开答案吗：QWIHBLGZZXJSXZNVBZW

难度系数：1

每4个字符一组，按照字符映射表进行替换，得到所有的可能性，依次进行base64解码，重复这个过程，即可

```
import base64
import itertools
# 字符映射表
char_map = {
    'A': ['A', 'a', '4'], 'B': ['B', 'b', '8'], 'C': ['C', 'c'],
    'D': ['D', 'd'], 'E': ['E', 'e', '3'], 'F': ['F', 'f'],
    'G': ['G', 'g', '6', '9'], 'H': ['H', 'h'], 'I': ['I', 'i', '1'],
    'J': ['J', 'j'], 'K': ['K', 'k'], 'L': ['L', 'l', '1'],
    'M': ['M', 'm'], 'N': ['N', 'n'], 'O': ['O', 'o', '0'],
    'P': ['P', 'p'], 'Q': ['Q', 'q', '9'], 'R': ['R', 'r'],
    'S': ['S', 's', '5'], 'T': ['T', 't', '7'], 'U': ['U', 'u'],
    'V': ['V', 'v'], 'W': ['W', 'w'], 'X': ['X', 'x'],
    'Y': ['Y', 'y'], 'Z': ['Z', 'z', '2']
}


def try_decode_base64(encoded_str):
    """尝试对给定字符串进行Base64解码，并检查是否为ASCII"""
    # 确保字符串长度为4的倍数，并根据需要添加填充字符
    padding = len(encoded_str) % 4
    if padding:
        encoded_str += '=' * (4 - padding)
    try:
        decoded_bytes = base64.b64decode(encoded_str)
        decoded_str = decoded_bytes.decode('ascii')  # 强制使用ASCII解码
        return decoded_str
    except (UnicodeDecodeError, base64.binascii.Error):
        return None


def generate_combinations(chars):
    """生成所有可能的字符替换组合"""
    return [''.join(c) for c in itertools.product(*[char_map[char] for char in chars])]


def process_group(group):
    """处理每组4个字符的所有可能性"""
    all_combinations = generate_combinations(group)
    results = []
    for combination in all_combinations:
        decoded = try_decode_base64(combination)
        if decoded is not None:
            results.append(combination)
    return results


def main():
    target_string = "QWIHBLGZZXJSXZNVBZW"
    groups = [target_string[i:i + 4] for i in range(0, len(target_string), 4)]

    group_results = []
    for group in groups:
        results = process_group(group)
        if results:
            group_results.append(results)
        else:
            print(f"No valid Base64 decoding found for the group: {group}")
            return

    # 生成所有可能的新target_strings
    new_target_strings = [''.join(t) for t in itertools.product(*group_results)]

    successful_decodes = []
    for new_target_string in new_target_strings:
        decoded = try_decode_base64(new_target_string)
        if decoded is not None:
            successful_decodes.append((new_target_string, decoded))

    if successful_decodes:
        for original, decoded in successful_decodes:
            print(f"Original string: '{original}'--> Decoded string: '{decoded}'
")
    else:
        print("No valid overall Base64 decoding found for any of the combinations.")


if __name__ == "__main__":
    main()
```

能按ASCII解出来只是一个过滤条件，还不一定就是正确文本。保留多个候选再结合上下文检查，才能看见脚本替人省掉了哪段重复工作，又把哪段判断留给了人。
