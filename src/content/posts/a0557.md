## 1、Jinja2模版引擎

视图函数可能需要表达业务逻辑（写数据库），又要表达表现逻辑（页面展示）

因此把表现层移到模版中，提高代码的可维护性

模版包含响应文本的文件，其中包含占位变量表示的动态部分，具体的内容只有在请求的上下文中才能知道。使用真实值替换变量，再返回最终得到的响应字符串，这个过程叫渲染～

为了渲染模版，Flask使用的是 Jinja2模版引擎～

![](/notes-assets/3209837c7961bc6f44be.jpg)

模版中使用{{ name }} 结构表示一个变量，这是一种特殊的占位符，告诉模版引擎，这个位置的值从渲染的数据中获得～

Jinja2 能识别所有类型的变量，比如列表、字典和对象～

![](/notes-assets/3b23575e23c96a7b6e00.jpg)

模板过滤器示例为 {{ name\|capitalize }}；原文拼写有误。对不可信输入使用 safe 会取消自动转义，必须谨慎处理。

| 过滤器名 | 说明 |
| --- | --- |
| safe | 渲染时不进行转义，危险 |
| capitalize | 把值的首字母转换成大写，其他是小写 |
| lower | 把值转换成小写形式 |
| upper | 把值转换成大写形式 |
| title | 把值中每个单词的首字母转换成大写 |
| trim | 把值的首尾空格删掉 |
| striptags | 渲染之前把值中所有的HTML标签都删掉 |

## 2、使用Flask-Bootstrap集成Bootstrap

bootstrap是前端框架，可以帮助前端人员快速的实现页面展示需求～

![](/notes-assets/2a79d3a7c606139337fa.webp)

## 5、使用Flask-Moment本地化日期和时间

为了在不同的地方，网站显示当地的时间，就需要使用moment.js，先安装flask-moment

![](/notes-assets/5483d0eefd12c9ebb0d3.jpg)

然后在base.html页面中引入moment.js

```
{% block scripts %}
{{  super() }}
{{ moment.include_moment() }}
{% endblock %}
```

再在路由函数中添加datetime变量

```
@app.route("/")
def index():
    return render_template("index.html",current_time=datetime.utcnow())
```

最后在index.html中使用flask-moment渲染时间戳

```
<p>当地时间：{{ moment(current_time).format('LLL') }}</p>
<p>那是几分钟前：{{ moment(current_time).fromNow(refresh=True) }} </p>
```
