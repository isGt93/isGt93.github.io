## 1.数据集搜集和数据清洗

MNIST 图像是 28×28 像素，即 784 维；原文 24×24 为笔误。训练和测试集分别使用 6 万与 1 万条。

## 2.特征化

数据集已经是一个二维数组了，训练集（60000,784），测试集（10000,784）

x是特征，y是对应的类别，也就是0123456789...

## 3.训练模型

实例化神经网络算法，隐藏层为一层，神经元个数为50个：

```
mlp = MLPClassifier(hidden_layer_sizes=(50,), #隐藏层，神经元个数
                    max_iter=10, #最大迭代次数
                    alpha=1e-4,#正则化项参数
                    solver='sgd',#激活函数，随机梯度下降 
                    verbose=10, #是否将输出打印到stdout
                    tol=1e-4, #优化容忍度
                    random_state=1,#随机数生成器的状态
                    learning_rate_init=.1)#学习率，用于权重更新
mlp.fit(X_train, y_train)
#X_train (60000, 784)
#y_train (60000,)
```

## 5.完整代码

```
import matplotlib.pyplot as plt
from sklearn.datasets import fetch_mldata
from sklearn.neural_network import MLPClassifier

mnist = fetch_mldata("MNIST original")

X, y = mnist.data / 255., mnist.target
X_train, X_test = X[:60000], X[60000:]
y_train, y_test = y[:60000], y[60000:]


mlp = MLPClassifier(hidden_layer_sizes=(50,), max_iter=10, alpha=1e-4,
                    solver='sgd', verbose=10, tol=1e-4, random_state=1,
                    learning_rate_init=.1)

mlp.fit(X_train, y_train)
print("Training set score: %f" % mlp.score(X_train, y_train))
print("Test set score: %f" % mlp.score(X_test, y_test))
```
