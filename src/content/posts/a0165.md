ailx10说：这篇是我2024年12月写的。ez\_curl 让我盯着前后端对同一份请求的不同理解看了很久。PHP 这边有检查，Express 那边又有自己的解析方式；我试着在头值里放换行，又堆查询参数，让末尾的 admin\=false 不按预想生效。本地环境能复现，可远程一直没有拿到 flag。这篇把这道题停在了真实的位置，没有为了补一个结尾把它写成成功。它留下的价值是那次对解析差异的摸索，也留下了一个提醒：本地能触发的现象，还需要和远端版本、限制、实际响应逐项对照。

本题比较前端 PHP 对输入的检查、cURL 实际构造的请求和后端 Express 的解析结果；这三层都应按具体版本和原始报文核验。

知识点1：

原实验尝试让头值中的换行在后端形成额外字段。cURL 与服务器是否接受、保留或拒绝此类输入，取决于版本及配置，不能一概而论。

知识点2：

查询参数上限及超限行为取决于 Express 所用查询解析器、版本和配置。原文一处称抛错、另一处称截断，两者需要实际复测。

难度系数：5（官方难度：4）

代码审计

- headers 中 不能有 `admin:true`
- params 转为 url ，并在尾巴上拼接 `&admin=false`

![](/notes-assets/dc277640c054ad43f7c3.webp)

`stripos` 函数用于查找字符串在另一个字符串中首次出现的位置。与 `strpos` 不同的是，`stripos` 对大小写不敏感。如果找不到子字符串，则返回 `false`。

`http_build_query` 函数用于生成 URL-encoded 的查询字符串。它接受一个数组（通常是关联数组）或对象作为输入，并返回一个格式化后的查询字符串，其中键值对之间用 \& 分隔，键和值之间用 \= 分隔。

```
<?php

highlight_file(__FILE__);

$url = 'http://back-end:3000/flag?';

$input = file_get_contents('php://input');

$headers = (array)json_decode($input)->headers;

for($i = 0; $i < count($headers); $i++){

    $offset = stripos($headers[$i], ':');

    $key = substr($headers[$i], 0, $offset);

    $value = substr($headers[$i], $offset + 1);

    if(stripos($key, 'admin') > -1 && stripos($value, 'true') > -1){

        die('try hard');

    }

}

$params = (array)json_decode($input)->params;

$url .= http_build_query($params);

$url .= '&admin=false';

$ch = curl_init();

curl_setopt($ch, CURLOPT_URL, $url);

curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);

curl_setopt($ch, CURLOPT_TIMEOUT_MS, 5000);

curl_setopt($ch, CURLOPT_NOBODY, FALSE);

$result = curl_exec($ch);

curl_close($ch);

echo $result;

```
