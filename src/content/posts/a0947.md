ailx10说：这篇是2018年11月之前写的，后来又改过。决策树入门，我先老老实实拿鸢尾花练。四个长度宽度特征、一百五十条记录，训练以后再用 Graphviz 导出 PDF，模型终于不只是一个 predict 调用，而是一条条能顺着走的分支。看节点怎样划分、最后落在哪类，比一上来喂复杂日志更容易抓住感觉。笔记记下数据矩阵和画树过程，是想先把最小例子做明白。等后面换成安全行为，至少知道树在挑什么问题问样本，而不是只拿最后一个分类标签当黑盒答案。

> 决策树既可用于分类，也可用于回归。本文通过鸢尾花样本说明分类树。

内部节点按特征条件划分样本，分支表示条件结果，叶节点给出预测；节点不是某个对象。

Scikit-Learn自带了iris数据集，iris有个好听的中文名字叫`鸢尾花`。

`iris.data` 150\*4的矩阵，表示150条记录，每个记录代表了一朵鸢尾花萼片和花瓣的长度宽度。

```

 [4.7 3.2 1.3 0.2]
 [4.6 3.1 1.5 0.2]
 ...
 [6.3 2.5 5.  1.9]
 [6.5 3.  5.2 2. ]
 [6.2 3.4 5.4 2.3]

```

使用决策树算法进行训练，并将训练结果保存成pdf文件：

原图展示训练数据被划分，叶子纯度不能证明测试集泛化；还需考虑树深、剪枝和独立验证。

![](/notes-assets/81d1a50418b5be3d7331.jpg)

完整代码：

```
from sklearn.datasets import load_iris
from sklearn import tree
import pydotplus

iris = load_iris()
clf = tree.DecisionTreeClassifier()
clf = clf.fit(iris.data, iris.target)

dot_data = tree.export_graphviz(clf, out_file=None)
graph = pydotplus.graph_from_dot_data(dot_data)
graph.write_pdf("iris.pdf")
```

训练叶子很纯不代表新样本也分得好，树也不只用于分类。把深度、剪枝和独立测试接上，图才会从好看的解释变成可检验的模型。
