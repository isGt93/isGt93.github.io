我也忍不住，看了一下，究竟是什么魔力的页面，能让僵尸主机这么兴奋？原来是后台入口。

![](/notes-assets/ee7938094b3b603c83fe.jpg)

接下来，写一个油猴子脚本，分析了访问最频繁的IP地址。

```
import sqlite3

conn = sqlite3.connect("glastopf.db")
cursor = conn.cursor()

hosts = {}
for row in cursor.execute('SELECT * FROM events'):
    host = row[2].split(':')[0]
    if host in hosts:
        hosts[host] += 1
    else:
        hosts[host] = 1

sorted_dict = sorted(hosts.items(), key=lambda item: item[1], reverse=True)
for host in sorted_dict:
    print(host)

conn.close()
```

![](/notes-assets/5d8c69421426ac9ea8a7.jpg)
