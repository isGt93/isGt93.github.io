ailx10说：这篇是我2025年3月写的。Brainfuck 这题看起来是一大串加减号和尖括号，我没急着丢进在线工具，而是先跟着指针和单元值走，看看第一个 f、后面的 l 怎样被循环算出来。理解这一小段以后，再写 Python 把括号配对、八位环绕和输出接起来。这篇把手算和解释器放在一起，想留住符号背后的动作。它不是在破某种加密，解释器也只够这道题用；逗号输入、越界和坏括号这些情况，还没有被完整处理。

---

本题程序使用若干 Brainfuck 指令构造并输出字符。以下是原实验中使用的语法子集：

- '\+' 增加当前字节的值
- '-' 减少当前字节的值
- '\>' 移动指针到右边
- '\<' 移动指针到左边
- '.' 输出当前字节的ASCII字符
- '\[' 和 '\]' 构成循环，当当前字节为0时跳出循环

```
+++++ +++++ [->++ +++++ +++<] >++.+ +++++ .<+++ [->-- -<]>- -.+++ +++.< ++++[ ->+++ +<]>+ +++.< +++++ +++[- >---- ----< ]>--- ----- ---.< +++++ ++[-> +++++ ++<]> +++.< +++++ +[->- ----- <]>-- ----- -.--. ----. --.++ +++++ +.<++ ++++[ ->+++ +++<] >++++ +.++. <++++ ++[-> ----- -<]>- ----- ----. -.<++ +++++ [->++ +++++ <]>+. ----. ++++. <++++ +++[- >---- ---<] >---- .+.<+ +++++ ++[-> +++++ +++<] >++++ +++++ ++.<
```

- 首先，初始单元格设置为0。第一个部分是10个\+，所以单元格0的值是10。
- 然后进入循环 \[-\>\+\+\+\+\+\+\+\+\+\+\<\]，即每次循环将单元格0减1，同时单元格1加10。循环直到单元格0为0，此时单元格1的值是10\*10\=100。
- 然后指针移动到单元格1，执行\>\+\+. 所以单元格1的值变为100 \+2 \=102，对应的ASCII是 'f'，输出。
- 然后\+ \+\+\+\+\+ .，加6，得到108，对应'l'，输出。

```
def brainfuck_interpreter(code):

    data = [0] * 30000

    ptr = 0

    code_ptr = 0

    output = []

    loop_stack = []

    loop_map = {}



    # 预处理循环结构

    for i, c in enumerate(code):

        if c == '[':

            loop_stack.append(i)

        elif c == ']':

            start = loop_stack.pop()

            loop_map[start] = i

            loop_map[i] = start



    while code_ptr < len(code):

        c = code[code_ptr]



        if c == '>':

            ptr += 1

        elif c == '<':

            ptr -= 1

        elif c == '+':

            data[ptr] = (data[ptr] + 1) % 256

        elif c == '-':

            data[ptr] = (data[ptr] - 1) % 256

        elif c == '.':

            output.append(chr(data[ptr]))

        elif c == '[':

            if data[ptr] == 0:

                code_ptr = loop_map[code_ptr]

        elif c == ']':

            if data[ptr] != 0:

                code_ptr = loop_map[code_ptr]

        code_ptr += 1



    return ''.join(output)



# 原始Brainfuck代码

bf_code = ("+++++ +++++ [->++ +++++ +++<] >++.+ +++++ .<+++ [->-- -<]>- -.+++ +++.< ++++[ ->+++ +<]>+"

           " +++.< +++++ +++[- >---- ----< ]>--- ----- ---.< +++++ ++[-> +++++ ++<]> +++.< +++++ +[->-"

           " ----- <]>-- ----- -.--. ----. --.++ +++++ +.<++ ++++[ ->+++ +++<] >++++ +.++. <++++ ++[->"

           " ----- -<]>- ----- ----. -.<++ +++++ [->++ +++++ <]>+. ----. ++++. <++++ +++[- >---- ---<]"

           " >---- .+.<+ +++++ ++[-> +++++ +++<] >++++ +++++ ++.<")



# 清理代码中的非指令字符

clean_code = ''.join([c for c in bf_code if c in '><+-.,[]'])



# 执行解密

print(brainfuck_interpreter(clean_code))
```
