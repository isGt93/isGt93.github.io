ailx10说：这篇是在2018年11月之前写的，后来又改过。以前把一张数字图压成七百多维向量，换成循环网络，就得让它一行一行走过模型。我把 MNIST 重排成二十八步、每步二十八维，再用双层 LSTM 和 softmax 跑一轮，观察验证结果。数据还是熟悉的那份，输入形状一改，理解方式却完全不同。这篇留下的正是这个转弯：同一张图片，模型可以当成一袋像素，也可以当成一段顺序。亲手把维度改对、训练走通，比单听“循环网络”几个字更容易记住。

---

TFLearn数字RNN篇把784reshape为28步28维，以双128LSTM和softmax训练一轮，验证95.44%。

## 前提和待核查点

双层不是因为输入二维，10节点为输出不是隐藏；测试作为训练监控验证集需另留独立最终评估。

## 历史实验记录与代码

## 1.数据清洗与特征提取

训练数据集(55000,784)，测试数据集(10000,784)，标签采用`one-hot`独热编码，

在DNN或MLP中，我们将28x28的图片，转换成维度为784的特征向量，

在RNN中，我们需要用28x28的特征向量，

```
//从文件中加载数据集

Extracting mnist/t10k-labels-idx1-ubyte.gz

(55000, 784) --> (55000, 28, 28)

(10000, 784) --> (10000, 28, 28)
```

## 2.训练样本

构造RNN神经网络，使用LSTM算法（长短期记忆），

```
#输入层：设置输入参数的形状为28,28    

    net = tflearn.input_data(shape=[None, 28, 28])

#设置使用lstm算法，2维，因为(28,28)是2维

    net = tflearn.lstm(net, 128, return_seq=True)

    net = tflearn.lstm(net, 128)

#隐藏层：设置全连接网络，10个隐藏节点，激活函数softmax

    net = tflearn.fully_connected(net, 10, activation='softmax')

#输出层：优化函数adam，损失函数categorical_crossentropy

    net = tflearn.regression(net, optimizer='adam',

                         loss='categorical_crossentropy')

#创建模型

    model = tflearn.DNN(net, tensorboard_verbose=2)

#训练模型

    model.fit(X, Y, n_epoch=1, validation_set=(testX,testY), show_metric=True,

          snapshot_step=100)
```

## 4.完整代码

```
from __future__ import division, print_function, absolute_import

import numpy as np

import tflearn

from sklearn import metrics

import tflearn.datasets.mnist as mnist



X, Y, testX, testY = mnist.load_data(one_hot=True)



def do_rnn(X, Y, testX, testY):

    X = np.reshape(X, (-1, 28, 28))

    testX = np.reshape(testX, (-1, 28, 28))



    net = tflearn.input_data(shape=[None, 28, 28])

    net = tflearn.lstm(net, 128, return_seq=True)

    net = tflearn.lstm(net, 128)

    net = tflearn.fully_connected(net, 10, activation='softmax')

    net = tflearn.regression(net, optimizer='adam',

                         loss='categorical_crossentropy', name="output1")

    model = tflearn.DNN(net, tensorboard_verbose=2)

    model.fit(X, Y, n_epoch=1, validation_set=(testX,testY), show_metric=True,

          snapshot_step=100)



do_rnn(X, Y, testX, testY)
```

验证分数给了继续尝试的理由，但看过它来调整模型以后，还需要另一份最终测试。把这层区分留下，学习过程里的进步才不至于和真正未知数据的表现混在一起。
