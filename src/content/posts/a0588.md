ailx10说：这篇是在2025年4月之前写的，后来又改过。离线安全分析工具原来在本机能跑，这次要变成 SOAR 预案，第一步就是搬进容器。测试容器里装依赖、拷代码都顺，等想到真实环境怎么导入，资源路径、site-packages 和日志输出又冒了出来。我把它包装成联动应用，再从页面导入，一项项修这些边角。这篇记录的是从“脚本能执行”到“平台能接住”的迁移过程。业务逻辑可能没大变，入口、文件位置和输出方式却都要跟着新环境重新对齐。

---

将离线分析工具移入SOAR容器，打包新增site-packages设置路径，再封装应用联动APP从网页导入，修正资源文件和日志输出。

核查提示：复制新增目录可能漏已存在的传递依赖和原生库；stdout契约需定位而非普遍删日志，环境命令空格可能是排版。 旧环境及截图细节未逐项核验。

本文记录将离线工具迁入容器并封装为 SOAR 应用的过程。复制依赖目录可能遗漏传递依赖或原生库，应在目标环境完整验证。

接下来，就是考虑移植到真正的生产环境中，由于生产环境没有联网，因此不能直接安装依赖，可以将 site-packages 拷贝出来，和代码一并上传到生产环境中，然后通过环境变量指定依赖路径，再次运行，OK也可以运行。这种方法需要登陆后台，还是比较麻烦的，于是我将安全工具代码封装成了一个应用联动APP，通过SOAR预案直接调应用联动APP，整个方案只需要在Web页面导入，无需登后台，极大的简化了使用难度。

启动镜像，进入容器，清除启动脚本，共享宿主机网络

```
docker run -it --rm --network host --entrypoint="" [镜像名称:标签] /bin/bash
```

安装 pip3（`python3.10`）

```
python3.10 -m ensurepip --upgrade
```

把宿主机的文件复制进容器中

```
docker cp ./file.txt my_container:/usr/src/app/
```

把容器中的文件复制到宿主机

```
docker cp <container_id>:/path/in/container/file.txt /path/on/host/
```

项目安装python3依赖

```
pip3 install aiohttp
pip3 install pandas
pip3 install pycryptodome
pip3 install tldextract
pip3 install openpyxl
pip3 install xlsxwriter
```

寻找python3依赖库的位置

```
import pandas
print(pandas.__file__)

# /usr/local/lib/python3.10/site-packages/
```

查看安装前的依赖，查看安装后的依赖，将新增的依赖复制出来，放置在自己的 pylibs 文件夹中

- 方案1：只需在 `main.py` 函数中导入指定文件夹下的库

```
import sys
sys.path.append("/path/to/your/pylibs")

# 接下来就可以导入你的库了
import your_library
```

- 方案2：设置环境变量

```
export PYTHONPATH=/path/to/your/pylibs:$PYTHONPATH
python3 your_script.py
```

坑1：代码配置文件路径问题，使用全局路径解决

```
current_file_path = os.path.dirname(os.path.abspath(__file__))
# 向上跳转一级目录到plugin目录
parent_dir = os.path.dirname(current_file_path)
dat_path = os.path.join(parent_dir, "effective_tld_names.dat")
```

坑2：我的日志同时打印到cmd和文件中导致SOAR预案内部报错，注释掉 cmd\_handler 即可

```
# cmd_handler = logging.StreamHandler()
# cmd_handler.setFormatter(
#     logging.Formatter("%(asctime)s %(filename)s[line:%(lineno)d] %(levelname)s %(message)s"))
# log.addHandler(cmd_handler)
```

容器里启动不报错还不算结束，平台得读到约定格式的结果。把stdout、资源和传递依赖核对清楚，后续联动才不会在看不见的边角上断掉。
