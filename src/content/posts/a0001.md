ailx10说：这篇是我2021年11月写的。翻出这份几年前的 Web 安全实验时，2021 年已经快过完了，那一年不少空闲时间都花在了备考上。我还记得自己一直有个疑问：为什么 Web 安全课一开始要讲 HTTPS？不过实验还是得一步步做，先把 Zoobar、Apache 和数据库搭好，再折腾多站点、CA 和服务器证书。这篇留下的主要就是这段准备过程。回头看，环境搭建占了不少篇幅，真正的 HTTPS 操作很多藏在截图里，它更像一张当年上课时留下的施工单。

---

## 一、搭建 Zoobar 站点

搭建zoobar网站  
开启apache服务和mysql服务

```
service apache2 start
service mysql start
```

建立数据库和表mysql-\>

```
create database myzoo;
use myzoo;
create table Person(PersonID int primary key auto_increment, Password varchar(100),Salt varchar(100),Username varchar(100),Token varchar(100),Zoobars int default 10, Profile varchar(5000));
```

在 myzoo/includes 中配置数据库连接。下列根目录配置来自旧实验记录；是否修改应以当前 Apache 配置与最小权限原则为准。

```
<Directory />
        #Require all denied
</Directory>
```

修改/etc/apache2/sites-available/000-default.conf

```
<VirtualHost 127.0.0.1:80>
    ServerName www.myzoo.com
    DocumentRoot /var/www/myzoo
</VirtualHost>
```

修改/etc/hosts

```
127.0.0.1        www.myzoo.com
```

重启apache

```
service apache2 restart
```

## 二、配置 Apache 多站点

配置攻击方实验站点 www.attack.com。Debian 系 Apache 通常使用 /etc/apache2/sites-available/attack.conf，启用方式应以本机版本为准。

```
<VirtualHost 127.0.0.3:80>
    ServerName www.attack.com
    DocumentRoot /var/www/attack
</VirtualHost>
```

启用站点后，检查 sites-enabled 中的配置或链接：

```
<VirtualHost 127.0.0.3:80>
    ServerName www.attack.com
    DocumentRoot /var/www/attack
</VirtualHost>
```

修改/etc/hosts

```
127.0.0.3 www.attack.com
```

重启apache

```
service apache2 restart
```
