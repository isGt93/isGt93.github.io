ailx10说：这篇是2020年7月之前写的，后来又改过。接着本机信息，我把视线放到域里：计算机、用户组、密码策略、信任、域控，再到管理员的会话和进程。用系统命令问一遍，再试 PowerView，两个角度放在一起才知道哪些内容已经收到了、哪些还只是局部视图。笔记里“密码信息”说的是策略，不是直接看见了大家的口令，这种小差别整理时也得补清。整个过程更像逐步画环境地图，而不是跑一条命令得到全部答案；每项结果都要带着当前身份和查询范围来理解。

---

内网信息收集续篇查域计算机、用户组、密码策略、信任/DC、管理员会话与进程，列工具并导入PowerView查询。

核查提示：密码信息是策略非明文；net view枚举不等于全部成员，SRV需DNS搜索后缀；Unrestricted不是强制必要且不改权限，截图与本地化组名需核。 原环境、代码和图内细节尚未逐项核验。

本篇整理历史域环境信息收集命令，涉及域控制器、用户组、会话和权限；结果受权限、语言和系统版本影响。

## 一、收集域内基础信息

1、查询域（需要启动Computer Browser服务）

- 在Win7上操作启用

![](/notes-assets/8bd9176d401a989117f4.webp)

- 在Win2012R2上操作启用

![](/notes-assets/3d8bca859c9e910de8f8.jpg)

```
net view /domain
```

![](/notes-assets/b055ba36b38393b6bce2.webp)

2、查询域内所有计算机（然而只看到预控服务器）

```
net view /domain:HACKBIJI
```

![](/notes-assets/bdaad46e2fbdd4802566.webp)

3、查询域内所有用户组列表（默认13个组）

```
net group /domain
```

![](/notes-assets/c9b9045d5cb62461c2a7.webp)

4、使用 net view 查看可枚举的计算机；结果不保证覆盖全部域成员。

```
net group "domain computers" /domain
```

![](/notes-assets/c8ee85b19678ddf7fbb5.webp)

5、查看域密码策略：这不是读取用户明文密码。

```
net accounts /domain
```

![](/notes-assets/f65465bcf8a3928555df.webp)

6、获取域信任信息

```
nltest /domain_trusts
```

![](/notes-assets/bff197dd1d69526d7216.webp)

## 二、查找域控制器

1、查看域控制器的机器名

```
nltest /DCLIST:HACKBIJI
```

![](/notes-assets/8a3c8d65bbf2488ddcda.webp)

2、查看域控制器的主机名

```
nslookup -type=SRV _ldap._tcp
```

![](/notes-assets/fe8cd4301ccfa8f900c2.webp)

3、查看当前时间

```
net time /domain
```

![](/notes-assets/11632d2fdc3d30bdefec.webp)

4、查看域控制器组

```
net group "Domain Controllers" /domain
```

![](/notes-assets/a1a433f97329bbe1bc33.webp)

## 三、查询所有域用户列表

1、向域控制器进行查询（实用命令）

```

```

![](/notes-assets/04709e6a63a4d3542750.webp)

2、获取域内用户的详细信息（用户名、描述、SID、域名、状态）

```
wmic useraccount get /all
```

![](/notes-assets/1b392fb94404395e4a2f.webp)

3、查询本地管理员组用户（2个用户名，1个用户组）

```

```

![](/notes-assets/55c4bf45ac18a96d3ef3.webp)

7、查询远程系统中运行的任务（不怎么灵）

```
FOR /F %i in (ips.txt) DO @echo [+] %i && @tasklist /V /S %i /U user /P password 2>NUL > output.txt && FOR /F %n in (names.txt) DO @type output.txt | findstr %n > NUL && echo [!] %n was found running a process on %i && pause
```

![](/notes-assets/75d5a3598e26bfc59a38.webp)

8、扫描远程系统的NetBIOS信息

```
for /F %i in (ips.txt) do @echo [+] Checking %i && nbtstat -A %i 2>NUL >nbsessions.txt && FOR /F %n in (admins.txt) DO @type nbsessions.txt | findstr /I %n > NUL && echo [!] %n was found logged into %i
```

## 六、利用Powershell收集信息

- 检查Powershell状态

![](/notes-assets/3bca3a1e1800370ff677.webp)

- 将状态修改成Unrestricted（需要管理员权限）

![](/notes-assets/86cb28a2d01fda5cc04a.webp)

- 下载PowerView.ps1[\[2\]](#ref_2)
- 导入PowerView.ps1，并运行查询命令

```
Get-NetDomain #获取当前用户所在域的名称
```

![](/notes-assets/a9628029e26910dee6e8.webp)

```
Get-NetUser #获取所有用户的详细信息
```

![](/notes-assets/e343a2c077962483f71f.jpg)

```
Get-NetComputer #获取域内所有机器的详细信息
```

![](/notes-assets/8a2f4156aae9ceeb55e0.webp)

```
Get-NetShare #获取当前域内所有的共享信息
```

![](/notes-assets/f946af2bb7b385c806fb.webp)

```
Get-ADObject #获取活动目录的对象（内容超级多）
```

![](/notes-assets/c2cc51176d8d894028bf.webp)

```
Invoke-UserHunter #获取域用户登陆的计算机信息，以及该用户是否有本地管理员权限
```

![](/notes-assets/c6de354ff91ca8c65d77.webp)

```
Invoke-ProcessHunter #通过查询域内所有的机器进程找到特定用户
```

![](/notes-assets/f9db6c1a7e9fcb1f1352.webp)

还有很多命令等待你自己去探索～
