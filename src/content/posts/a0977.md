ailx10说：这篇是在2018年11月之前写的，后来又改过。循环网络继续拿 MNIST 练手，我用底层 TensorFlow 写 LSTM，让图像按二十八步进入，最后接十分类输出。第一版结果只有七成左右，和前面见过的高分差得挺远，于是把完整代码放出来，也想请人看看哪里还能改。它是一份还在路上的作业，没有把不够好看的数字藏起来。反复用同一套数据练新接口有个好处，结果一反常，注意力就会更自然地回到维度、训练顺序和结构这些自己刚写下的地方。

---

技术栈：`TensorFlow + RNN + LSTM`

准确率：70%，期待后面会优化模型，有大佬能指出其中的不足吗？

完整代码：

```
import tensorflow as tf

from tensorflow.contrib import rnn

import pickle

import gzip

#独热编码

def get_one_hot(x,size=10):

    v=[]

    for x1 in x:

        x2=[0]*size

        x2[(x1)]=1

        v.append(x2)

    return v

#加载样本，输出训练集，验证集，测试集

def load_data():

    with gzip.open('../data/MNIST/mnist.pkl.gz') as fp:

        training_data, valid_data, test_data = pickle.load(fp)

    return training_data, valid_data, test_data



training_data, valid_data, test_dat=load_data()

x_training_data,y_training_data=training_data

x1,y1=test_dat



y_training_data=get_one_hot(y_training_data)

y1=get_one_hot(y1)



#训练参数

batch_size=128 #1批数据128条样本

trianing_steps = 1000 #训练1000批数据

num_input = 28

timesteps = 28

num_hidden = 128 #隐藏层节点数

num_classes = 10 #分类数

#1 struct

x = tf.placeholder("float", [None, timesteps,num_input]) # x = (-1,28,28)

y_ = tf.placeholder("float", [None,num_classes]) # y = (-1,10)



W = tf.Variable(tf.random_normal([num_hidden, num_classes])) # W = (128,10)

b = tf.Variable(tf.random_normal([num_classes])) # (10,)



# 返回 x*W + b

def RNN(x,W,b):

    x = tf.unstack(x,timesteps,1) 

    lstm_cell = rnn.BasicLSTMCell(num_hidden,forget_bias=1.0)

    outputs,states = rnn.static_rnn(lstm_cell,x,dtype=tf.float32)

    return tf.matmul(outputs[-1],W) + b 



logits = RNN(x,W,b)

prediction = tf.nn.softmax(logits)

#2 loss

loss_op = tf.reduce_mean(tf.nn.softmax_cross_entropy_with_logits(logits=logits,labels=y_))

optimizer = tf.train.GradientDescentOptimizer(learning_rate=0.01)

train_op = optimizer.minimize(loss_op)



correct_pred = tf.equal(tf.argmax(prediction,1),tf.argmax(y_,1))

accuracy = tf.reduce_mean(tf.cast(correct_pred,tf.float32))



init = tf.global_variables_initializer()

#3 data

with tf.Session() as sess:

    sess.run(init)

    for i in range(int(len(x_training_data)/batch_size)):    

        batch_x=x_training_data[(i*batch_size):((i+1)*batch_size)]

        batch_y=y_training_data[(i*batch_size):((i+1)*batch_size)]

        batch_x = batch_x.reshape(batch_size,28,28)

        sess.run(train_op,feed_dict={x:batch_x,y_:batch_y})



#4 acc



    x1 = x1.reshape(-1,28,28)

    print(sess.run(accuracy,feed_dict={x:x1,y_:y1})
```

七成左右的结果是下一次改进的起点，不是RNN能力的终点。把数据顺序、训练时长和收敛状态保存下来，后来再改参数，才能知道自己究竟改变了什么。
