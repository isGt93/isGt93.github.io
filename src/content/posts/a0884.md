ailx10说：这篇是在2018年12月之前写的，后来又改过。接着折腾 tiny-c 的 0.1 版，我把词法、语法和编译脚本摆在一起，让它不只算一个表达式，还能声明变量、赋值、打印，再用语义动作吐出简单的栈式指令。一个小语言慢慢长出骨架，那种感觉比单看工具文档实在得多。我把每个文件的职责和对应代码留在这里，也顺势想到攻击检测：如果能先认词、再认结构，是不是就能少靠几段零散字符串做判断？这篇便是沿着这个念头继续往前搭的一块实验积木。

词法分析文件`scanner.l`：切词的规则，将文本流变成token流，后面以token为单位分析。

![](/notes-assets/57e7db9b23d65d247de0.jpg)

- 数字 T\_IntConstant `[0-9]+`
- 字符串 T\_StringConstant

  ```
  \042[^\042
  ]*\042
  ```
- 标识符 T\_Identifier `[_a-zA-Z][_a-zA-Z0-9]*`
- 类型 T\_Int `"int"`
- 系统函数 T\_Print `"print"`
- 字符 是字符本身 `[-/+*()=,;]`
- 空格 忽略
- 回车换行 行数\+1
- 其他 报错

```
%{
#define YYSTYPE char *
#include "y.tab.h"
int cur_line = 1;
void yyerror(const char *msg);
void unrecognized_char(char c);
#define _DUPTEXT {yylval = strdup(yytext);}
%}

/* note \042 is '"' */

OPERATOR        ([-/+*()=,;])
INTEGER         ([0-9]+)
STRING          (\042[^\042
]*\042)
IDENTIFIER      ([_a-zA-Z][_a-zA-Z0-9]*)
WHITESPACE      ([ 	]*)

%%
{OPERATOR}      { return yytext[0]; }
"int"           { return T_Int; }
"print"         { return T_Print; }

{INTEGER}       { _DUPTEXT; return T_IntConstant; }
{STRING}        { _DUPTEXT; return T_StringConstant; }
{IDENTIFIER}    { _DUPTEXT; return T_Identifier; }

{WHITESPACE}    { /* ignore every whitespace */ }

              { cur_line++; }
.               { unrecognized_char(yytext[0]); }
%%

int yywrap(void) { 
    return 1;
}

    char buf[32] = "Unrecognized character: ?";
    buf[24] = c;
```

自定义攻击语法可以作为研究思路，但语法匹配或解析失败本身不能断定输入是否安全，仍需考虑真实解释器和上下文。

在解决这个疑难问题之前，我们先看tiny-c语言0.1版本是如何定义语法的：

- S的产生式：`Stmt` \| `S Stmt`，很明显S可以递归`Stmt`
- Stmt的产生式：`VarDecl ';'` \| `Assign` \| `Print`，第一个像变量申明，第二个像赋值语句，第三个像是输出语句，之所以说像，是因为它们都属于非终结符
- VarDecl的产生式：`T_Int T_Identifier`  \| `VarDecl ',' T_Identifier`  ，第一个像是单个变量申明，第二个像是多个变量申明
- Assign的产生式：`T_Identifier '=' E ';'`，很明显的赋值语句
- Print的产生式：`T_Print '(' T_StringConstant Actuals ')' ';'` ，很明显打印
- Actuals 的产生式：`/* empty */` \| `Actuals ',' E` ，格式化打印后面的数字
- E的产生式：`E '+' E` 加法

`E '-' E` 减法

`E '*' E` 乘法

`E '/' E` 除法

`'-' E %prec U_neg` 貌似是取反 ，右结合

`T_IntConstant` 数字

`T_Identifier` 标识符

`'(' E ')'` 括号

可惜后面的action是生成汇编代码，

```
%{
#include <stdio.h>
#include <stdlib.h>
void yyerror(const char*);
#define YYSTYPE char *
%}

%token T_StringConstant T_IntConstant T_Identifier T_Int T_Print

%left '+' '-'
%left '*' '/'
%right U_neg

%%

S:   
    Stmt                        { /* empty */ }
|   S Stmt                      { /* empty */ }
;

Stmt:
    VarDecl ';'                 { printf("

"); }
|   Assign                      { /* empty */ }
|   Print                       { /* empty */ }
;

VarDecl:
    T_Int T_Identifier          { printf("var %s", $2); }
|   VarDecl ',' T_Identifier    { printf(", %s", $3); }
;

Assign:
    T_Identifier '=' E ';'      { printf("pop %s

", $1); }
;

Print:
    T_Print '(' T_StringConstant Actuals ')' ';'
                                { printf("print %s

", $3); }
;

Actuals:
    /* empty */                 { /* empty */ }
|   Actuals ',' E               { /* empty */ }
;

E:
    E '+' E                     { printf("add
"); }
|   E '-' E                     { printf("sub
"); }
|   E '*' E                     { printf("mul
"); }
|   E '/' E                     { printf("div
"); }
|   '-' E %prec U_neg           { printf("neg
"); }
|   T_IntConstant               { printf("push %s
", $1); }
|   T_Identifier                { printf("push %s
", $1); }
|   '(' E ')'                   { /* empty */ }
;

%%

int main() {
    return yyparse();
}
```

编译makefile：

```
OUT      = tcc
SCANNER  = scanner.l
PARSER   = parser.y
OUTFILES = lex.yy.c y.tab.c y.tab.h y.output $(OUT)

CC       = gcc
OBJ      = lex.yy.o y.tab.o

.clean:
	rm -f *.o $(OUTFILES)

$(OUT): $(OBJ)
	$(CC) -o $(OUT) $(OBJ)

lex.yy.c: $(SCANNER) y.tab.c
	flex %JSON%lt;

y.tab.c y.tab.h y.output: $(PARSER)
	bison -vdty %JSON%lt;
```
