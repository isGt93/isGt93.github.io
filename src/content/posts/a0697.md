ailx10说：这篇是在2022年1月之前写的，后来又改过。这次我想看看 WiFi 钓鱼究竟怎样把“网络问题”包装成让人输入密码的页面，于是用两张无线网卡和 Kali 搭实验，再拿自己的小米手机连上去观察。设备状态、网卡角色和门户页面都得一点点对，抓到 HTTP 后，界面上那句提示和实际提交的数据才接了起来。这篇记录的是本人设备上的受控实验。它把一个平时听来很抽象的风险变成几步能看的过程：用户以为自己在修连接，真正交出去的东西却可能是另一回事。

---

本文演示了黑客是如何通过Wi-Fi钓鱼页面，成功的拿到受害者的密码。建议广大读者，出行在外，关闭手机的无线连接，使用4G或5G网络通信。即使打开了手机的无线连接，千万不要输入自己的密码或者下载安装来历不明的软件。

![](/notes-assets/61b4e1ff423f7a4d79e9.jpg)

- 实验环境：Kali Linux虚拟机
- 实验设备：2个无线网卡（详情见附录）
- 实验时间：2020年1月3日晚上
- 实验地点：自己宿舍的床上
- 攻击者：ailx10的Kali Linux虚拟机
- 受害者：ailx10的小米手机

## 安装：在kali中安装wifiphisher就是这么简单

```
apt-get install wifiphisher
```

## 第一步：启动wifiphisher，选择利用的Wi-Fi

```
wifiphisher
```

![](/notes-assets/6a87c04ffdd3a7b1c03f.jpg)

启动界面，选择目标WiFi

最好选择人来人往，流动量大，使用人数多的Wi-Fi作为目标，比如酒店、火车站、肯德基、星巴克等。流传很广的是大概是如何，使用钓鱼Wi-Fi窥探星巴克美女白领的网上生活。不过，我没有做过，我知道法律的底线。于是，我选择的是假日酒店honor 356作为目标，开始了第一次钓鱼实验。

## 第二步：选择钓鱼场景

默认场景有4个，都是英文的，毕竟是老外写的软件，所以在咱这里都不适应，因为这种骗局太没技术了，一眼就看穿了。所以，网上有很多定制化的场景，比如把Facebook页面改成QQ页面，英文改成中文，这样就国产化了，中奖的概率就大大提升了。

![](/notes-assets/918b7e3bc144d817d424.webp)

默认场景1:脸书登陆页面

我选择的是第一个场景，会生成一个免费Wi-Fi，毕竟免费是最吸引人的嘛，也是最容易中奖的嘛。连接上免费Wi-Fi之后，手机会弹出一个脸书登陆页面，这个页面下你输入的所有信息，都会被黑客记录。丰富的场景以假乱真，这就是你隐私、密码泄漏的原因。所以出门在外用4G、付费才是正确途径，快来收听我的网络安全知乎Live，带你遇见更大的世界。

## 第三步：等待鱼儿上钩

这个时候，打开手机就可以看到免费Wi-Fi，安安静静的等着就可以了，就像小时候在河边钓鱼一样，所以类似的这种中间人攻击手法，都叫做钓鱼攻击。我在上大学的时候，就亲身经历了淘宝里的一场骗局：一个自称店家的陌生人打电话说我的货中途丢了，让我登陆一个给定的网址进行退款，这个网址展现出来的页面和淘宝退款一毛一样，需要输入淘宝的用户名和密码。万一，我输入了，那就被钓鱼了，密码泄漏就是这么没有技术含量。

![](/notes-assets/f00ecfb867d4a705df66.jpg)

免费Wi-Fi已经就绪，等待鱼儿上钩

## 第四步：鱼儿上钩，起杆

这里是我的小米手机连接了免费Wi-Fi，手机发起的HTTP请求，在这里都可以看到。我是受害者，也是攻击者，我拿自己做实验。手机刚刚连接上，HTTP请求就开始刷屏了，可能是手机后台在跑应用，我还没操作手机的时候：可以看到米U和QQ在跑。

![](/notes-assets/ea100a07ce30dab28aa1.jpg)

受害者手机安静状态

当我手机打开知乎App的时候：可以看到知乎图片和专栏的请求数据，知乎的手机App请求的服务器地址是`118.89.204.198`，这个相比小米和腾讯的域名请求，稍稍逊色了一点。

![](/notes-assets/dec8a9ec8407f3ecfbd1.jpg)

受害者手机浏览知乎App

不过，都是一堆网址索然无味，还不能保存浏览过的图片，差评。再看看钓鱼的脸书有没有货，直接按ESC将退出程序，这时候会显示受害者在钓鱼页面输入的信息，不同场景输入的内容不同，下面是场景2：升级路由器固件，捕获到的密码。这就成功啦～

![](/notes-assets/45d50ec72da9a7a1c544.webp)

场景2:升级路由器固件中输入的密码

## 第五步：洗洗睡觉，回忆实验

实验成功的关键1：你需要插入2个无线网卡

- 输入`iwconfig`出现下面内容，就OK～

![](/notes-assets/5e3ccea30e4a48a79ed8.jpg)

需要2个网卡

实验成功的关键2：你需要保证`wifiphisher`运行的时候，2个网卡都处于工作状态

- `wifiphisher`运行时，输入`ifconfig`出现下面内容，就OK～

![](/notes-assets/3e856d2ceaf89c1d8b0c.jpg)

2个网卡需要都处于工作状态

如果`wifiphisher`运行时，输入`ifconfig`只出现一个`wlan1`，那么需要退出`wifiphisher`，拔掉`wlan0`的网卡，重新插入电脑，再试一次。我试了3次，最终成功了。实验过程中，会遇到很多问题，我前前后后重启了20多次系统，成功不易，悄悄告诉你，实验是在虚拟机中做的，折腾不坏的。
