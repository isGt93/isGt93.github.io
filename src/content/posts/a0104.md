ailx10说：这篇是我2024年10月写的。我原来判断一个页面是不是 phpinfo，习惯先找 PHP Version 这样的关键字，直到做 ThinkPHP 实验时遇到只返回半截页面的情况：明明是 phpinfo，关键字却没了。于是我换了个思路，不盯某一句话，而是用 BeautifulSoup 看表格有多少行、两列单元格占多大比例。这篇记录的就是这个小补丁从哪来、怎么写。不过这仍是页面特征上的猜测，普通页面也可能长得像它；没有负样本和误报统计，不能因为一次命中了就当成万能检测。

---

识别 `phpinfo()` 输出时，直接搜索 `PHP Version` 可能漏掉被截断或不包含标题的页面。原文提出另一种启发式：如果 HTML 至少有 10 个表格行，并且超过一半的行各含两个 `td`，就将页面作为可疑候选。

```python
from bs4 import BeautifulSoup


def looks_like_phpinfo(html_content: str) -> bool:
    rows = BeautifulSoup(html_content, "html.parser").find_all("tr")
    if len(rows) < 10:
        return False
    two_cell_rows = sum(len(row.find_all("td")) == 2 for row in rows)
    return two_cell_rows > len(rows) / 2
```

此函数返回的是**结构候选**，不是确证。普通后台页面也可能有大量两列表格；不同版本、样式或不完整输出也可能不满足这一规则。实际检测应结合多个独立特征，对已知正样本和正常页面负样本分别测试，并记录误报与漏报。

代码需要安装 `beautifulsoup4`。原文并未提供完整测试集或误报率，因此不应将该阈值作为通用判定标准。

规则在几个样例里命中，只说明这个想法值得继续试。接下来更需要的，是找一些不像phpinfo却结构相似的页面，看它会不会认错；检测不能只用命中的样本说话。
