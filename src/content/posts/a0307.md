### 文件读取实验：记录失败及其原因

本来以为这个比较简单，我就草草写一下，过了，结果翻车了

之前是ok的，现在不灵了

- cpio Abusing

```
./cpio -o < /root/root.txt > /dev/stdout
```

![](/notes-assets/2c971c198d5fa61577be.webp)

尝试读取特权文件

原本这样是ok的，但是现在setuid失效了

- git Abusing

```
./git diff /dev/null /root/root.txt
```

![](/notes-assets/266b2ef59ff5e4ebc753.webp)

git.提权

shell 重定向会先由 shell 打开目标文件，cpio 自身的 SUID 权限不会替 shell 完成这个打开操作。

旧笔记最值得重看的地方，往往就是这种前后差异。把曾经的成功与现在的失败同时保存，能提醒自己确认条件，而不是不断修改命令直到碰巧得到输出。
