ailx10说：这篇是在2024年11月之前写的，后来又改过。我在做题时碰到一个挺反直觉的办法：拿 ZipArchive 去打开一个根本不是 ZIP 的 lock 文件，再 close，文件竟然没了。于是这篇就围着这个很小的现象做记录，先看文件在不在，再用 OVERWRITE 打开，最后对照关闭前后的状态。字数不多，但这种细节很容易过几天就忘，只记得有个“巧招”却说不清怎么来的。它毕竟是当时环境里的实验，不能因为那次删掉了，就说所有版本、任意文件和任意权限下都能得到一样的结果。

---

作者在一次实验中观察到非 ZIP 文件在 OVERWRITE 打开并关闭后消失；该现象依赖具体实现和环境，原文未记录足以泛化的版本与错误信息。

![](/notes-assets/c7b95ffa08b79812b5d4.webp)

```
<?php



$filename = './sandbox/lock.lock';

// 测试前，文件存在

if (!file_exists($filename)) {

    die("测试文件不存在，请先创建文件 $filename 

");

} else {

    echo "测试前：文件 $filename 存在

";

}



// 创建 ZipArchive 实例

$zip = new ZipArchive();



// 尝试打开文件，设置为 OVERWRITE 模式

$zip->open($filename, ZipArchive::OVERWRITE);

$zip->close();





// 检查文件是否存在

if (file_exists($filename)) {

    echo "测试后：文件 $filename 仍然存在

";

} else {

    echo "测试后：文件 $filename 已被删除

";

}

```

无用的知识，又增加了。

原环境里文件消失了，这个现象就先记在这组版本和参数之下。只有把对象类型与打开方式一起说明，读者才知道自己要验证的是哪一段行为。
