ailx10说：这篇是在2024年7月之前写的，后来又改过。做蓝队检测时遇到一段 PowerShell 通信，我想先解决一个小问题：这串文本里到底有没有 PowerShell 语句？于是把特征分成两类，强特征命中就先认，弱特征至少凑两个再判断，边列规则边拿例子跑。这篇像一份从实际输入里长出来的小检测器，不是从完整语法解析开始的。它留下的是当时怎样取舍：单个常见词太容易撞，几个特征放在一起又能多一点依据，后面再拿真实样本慢慢补。

---

原设计是命中强特征或至少两条弱特征；规则存在重复和疑似语法问题，需要补充负例、误报率与性能评估。

![](/notes-assets/6ce35a994fdaf687bd85.webp)

我的代码如下：

```
import re

# powershell强特征
strong_powershell_features = [
    r'\.\s*(Add-Type|Remove-Type)',  # PowerShell反射
    r'\.\s*(Start-Sleep|Write-Host|Write-Output)',  # PowerShell内置命令
    r'(Get-|Set-|Remove-|Invoke-|New-)',  # PowerShell命令动词
    r'-(Verbose|Debug|ErrorAction|WarningAction)',  # PowerShell参数
    r'\[(Ref|PS(Custom)?Object|Object\[\])\]',  # 类型声明，如 [Ref], [PSObject], [Object[]]
    r'\$((PS(Version|Command)|Host)\.\w+)',  # 特殊变量，如 $PSVersionTable, $Host
    r'\$ExecutionContext',  # 执行上下文
    r'\$MyInvocation',  # 调用信息
    r'\$((Script|This)Block)::',  # 脚本块或当前块
    r'\$((LASTEXITCODE|ERROR)\s*=)',  # 退出代码或错误
    r'\$((MATCHINFO|OFS|TRUETYPE)\s*=)',  # 匹配信息或输出字段分隔符或布尔值
    r'\$((PS(ScriptRoot|CommandPath)|MyInvocation)\.\w+)',  # 脚本根目录或命令路径
    r'\$((Verbose|Debug|Warning)Preference)',  # 偏好设置
    r'\$((ConfirmPreference|WhatIfPreference)\s*=)',  # 确认或假设的偏好设置
    r'\$((FormatEnumerationLimit|OFS)\s*=)',  # 枚举限制或输出字段分隔符
    r'\$((ProgressPreference|Transcript)\s*=)',  # 进度条或记录偏好设置
    r'\$((WhatIf|Confirm)\s*=)',  # WhatIf或Confirm参数
    r'\$((ShellId|HostVersion)\s*=)',  # Shell ID或Host版本
    r'\$((StackTrace|MyInvocation)\s*=)',  # 堆栈跟踪或调用信息
    r'\$((NestedPromptLevel|PSVersionTable)\s*=)',  # 嵌套提示级别或版本表
    r'\$((Culture|UICulture)\s*=)',  # 文化或UI文化
    r'\$((ExecutionContext|ReportError)\s*=)',  # 执行上下文或报告错误
    r'\$((MaximumAliasCount|MaximumDriveCount)\s*=)',  # 别名或驱动器计数限制
    r'\$((MaximumErrorCount|MaximumFunctionCount)\s*=)',  # 错误或函数计数限制
    r'\$((MaximumHistoryCount|MaximumVariableCount)\s*=)',  # 历史或变量计数限制
    r'\$((FS|(Provider)?Path)\s*=)',  # 文件系统或路径
    r'\$((OldPreference|NewPreference)\s*=)',  # 旧或新的偏好设置
    r'\$((Script:|PWD:|HOME:)\s*=)',  # 脚本或工作目录或家目录
    r'\$((Public|Private|Function)\s*=)',  # 公共、私有或函数作用域
    r'\$((Args|MyInvocation|PSBoundParameters)\s*=)',  # 参数或调用信息或绑定参数
    r'\$((Verbose|Debug|Warning|Error)\s*=)',  # 详细、调试、警告或错误级别
    r'\$((UseTransaction|PSCulture)\s*=)',  # 使用事务或文化
    r'\$((ConfirmPreference|WhatIfPreference)\s*=)',  # 确认或假设偏好设置
    r'\$((FormatEnumerationLimit|OFS)\s*=)',  # 枚举限制或输出字段分隔符
    r'\$((ProgressPreference|Transcript)\s*=)',  # 进度条或记录偏好设置
    r'\$((WhatIf|Confirm)\s*=)',  # WhatIf或Confirm参数
    r'\$((StackTrace|MyInvocation)\s*=)',  # 堆栈跟踪或调用信息
    r'\$((NestedPromptLevel|PSVersionTable)\s*=)',  # 嵌套提示级别或版本表
    r'\$((Culture|UICulture)\s*=)',  # 文化或UI文化
    r'\$((ExecutionContext|ReportError)\s*=)',  # 执行上下文或报告错误
    r'\$((MaximumAliasCount|MaximumDriveCount)\s*=)',  # 别名或驱动器计数限制
    r'\$((MaximumErrorCount|MaximumFunctionCount)\s*=)',  # 错误或函数计数限制
    r'\$((MaximumHistoryCount|MaximumVariableCount)\s*=)',  # 历史或变量计数限制
    r'\$((FS|(Provider)?Path)\s*=)',  # 文件系统或路径
    r'\$((OldPreference|NewPreference)\s*=)',  # 旧或新的偏好设置
    r'\$((Script:|PWD:|HOME:)\s*=)',  # 脚本或工作目录或家目录
    r'\$((Public|Private|Function)\s*=)',  # 公共、私有或函数作用域
    r'\$((Args|MyInvocation|PSBoundParameters)\s*=)',  # 参数或调用信息或绑定参数
    r'\$((ShellId|Host)\s*=)',  # Shell ID或Host
    r'\$((Verbose|Debug|Warning|Error)\s*=)',  # 详细、调试、警告或错误级别
    r'\$((UseTransaction|PSCulture)\s*=)',  # 使用事务或文化
    r'\[CmdletBinding\(\)\]',  # CmdletBinding属性
    r'\$((PSCmdlet|Host)\.\w+)',  # PSCmdlet或Host的方法或属性
]
# powershell弱特征
weak_powershell_features = [
    r'\;,  # PowerShell变量前缀
    r'\$env:',  # 环境变量引用
    r'\$Args',  # 参数数组
    r'Param\(',  # 参数块
    r'\$PROFILE',  # PowerShell配置文件
    r'\$((PWD|HOME)\s*=)',  # 工作目录或家目录
    r'\$ShellId',  # Shell ID
    r'\$((FORE|BACK)GROUND)',  # 前台或后台作业
    r'\$((Using|Assembly)\s*=)',  # 使用的命名空间或程序集
    r'\$((ShellId|HostVersion|Host)\s*=)',  # Shell ID或Host版本
    r'\.\s*(NET|Math|String)\.',  # 静态类调用，如 [System.Net] 或 [Math] 或 [String]
    r'Begin\(\)',  # Begin块
    r'Process\(\)',  # Process块
    r'End\(\)',  # End块
    r'Try\(\)',  # Try块
    r'Catch\(\)',  # Catch块
    r'Finally\(\)',  # Finally块
    r'ForEach\(\)',  # ForEach循环
    r'While\(\)',  # While循环
    r'Do\(\)',  # Do循环
    r'If\(\)',  # If语句
    r'ElseIf\(\)',  # ElseIf语句
    r'Else\(\)',  # Else语句
    r'Switch\(\)',  # Switch语句
    r'Break',  # Break语句
    r'Continue',  # Continue语句
    r'Return',  # Return语句
    r'Throw',  # Throw语句
    r'Exit',  # Exit语句
]

# 判断是否包含 powershell 语句
def is_powershell_script(text, min_features=2):
    matched_features = {}
    strong_feature = matched_features["strong_feature"] = []
    weak_feature = matched_features["weak_feature"] = []

    for command in strong_powershell_features:
        if re.search(command, text, re.IGNORECASE):
            strong_feature.append(command)

    for command in weak_powershell_features:
        if re.search(command, text, re.IGNORECASE):
            weak_feature.append(command)

    # 如果至少有2个弱特征匹配或者1个强特征，则认为是PowerShell脚本
    if len(weak_feature) >= min_features or strong_feature:
        return True, matched_features
    return False, matched_features

# 示例 powershell 语句
text_to_check = [
    'Get-ChildItem -Path "C:\Program Files" -Recurse | Where-Object { $_.PSIsContainer -eq $false } | ForEach-Object { Unblock-File -Path $_.FullName; Set-FileHash -Path $_.FullName -Algorithm SHA256 }',
    '$computers = Get-Content "C:\computers.txt"; foreach ($computer in $computers) { Test-Connection -ComputerName $computer -Count 4 -Quiet }',
    '$users = Get-ADUser -Filter * -Properties * | Select-Object -Property Name,EmailAddress; $users | ForEach-Object { Send-MailMessage -To $_.EmailAddress -Subject "System Update" -Body "Your system will undergo maintenance on the weekend." -From noreply@example.com -SmtpServer smtp.example.com }'
]

# 测试 powershell 检测效果
for text in text_to_check:
    is_script, features = is_powershell_script(text)
    if is_script:
        print(f"该文本是PowerShell脚本。命中的特征有：{features}")
    else:
        print(f"该文本不是PowerShell脚本，或者特征不足。命中的特征有：{features}")
```

识别出一种语言，并不等于识别出恶意。负例、组合阈值和错误写法还需要继续测，只有把误报也放进来，这份规则才不至于只在熟悉的样本上显得很聪明。
