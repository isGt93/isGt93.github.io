ailx10说：这篇是在2022年1月之前写的，后来又改过。第四天的南邮题让我在 PHP 的返回值上绕了好几圈。表面是输入检查，一层 ereg、一层 strpos，再加上数组参数，真正决定能否过去的却是这些函数遇到异常输入时返回什么、后面的判断又怎么接。我还在自己的网站上放了测试代码，想把题里的现象拆开看看。另一题则继续折腾两个不同字符串的摘要比较。这篇就是这些小测试的记录。读到最后，题目的重点已经不只是“提交什么能过去”，而是一次异常返回，究竟怎样被后面的判断接成了另一条路。

## `/x00`

需要我们提交`GET`请求 满足条件即可拿到`flag`

> ereg 是已移除的历史 PHP 正则 API，返回值及类型错误处理与运行版本有关。

原题意图限制输入格式；这里只分析原环境，不能把该过滤方式用于新代码。

> strpos() 函数查找字符串在另一字符串中第一次出现的位置

strpos 可能返回位置 0 或 false，比较时应区别类型。

![](/notes-assets/83ff7ec8815f742d6120.jpg)

在自己的网站上写了一个测试代码 如下

```
<?php

    $flag = "hackbiji.top";

    echo $_GET['nctf'];



    if (isset ($_GET['nctf'])) {

        if (@ereg ("^[1-9]+$", $_GET['nctf']) === FALSE)

            echo "no flag";

        else if (strpos ($_GET['nctf'], '#biubiubiu') !== FALSE)   

            die('Flag: '.$flag);

        else

            echo "no flag";

    }

?>

```

咱们可以直接`wget`访问页面 并将页面的返回信息保存到文件中 如下 我们拿到结果

原文以数组形式提交参数，并观察到旧环境警告及后续结果；这依赖旧版函数的错误返回语义，现代版本可能直接抛出异常。

![](/notes-assets/6e3eb6d5279249035e1b.jpg)

原作者记录数组输入在当时题目中通过判断；该结果未经当前环境复核。

## `bypass again`

另一题同样涉及摘要字符串的宽松比较，不能称为 MD5 碰撞。

`a!=b` 但是 `md5(a) == md5(b)` 自然想到`0e`

```
if (isset($_GET['a']) and isset($_GET['b'])) {

if ($_GET['a'] != $_GET['b'])

if (md5($_GET['a']) == md5($_GET['b']))

die('Flag: '.$flag);

else

print 'Wrong.';

}

```

构造请求 `?a=QNKCDZO&b=s878926199a` 直接拿到结果

![](/notes-assets/9c200bb259525ddaf2af.jpg)

记住一组能过关的字符串不难，难的是解释它为什么能过。把比较类型和异常返回放在同一条执行线上，题解才不会变成一串离开旧环境就失效的口令。
