ailx10说：这篇是我2023年12月写的。文本隐写继续往下做，就不只是找隐藏文字了。我开始围着压缩包的范围、日期提示和掩码生成候选，有时拿已知明文推恢复，有时面对短文件再看 CRC 的线索。开了第一层包，还可能遇到 Base64 图片、里面的提示和下一层编码。这篇把五题的这种层层推进留下来。它给我的复盘重点是：每次缩小搜索范围，都应该有题目线索支持，不能只把“最后用了某个字典”当成完整过程；恢复出来的文件，也得继续确认是不是下一步真正要找的东西。

这里`*`看做数字，`？`看做字符，然后遍历右边的所有可能，计算md5值是否等于左边

```
# python3
import hashlib

# 原始字符串和哈希值
str_src = list('mk?**ijnb??*7yg?')
str_md5 = '33326b6c6d763bf61129bf9b385420a5'

# 字符集合列表
str1_list = 'abcdefghijklmnopqrstuvwxyz'
str2_list = '0123456789'

def generate_combinations():
    for a in str1_list:
        for b in str2_list:
            for c in str2_list:
                for d in str1_list:
                    for e in str1_list:
                        for f in str2_list:
                            for g in str1_list:
                                yield f'mk{a}{b}{c}ijnb{d}{e}{f}7yg{g}'

# 生成器函数生成所有可能的字符串组合
combinations = generate_combinations()

# 遍历生成的字符串组合，进行哈希比较
for str_combination in combinations:
    stry_md5 = hashlib.md5(str_combination.encode()).hexdigest()
    if stry_md5 == str_md5:
        print(str_combination, stry_md5)
        break  # 找到匹配项后停止搜索
```

运行脚本，5分钟左右拿到flag


凯撒密码解密脚本如下：

```
def caesar_decrypt(ciphertext, shift):
    plaintext = ''
    for char in ciphertext:
        if char.isalpha():  # 只对字母进行解密，保持其他字符不变
            shifted = ord(char) - shift
            if char.islower():  # 对小写字母进行处理
                if shifted < ord('a'):
                    shifted += 26  # 如果超出了 'a' 的ASCII码范围，循环移动回去
            else:  # 对大写字母进行处理
                if shifted < ord('A'):
                    shifted += 26  # 如果超出了 'A' 的ASCII码范围，循环移动回去
            plaintext += chr(shifted)
        else:
            plaintext += char  # 对于非字母字符，保持不变
    return plaintext

# 密文
ciphertext = "jpek{gvg32erhgpewwmgpkssh}"

for shift in range(1,32):
    decrypted_text = caesar_decrypt(ciphertext, shift)
    print("Decrypted text:", decrypted_text)
```
