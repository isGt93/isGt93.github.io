ailx10说：这篇是我2024年12月写的。SSRF Me 一开始还得先过验证码，我按题目给的 MD5 后缀条件搜索数字候选，再往服务端请求的入口走。file 协议能读文件，但目标词又被过滤，只好继续看百分号编码经过几层解析后会变成什么。这篇把这两段连在一起，像一次先拿通行证、再拆输入处理链的小练习。这里的验证码搜索并不是做出了完整的 MD5 碰撞，编码也不是无条件的万能钥匙；每层检查和解码的先后，才是那次实验为什么会出现结果的关键。

---

本文记录一道 SSRF 题中地址访问、文件读取和编码处理的历史实验。

验证码的摘要后缀搜索属于部分原像条件，不是两个完整摘要的碰撞；编码能否通过取决于实际解码层次。

难度系数：4（官方难度：5）

![](/notes-assets/39bddce95bcec61cecc6.webp)

填写URL：`http://127.0.0.1:80/`和数字验证码 `82043`，得到下面这样的，说明是SSRF

![](/notes-assets/ceed8b23d80bd70c7c22.webp)

我们可以使用 file 协议读取系统文件`/etc/passwd`，这个地方验证码（纯数字）需要重新计算

```
import hashlib

import itertools

def find_numeric_captcha(target_end):

    charset = '0123456789'

    max_length = 8

    for length in range(1, max_length + 1):

        for captcha in itertools.product(charset, repeat=length):

            captcha_str = ''.join(captcha)

            md5_hash = hashlib.md5(captcha_str.encode()).hexdigest()

            if md5_hash.endswith(target_end):

                return captcha_str

    return None



if __name__ == "__main__":

    target_end = "b41447"

    captcha = find_numeric_captcha(target_end)

    if captcha:

        print("Found captcha:", captcha)
```
