ailx10说：这篇是在2024年1月之前写的，后来又改过。这次 RSA 题给的不是一把完整私钥，而是 p、q、dp、dq 和密文。我顺着这些碎片往回想，分别在模 p、模 q 下算出结果，再借中国剩余定理把两边拼起来。写这篇时，我把组合过程和模逆也展开了，不想最后只剩一段看不懂的脚本。它像一次把公式重新拆装的小练习：dp、dq 为什么有用，两个局部结果为什么还能还原成一个明文。能把这层关系捋顺，再看带 CRT 参数的 RSA 私钥，很多字段就不再只是名字。

---

本题已知密文以及 p、q、dp 和 dq；目标是在这些私钥组成参数已知时还原消息。

中国剩余定理CRT可以加速RSA解密过程，当RSA私钥包含了CRT参数 `dp` 和 `dq` 时，可以利用CRT来将一次模 `N` 的解密运算转换为两次模 `p` 和模 `q` 的运算，从而加速RSA解密。

![](/notes-assets/c887f239da0e4d1d0247.webp)

1、了解RSA 加密5步曲：

（1）选择两个大素数 `p` 和 `q`，计算模数 `N`：

```
N = p * q。
```

（2）计算欧拉函数 φ(N)：

```
φ(N) = (p - 1) * (q - 1)。
```

（3）选择公钥 `e`：

```
选择一个与 φ(N) 互质的指数 e，通常选择较小的质数。
```

（4）生成私钥 `d`：

```
计算 d，使得 (d * e) % φ(N) = 1。
```

（5）加密明文 `m`：

```
将明文 m 转换成整数，然后使用公钥 (e, N) 进行加密，得到密文 c。
```

2、使用私钥解密密文 `c`：

```
使用私钥 (d, N) 对密文 c 进行解密，得到原始的明文 m。
```

3、RSA 中国剩余定理解密密文`c`：

- `dp` 是私钥 `d` 对 `(mod p - 1)` 的模。换句话说，`dp = d mod (p - 1)`。
- `dq` 是私钥 `d` 对 `(mod q - 1)` 的模。换句话说，`dq = d mod (q - 1)`。

```
中国剩余定理使用私钥 (dp, dq, p, q) 对密文 c 进行解密，得到原始的明文 m。
```

以下为原题示例。代码计算并恢复的是明文整数 m，而非恢复私钥指数 d；整数转字节应处理前导零和十六进制长度。
