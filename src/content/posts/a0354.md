ailx10说：这篇是2022年1月之前写的，后来又改过。接着前一篇解码，我又把编码的方向补上：一个字节拆成高低四位，查十六进制表，空格和特殊字符按选定的策略输出。以前只关心编码后能不能发出去，自己写 C 才会想输出要分配多长、char 的符号会不会影响索引、内存该在哪里释放。笔记把这些步骤留了下来，也顺手解释了大小写转换。它不是打算取代所有 URL 库，而是想把平时看见的百分号字符串还原成几个确切动作，这样再碰到多层编码时就不容易只凭感觉猜。

---

编码规则由上下文决定；这里的空格转加号属于特定表单编码策略。

一个字节可拆成高、低两个四位值，分别转换为十六进制数字。C 的 char 是否有符号取决于实现，应使用 unsigned char 表示字节。

这是一个很现实的问题 也是一个值得思考的问题 代码如下：

```
#include <stdio.h>
unsigned char *d2x(unsigned what, unsigned char *where) {
    static const char d2x_table[] = "0123456789abcdef";
    what = what & 0xff;
    unsigned char* x = where;
    *x++ = d2x_table[what >> 4];
    *x++ = d2x_table[what & 0x0f];
    return where;
}
int main()
{
    unsigned char x[10] = {0};
    unsigned what = 255;
    unsigned char* s = d2x(what,x);
    printf("%s
",s);
}
```

在 ASCII 环境下，按位与 0xdf 可将小写英文字母转换为大写；使用前仍需确认字符是有效十六进制字符。

下面的 x2c 片段没有验证输入字符，不能直接作为健壮的解码器。

```
unsigned char x2c(unsigned char *what) {
    unsigned char digit;
    digit = (what[0] >= 'A' ? ((what[0] & 0xdf) - 'A') + 10 : (what[0] - '0'));
    digit *= 16;
    digit += (what[1] >= 'A' ? ((what[1] & 0xdf) - 'A') + 10 : (what[1] - '0'));
    return digit;
}
```

下方示例还需要检查分配长度计算溢出、分配失败，并在使用后释放内存；其编码字符集合是特定策略，不适用于所有 URL 组成部分。

```
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
unsigned char* c2x(unsigned what,unsigned char* where)
{
    static const char c2x_table[] = "0123456789abcdef";
    what = what & 0xff;
    *where++ = c2x_table[what >> 4];
    *where++ = c2x_table[what & 0x0f];
    return where;
}

char* url_enc(const char* input,unsigned int input_len,int* changed)
{
    char *rval, *d;
    unsigned int i, len;
    int count = 0;
    *changed = 0;
    len = input_len * 3 + 1;
    d = rval = (char*)malloc(len);
    if(NULL == rval)
        return NULL;

    for(i = 0;i < input_len;++i)
    {
        unsigned char c = input[i];
        if(' ' == c)
        {
             *d++ = '+';
             *changed = 1;
             ++count;
        }
        else
        {
            if((42 == c)||((c >= 48) && (c <= 57))
              ||((c >= 65) && (c <= 90))
              ||((c >= 97) && (c <= 122)))
            {
                *d++ = c;
                ++count;
            }
            else
            {
                *d++ = '%';
                ++count;
                c2x(c,(unsigned char*)d);
                d += 2;
                count += 2;
                *changed = 1;
            }
        }
    }
    *d = '\0';
    return rval;
}


int main()
{
    const char* hack = "i 520 hackbiji.top";
    int flag = 0;
    unsigned int input_len = strlen(hack);
    char* geek = url_enc(hack,input_len,&flag);
    printf("%s
",geek);
    return 0;
}
```

所以这份练习不只是把结果打印出来，还得说清它遵循哪套规则。表单里的加号和普通URL里的百分号处理不是一句“URL编码”就能全部盖住的。
