## `md5 collision`

![](/notes-assets/2b7ba92622f710dad8da.jpg)

```
$md51 = md5('QNKCDZO');

$a = @$_GET['a'];

$md52 = @md5($a);

if(isset($a)){

if ($a != 'QNKCDZO' && $md51 == $md52) {

    echo "nctf{*****************}";

} else {

    echo "false!!!";

}}

else{echo "please input a";}

```

核心是满足条件:`$a!='QNKCDZO'&&$md51==$md52`

题目使用宽松比较检查两个 MD5 摘要；这与两个输入产生完全相同的摘要（密码学碰撞）不是同一概念。

首先打印一下`a`的`md5`的值`0eXXX` 这个`0e`比较特殊

```
root@gt:~/Codes# cat 1.php 

<?php

$a = md5('QNKCDZO');

echo $a;

echo "

";

?>

root@gt:~/Codes# php 1.php 

0e830400451993494058024219903391

```

为什么说`0e`在`PHP`中比较特殊呢?我们来验证一下

很明显`a`和`b`是不相等的 但是在`PHP`中 神奇的`==` 输出`eq`

某些完全符合数字字符串形式的 0e 摘要，在特定 PHP 版本的宽松比较中可能被按数值比较；并非所有以 0e 开头的字符串都满足条件。

```
root@gt:~/Codes# cat 2.php 

<?php

$a = '0e123';

$b = '0e456';

if($a == $b)

    echo "eq

";

else

    echo "not eq

";

?>

root@gt:~/Codes# php 2.php 

eq

```

目标是寻找在指定 PHP 版本下与参考摘要宽松比较相等的完整摘要字符串，而非只检查前缀。
