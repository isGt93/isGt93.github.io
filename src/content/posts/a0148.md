ailx10说：这篇是我2024年10月写的。Bugku 刷到十一到二十题，线索开始散在更多位置：源码中的 Base64、游戏分数和签名、客户端口令、目录与弱密码，连响应里某个词的变化都可能影响下一步。我也用上 Intruder，把成功和失败的内容差别当成观察点。这篇把这些尝试按题留下，能看到我一边找入口、一边换工具的过程。它们都属于具体靶场的小机关，不是发现一个相似字段就能下结论；尤其“页面变了”之后，还得确认究竟是哪项判断真的被绕过去了。

### 12、本地管理员

![](/notes-assets/dc426ba6701a27b1c27d.webp)

使用Hackbar ，请求头添加 XFF 地址，登录依然无效，然后查看源代码，得到密码线索

![](/notes-assets/a8b9782d1bedc9f42c80.webp)

```
echo "dGVzdDEyMw==" | base64 -d
```

### 13、game1

![](/notes-assets/355055c76077d55cebed.webp)

游戏题一般就是达到一定分数或者通关，就能拿到flag，Burp 抓包看到请求规律，sign是`zM` \+ `score的base64编码` \+ `==` ，有点混淆的意思

```
GET /score.php?score=200&ip=114.221.8.187&sign=zMMjAw== HTTP/1.1

GET /score.php?score=50&ip=114.221.8.187&sign=zMNTA=== HTTP/1.1
```

![](/notes-assets/940859caf6339ffb23ad.webp)

构造一个大的score值，然后计算一下sign，Burp重放一下，就拿到flag了

![](/notes-assets/3ed68f95eb2c208424b1.webp)

### 14、源代码

![](/notes-assets/270298b5c3c516ebe057.webp)

URL解码，阅读代码：

```
function checkSubmit(){var a=document.getElementById("password");if("undefined"!=typeof a){if("67d709b2b54aa2aa648cf6e87a7114f1"==a.value)return!0;alert("Error");a.focus();return!1}}document.getElementById("levelQuest").onsubmit=checkSubmit;
```

填写 67d709b2b54aa2aa648cf6e87a7114f1 就能拿到 flag

![](/notes-assets/8d18ff65579ec7d128a1.webp)

### 15、网站被黑

![](/notes-assets/73152b8252ebdff8fcaf.webp)

没啥线索，就是web目录扫描，这里 dirb 爆破的有点慢了，得到`shell.php`

```
dirb http://114.67.175.224:18945/ -X .php
```

![](/notes-assets/83fc079f3910040669c3.webp)

随便输入一个密码，发现进不去，这里没啥技巧，又是爆破，这次上Burp，使用自带的密码列表（有3424条）

![](/notes-assets/6ca83545cf420ded7d1d.webp)

根据响应内容的长度差异，爆破出了密码（hack），在响应中找到flag

![](/notes-assets/5613361fc3acb48741a9.webp)

### 16、bp

![](/notes-assets/c0039fd0787fef574801.webp)

根据题目的提示，加载top1000字典，密码可能是以z开头的

![](/notes-assets/6b1d916a1778f38d0a75.webp)

很遗憾，响应内容的长度都一样，说明成功特征很可能在响应内容中

![](/notes-assets/d3d1669acd26de562085.webp)

因此，需要过滤响应内容，在Burp的Intruder模块下，可以设置正则提取

![](/notes-assets/7eb5a8f259867b94c4e2.webp)

失败的响应中都有`code: 'bugku10000'`，不存在这个特征的就是成功的，得到密码`zxc123`

![](/notes-assets/c2b500e33209fb3c92d6.webp)

输入密码，得到flag

![](/notes-assets/2a79fc5dbb3ce563d068.webp)
