## 第七关：考察AES解密、B64解码、凯撒密码、MD5反查

这一题比较复杂，基本上能卡死很多新手，这里的凯撒密码26个小写字母，26个大写字母，10个数字，它们都是独立进行移位操作的，如果不知道这一点，无论怎么算也算不出来的。

![](/notes-assets/a2264782e3316a0897fd.jpg)

第一步：通过python写了一个凯撒解密和base64解码得到下面4条索引

- s1:e498749f3c42246d50b15c81c101d988
- s2:7855cca1372aed929a9ae2afb1011134
- s3:ef70fa420673dcde611a56e1aaf34412
- s4:4d369630702981cadf5008bb04dec976

第二步：原文使用摘要反查寻找候选明文。反查不是哈希解密，也不等于构造哈希碰撞。

- s1:e498749f3c42246d50b15c81c101d988（**Application**）
- s2:7855cca1372aed929a9ae2afb1011134（**Pineapple**）
- s3:ef70fa420673dcde611a56e1aaf34412（**WarDriving**）
- s4:4d369630702981cadf5008bb04dec976（**Threat**）

第三步：原题在给定条件下进行 AES 解码；这不证明 AES 算法被攻破。

- s2: **Pineapple**-》**Spectre**

原记录使用外部工具尝试解码；外站当前状态和数据处理方式未经核验。

![](/notes-assets/e17ad0c98109740ecf44.jpg)

第四步：提交答案

- 提交地址：http://ec2-3-14-88-12.us-east-2.compute.amazonaws.com/level7/level7.php
- **密钥：Level7 Spectre**

```
import base64

str1 = "FZW5UJi0UCEfEfWeSpW2FJAcEpK1EfmdEfKcSCW5UJm="

num = 26



def caesar(str="123",num=1):

    l = list(str)

    i = 0

    while i < len(l):

        if l[i]>='0' and l[i]<='9':

            i = i+1

        elif l[i]>='a' and l[i] <='z':

            l[i]=chr(ord('a')+(ord(l[i])+num-ord('a'))%26)

            i =i+1

        elif l[i]>='A' and l[i] <='Z':

            l[i]=chr(ord('A')+(ord(l[i])+num-ord('A'))%26)

            i=i+1

        else:

            i =i+1

    ans = "".join(l)

    return ans





for i in range(num):

    caesar_str = caesar(str1,i)

    try:

        b64_str = base64.b64decode(caesar_str)

        if not b64_str == "":

            print("s1:"  + b64_str)

    except:

        pass
```
