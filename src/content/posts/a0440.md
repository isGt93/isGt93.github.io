ailx10说：这篇是2022年1月之前写的，后来又改过。weevely 这次先生成带口令的 PHP 代理，放到测试网站根目录，再从客户端接过去。能查看信息和继续探测，可想改页面却碰到权限不足，这个结果正好把“拿到一个 shell”和“能改所有文件”拆开了。我把失败保留在笔记里，也看了工具如何混淆生成的内容。对我来说，最值得记的不是代码看着多乱，而是进程实际以谁运行、能碰什么；那些压缩和变换不会替它创造文件权限，旧 PHP 语法还会给换环境带来新的问题。

---

本文记录 Weevely PHP 代理在旧版实验环境中的使用；先在网站中放入脚本需要已有文件写入或部署能力。

- 如果是asp网站就叫asp菜刀
- 如果是php网站就叫php菜刀
- 如果是jsp网站就叫jsp菜刀

Antak 是 ASPX 文件，Weevely 示例则针对 PHP。旧脚本语法与 PHP 版本可能不兼容。

- 通过weevely生成php网站的webshell
- 密码是`ailx10`
- webshell文件是`ailx10.php`

```
weevely generate ailx10 ./ailx10.php
```
