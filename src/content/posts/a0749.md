ailx10说：这篇是在2024年5月之前写的，后来又改过。文件的创建、访问、修改时间平时看着挺像天然记录，我试了 NewFileTime 才更直观地感到，它们也能被工具改来改去。在 Windows 11 ARM64 上，把文件拖进去，分别设成当前、过去和未来的时间，再回属性里对照，几步就能看出变化。于是这篇很短，却让我想到了调查取证里的另一层问题：时间字段看见了还得问它怎么留下来的。我没有把工具写得多神秘，就是把一次亲手改时间、再看结果的实验原样记下来。

---

```
支持：Windows 11, Windows 10, 8.1, 7, ... , Server 2012-2019, 2022, x64, x32, x86，
亲测ARM 64也是支持的
```

工具可以将选中的时间戳设为当前时间；这不一定恢复文件最初的时间。

![](/notes-assets/d7b01697d2bade183355.webp)

你可以通过属性右侧的复选框选择或取消选择三个时间戳（修改、创建、访问）中的任何一个，输入想要的确切日期/时间。

![](/notes-assets/e77bc4471880c25151c7.webp)

正确指定日期/时间后，只需单击屏幕左中部分的“设置时间”按钮即可。

![](/notes-assets/0abfa4b7a5b8dc9c46b5.webp)

按“重置”按钮即可从程序中清除文件和文件夹。

![](/notes-assets/737be05f7f3b47b79053.webp)
