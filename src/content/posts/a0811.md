ailx10说：这篇是在2023年3月之前写的，后来又改过。Wireshark 用过不少次，这章却让我从“找某个包”转向“先看整段流量”。我拿 Nmap 主机发现作例子，边扫边抓，再看会话统计、IO 图和专家信息，发现同一份数据换种视图，重点会完全不同。以前容易盯在某条请求上，统计先摊开，谁在说话、什么时候突然热闹起来，就直观多了。我把这些入口留在笔记里，像给已经熟悉的工具再添几条路，省得每次调查都只能在包列表里从头往下翻。

---

网络安全防御实战--蓝军武器库是2020年出版的，已经过去3年时间了，最近利用闲暇时间，抓紧吸收，总的来说，第7章开始学习抓包工具wireshark，如果你怀疑自己的电脑中毒了，那么用wireshark可以很轻松的找到异常通信的IP地址，然后去微步在线查一下情报，看看是不是国外的恶意IP地址，黑客一般都使用国外的代理IP隐藏自己的真实IP地址，再找出恶意IP地址对应的进程，即可找到电脑里面的恶意程序～

1、wireshark抓包

（1）先通过nmap进行端口扫描（快速扫描整个网络C段）

```
nmap -sP 192.168.0.1/24
```

![](/notes-assets/62704318fd3344a5df67.webp)

（2）原实验中的主机发现使用 ARP 请求；主机发现与端口扫描是不同步骤，具体行为取决于网络位置和扫描参数。

![](/notes-assets/97da318498a474dba400.webp)

（3）nmap对存活主机扫描过程进行抓包（实线表示属于同一个会话）

```
ip.src == 192.168.0.1/24 and ip.dst == 192.168.0.1/24 
```

![](/notes-assets/0dc4df2bf7028f536c2b.webp)

2、wireshark 分析

（1）statistics -》 conversations 统计通信主机活跃程度（数据包数量，数据包字节大小）

```
通信频率最高的ip地址 36.110.236.3，经过微步在线查询，对应的域名是 360.cn
```

![](/notes-assets/6c6467d15018eb119a3b.webp)

```
360悄悄运行在我的电脑里，并一直与国家互联网应急中心(CNCERT/CC)保持某种通信
```

![](/notes-assets/42edbe96670251dd0229.webp)

（2）statistics -》IO graphs 绘制可视化图表，可以看到总流量和360流量对比

![](/notes-assets/39a206f45446ff52077b.webp)

（3）analysis -》expert information 异常数据包统计

- chat 蓝色：普通工作流
- note 青色：一般错误
- warning 黄色：异常错误
- error 红色：严重问题

![](/notes-assets/0c1e9ef45645cde4c64e.webp)

频繁出现的IP和高等级提示都只是分析线索。把请求内容、时序和环境接回来，工具上的颜色才不会直接变成对恶意行为的判决。
