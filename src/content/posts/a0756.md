ailx10说：这篇是在2024年5月之前写的，后来又改过。SSH 高交互蜜罐跑了两周，我本来盼着看到点新鲜故事，结果最常见的却是弱口令试进去，敲一下 uname 就没下文了。既然没有大事件，索性把这一条命令拆开看看，系统名称、版本、主机名、内核和架构，每个参数都能帮访问者判断眼前是什么。于是有了这篇有点自嘲的小记录。蜜罐不是每天都有惊险剧情，许多时候就是重复而平淡的探测；把这些常见动作认熟，后面遇到多出来的一步才更容易注意到。

---

本文记录 SSH 蜜罐在认证尝试后收到的 uname 命令。一次命令只能说明信息收集行为，不能推断后续攻击目的。

```
uname -s -v -n -r -m
```

![](/notes-assets/0ec1b172d0ce78edff90.webp)

```
蜜罐网址：https://ailx10.hackbiji.top:4433/web
用户名：ailx10
密码：ailx10@hacker
```

命令解读：

uname 的 -s、-n、-r、-v、-m 分别显示内核名称、节点名、内核发行标识、内核版本与机器硬件名称；-r 不等于 Linux 发行版名称。

原文记录了一个来源 IP 的多次口令尝试和登录后的命令；来源地域是定位线索。

![](/notes-assets/a9c21c652d0f32028323.webp)

实在没啥好分析的了。

一次系统探查不是完整攻击故事，但仍值得按原样保存。内核、主机和架构信息为后续动作提供了条件，至于后面做没做，记录里没有就不替它补上。
