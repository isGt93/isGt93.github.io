## 5、15 PNG IHDR

图片高度被篡改，导致文件打不开，需要恢复文件的高度

![](/notes-assets/a9edc5df31962af80aea.webp)

使用WinHex打开

![](/notes-assets/c64a964fd041cff99f9c.webp)

将上面的值带入脚本，计算得到 height \= 00 00 02 26

```
# python3
import binascii
import struct

crc32key = 0xFE1A5AB6
for i in range(0,65535):
    height = struct.pack('>i',i)
    header = b"\x49\x48\x44\x52"
    width = b"\x00\x00\x02\x9C"
    color = b"\x08\x06\x00\x00\x00"
    data = header + width + height + color
    crc32result = binascii.crc32(data) & 0xffffffff
    if crc32result == crc32key:
        hex_height = ' '.join(f'{x:02X}' for x in height)
        print(hex_height)
        break
```

![](/notes-assets/0a58cbbf7ff025a8b9f1.webp)

通过 WinHex 直接修改图像的高度，再保存

![](/notes-assets/30f205de6fc5776276a1.webp)

再打开图像，便可以直接查看到隐藏的 flag

![](/notes-assets/bd3ab75b2f37b1bb62cb.webp)

枚举高度时，真正检验猜测的是校验关系，不是图片看起来顺眼。每个工具结果最好都能再找到一个对应依据，这样多走的一步，能让解题少靠一些运气。
