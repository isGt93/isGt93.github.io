ailx10说：这篇是2024年7月之前写的，后来又改过。接着 jSQL，我又换 SQLMap 走同一组 DVWA 页面，这回把原始 HTTP 请求存下来交给 -r。低级和中级有了结果，高级依然没检测出来，于是把成功和没走通的都记在一起。请求文件让我少手动拼一些参数，也更容易知道登录状态、提交方式究竟是什么。文章留下的是这次工具与页面的配合，不是给高级题下了“永远扫不出”的结论；没结果时，回头看业务流程和输入怎么到数据库，往往比立刻换一个更大参数更有用。

---

低、中级测试在原环境中报告成功，高级测试未检测到漏洞。工具检测到问题与实际利用成功并不总是同一回事。

（1）低级设置：原文报告测试成功。

```
sqlmap -r low.txt
```

```
sqlmap -r medium.txt
```

（3）高级设置：原文报告未检测到漏洞；由于缺少源码和状态流程分析，不能泛化为工具无法检测该级别。

```
sqlmap -r high.txt
```

低级和中级跑通了，高级没有检出，记录就停在这个事实上。它还不是对工具能力的最终评价，下一步该回到高级页面的状态流程和代码，而不是只把参数再堆一遍。
