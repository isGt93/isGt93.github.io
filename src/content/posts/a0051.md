ailx10说：这篇是在2022年1月之前写的，后来又改过。那阵子我主要用 Mac 做实验，虚拟机装了一堆，磁盘空间眼看就不够；另一边，一台台式机却放着吃灰。于是没有急着拆机器扩容，而是先把 Windows 10 的远程桌面配好，让 Mac 直接连过去用那台电脑的资源。主机、账号、声音在哪边播放，看起来都是小设置，用顺以后却真能省掉来回换设备的麻烦。这篇记录的就是这个生活里的小办法。说是给 Mac“赋能”，实际上借用的是另一台电脑的运行和存储能力，并不是凭空增加了本机内存。

---

远程桌面可以让 Mac 用户操作另一台 Windows 计算机。远程访问使用的是对方机器的计算资源和存储空间，并不会增加 Mac 本机的内存或磁盘容量。

## 连接前准备

确认目标 Windows 版本支持作为远程桌面主机，主机已开启远程桌面，账户具有登录权限，两台设备之间的网络可以连通。实际设置名称因系统版本而异。

## 建立连接

1. 在 Windows 电脑的系统设置中启用远程桌面，确认计算机名或 IP 地址以及允许登录的账户。
2. 在 Mac 上安装受支持的远程桌面客户端，创建连接并填写主机名或 IP 地址。
3. 使用被授权账户登录，核对证书提示后连接。
4. 需要声音时，在客户端检查音频播放位置：若要从 Mac 扬声器播放，选择在本地设备播放；若要从 Windows 主机输出，则选择远程设备。选项名称以客户端界面为准。

## 安全注意事项

使用强密码及适当的账户权限，按需限制可访问来源；避免将远程桌面端口直接暴露到公网。跨网络访问可使用组织批准的安全接入方式。出现连接或音频问题时，分别检查网络、账户权限、远程桌面设置及客户端音频选项。

连接成功只是开始，能否稳定使用还得看主机状态、网络和权限。把这些小设置记下来，下次重新接入时就不必凭记忆把所有选项再试一轮。
