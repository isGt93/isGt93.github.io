## 客户端

输入服务端的IP地址，然后启动

![](/notes-assets/fa6eddbfb9de8d65a9a6.webp)

结果，我的EDR管理平台上，并没有agent上线，气死我啦，为什么呢，明明按照教程一步一步走的啊？

尝试一下centos 7 安装agent，命令如下：

```
sudo WAZUH_MANAGER='localhost' WAZUH_AGENT_GROUP='default' yum install https://packages.wazuh.com/4.x/yum/wazuh-agent-4.2.5-1.x86_64.rpm
```

启动agent，命令如下：

```
sudo systemctl daemon-reload
sudo systemctl enable wazuh-agent
sudo systemctl start wazuh-agent
```

还是没有agent上线，唉，失败是成功之母\~

![](/notes-assets/087c5c6ab4c0bcbfc075.webp)

部分上线以后页面又空了，说明链路还没稳定。保留每轮日志和手动改动，下一次才能分清是数据没来、权限不对，还是展示层出了问题。
