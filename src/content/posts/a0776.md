ailx10说：这篇是在2026年1月之前写的，后来又改过。这次换个视角，不是给靶机发载荷，而是拿一份蓝队题目，站在服务器已经出事之后找线索。题面里小李看到 CPU 飙升就关机，我要做的是从系统和日志里把过程拼回来：近期 PHP、Web 访问、PowerShell 隐藏账号，再逆向打包程序找矿池。故事背景是题目给的，我的任务是一项项把答案落到文件和记录上。写这篇时，最有意思的就是碎片彼此接上的瞬间，一处看着不起眼的路径，可能正好解释另一边的异常。

---

1.攻击者的shell密码  
2.攻击者的IP地址  
3.攻击者的隐藏账户名称  
4.攻击者挖矿程序的矿池域名(仅域名)  
5.有实力的可以尝试着修复漏洞

最近玩了一下调查取证，感觉有点意思，简单记录一下我的过程，完整过程稍后同步在黑客笔记。

---

列出最近修改的 .php 文件，发现可疑文件 `shell.php` ，这是一个 典型的加密 Webshell（冰蝎 Behinder 的 PHP 服务端），默认连接密码是 `rebeyond`，它的通信密钥是 `md5("rebeyond")` 的前 16 位。

你可以通过 Web 服务器访问日志 找到谁访问过 `/shell.php`，发现日志中所有对 `/shell.php` 的请求都来自：`192.168.126.1` 。

`net user` 显示4个账号，这些都是 Windows Server 2022 的默认系统账户，没有额外用户！查看所有本地用户（PowerShell 更全），在 Windows 中，以 `$` 结尾的用户账户会被系统视为“隐藏”，不会出现在登录屏幕或普通用户列表中，但依然可以通过命令行或远程桌面登录（如果权限足够）。

```
Get-LocalUser | Select Name, Enabled, Description
```

找到了！隐藏账户就是：`hack168$`

因为小李已经关机，所以挖矿进程已经终止。既然进程没了，我们就不能靠 `netstat` 或任务管理器。 必须通过“痕迹取证”来找挖矿程序留下的线索！

打开 Everything，搜索关键词：`.exe` \+ 按“修改时间”排序（找 2024-02-26 前后），找到文件名 `Kuang.exe`（“矿”的拼音，明显是挖矿程序），修改时间应为 2024-02-26 左右（与 Webshell 活动时间一致）。

`Kuang.exe` 是一个 Python 程序，通过 PyInstaller 打包成 Windows 可执行文件，这里可以逆向分析，使用 `pyinstxtractor.py` 提取资源，使用 uncompyle6 反编译 `.pyc`，得到源代码，得到矿池域名。
