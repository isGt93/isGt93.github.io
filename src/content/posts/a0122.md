ailx10说：这篇是在2022年1月之前写的，后来又改过。这篇写的是我做完一轮基础题后，给自己留的一次小结。那一段学习持续了七十六天，六个方向加起来完成六十九道题，报告也陆续整理完了。我把各类题用到的知识和自己实际花掉的时间列出来，一方面回头看看走过哪段路，另一方面准备往进阶题继续走。这里没有一夜开窍的故事，更多是把一题题做下去，再把零散笔记攒成体系。它也提醒我：总题数只是一个记号，真正留下来的，还得是自己能重新讲明白的那些过程。

---

我用了约 76 天，完成了 69 道入门题。

| 方向 | 主要观察点 |
| --- | --- |
| Web | HTTP 请求、客户端与服务端逻辑、常见漏洞及代码审计 |
| Crypto | 编码、古典密码、基础数论和公开密钥密码的题目参数 |
| Misc | 文件格式、图片、数据编码和流量分析 |
| Reverse | 程序结构、静态分析、调试和输入校验 |
| Pwn | 栈布局、内存错误、系统保护机制与程序行为 |
| Mobile | 应用包、Java 与 native 代码、配置和本地数据 |

练习时先记录目标、环境与题目附件，再将观察、假设、验证步骤和结果分开。卡住时回看基础知识，并保留失败路径和未解决的问题；有结果不代表已经理解每一步。

各类历史题解可能包含旧环境和截图，原记录的题目数与部分文章标题并不完全一致，统计不应视为当前题库清单。

这个小结不是给自己宣布学成，而是给前一段路做个记号。把能讲清的内容留下，把还会卡住的地方带进进阶，学习才不会在完成数量之后突然断掉。
