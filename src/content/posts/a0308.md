### Docker Abusing Challenge[\[1\]](#ref_1)

本次实验在有权限访问高权限 Docker daemon 的前提下进行。挂载宿主文件系统可能带来宿主级风险；不能将这一结果推广到所有 Docker 安装或 rootless 配置。

```
docker run -v /etc/:/mnt -it alpine
```

```
docker run -v /:/mnt --rm -it alpine chroot /mnt sh
```

今年国庆节回家了，路上有点堵车，好在加满了油，带足了水和干粮，开了3个半小时，小城市的生活节奏还是要慢很多，挣不到什么钱，也落的清净，小城镇的青年人很少，基本上都是40、50岁以上的，过着养老的生活，躺平了，就这样过一生了吧～

大城市的生活节奏很快，早上起的很早，晚上回来很晚，早上有早高峰，堵，晚上有晚高峰，堵，一天24小时，在路上就干掉2小时，以前就干开车，后来听着音乐开车，不敢开窗户，外面尾气很大，空气不好，现在大环境越来越卷，要提前适应苦日子～

最近忙活docker，发现非常简单，距离上次玩docker已经过去近3年了吧，之前我们的AI就放在docker里面，然后内存泄漏，定位了好久，最终被我发现了，程序写了一个死循环，然后定时任务执行AI检测线程，在DGA的初始化过程中，发现加载模型，最后内存泄漏～

现在我也时常想着做一个docker靶场，把一些我做过的实验放在里面，供大家玩耍，但是又担心被大家root到权限，给玩坏了，所有想着用docker做一个定时重置实验环境的靶场，终究还是没有做，一方面是暂时没有那个精力，另一方面是自己实力不允许～
