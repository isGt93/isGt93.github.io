使用长度、链接和攻击字符词计数构成六维特征，用SVC进行报文三分类，保存模型并展示混淆矩阵与少量推理计时。

## 前提和待核查点

约98%属于给定划分；三个样本计时不足以推出生产吞吐，需查看分类型漏检与数据重复。

## 历史实验记录与代码

## 解决的问题：

早上定位到循环神经网络的高阶API预测函数在Nginx中无法正常工作，当时第一反应是要不用低阶TensorFlow重写一个分发器，但是那块API真心要花些时间的，敏捷开发是不会给你那么多时间的。中午一觉醒来，决定用SVM试试多分类，找了大量的博客，写得都不明不白，还是亲自实战一下，才发现是如此友善，于是一个基于SVM的攻击报文多分类器就出来了。

## 代码结构：

```
├── data

```

## 运行结果：

性能：一次分类3个样本，一个样本平均60us。

原实验在给定划分上报告约 98% 的准确率；3×3 混淆矩阵应逐类查看漏检和误报，少量预测耗时不能代表生产吞吐。

```
metrics.confusion_matrix:

[[3925    5   87] 

 [  10 6425    5]

 [ 159    7 3838]]
```

在我自己写的测试函数上，几个样本都预测成功了，依据`metrics.confusion_matrix`数据，可以很快写一个代替循环神经网络的攻击载荷分发器程序，把核函数换成径向基函数`rbf`准确率还会上升一个百分点。

## 完整代码：

```
# waf.py by ailx10

import re

import numpy as np

import urllib

from sklearn import cross_validation

from sklearn import datasets

from sklearn import svm

from sklearn.externals import  joblib

from sklearn.metrics import classification_report

from sklearn import metrics

import time



def get_len(url):

    return len(url)



def get_url_count(url):

    if re.search('(http://)|(https://)', url, re.IGNORECASE) :

        return 1

    else:

        return 0



def get_xss_evil_char(url):

    return len(re.findall("[<>,\'\"/]", url, re.IGNORECASE))



def get_xss_evil_word(url):

    return len(re.findall("(alert)|(script=)(%3c)|(%3e)|(%20)|(onerror)|(onload)|(eval)|(src=)|(prompt)",url,re.IGNORECASE))



def get_sql_evil_char(url):

        return len(re.findall("[-,\'\"*/]", url, re.IGNORECASE))



def get_sql_evil_word(url):

    return len(re.findall("(SELECT)|(CASE)|(WHEN)|(ORDER)|(GROUP)|(count)|(%2C%20)|(char)|(NULL)|(AND)",url,re.IGNORECASE))





def do_metrics(y_test,y_pred):

    print "metrics.accuracy_score:"

    print metrics.accuracy_score(y_test, y_pred)

    print "metrics.confusion_matrix:"

    print metrics.confusion_matrix(y_test, y_pred)

    print "metrics.recall_score:"

    print metrics.recall_score(y_test, y_pred,average=None)

    print("saved!")



def get_feature(filename,x,y,atk_index):

        with open(filename) as f:

            for line in f:

                line = line.strip('

')

                line = urllib.unquote(line)

                f1=get_len(line)

                f2=get_url_count(line)

                f3=get_xss_evil_char(line)

                f4=get_xss_evil_word(line)

                f5=get_sql_evil_char(line)

                f6=get_sql_evil_word(line)

                x.append([f1,f2,f3,f4,f5,f6])

                y.append(atk_index)



def get_pkt_feature(pkts):

    x = []

    for pkt in pkts:

        pkt = urllib.unquote(pkt)

        f1=get_len(pkt)

        f2=get_url_count(pkt)

        f3=get_xss_evil_char(pkt)

        f4=get_xss_evil_word(pkt)

        f5=get_sql_evil_char(pkt)

        f6=get_sql_evil_word(pkt)

        x.append([f1,f2,f3,f4,f5,f6])

    return x





def train():

    x = []

    y = []

    get_feature('./data/sql-10000.txt',x,y,2)

    get_feature('./data/xss-200000.txt',x,y,1)

    get_feature('./data/good-xss-10000.txt',x,y,0)



    x_train, x_test, y_train, y_test = cross_validation.train_test_split(x,y, test_size=0.4, random_state=0)

    clf = svm.SVC(kernel='linear').fit(x_train, y_train)



    y_pred = clf.predict(x_test)

    joblib.dump(clf,"./model/waf.pkl")

    do_metrics(y_test, y_pred)



def waf_load():

    clf=joblib.load("./model/waf.pkl")

    return clf





def test(clf):

    x1 = "i love web security!"

    x2 = "<script>alert(1)</script>"

    x3 = "-2' union select group_concat(Username),2,3 from Person"

    x = [x1,x2,x3]

    x = get_pkt_feature(x)

    y = clf.predict(x)

    #print(y)





if __name__ == "__main__":

    #train()

    clf = waf_load()

    num = 0

    o1 = time.clock()

    while(num < 1000):

        test(clf)

        num += 1

    o2 = time.clock()

    print(o2 - o1)
```

保存模型与几次计时让它更像一个可调用组件，但生产吞吐还要另外测。把每类错误和独立输入留好，后面就能同时比较识别效果与工程成本。
